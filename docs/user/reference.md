## 文件夹和文件名

在设置里登记的是总文件夹，第一层子文件夹就是作品，作品里面怎么分子目录都行：

```
otomad素材/                         ← 原素材文件夹
├── ゆるゆり/                        ← 作品
│   ├── [VCB-Studio] Yuru Yuri [01].mkv
│   └── [VCB-Studio] Yuru Yuri [01].srt
├── Blue Archive/                    ← 作品（游戏）
│   └── ホシノ/
│       ├── hoshino_001.wav
│       ├── hoshino_001.srt
│       └── hoshino_001.png          ← 同名图片会绑定为画面
└── Drum Kit A/                      ← 作品（音效包）
    └── kick_01.wav
```

| 内容 | 规则 |
|---|---|
| 作品 | 第一层子文件夹名；直接放在总文件夹下的归“未指定作品” |
| 素材标识 | 从文件名推断，`[字幕组] 作品 [01]`、`作品 - 01`、`作品 第01話` 都能认出 `01`；认不出时用文件名。规则在设置 → 原素材 |
| 字幕 | 同名的 `.srt` 优先，其次 `.ass`；也认 `视频名.ja.srt` 和 `Subs`、`字幕` 这类子文件夹。只关联，导入要你点一下 |
| 画面 | 与音频同名的视频、动图或图片会自动绑定，可以在「作品设置…」里关掉 |

每次启动和重新扫描时，应用会登记新文件，并给还没关联的原素材补上字幕。你手动选过或清空过字幕的原素材不会被改。

在文件管理器里移动或改名文件后重新扫描，应用会认出是同一个文件。

## 字幕写法

要做语音分析，就需要 UTF-8 的 SRT，每行写实际说出来的日语。推荐的写法只有一种：一条字幕一个人，每个台词行开头写说话人。

```
1
00:00:01,000 --> 00:00:03,000
（京子）こんにちは

2
00:00:03,500 --> 00:00:04,000
（足音）

3
00:00:05,000 --> 00:00:06,000
（京子、結衣）ありがとう
```

| 你写的 | 应用读成 |
|---|---|
| `（京子）こんにちは` | 京子说的台词 |
| `（京子、結衣）ありがとう` | 两个人同时说 |
| `こんにちは` | 不知道是谁说的台词 |
| `（足音）`（整行只有括号） | 音效提示 |
| `歳納(としのう)京子` | 台词「歳納京子」，中间的括号只会去掉 |
| `♪～` 开头、`～♪` 结尾 | OP / ED 标记，批量建采样和批量分析会跳过 |

还要注意这些：

- 一条里有一行没标说话人，这一条就不记说话人。台本里会提示“原字幕有标注但没记”。
- 只有括号的行，如果下一行是没标注的台词，应用两样都不认，因为分不清它是音效还是名字。
- 哼歌不要写成 `♪（ハミング）`。写成音效行 `（ハミング）`，或者写出歌词。
- 一条字幕不能超过 120 秒。更长的音乐或音效要拆成几条，否则预览会标为无效。
- 双语字幕要删掉中文行，并删掉注音、译注和说明文字。

规则可以在设置 → 字幕里改，也可以试算一行怎么读。

## 界面

| 位置 | 内容 |
|---|---|
| 左侧导航 | 采样库、原素材；下面是任务和设置 |
| 顶栏 | 采样库的用途切换、全局 BPM、命令与跳转、撤销、操作历史、⋯（管理标签、主题、快捷键） |
| 采样库 | 左边是列表，右边是详情区：画面、波形、语音、节奏、资料与标签 |
| 原素材页 | 左边是按作品分组的列表，右边是画面、时间线和台本 |
| 底部播放条 | 正在放什么、哪个版本；最近导出的文件也在这里，可以直接拖进 DAW |
| 命令面板 | 对当前对象能做的事，和右键菜单一样；输入 `180` 回车就是把 BPM 设为 180 |

时间线波形卡右上的「频谱 ▾」可以切到对数、线性或 Mel 频谱（视口 30 秒以内）。

列表第二行随性质变化：语音显示节奏小图和音块数，调谐单音显示音名和音高曲线，非调谐单音显示起音时间和包络。

## 设置

每次修改都可以撤销，只作用于之后的操作。

| 组 | 内容 |
|---|---|
| 通用 | 界面语言等 |
| 推理设备 | ONNX 硬件加速：Windows 用 DirectML，macOS 用 CoreML；默认 CPU |
| 原素材 | 原素材文件夹，作品与素材标识的推断规则 |
| 字幕 | 说话人和音效的识别规则，可以试算 |
| 文本前端 | 用户辞典：每行 `表记<Tab>読み`，可以预览一句看结果 |

| 拉平 | 拉平的默认选项 |
| 导出 | REAPER 交接的默认方式；视频格式（H.264 MP4 + AAC 或 ProRes 422 HQ） |

| 任务 | 并发数 |
| 存储与缓存 | 按类别列出占用和可清理量 |
| 环境与模型 | 模型状态、检测和导入 |

## 检索条件

三种检索都在采样里搜。音高检索还可以直接搜整条音轨。

| 检索 | 条件 |
|---|---|
| 节奏检索（语音） | 一串音块，每块可以写辅音、元音、相对音高和响度，并画出时值。节奏策略：不限节奏、必须满足节奏、按相似度排序。首尾：任意位置、从句首、到句末、句首与句末。有 BPM 时按 BPM 比较，否则比归一化的节奏形状 |
| 音高检索 | 几个音高块，每块有时长和音名或范围；可以忽略八度 |
| 单音 · 音色 / 瞬态 | 有效声音时长、起音上升时间、谱质心、噪声倾向等指标的范围。这项是实验功能，效果可能很差，指标口径也可能调整 |

## 标签表达式

优先级是 `NOT` > `AND` > `OR`。可以用括号和双引号，`命名空间:*` 匹配整个命名空间。写错时输入框标红，并提示第几个字符出错。

```
character:京子 AND NOT topic:game
(topic:game OR topic:food) AND character:*
```

范围行里，同一分面内是“或”，不同分面之间是“且”。

## 采样名称的建议

| 选区 | 建议的名称 |
|---|---|
| 完整盖住一句或几句 | 这几句台词，多句用“ / ”连接 |
| 只盖住一句的一部分 | 选中部分（这句），如 `ニュウ（入部希望です）` |
| 只选到半拍 | 用罗马字，如 `b（入部希望です）` |
| 跨两句各选一部分 | 如 `ですイk（入部希望です / 行くよ）` |
| 没有台词 | 原素材名 起–止 |

部分选中的名称要求这些句子已经做过语音分析。名称随时可以改。

## 数据在哪

都在工作区里：

| 文件夹 | 内容 |
|---|---|
| `Library/` | 生成的音轨、导出的 WAV 和视频、REAPER 文件，可以在文件管理器里使用 |
| `Models/` | 模型 |
| `Agent/` | 你的 agent 约定（`playbook.md`）和 skill（`skills/`），可以直接改 |
| `Data/` | 数据库与缓存，不要手动改 |
