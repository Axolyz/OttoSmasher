# 概念

## 基本对象

| 词 | 意思 |
|---|---|
| 工作区 | 你的全部数据所在的文件夹：数据库、生成的音轨与导出、模型。程序目录只读，更新应用不动工作区 |
| 原素材 | 你登记的原始文件，比如一集番剧或一个音效。应用只记下位置，不复制、不转码 |
| 作品、素材标识 | 原素材按作品分组。素材标识在作品里区分和排序原素材，比如集数或编号 |
| 音轨（资产） | 原素材里的一条声音：原混音、分离出的人声或音效、拉平或回导的成品。每个角色（人声、音效）可以指定一条默认轨 |
| 台词段 | 原素材上谁在什么时候说了什么，一般来自字幕。语音分析靠它知道要对齐哪段文字 |
| 音效提示、区段标签 | 原素材上的时间标注：哪里有个音效，哪一段属于谁或什么场景。采样会继承它覆盖到的区段标签 |
| 采样 | 从原素材上切下来、能直接使用的一段，绑定在某条音轨的某个区间上，有名称、性质、标签和星标 |
| 性质 | 采样的用途：语音、调谐单音（有明确音高）、非调谐单音（打击、音效）、未分类 |
| 任务 | 耗时的操作，比如分析、分离、拉平和导出视频。它们在后台排队，你可以在任务抽屉里查看、取消或重试 |

## 三层各管一件事

- 原素材和台词段记事实：哪里说了什么、谁说的。
- 采样是能试听、拖出、导出、卡拍和检索的单位。把整集台词都建成采样很正常，建成采样只表示它能用。
- 星标、标签和筛选器记你的取舍，可以随时改，也可以有好几个维度。

检索和整理只针对采样。想在原料里找一句话在哪，用原素材页的台词搜索。

## 采样不复制声音

采样只记“哪条音轨的哪个区间”，导出时才生成文件。所以建采样很快，也不占多少空间。

采样之间没有父子关系。从一个采样里再截取、拉平或回导出来的新采样，和它只是相关采样。“资料与来源”里的加工链会写明声音是怎么一步步做出来的，比如拉平成品 ← 人声 ← 原混音。

## 语音分析

语音分析做两件事：

1. 文本前端把台词转成音素和读音。它用 pyopenjtalk-plus，多音字由 tsqyomi 预测，再套用你的用户辞典。
2. 对齐用 pydomino 找出每个音素在音频里的时间。

一句台词的音素只有一份，属于原素材的时间线。原混音、分离出的人声和拉平成品都读这一份，所以同一句只需要分析一次，修一次音素时间，处处生效。回导成品是例外：外面改过的声音时间可能变了，要单独分析。

只盖住半句的音轨不能拿来分析，但可以读到它盖得住的那几个音。不含人声的音轨不读音素，也不能分析。

音块、停顿和语段是现算的，所以调灵敏度、切分语段都不用重新分析。

对齐只用 pydomino 一个模型，失败时不会换模型重试。

## 音高什么时候测

音高（FCPE 模型）是音高检索、单音指标、拉平和相对音高的基础。它按音轨保存，测过的部分所有功能共用，除非文件或模型变了，否则不会重测。空间很小，每小时音频约 4 MB。

| 什么时候 | 测哪里 |
|---|---|
| 后台自动（默认开，设置 → 语音分析「自动准备检索」） | 每个采样的范围，以及每个原素材的默认人声轨；排在你提交的任务后面 |
| 语音分析 | 分析的台词段覆盖到、还没测过的部分 |
| 检索浮层「准备当前范围索引」 | 关掉自动时手动测当前范围 |
| 单音指标「后台准备当前范围指标」 | 当前范围里缺指标的采样 |
| 拉平 | 这次要拉平的选区和成品 |

没有音高不等于静音。节奏和停顿按能量判断，不看音高。

## 卡拍

节奏面板把每个元音或拨音算作一个音块。卡拍时每块的起音核心逐样本保留，只用 Rubber Band R3 保音高伸缩中间的部分。

BPM 在顶栏，全局一个。留空就是保持原语速的卡拍。

## 撤销和删除

资料修改都可以撤销。删除原素材、全局改名这类操作执行前会先给你看影响范围。

磁盘上的原始文件和你导出过的文件，应用永远不会删。
