## 准备素材

应用按文件夹认作品，按同名文件认字幕和画面，按字幕的写法认台词、说话人和音效。素材越规整，后面越省事。

1. 按[文件夹规则](reference.md#文件夹和文件名)整理文件。
2. 把字幕改成和视频同名、编码为 UTF-8 的 SRT。
3. 按[字幕写法](reference.md#字幕写法)清理内容。

字幕还没整理过的话，先看[预处理字幕](#预处理字幕)。

## 预处理字幕

字幕是台词采样和语音分析的基础。播放器里看着正常的字幕，未必适合直接建库：译文、注音和说明文字可能混进台词，时间可能属于另一个片源或者没有对齐，一条字幕也可能包含两个人先后说的话。这些问题会影响采样边界、人物标签、音素对齐，以及后面的卡拍和节奏检索。

预处理就是把字幕整理成适合目标片源的台词：文字对应实际说出的内容，时间贴合语音，先后换人的条目按需要拆开，并补上说话人。最后每个视频得到一份同名的 UTF-8 SRT，放在视频旁边，再导入 Otto。具体写法见[字幕写法](reference.md#字幕写法)。

下载的双语字幕、CC 字幕、其他版本的字幕，以及机器转写的字幕，都适合先做这一步，尤其是在整季批量建采样之前。已经处理好、与片源一致的字幕可以直接用。原素材可以先登记、分离人声，供预处理使用；整理好字幕后再正式导入、建采样和分析。

这类工作需要结合文字和声音判断，内置的 `preparing-subtitles` skill 就是为此准备的。按[字幕预处理的任务提示](agents.md#按方法论预处理字幕)告诉 agent 素材位置、正确字幕源、目标片源和处理精度即可，具体方法由 skill 引导。完成后可以试听几处台词，确认起止和说话人，并查看 agent 留下的待确认项。

## 登记原素材

用文件夹登记：

1. 打开设置 → 原素材，点「添加原素材文件夹…」，选择总文件夹。
2. 等后台扫描完成。

之后每次启动都会再扫一次。你也可以在原素材页列表顶部点「重新扫描原素材文件夹」。

也可以点原素材页列表顶部的「导入」，或者把文件、文件夹拖进原素材页或采样库，再在导入框里统一设置作品或按文件名推断。点「导入」时会先问你选文件还是文件夹。推荐导入整理好的文件夹，同名字幕和画面会自动关联。

两种方式的区别：在设置里登记的原素材文件夹会自动分作品，每次启动都会发现新文件；直接导入的作品要自己指定，文件挪动后要手动重新定位。

要改单个原素材的作品、素材标识、音频流或字幕，打开「作品与输入设置…」。文件夹里的作品跟着文件夹走，要改名就用作品的「作品设置…」，磁盘上的文件夹会一起改名。

## 边看边建采样

适合一边看一边挑好用的句子。需要同名字幕。

1. 在原素材页打开一集，选 ⋯ →「导入字幕…」，看过预览后导入。
2. 选「整片分离…」，选择 `bs_roformer_voc_hyperacev2` 分离，完成后在「人声 / 音效与默认轨…」的下拉框里把分离出的人声设为默认人声轨。默认轨只影响之后建的采样，所以要先设好。素材本来就是干声时可以不分离，勾选原混音的“人声”并设为默认人声轨；背景不干净的素材不分离的话，语音分析基本不能用。
3. 播放。单击台本的一行可以跳到这句。
4. 听到好的，在台本行或画面上的字幕上右键，选「从这段建采样…」。
5. 看完一集，到采样库勾选这些采样，右键选「语音分析…」。

字幕没覆盖到的声音，在时间线上拖选后点「截取」。音效可以切到“音效提示”层，右键选「从这条提示建采样…」。

要找一句话：在台本顶上的搜索框（⌘⇧F 或 /）搜这一集，文字和读音都能搜；在原素材列表的搜索框（⌘F）搜全部原素材的台词。这里只搜已导入的文本层，采样库的搜索只搜已建好的采样。

## 批量建采样并检索

适合把一整季的台词做成采样，之后按节奏或音高找。先完成[字幕预处理](#预处理字幕)，准备好同名字幕，并装好 PyMSS Studio 和 HyperACE v2。

1. 在原素材页右键作品组，选「给整组 n 个原素材导入字幕标记…」。
2. 右键作品组，选「整片分离（n 个）…」。全部完成后，再选「把分离出的人声设为默认人声轨（n 个）…」。
   素材本来就是干声时可以不分离，选「把原混音设为人声与默认人声轨（n 个）」。背景不干净的素材不分离的话，语音分析基本不能用。
3. 右键作品组，选「从台词段批量建采样…」，全选后点「创建 n 项」。OP / ED 里的会跳过；没设默认人声轨的集不会列出来。
4. 点作品组的「勾选整组」，右键选「语音分析…」。确认框会写明分析几段、跳过几段。
5. 分析完成后，后台会自动准备检索。到采样库点「节奏检索」，画几个音块后点「查找」。

## 处理没有字幕的视频

没有台词文本就做不了语音分析，但截取、分离、拉平、音高检索和导出都能用。

有办法转写的话，用语音识别生成同名 SRT，让 agent 清理后按上面的步骤做。机器转写有错字，重要的句子要记得手改。

没有 SRT 的话，可以选下面任一种：

- 在时间线上选区后右键「添加台词…（当前选区）」，逐句输入，之后照常分析。
- 只当声音素材用：选区后「截取」「分离」「拉平」；或者用音高检索的“已分析原素材音轨”模式在整条音轨上找音。

## 导入音效包和乐器单音

1. 按包分成作品文件夹，并把文件名改成你想要的采样名。建议按用途分子文件夹，方便分批设性质。
2. 登记文件夹。
3. 右键作品组，选「为整组 n 个原素材建立全长采样…」，选性质：打击和音效选非调谐单音，有明确音高的选调谐单音。同一作品里性质不同时，先勾选一部分，再选「为所选 n 个原素材建立全长采样…」，分几批做。
4. 到采样库，在顶栏切换用途。调谐单音用「音高检索」按音名找；非调谐单音用「瞬态筛选」「音色筛选」（实验功能，效果可能很差）。

## 导入游戏语音和立绘

这一步的预处理工作量大，最适合交给 agent。

1. 把语音文件放到 `<总文件夹>/<游戏名>/<角色或分类>/`。
2. 给每个语音文件放一个同名 `.srt`，只有一条，时间从 0 到文件时长：
   ```
   1
   00:00:00,000 --> 00:00:02,350
   （ホシノ）うへ～、おじさん眠くなってきちゃった
   ```
   结束时间不能超过文件时长。
3. 给每个语音文件放一张同名图片，同一角色的立绘复制成多份即可。
4. 登记文件夹。
5. 右键作品组，依次选：
   - 「给整组 n 个原素材导入字幕标记…」
   - 「把原混音设为人声与默认人声轨（n 个）」
   - 「为整组 n 个原素材建立全长采样…」，性质选语音
6. 点「勾选整组」，选「语音分析…」。

之后可以按人物筛选、按节奏检索，详情区会显示立绘。

## 编辑台词

原素材页时间线上方的音源下拉框可切换音轨，播放进度、播放／暂停状态、时间线缩放和选区会保留。

- 改文字、边界或说话人：直接编辑台词段。改文字或边界后，这段要重新分析。
- 标片头片尾：「从字幕识别 OP/ED」或「OP/ED…」。
- 改了说话人规则后：「按当前规则重新生成说话人」，手改过的段不动。
- 从头重新导入：「删除导入的字幕标记…」。手输的段不删，改过的段默认留下，可以撤销。时间和文字都没变的段重新导入时不会更新说话人，所以要先删再导入。
- 给一段时间打标签：时间线上右键「新增区段标签…（当前选区）」。落在里面的采样会继承。

## 截取采样

| 方式 | 操作 |
|---|---|
| 手动 | 时间线上框选，点「截取」，填写名称、性质和可选的本地标签后保存。标签每行一个 |
| 逐句 | 台本行或画面字幕上右键「从这段建采样…」 |
| 音效 | 音效提示上右键「从这条提示建采样…」 |
| 批量 | 「从台词段批量建采样…」「从音效提示批量建采样…」 |
| 整个文件 | 「建立全长采样…」 |

从台词段批量建采样要先有默认人声轨，应用不会自动用原混音。

## 整理采样

采样库里是全部采样，包括还没听过的。

1. 把好用的按 S 打星，或者加标签，例如 `#好用`。
2. 用查找栏搜名称、备注、台词原文和读音，或者写[标签表达式](reference.md#标签表达式)。搜索名称和备注时，合成或分开写的假名与浊点都能匹配。
3. 用范围行的「＋」按作品、类型、人物、音高加条件。单击人物块可以切换“只要单人”。
4. 点 ⚑ 把当前范围存为筛选器。

要移除单个条件，点条件块上的 ×。⚑ 菜单里的「清空标签范围」只清这一行，查找文字、主表达式、星标、当前项目和用途仍然生效。当前筛选器有临时改动时，可以选择「恢复已保存的标签范围」。

批量操作：勾选后用「批量操作 ▾」或右键菜单。「添加标签…」「编辑资料…」都会先给你看前后对比，也都可以撤销。

全局改名或移除标签：顶栏 ⋯ →「管理标签…」。人物改名会连台词段的说话人一起改。

详情区的波形两边留有余量，灰显的部分也能框选和截取。再次截取会预填当前采样的本地标签，保存前可以删改。保存后，右侧打开新采样，左侧保留当前筛选和页码。要看更远的前后文，用「返回原素材」。它会回到这个采样来自的整条音轨，并把这段设为选区。

「资料与来源」里的“相关采样”列出同一原素材上时间有重叠的其他采样。

详情区的标签按分面分组，淡色写来源。点继承来的标签可以「去来源」改原来的标注。

## 按项目整理采样

1. 点顶栏 BPM 旁的文件夹，输入项目名并保存。例如输入 `dil`，以后纳入这个项目的采样会有本地标签 `project:dil`。输入另一个项目名可切换，留空保存可清除当前项目；已有标签保留。
2. 手动截取、拉平、局部分离和回导时，新采样会自动加入当前项目。拉平和分离按提交任务时的项目归类。批量建候选、导入素材包、播放或改名都不会自动加入。再次截取时，原采样的本地标签照常预填；如果新采样不属于原来的项目，保存前可以删掉预填的旧项目标签。
3. 找到已有的好用采样时，用右键菜单的「加入当前项目」。可先勾选多条再一起加。同一采样可以加入多个项目，也可以独立打星。要移出项目，删掉该采样的对应项目标签即可。
4. 点查找栏星标旁的文件夹「只看本项目」。它和文字、星标、用途、保存的筛选器一起生效。关掉它即可去全库找新候选，顶栏仍记住当前项目。已有检索结果是保存的快照；要按当前范围检索，重新发起即可。要搜整条原片音轨，先关闭「只看本项目」。

项目标签表示你把这条采样纳入了项目素材，方便下次继续挑选。

## 语音分析

从这些地方都能开始：采样右键或语音卡的「语音分析…」、批量操作、原素材 ⋯、台词段右键「语音分析这段…」。

确认框会写明分析几段、跳过几段，以及无法处理的原因。

对不准时，依次试试：

1. 确认台词文字和边界是对的。
2. 确认用的是分离后的人声轨。原混音有背景音乐或音效时，结果基本不能用。默认轨只影响之后建的采样，已有采样不换轨。
3. 在设置 → 文本前端的用户辞典里给专有名词指定读音，然后重新分析。
4. 在详情区的波形上切到“音素”层，点「✎ 编辑音素时间」拖边界。人工版本不会被重新分析覆盖。

## 调整卡拍

在详情区的「节奏与卡拍」面板里：

| 想做的 | 用 |
|---|---|
| 换密度 | 卡拍方案（近快、近慢） |
| 听节拍 | 「原声＋咔哒」「纯咔哒」 |
| 改每块占几格 | 「人工占格」 |
| 同一元音重复发音 | 「在音素前拆开」 |
| 切开或合并语段 | 「语段切分」 |
| 按 mora 试听 | 「按 mora（临时）」，「写进人工占格」才保存 |

这些都可以撤销。

## 管理任务

按 Ctrl+J / ⌘J 打开任务抽屉，可以看进度、取消或重试。排队中的任务可以「提到最前」，正在跑的不会被打断。

批量任务一条都没做成才算失败。部分失败时任务仍显示成功，逐条原因要在结果里看。

## 检索

音高检索可以用来辅助原音系音 MAD 的制作。

1. 在采样库列表上方点检索按钮。▾ 可以换成节奏检索、音高检索、音色筛选或瞬态筛选。
2. 设置[条件](reference.md#检索条件)。
3. 如果提示缺索引，点「准备…」。自动准备开着时一般不用管。
4. 点「查找」。

结果是一个固定的标签页，不随资料变化重算，失效的命中会标出来。命中的右键菜单可以定位、试听、保存成新采样、拉平、导出和复制 REAPER 交接。

## 拉平

把一段声音的音高拉成一个音。

1. 从采样右键、详情区、时间线选区或命中右键打开「拉平…」。
2. 选处理范围：整段、仅元音、从首个元音起，或内部拉平（首尾保留）。
3. 选目标：段内自动、交界自动，或手动指定音名。

成品是一条新音轨，可以照常截取和导出。声码器是非商业许可（CC BY-NC-SA 4.0）。

## 分离人声

1. 安装 [PyMSS Studio](https://github.com/pymss-project/pymss-studio/releases)：Windows 按显卡选 CUDA（NVIDIA）、ROCm（AMD）或 CPU 版，macOS 选 Apple Silicon 的 MLX 版。在 Studio 里完成推理环境安装。
2. 在 Studio 里下载模型：
   - HyperACE v2（`bs_roformer_voc_hyperacev2`）：人声分离任务稳定的基线模型，适合做默认人声轨。注意不要选名字相近的 `bs_roformer_inst_hyperacev2`。
   - BandIt v2 multi：分成对白、音乐、音效三轨，适合找音效和去 BGM。
3. 回到设置 → PyMSS Studio 刷新。
4. 选 ⋯ →「整片分离…」，或者在时间线选区后点「分离」，再选择模型。对话框不会默认选中模型。
5. 在「人声 / 音效与默认轨…」把人声设为默认人声轨，把音效设为默认音效轨。

任务里的“分离设备设置”是提交时冻结的 PyMSS 设置，和 ONNX 加速开关无关；“自动”表示交给 Studio 选择。重试时用当前设置。

每次分离都会真的再跑一遍。多出来的音轨在「人声 / 音效与默认轨」或设置 → 存储里删。应用不会替你下载分离模型，也不会换别的模型。

## 导出和交接

入口在详情区的「交接 ▾」、右键菜单和批量操作。

| 想要 | 操作 |
|---|---|
| WAV | 「导出原声 WAV」「导出卡拍 WAV」，文件在 `Library/Exports/<日期>/` |
| 拖进 DAW | 按住 Alt（⌥）拖原声，Alt+Shift（⌥⇧）拖卡拍 |
| 粘贴到 REAPER | Ctrl+C / ⌘C，到 REAPER 里粘贴 |
| 拖进 REAPER | 按住 Alt+Ctrl（⌥⌘）拖动。item 会落在指针上面一轨、稍微偏右，要精确位置请用粘贴 |
| 视频片段 | 「导出视频片段…」，可选原声版或卡拍版，也可以不带声音 |

复制或拖进 REAPER 时，每个音头都会自动挂好拉伸标记。有两种方式，都用未卡拍的原声文件：“原声”只在音头放 1 倍速标记，方便手动卡拍；“卡拍效果”用拉伸标记直接卡好。删除所有标记就回到原声。默认用哪种在设置 → 导出。

没有画面的采样不能导出视频，要先绑定画面。

## 绑定画面

选「画面绑定…」，换成别的视频、循环动画或静态图片。优先级是采样 > 原素材 > 原素材自带视频。

多选原素材后，「画面绑定：匹配同名文件（n 个）…」可以一次配上同名视频或图片。

## 处理过的声音放回来

用复杂手段在外部处理好的声音，可以放回原来的位置，称为“回导”。它也能关联到原画面和原标签。

1. 在时间线上选好起点。
2. 点「回导」，选择文件。终点是起点加文件时长，越界不能保存。

文件会复制进素材库，并生成一条新音轨和一个新采样。

## 省磁盘

- 清缓存：设置 → 存储与缓存 →「清理」。只删可重建的缓存和成功分离留下的中间文件，有任务在跑时不清理。空闲时也会自动整理。失败的分离任务会保留现场，原素材、素材库、测量结果、数据库和模型都不算缓存。
- 存切片：选「独立化…」，把采样用到的声音存成无损切片，画面存成视频片段。之后即使删除原素材，这些采样也能播放和导出，只是不能返回原素材。
- 删原素材：选「删除原素材…」，勾选要先独立化的采样，点「独立化 n 个并删除原素材」。磁盘上的原始文件不会被删。

## 排错

| 现象 | 怎么办 |
|---|---|
| “模型文件不在应放的位置” | 到设置 → 环境与模型检查。发布版带着全部模型，缺了就重新安装，或用「从文件导入…」 |
| “文件在，还没校验” | 点「检测环境与模型」 |
| 字幕导入报编码错误 | 把字幕转成 UTF-8，比如用记事本另存为 UTF-8 |
| 放好字幕后没关联上 | 点「重新扫描原素材文件夹」。手动选过或清空过字幕的，要到「作品与输入设置…」改 |
| 说话人不对，台词里混进括号内容 | 检查[字幕写法](reference.md#字幕写法)，或者到设置 → 字幕改规则，再「按当前规则重新生成说话人」 |
| 预览里有一条标“超过 120 秒” | 把这条拆成几条。其余的可以照常导入 |
| 字幕里的音乐标记报 OP/ED 错误 | 插入曲也会用 `♪`。保留真正的 OP、ED，把其他音乐改成音效行 |
| 批量建采样提示“要先指定默认轨” | 在「人声 / 音效与默认轨…」把分离出的人声设为默认。干声素材可以多选后选「把原混音设为人声与默认人声轨（n 个）」 |
| 找不到 PyMSS Studio | 安装 Studio，或在设置 → PyMSS Studio 指定位置和数据目录 |
| 原素材移动了位置 | 文件夹里移动的，重新扫描即可；不在文件夹里的，右键「重新定位…」；多个一起搬时，勾选后「重新定位（n 个）…」 |
| 磁盘不够 | 看[省磁盘](#省磁盘) |
