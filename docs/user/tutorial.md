# 入门教程：从一集番剧到 REAPER

这篇教程带你走完最短的一条路：登记一集带字幕的番剧，从一句台词建一个采样，按 BPM 卡拍试听，再粘贴进 REAPER。大约需要十分钟。

你需要准备：

- 一集番剧的视频文件。
- 一个和视频同名的日语 UTF-8 SRT 字幕，放在视频旁边。
- 如果想走完最后一步，还要一个 REAPER。没有的话，可以到第 6 步导出 WAV。

快捷键按 Windows / macOS 写。

## 1. 放好素材

新建一个总文件夹，再在里面为这部作品建一个文件夹，把视频和字幕放进去：

```
otomad素材/
└── ゆるゆり/
    ├── Yuru Yuri [01].mkv
    └── Yuru Yuri [01].srt
```

## 2. 登记文件夹

1. 打开应用，按 Ctrl+, / ⌘, 打开设置。
2. 在“原素材”里点「添加原素材文件夹…」，选择 `otomad素材`。
3. 按 Ctrl+2 / ⌘2 到原素材页。

你会看到左边的列表里出现“ゆるゆり”这个作品，下面是这一集。

## 3. 导入字幕

1. 点开这一集，在 ⋯ 菜单里选「导入字幕…」。
2. 看一遍预览，确认每行被读成了台词还是音效。
3. 点导入。

右边的台本里会列出每一句台词。单击一句，播放位置就跳到那里。

## 4. 指定人声轨

这篇教程跳过人声分离，直接用原来的声音。

1. 在 ⋯ 菜单里打开「人声 / 音效与默认轨…」。
2. 把原混音设为人声和默认人声轨。

## 5. 建一个采样

1. 在台本里找一句喜欢的台词，按空格听一下。
2. 右键这一行，选「从这段建采样…」。
3. 名称默认就是这句台词，确认保存。

按 Ctrl+1 / ⌘1 到采样库，新采样就在列表里。

## 6. 分析并卡拍

1. 右键这个采样，选「语音分析…」并确认。
2. 等任务完成。按 Ctrl+J / ⌘J 可以打开任务抽屉看进度。
3. 在顶栏的 BPM 框里输入 `180`。
4. 选中采样，按空格听原声，按 B 听卡拍后的效果。

详情区的波形上会显示音素，节奏面板会显示每个音块。

## 7. 交给 REAPER

1. 选中采样，按 Ctrl+C / ⌘C 复制 REAPER 交接。
2. 到 REAPER 里粘贴。

粘贴进来的是未处理的原声加拉伸标记，听上去已经卡好拍。删掉所有标记就回到原声。

没有 REAPER 的话，用详情区的「交接 ▾」导出原声或卡拍 WAV。
