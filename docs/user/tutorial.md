# 入门教程

这篇教程带你走完一条完整的路：登记一集带字幕的番剧，分离人声，从一句台词建一个采样，按 BPM 卡拍试听，再粘贴进 REAPER。

除去下载和安装，大约需要二三十分钟，其中大部分时间在等人声分离。24 分钟的一集在 Apple 芯片上约需 10 分钟，其他电脑会有差别。

快捷键按 Windows / macOS 写。

## 准备

- 一集番剧的视频文件。
- 一个和视频同名的日语 UTF-8 SRT 字幕，放在视频旁边。
- [PyMSS Studio](https://github.com/pymss-project/pymss-studio/releases)：
  1. 安装后，在 Studio 里完成推理环境安装。
  2. 手动下载人声模型 HyperACE v2。它在 Studio 里叫 `bs_roformer_voc_hyperacev2`，不要下载成名字相近的 `bs_roformer_inst_hyperacev2`。OttoSmasher 不会替你下载分离模型。
- REAPER。没有的话，最后一步可以导出 WAV。

## 1. 放好素材

新建一个总文件夹，再在里面为这部作品建一个文件夹，把视频和字幕放进去：

```
otomad素材/
└── ゆるゆり/
    ├── Yuru Yuri [01].mkv
    └── Yuru Yuri [01].srt
```

## 2. 登记文件夹

1. 打开应用，按 Ctrl+, / ⌘, 打开设置。
2. 在“原素材”里点「添加原素材文件夹…」，选择 `otomad素材`。
3. 按 Esc 关闭设置，按 Ctrl+2 / ⌘2 到原素材页。

左边的列表里会出现“ゆるゆり”这个作品。点开它，再点这一集。

## 3. 导入字幕

1. 点标题旁边的 ⋯，选「导入字幕…」。
2. 看一遍预览，确认每行被读成了台词还是音效。
3. 点导入。

右边的台本里会列出每一句台词。单击一句，播放位置就跳到那里。

## 4. 分离人声

1. 点 ⋯，选「整片分离…」。
2. 在模型列表里选 `bs_roformer_voc_hyperacev2`。列表不会默认选中，选好后才能点「排队分离」。
3. 等任务完成。按 Ctrl+J / ⌘J 可以打开任务抽屉看进度。

列表里没有这个模型的话，回到 PyMSS Studio 确认已经下载完整，再到设置 → PyMSS Studio 刷新。

## 5. 设默认人声轨

1. 点 ⋯，选「人声 / 音效与默认轨…」。
2. 在“默认人声轨”下拉框里选名字带 `vocals` 的那条。
3. 点「关闭」。

这一步要在建采样之前做。默认轨只影响之后建的采样，已有的采样和分析不会换轨。

> **可以跳过分离吗？** 素材本来就是干声（如游戏语音）时可以：在这个对话框里勾选原混音的“人声”，再把它设为默认人声轨。
> 如果素材有背景音乐或音效，跳过分离后，第 7 步的语音分析错误率会大幅上升，结果基本不能用，后面的卡拍和 REAPER 拉伸标记也会跟着出错。

## 6. 建一个采样

1. 在台本里单击一句喜欢的台词，按空格听一下，再按空格停止。
2. 右键这一行，选「从这段建采样…」。
3. 名称默认就是这句台词，点「保存为新采样」。

按 Ctrl+1 / ⌘1 到采样库，新采样就在列表里。

## 7. 分析并卡拍

1. 单击这个采样，再右键它，选「语音分析…」并确认。
2. 等任务完成。
3. 单击顶栏的 BPM，输入 `180`，按回车。
4. 单击采样，按空格听原声，按 B 听卡拍后的效果。

详情区的波形上会显示音素，节奏面板会显示每个音块。

## 8. 交给 REAPER

1. 选中采样，按 Ctrl+C / ⌘C 复制 REAPER 交接。
2. 到 REAPER 里粘贴。

粘贴进来的是未处理的原声，每个音头都已经挂好拉伸标记，听上去已经卡好拍。删掉所有标记就回到原声。

没有 REAPER 的话，点详情区的「交接 ▾」，选择导出原声或卡拍 WAV。
