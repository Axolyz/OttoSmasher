# 量化索引与虚拟语段（Demo 0.7）

默认检索直接比较“原节奏量化（无 mora）”已有的整数节奏型，支持切换纯 mora、mora 参考校准。
模型选择和卡拍算法是两个维度。原录音变形匹配保留为明确选择的旧算法，不作为失败回退。

## 索引和命中

- `rhythm_index` 保存源分析、语段、BPM 无关的三路线占格、休止及源点对应。四倍率是每拍
  1、2、4、8 格，沿用 Demo 0.6 的节奏型；整句的推断算法和内部起点未被重写。
- 热检索不读取波形，不进行音素推断、整数格距推断或线性优化；只比较选定网格和平移。
  音块左沿要求一个起点，半开覆盖区 `[start,end)` 禁止额外起点，块外仍不受约束。
- `start/end/both` 针对所选整句或语段的第一／最后一个节奏起点，不针对 WAV 左右边界。
  查询保留原来的音素、强弱、音长条件。音长是源音素经分段时间映射后的估计，非重新检测。
- 允许小容差时，命中点可以有非零误差；不会悄悄重排已量化节奏以消除误差。
  `rhythm_error`、`deformation_penalty`、`speed_penalty` 分开保存和展示；零格点误差不是听感满分。
- 每个范围返回得分最好的倍率，详情保留其余倍率作独立参考。结果按父字幕归组。
  `matched_plan_id` 指定实际命中的方案；试听、WAV/TextGrid 和 REAPER 使用相同方案。
  修改 BPM、算法或范围会解除命中绑定，不把新的独立参考伪装成原搜索命中。
- 开启速度限制后才使用 `factor_min/max`；默认不会沿用旧的 0.85–1.18 硬过滤。

## 停顿与范围

保留整条字幕和原媒体，额外建立虚拟语段；不重新裁切或覆盖模型输出。语段保存父句、
父节奏单元／音素索引、绝对源秒数、前后范围及切分证据，单独试听时才生成缓存 WAV。
语段各自重新估计时间尺、占格及尾音，不截取整句占格向量来冒充独立分析。

自动切分要求连续低能量核心默认至少 0.28 秒，前后有完整节奏单元，中点不跨有效音素，
也不把促音闭塞当休止。短弹性间隙和 CTC blank 本身不会产生语段。阈值可调，允许按父句
节奏点手动切分、忽略自动切分。没有停顿的整句不重复建立一个同内容语段。

音频选择通过显式 `audio_selection` 校验父句 ID、源指纹、人声 SHA 和父裁切范围。
人声与原混音使用同一绝对范围。前导辅音和尾音保留，语段读音不可靠时标明未知／音素，
不把整句汉字当成剪出的语段转写。整句上下文始终可见。

## 独立语段连接

整句默认仍使用原有整句量化。开启“按连续语音段组合整句”后，各语段先独立推断，
连接时固定每段全部起点和句尾控制点，只调整连接处的整数休止。

默认休止由原连接时长按源时间尺取最近整数格；不会把较长休止截短到候选枚举上限。
可编辑范围至少 1–32 格，原始休止超过 32 格时上限扩展到原值。
最少 1 格是为了保留尾音控制点与下一起点之间的正时长声音；弱声音不被替换为零。

搜索中“尝试调整语音段之间的休止”默认关闭。开启后额外检索这些独立连接模式：
候选总数不超过 128，优先原休止、查询跨度提示和近邻值；完整覆盖时才标 `complete=true`。
单间隙通常能穷尽，多间隙会明确报告有界检索。它不搜索跨作品或任意顺序的排列。

## 版本与接口

- `POST /api/rhythm`：新增 `engine/strategy/scope/densities/speed_filter`。
- `POST /api/rhythm-index {analysis_kind}` 或 `scripts/build_rhythm_index.py`：可恢复构建，记录失败。
- `GET /api/cues/{id}`：增加各模型 `scopes` 和 `segment_settings`。
- `GET /api/cues/{id}/scope`：取得当前虚拟范围的独立 analysis/rhythm。
- `POST /api/cues/{id}/segments`：阈值、人工拆分和忽略切口。
- `POST /api/cues/{id}/quantization-plans`：支持 `scope_id/matched_plan_id/composition/rest_overrides`。
- 索引签名包含上游分析更新时间、分组、占格设置、语段设置和派生算法实现指纹。
  修改后按句重建，旧范围／方案失效；修改节奏分组会退役原有按索引编号保存的手工切口。
- `indexed-reference-v1` 方案带原分析、范围、索引签名、全部时间对应和检索证据。
  新试听与导出不为查询画布的空白补整段静音，但保留完整所选音频及原查询坐标映射。
  REAPER 仍保存未变速原声和完整拉伸标记，无需运行插件或导入脚本。

首次构建与修改源数据后的重建需要额外耗时；缓存不是对过时分析的永久复用。
数值、自动边界和周期证据均不等于人工感知标注。
