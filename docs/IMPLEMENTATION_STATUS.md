- FFmpeg 9.0.1；项目内 Git 2.55.0。

- HubertFA 1218 模型、MFA Japanese 声学模型／词典、pymss HyperACE v2 模型已下载；
  7 个模型／配置文件通过 SHA-256 检查，指纹见 `dependencies/models.lock.json`。
- SOFA、Yohane、FA-Kara、StrangeUtaGame、TextGrid2oto 目前作为后续适配参考，
  未安装完整训练／GUI 环境；这次未评价其精度。
- 运行时、模型和原始视频未进入 Git；没有创建远程 GitHub 仓库。

## 数据与可用功能

12 集配对导入，4,730 条字幕；再次导入跳过全部 12 集、无错误。
4,515 条台词全部完成混合音轨的基础能量分析。声事件和音乐标记分别保存。

CLI 与 FastAPI 界面共用 SQLite 和 Python 操作。已有文本／假名／集数检索、前后字幕、
波形、模型音素显示、原声和整句保音高变速、加节拍试听、收藏、问题标记和导出。
导出的 WAV、TextGrid、lab、清单包含来源与查询上下文。所有模型标签都标记为未人工校正。

节奏网格支持必须起音／禁止新起音／不限制；在必须起音的格子上可限制元音标签、
相对能量和音素长度。原始时长不会预先量化；同一个 0.75 时长单位在不同全句倍率下
可以参与 0.5 和 1 的筛选。当前只有整句缩放与平移，没有局部对齐或任意音素填充。

## 对齐诊断

两后端使用同一批 24 句、每句前后保留 0.65 秒的原混音。选择的是字幕前后空隙均至少 1 秒、
时长 1–7 秒的单行台词；这是诊断样本，不是随机代表全库的准确率评测。

| 后端 | 当前结果 | 需要检查的情况 |
| --- | --- | --- |
| HubertFA | 24 个 TextGrid | 16 句含小于 20 ms 的音素；10 句涉及模型不能独立表示的 `cl` |
| MFA 修正版 | 23 个 TextGrid，1 句无产出 | 3 句含 `spn` 未识别部分 |

HubertFA 的输入由 pyopenjtalk-plus 生成，I/U 归并为 i/u，`cl` 对应该检查点的静音类别。
MFA 使用自身 Japanese/Sudachi 前端及日语词典。MFA 第一轮受字幕空格影响，出现整段未登录词；
第二轮去掉输入中的排版空白再分词，保留旧输出与版本。新版失败不会回退到旧版“成功”结果。
原字幕未修改。

这两套结果的原生音素表和前处理不同。没有人工金标，不能把边界一致度解释为准确率，
也不能用检索命中数量宣布某个模型更好。MFA 失败的一句是“水場はあそこだね 行こうか”。

人声分离：pymss/HyperACE v2 在 MLX 上处理一个真实片段成功，分离阶段约 13.7 秒。
这是单声道诊断片段，模型复制成双声道处理；尚未用它推断整集吞吐，也尚未与分离后对齐比较。

## 检查结果

- 14 项自动测试通过：日语读音和路径、注释解析、导入回滚／重复执行、失败版本选择、
  字幕余量、整句倍率、必须／禁止起音、未知属性拒绝、音长与 IOI 区分、0.75 多种匹配、
  本地 API、收藏和原声导出。
- 音频测试验证保音高变速、实际输出长度及三组脉冲节奏的缩放位置。
- 真实片段四次导出检查通过，两个变速样例的时长偏差约 −7.3 ms 和 −11.0 ms。
  这不能保证每个真实语音起点严格仿射；试听仍是判断依据。
- 本机默认四拍条件查询：全库能量候选约 0.27 秒；24 句诊断池查询低于 0.02 秒。
  数据已缓存，不包含前处理耗时。结果数量和候选明细见 `outputs/validation/report.json`。
- 浏览器实际检查了节奏查询、句子详情、变速播放、加节拍播放和 WAV／TextGrid 导出，未见 JS 错误。
- 四个 Python 环境依赖检查通过；测试工具有两条上游弃用提示，没有测试失败。

## 下一轮优先事项

1. 对一小批“普通台词、拖长音、促音、尖叫、带配乐、连续说话”建立人工校对参考，
   对比两个后端与分离前后结果。补入 SOFA 或 CTC 后端需要其可用的日语模型和明确的标签映射。
2. 定义适合音合わせ的节奏锚点，处理相邻同元音、长音以及子音与元音开始之间的听觉差异。
   不把每个模型音素边界直接等同于一个节奏点。
3. 分组对齐连续字幕，检验失败标记和局部重跑，再扩大到全库音素覆盖。
4. 然后增加音高／扬调、连续两三句检索及更完整的校正交互。MIDI 与 agent 放在这些验证之后。

当前不必新增番剧或 MIDI。需要音乐场景验证时，准备 2–3 段约 10–20 秒、想填台词的原曲片段，
附 BPM 或大致小节位置即可；有 MIDI 可以附带，但不是 helper 验证的前提。
