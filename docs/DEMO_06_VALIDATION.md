## 代表例

SOFA「ねえ 何か言ってよ！」（`5125c666975c64b8b0e278eb`）：

| 路线 | 六个单元的占格 | 默认倍率 |
| --- | --- | --- |
| 纯 mora，补格关 | 2, 1, 1, 3, 1, 1 | ×4 |
| mora 参考校准 | 3, 2, 1, 2, 1, 4 | ×4 |
| 无 mora | 5, 3, 1, 3, 2, 7 | ×8 |

纯 mora 开启补格时，尾音从 1 格改为 3 格，文本仍是 1 mora，不增加起点。无 mora 的 ×8 严格输出约 1.518 秒，整体连续语音时长倍率约 0.852。单元列表仍以模型标记为准，不能据此说 SOFA 找准了所有音。

SOFA「どうしたの？ ボス 早く進めよう」（`bc985d03aab4ff9d225feedc`）：有约 11 ms 的极短模型间隔。降低它对整体时间尺的影响后，无 mora 的默认 ×8 连续语音时长倍率约 0.948；该起点仍然保留，其局部大拉伸仍显示。这一句校准与无 mora 相同，是应该合并展示的结果。模型边界本身没有自动修复，必要时仍应人工调整分组。

## 限制

音素边界、连读分组及停顿仍是未经逐句人工校正的估计。无 mora 可以摆脱文本格数，但不能凭量化修正错标的起点。搜索是有界的，极短间隔权重、简单节奏惩罚和周期权重仍属于实验选择；大幅变速仍可能改变音色／语气。三路线和原声需要继续通过用户试听评价。
