# 派生采样、批次与自适应检索（2026-09-15）

这是当前 Electron Helper 的数据与操作约定，覆盖旧的多集合／加工版本界面约定。入口仍为 `./otto ui library`、`./otto ui search`、`./otto ui cut`，或根目录启动文件。升级后重新打开窗口以加载新界面。

## 保存与来源

每个明确保存的裁切、分离、卡拍、拉平结果有自己的采样 ID。直接父级、输入音频、父级选区和子采样到父采样的时间映射保存在 `sample_edges`；不可变音频引用保存在 `sample_assets`。偏移和实际变速控制点组合到原片秒数。原句 ID、模型版本、祖先音素 ID 和可靠读音／词定位留在派生记录与局部分析里。词定位只在分词读音与对齐读音一致（含等价长音写法）时提供；不一致时显示音素和原句，不猜汉字。

试听、切换模型和算法不登记。重复保存相同操作结果复用已有记录。一个采样可以有多个派生，但不是多层文件夹。旧加工记录迁成子采样；纯文件副本只留存储引用。旧表和 CLI 的兼容接口保留，桌面不再显示加工版本归档。

每个库采样只在一个平级文件夹中。初始名称为语音、调谐单音、非调谐单音、未归档，右键可改名，也可新建。星标独立于文件夹，标签支持交集。旧多集合中保留一个归属，其余转为 `旧集合:` 标签。旧人工分组、占格和语段设置按后端迁入。

原句语料默认绑定已有分离人声；绑定后换模型不换切点。固定范围之外的模型标签明确失败，不替换成另一模型的结果。原片、人声和去人声残差可以作参考；没有覆盖选区的分离结果时提示准备任务，不回退混音。分离任务默认仅准备共享音源，明确“保存分离结果”才登记派生。残差保留模型与输入来源，不标成干净背景音。

截取器使用原片时间；采样详情使用采样本地时间。跨出父采样范围时，先“打开原片完整范围”。预览波形和视频引用同一范围及音源，默认生成至多一分钟的附近代理。导出 WAV、视频使用所选声音；变速采样的视频导出明确不支持，本轮可导出 WAV。

## 选音与分析

单击音素，Shift 单击连续选择；波形选区和数值切点同步，允许截断音素。保存选区后建立独立子采样并重建局部首尾、停顿、分组、相对属性及三条量化路线。裁断部分保留 `partial` 与 `edit_boundary` 来源标记，不制造逐 mora 时刻。

采样自行选择 narabas／SOFA／HubertFA，以及纯 mora／mora 参考校准／原节奏无 mora。默认 narabas 和无 mora；MFA 仅保留历史。子采样继承父级当时的模型、算法选择，此后独立。三份测量快照也随采样固定，父级重新对齐不会覆盖已有子采样。裁切不重跑推理；原声不同的特征不冒用人声 F0。音高缺失保持未知。

新文件可提供实际台词，安排 pymss 和三个后端任务。无文本文件不运行强制对齐，不新增 ASR。字幕仍应先在项目既有独立预处理流程中清洗和校时。后台任务有日志、取消、重试，关闭窗口不取消任务。

## 三个倍率与搜索

骨架是与目标 BPM 无关的整数占格。查询时在 `2^k` 格／拍中寻找原速以上最近、原速以下最近、前者双倍密度三个方案，可超过 ×8，也可低于 ×1。实际语速由共享采样帧映射计算，排除休止、前后填充；密度不是语速。恰好原速保留。显示无效映射，不强凑候选。

检索使用各采样的模型和算法，三个密度都参与，音块筛选继续使用 FCPE、能量与当前角色标注。搜索不运行模型或渲染。自动停顿语段有独立占格骨架，句首／句末可命中这些语段；休止组合保留现有有界搜索，不宣称枚举所有组合。

命中绑定 `plan_id`，显示哪些元音对应查询音块。试听与 WAV／标注／REAPER 交接消费同一计划，不增加独立播放器速度。改分析、分组或算法使旧计划失效；标签和星标不改变音频或索引。

## 候选批次

普通列表过滤不创建文件夹。“检索并生成候选批次”建立一个同层批次文件夹，并保存查询、候选来源和计划 ID。候选默认不混进日常已确认列表；可进入批次试听、筛选并批量接收／丢弃。局部分析准备为独立后台投影任务，任务完成后候选即可参与检索；不会在搜索请求内推理。

接收自动归档到生成批次前选择的目标。完整候选若已经是已归档采样，复用原采样，不移动或降级；重复处理结果同样复用。丢弃只改变候选状态，不删父级、共享音源或持久文件。批次来源标签持续保留。

拉平批次默认接收至调谐单音。单条“仅元音”要求可靠音素范围，保留其他区间；“辅音一起处理”让全选段重合成，但不替清音添加 F0。FCPE 的可靠半音分布选一个代表音高，再取最近十二平均律音，A4=440 Hz。PC-NSF-HiFiGAN 使用本地 HiFiShifter 的 ONNX、配置和预处理，模型指纹在 `dependencies/flatten-model.json`。处理在 features 环境进行，输出持久 WAV、来源清单和更新 F0。没有足够可靠 F0 会失败。

## CLI 示例

JSON 参数可从文件或 `--json -` 的标准输入读取。输出为 JSON。与 GUI 共用采样操作：

```sh
./otto samples register --json import.json
./otto samples get SAMPLE_ID
./otto samples select SAMPLE_ID --json selection.json
./otto samples prepare SAMPLE_ID
./otto samples preferences SAMPLE_ID --json preferences.json
./otto samples plans SAMPLE_ID --json bpm.json
./otto samples search --json query.json
./otto samples flatten SAMPLE_ID --json flatten.json
./otto samples export SAMPLE_ID --json export.json
./otto samples review --json decision.json
```

- `import.json`: `{"path":"/absolute/file.wav","folder_id":"speech","text":"実際の台詞"}`；省略 text 就不对齐。
- `selection.json`: `{"start":0.12,"end":0.48,"role":"selected","folder_id":"pitched"}`，单位为父采样本地秒。
- `preferences.json`: `{"active_phone_backend":"sofa","active_quantization_strategy":"acoustic"}`。
- `bpm.json`: `{"bpm":120}`。
- `query.json`: `{"bpm":120,"notes":[{"start_beats":0,"end_beats":0.5}],"pool":"all"}`；只检索，不自动登记。
- 显式批次检索使用 `{"batch":true,"target_folder":"speech","query":{...}}`。
- `flatten.json`: `{"mode":"vowels"}` 或 `{"mode":"all"}`。
- `export.json`: `{}` 导出绑定原声，`{"plan_id":"..."}` 保存卡拍子采样。
- `decision.json`: `{"ids":["CANDIDATE_ID"],"accept":true}`。

底层表有原始测量、局部投影、偏好、角色标注、持久资产及缓存的独立职责；`data/sample-cache`、`data/cache`、`data/previews` 可重建，`data/media` 和 `outputs` 是持久输出。请勿把删除试听缓存扩大为删除 `data/vocals`、对齐输入或模型目录。
