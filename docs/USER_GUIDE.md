## 快速开始

### 开始之前：素材要先整理好

OttoSmasher 的流程**依赖一定的预处理**：应用按**文件夹**认作品、按**同名文件**认字幕和画面、按**字幕的写法**认台词、说话人和音效。
素材整理得越规整，后面越省事。这些整理可以手动做；如果你有**本地运行的 LLM agent**（能读写你电脑上文件的那种），
把下面的要求原样交给它做最快。

**1. 文件夹结构**：建一个总文件夹（例如 `D:\otomad素材` 或 `~/Movies/otomad素材`），第一层子文件夹就是**作品**，作品文件夹里怎么分子目录都行：

```
otomad素材/                         ← 原素材文件夹（在设置里登记的就是它）
├── ゆるゆり/                        ← 作品
│   ├── [VCB-Studio] Yuru Yuri [01].mkv
│   ├── [VCB-Studio] Yuru Yuri [01].srt     ← 和视频同名的字幕，自动关联
│   └── …
├── Blue Archive/                    ← 作品（游戏）
│   └── ホシノ/                      ← 子目录随意
│       ├── hoshino_001.wav
│       ├── hoshino_001.srt          ← 同名字幕：这句台词
│       └── hoshino_001.png          ← 同名图片：自动绑定为画面（立绘）
└── Drum Kit A/                      ← 作品（音效包）
    └── kick_01.wav
```

**2. 文件名**：每个文件的**素材标识**（在一个作品里区分和排序原素材，比如集数、编号、角色名）从文件名推断：
番剧常见的 `[字幕组] 作品 [01]`、`作品 - 01`、`作品 第01話` 都能认出 `01`；认不出时素材标识就是文件名本身。
所以短采样、游戏语音的文件名最好就是你想看到的名字（全长采样的名称也取文件名）。

**3. 字幕（台词）**——要做语音分析就需要日语台词文本：
- 格式 SRT，**编码 UTF-8**（GBK、UTF-16 等会报错，先转码）；文件名与视频 / 音频相同（扩展名不同），放在同一文件夹。
- 每行写**实际说出来的日语**。中日双语字幕要删掉中文行；注音假名、译注、说明文字要删掉。
- **说话人**写在行首的括号里：`（京子）こんにちは`。默认规则把台词行里所有最外层括号都当作说话人，
  所以台词正文里不要留别的括号（例如 `歳納(としのう)京子` 里的注音会被当成说话人）。说话人名里嵌套的读音
  `（京子(きょうこ)たち）` 默认会去掉，记成「京子たち」。规则可以在 设置 → 字幕 里改。
- 只有括号的行是**音效**：`（足音）`、`（ドア）（足音）`，会变成音效提示。
- `♪～` 开头 / `～♪` 结尾的行标出 OP / ED，批量建采样和批量分析时会跳过。
- 哼歌、歌声不要写成 `♪（ハミング）`：会变成一段只有“♪”的台词，分析不了（准备清单里记作“文字读不出音”）。写成音效行 `（ハミング）`，或写出歌词。

**4. 给本地 LLM agent 的说明示例**（按你的情况改）：

```
在 <总文件夹> 里：
1. 第一层子文件夹按作品分好，字幕文件改名成和对应视频完全相同的文件名（只换扩展名）。
2. 把字幕转成 UTF-8 的 SRT；删掉中文翻译行、注音假名、译注，每行只留日语台词。
3. 说话人统一写成行首的全角括号（京子），台词正文里不要留别的括号；纯音效行写成（足音）这样只有括号的行。
不要删除或移动视频文件本身，改动前先列出计划给我确认。
```

**5. 模型与分离工具**：设置 → 环境与模型「下载缺少的模型」（见 README）；要分离人声再装 PyMSS Studio（见 [第 11 节](#11-人声分离)）。

### 共同的第一步：登记原素材文件夹

1. 设置（Ctrl+, / ⌘,）→ **原素材** →「添加原素材文件夹…」，选上面的总文件夹。
2. 应用在后台扫描：每个音频 / 视频文件登记成一个**原素材**（只记位置，不复制、不转码）。之后每次启动会再扫一次，也可以在原素材页列表顶部点「重新扫描原素材文件夹」。
3. 扫描时自动推断：
   - **作品** = 第一层子文件夹名（直接放在总文件夹下的归“未指定作品”）；
   - **素材标识** = 按文件名推断（规则在 设置 → 原素材「作品与素材标识推断规则」，可以试算），推断不到就用文件名；
   - **同名字幕**（.srt 优先，其次 .ass）自动关联——只是关联，导入要你点一下（见各场景）；
   - **同名画面**（与音频同名的视频 / 动图 / 图片）自动绑定，可在作品的「作品设置…」里关掉；
   - 在 Finder / 资源管理器里移动或改名文件后重新扫描，应用会认出是同一个文件，字幕标记和采样都保留。
4. 到 **原素材** 页（Ctrl+2 / ⌘2），左边按作品分组列出。作品组的右键（或 ⋯）菜单里有整组操作，后面各场景会用到。

> 也可以不登记文件夹，直接把文件拖进原素材页或采样库，或用「＋ 添加原素材」「导入」选文件——这时作品可以在导入框里统一指定或按文件名推断。
> 素材多的时候还是推荐文件夹：作品就是文件夹，整理一次以后都不用再管。

### 场景 A：有字幕的番剧——边看边手动建采样

适合“审片”：一边看一边挑好用的句子，不想一次建一大堆采样。

预处理：同名字幕（见上）。
1. 原素材页打开一集 →（列表行或查看器的 ⋯）「导入字幕…」→ 看一遍预览（每行是台词还是音效、说话人是谁）→ 导入到文本层。
2. （推荐）先分离人声：「整片分离…」选 HyperACE v2，完成后在「人声 / 音效与默认轨…」把分离出的人声设为默认人声轨。
   不分离也行：在同一个对话框里把原混音设为人声与默认人声轨。
3. 播放：右侧的**台本**列表可以跟着播放滚动，单击一行跳到这句，画面上同时显示这句字幕。
4. 听到好的：台本行（或画面上的字幕）右键 →「从这段建采样…」→ 名称默认就是台词，确认保存。仍然留在原素材页，接着看。
   想要一段字幕没覆盖到的声音：时间线上拖选 → 选区操作栏「截取」。音效：覆盖层切到「音效提示」，右键提示「从这条提示建采样…」。
5. 看完一集，到采样库（Ctrl+1 / ⌘1）里整理：勾选这些采样 → 右键「语音分析…」，之后就能卡拍试听、拉平、导出。

### 场景 B：有字幕的番剧——批量建采样，然后检索

适合“建库”：整季的台词全部变成采样，之后用节奏检索、音高检索找。

预处理：同名字幕（见上）；建议先装好 PyMSS Studio 和 HyperACE v2 模型。
1. 原素材页，作品组右键 →「给整组 n 个原素材导入字幕标记…」（每集按默认选项导入，没关联字幕的跳过）。
2. 分离人声：逐集「整片分离…」（排队执行），完成后逐集在「人声 / 音效与默认轨…」把人声设为默认人声轨。
   不分离：作品组右键 →「把原混音设为人声与默认人声轨（n 个）」一次设好（对白清晰的素材可以先这样，之后分离了再换）。
3. 每集 ⋯ →「从台词段批量建采样…」→ 全选 →「创建 n 项」（名称 = 台词，性质 = 语音，OP / ED 里的跳过）。
4. 作品组「勾选整组」→ 右键「语音分析…」：按台词段分析（不用先建采样也行）；确认框写清分析几段、跳过几段、几段无法处理。
5. 分析完成后，后台会自动准备检索用的索引和音高（见 [第 7 节](#7-音高什么时候测)）。到采样库点上方的「节奏检索」（▾ 可换音高检索），
   画几个音块 →「查找」。命中可以直接卡拍试听、导出、复制 REAPER 交接。

### 场景 C：没有字幕的视频

没有台词文本就做不了语音分析（对齐要知道说了什么），但截取、分离、拉平、音高检索、导出都能用。

预处理（推荐）：用**本地**的语音识别（例如 Whisper / faster-whisper / kotoba-whisper）给视频生成日语 SRT，同名放在旁边；
再让本地 LLM agent 按上面的要求清理（去掉识别出来的重复行、能认出说话人就补上括号）。机器转写有错字，对齐会受影响，重要的句子在应用里手改段文字即可。
1. 有了 SRT：之后按场景 A 或 B 做。
2. 没有 SRT：
   - 时间线上选区 → 右键「添加台词…（当前选区）」逐句手打台词，之后照常语音分析；
   - 或者只当声音素材用：选区「截取」「分离」「拉平」；**音高检索**选“已分析原素材音轨”，在整条音轨上找音（音高会在后台自动测）。

### 场景 D：大量现成的短采样（音效包、乐器单音）

预处理：按包分成作品文件夹；**文件名改成你想要的采样名**（全长采样的名称就是文件名）；
建议按用途分子文件夹（例如 `打击/`、`单音/`、`人声/`），后面可以分批设性质。可以让本地 LLM agent 按内容或原文件名批量改名、分类。
1. 登记原素材文件夹后扫描（短文件约每个 60 ms，1500 个约 1.5 分钟）。
2. 原素材页，作品组右键 →「为整组 n 个原素材建立全长采样…」→ 选性质：打击、音效 = **非调谐单音**，有明确音高的单音 = **调谐单音**，台词 = **语音** →「创建 n 项」。
   同一作品里性质不同的，先勾选一部分原素材再右键「为所选 n 个原素材建立全长采样…」，分几批做。
3. 到采样库，顶栏用途切到“非调谐单音”或“调谐单音”：
   - 调谐单音：列表第二行显示音名和音高曲线，「音高检索」按音名找；
   - 非调谐单音：「瞬态筛选」/「音色筛选」按起音、亮度、噪声倾向等指标筛（**这两个筛选目前是未经充分测试的 EA 状态**）。
4. 需要更细的分类时，在采样库给采样批量加标签（勾选 → 右键「添加标签…」）。

### 场景 E：游戏语音（已知每句台词）+ 立绘

游戏语音通常是一句一个文件、已经是干声、台词表也有。

预处理（这一步工作量最大，最适合交给本地 LLM agent）：
- 文件夹：`<总文件夹>/<游戏名>/<角色或分类>/` 下放语音文件。
- **台词 → 同名 SRT**：每个语音文件旁边放一个同名 `.srt`，只有一条，时间从 0 到这个文件的时长，内容是“（角色名）台词”：
  ```
  1
  00:00:00,000 --> 00:00:02,350
  （ホシノ）うへ～、おじさん眠くなってきちゃった
  ```
  结束时间不要超过文件本身的时长（可以用 `ffprobe` 读）。台词表通常是表格（文件名 → 角色 → 台词），让 agent 按表生成。
- **立绘 → 同名图片**：给每个语音文件放一张同名的 `.png` / `.jpg`（同一角色的立绘复制成多份即可），扫描时自动绑定为画面；
  导出视频片段时画面就是这张立绘。

步骤：
1. 登记原素材文件夹、扫描。
2. 作品组右键 →「给整组 n 个原素材导入字幕标记…」：每个文件得到一条台词段（带说话人）。
3. 作品组右键 →「把原混音设为人声与默认人声轨（n 个）」：游戏语音本来就是干声，不用分离。说话人会变成人物标签（`character:ホシノ`）。
4. 作品组右键 →「为整组 n 个原素材建立全长采样…」，性质选**语音**。
5. 作品组「勾选整组」→「语音分析…」。之后在采样库按人物、标签表达式筛选，用节奏检索找句子；详情区会显示立绘。

## 1. 基本概念

| 词 | 意思 |
|---|---|
| **工作区** | 你的全部数据所在的文件夹：数据库、素材库（生成的音轨与导出）、模型。程序目录只读，更新应用不动工作区 |
| **原素材** | 你登记的原始文件：一集番剧、一段视频、一个游戏语音文件、一个音效……**不复制、不转码**，应用只记下它的位置 |
| **作品 / 素材标识** | 原素材按作品分组；素材标识在一个作品里区分和排序原素材（集数、编号或名称），推断不到时就是文件名 |
| **音轨（资产）** | 原素材里的一条声音：原混音、分离出的人声 / 音效、拉平或回导的成品。音轨可以有角色（人声 / 音效），每个角色可以指定一条**默认轨** |
| **台词段** | 原素材上“谁在什么时候说了什么”（一般来自字幕）。语音分析靠它知道该对齐哪段文字 |
| **音效提示、区段标签** | 原素材上的时间标注：哪里有个音效、哪一段属于谁 / 什么场景。采样会继承它覆盖到的区段标签 |
| **采样** | 你截取并保存的一段：绑定在某条音轨的某个区间上，有名称、性质、标签、星标、备注 |
| **性质** | 采样的用途：**语音**（台词）、**调谐单音**（有明确音高的单音）、**非调谐单音**（打击、音效）、**未分类** |
| **任务** | 耗时的操作（语音分析、分离、拉平、下载模型、导出视频…）都在后台排队，任务抽屉（Ctrl+J / ⌘J）里看进度、取消、重试 |

资料修改（改名、标签、性质、设置…）都可以撤销（Ctrl+Z / ⌘Z）。删除原素材、全局改名这类操作执行前会先给你看影响范围。

## 2. 界面一览

- **左侧导航**：采样库（Ctrl+1）、原素材（Ctrl+2）、工具（Ctrl+3）；下面是任务（Ctrl+J）和设置（Ctrl+,）。macOS 把 Ctrl 换成 ⌘。
- **顶栏**：采样库的用途切换（全部 / 语音 / 调谐单音 / 非调谐单音 / 未分类）、全局 **BPM**（留空 = 原速卡拍）、
  **命令与跳转（Ctrl+K / ⌘K）**、撤销、⋯（管理标签、主题、快捷键）。
- **采样库**：左边是列表，右边是**详情区**——当前采样的画面、波形、语音、节奏、资料与标签都在这里。
- **原素材页**：左边是按作品分组的列表，右边是查看器：画面、时间线（波形、台词段、音效提示等覆盖层）、台本。
- **底部播放条**：任何时刻只有一个声音在放；显示正在放什么、哪个版本；最近一次导出的文件也显示在这里，可以直接拖进 DAW。
- **命令面板（Ctrl+K / ⌘K）**：在输入框里也能打开。最上面是对**当前对象**（勾选的采样，没有勾选就是正在看的采样；原素材页是当前原素材）能做的事，
  和右键菜单一样；输入几个字过滤，回车执行。直接输入 `180` 回车 = 把 BPM 设为 180。

## 3. 原素材：登记、播放、台词

**登记**：推荐用原素材文件夹（见[快速开始](#共同的第一步登记原素材文件夹)）。
也可以在原素材页点「＋ 添加原素材」或把文件 / 文件夹拖进来：导入框里作品可以“统一设为”一个名字，或“按文件名推断”。
单个原素材的作品、素材标识、分析用哪条音频流、关联哪个字幕，在「作品与输入设置…」里改（原素材文件夹里的作品跟着文件夹走，要改名用作品的「作品设置…」，会连磁盘上的文件夹一起改名）。

**播放**：时间线上点一下跳到那里。焦点在查看器时：空格 播放 / 暂停，Shift+空格 只播选区（到终点精确停下），L 循环选区，F 适合窗口，Z 放大选区，← / → 逐帧，Esc 清除选区。
拖动框出选区后，选区操作栏里有 截取、拉平、分离、回导、导出。波形卡右上的「频谱 ▾」可以切到对数 / 线性 / Mel 频谱（视口 30 秒以内）。

**台词（文本层）**：「导入字幕…」：预览每行是台词还是音效、解析出的说话人，勾选要导入的类别（台词段、音效提示、说话人、OP / ED）后导入；再导入时，你手改过的段受保护。
- 台词段可以直接编辑文字、边界、说话人；改文字或边界后，这段已有的语音分析停用，要重新分析。
- 「从字幕识别 OP/ED」「OP/ED…」：标出片头片尾，批量建采样和批量分析默认跳过它们。
- 「按当前规则重新生成说话人」：改了说话人规则后用；手改过的段不动。
- 时间线右键「新增区段标签…（当前选区）」：给一段时间打标签（例如 `character:京子`），落在里面的采样会继承。

**音轨与默认轨**：「人声 / 音效与默认轨…」：给音轨标角色（人声 / 音效），指定默认人声轨 / 默认音效轨。从台词段批量建采样要先有默认人声轨（不会自动用原混音）；
说话人只作用于带人声角色的音轨。多选原素材或整个作品组时，「把原混音设为人声与默认人声轨（n 个）」可以一次设好（已经有默认人声轨的不动）。

## 4. 截取采样

- **手动**：时间线上框选 → 选区操作栏「截取」→ 名称（按命名规则给出建议，可改）、性质 →「保存为新采样」。
- **逐句**：台本行 / 画面上的字幕右键「从这段建采样…」；音效提示右键「从这条提示建采样…」。
- **批量**：「从台词段批量建采样…」「从音效提示批量建采样…」：整页表格，勾选后一次创建。
- **整个文件**：「建立全长采样…」（单个、多选、整个作品组都有），名称是文件名，性质在对话框里选。

采样只记“哪条音轨的哪个区间”，不复制声音；导出时才生成文件。

**名称的建议**：选区没有把碰到的台词句完整盖住时，名称是“选中部分（这几句）”——完整选中的词写原文，词只选中一部分时，
完整选中的拍写片假名、只选到半拍（只有辅音或只有元音）写罗马字。例如「入部希望です」里只选了“にゅう” → `ニュウ（入部希望です）`，
只选了「ボ」的辅音 → `b（入部希望です）`，跨两句各选一部分 → `ですイk（入部希望です / 行くよ）`（这些句子要先做过语音分析）。
完整盖住一句或几句时写这几句台词（多句用“ / ”连接），没有台词时写“原素材名 起–止”。名称随时可以改。

## 5. 采样库：浏览、筛选、整理

**列表与详情区**：
- 空格 = 试听原声，**B** = 试听卡拍；**1 / 2 / 3 / 0** = 设为 语音 / 调谐单音 / 非调谐单音 / 未分类；**S** = 星标。
- 勾选框多选，Ctrl+A / ⌘A 全选当前条件下的全部；勾选后「批量操作 ▾」与右键菜单作用于勾选集。
- 列表第二行随性质显示：语音 = 节奏小图 + 音块数；调谐单音 = 音名 + 音高曲线；非调谐单音 = 起音时间 + 包络。
- 详情区的波形只显示这个采样的范围，两边各留 1 秒（或采样长度的一半，取大的）余量，余量灰显、里面也能框选和截取。要看更远的前后文用
  「返回原素材」：它会换到这个采样来自的**整条**音轨（拉平、局部分离出来的成品会换回它们来自的整轨），把这段设为选区，并在时间线的“采样”车道上突出它。
- 「资料与来源」里：**加工链**写着这个声音是怎么一步步做出来的（例如 拉平成品 ← 人声 ← 原混音），每一步都能点开；**相关采样**列出同一原素材上时间有重叠的其他采样（任何音轨上的都算），单击打开。
  采样之间没有“父子”之分：从一个采样里再截取、拉平、回导出来的新采样，和它就是相关采样。

**查找栏**：
- **文字**：搜名称、备注，以及采样读到的台词段的原文和**读音**（搜「きょう」能找到「今日」）。
- **表达式**：标签表达式，`NOT` > `AND` > `OR`，可用括号、双引号，`命名空间:*` 匹配整个命名空间。写错时整框标红，下面写第几个字符出错。
- ★：只看星标。

**范围行**（查找栏下面）：「＋」按分面（作品、类型、人物、音高、其他）加条件，每个值后面写着采样数；同一分面内是“或”，不同分面是“且”。
单击人物块切换“只要单人”。⚑ 把当前范围**存为筛选器**，以后一点就用；改动后可以「更新」或「另存」。

**标签**：
- 批量「添加标签… / 移除标签…」「编辑资料…」都是先预览（逐字段前后对比）再应用，可撤销。
- 详情区的标签按分面分组，淡色写来源（本地 / 区段 / 原素材 / 自动）；点一下继承来的标签可以「去来源」改原来的标注。
- 顶栏 ⋯ →「管理标签…」：按分面列出所有标签和计数，可以**全局改名或移除**（人物改名会连台词段的说话人一起改），应用前先给影响预览。

## 6. 语音分析

语音分析做两件事：**文本前端**（把台词转成音素和读音：pyopenjtalk-plus，多音字用 tsqyomi 预测读音，再套用户辞典）和
**对齐**（pydomino 找出每个音素在音频里的时间），并按能量算出每个元音的**有效范围**（真正发声的部分）。
**一句台词的音素只有一份**，和台词段一样属于原素材的时间线：原混音、从它分离出来的人声、拉平成品……原素材上所有含人声的音轨都读这一份（只盖住半句的音轨显示它盖得住的那几个音，两头标 ◐）；
在哪条轨上测的只作记录（语音卡写“这句的音素在「某某」上测得”）。唯一的例外是**回导成品**（外面改过的声音，时间可能变了）：它和从它再加工出来的音轨另有一份，要单独分析。
音块、停顿、语段不是分析时存下来的，而是你看节奏面板、做检索时根据对齐结果和音频现算的——所以调停顿灵敏度、切分语段不用重新分析。
分析完顺便把这段音频还没测过的音高测掉（见下一节）。

- 入口：采样右键 / 详情区语音卡「语音分析…」、批量操作、原素材 ⋯「语音分析…」（按台词段，不用先建采样）、台词段右键「语音分析这段…」。
- 确认框写清：将分析几段、几段已是最新跳过、几段无法处理（原因，例如没读到台词段）。
- 在哪条轨上测：原素材页 = 你正在看的那条轨；采样入口 = 默认人声轨，没有就是采样所在的那条人声轨（它只盖住半句时用它往上第一条盖得住整句的人声轨），再没有用原混音。
  语音分析要整句，所以只盖住半句的音轨（例如拉平一个音得到的成品）不能拿来测，确认框会写原因。
- 同一句只分析一次，所有读到它的采样共用；修一次音素时间，处处生效（在拉平成品上也能修，只改它盖得住的那几个音）。
- **不含人声的音轨**不读音素、也不能拿来分析：只标了“音效”的声部、没标角色的分离声部（例如音乐）以及从它们加工出来的音轨。
  这些音轨上的采样在列表里语音状态显示“—”。需要的话在「人声 / 音效与默认轨…」给它开“人声”角色，立即生效。
- **对不准时**：详情区波形上切到“音素”层，「✎ 编辑音素时间」拖边界（保存为人工版本，不会被重新分析覆盖）；或者改台词段的文字、
  在 设置 → **文本前端 → 用户辞典** 里给专有名词指定读音（每行 `表记<Tab>読み`，可以先「预览」一句看结果），再重新分析。
- 只用 pydomino 一个对齐模型，失败不会自动换模型重试。

## 7. 音高什么时候测

音高（F0，用 FCPE 模型）是音高检索、单音指标、拉平、节奏面板里“相对音高”的基础。它按**音轨**、每 60 秒一块保存，
测过的块所有功能共用，除非文件或模型变了，否则不会重测。触发的时机：

| 什么时候 | 测哪里 | 说明 |
|---|---|---|
| **后台自动**（默认开：设置 → 语音分析「自动准备检索」） | 每个采样的范围；每个原素材的**默认人声轨**整条（没有就原混音） | 启动时检查一遍，之后新建或修改采样、语音分析完成后约 1.5 秒检查一次。排在你提交的任务后面，每个任务最多 6 块（6 分钟音频），不挡你的操作 |
| 语音分析 | 分析的台词段覆盖到、还没测过的块 | 对齐做完后顺便测。还没下载 FCPE 时对齐照常保存，只是不测音高，任务里会有黄色提醒；放好 FCPE 后由后台自动补测 |
| 检索浮层「准备当前范围索引」（关掉自动时用） | 当前范围里还没测的采样范围，或整条音轨（音轨模式） | 手动 |
| 单音指标「后台准备当前范围指标」 | 当前范围里缺指标的采样 | 先测音高再算指标 |
| 拉平 | 这次要拉平的选区（每次都测，不读缓存）；拉平成品整条 | 成品的音高存下来，之后可以在成品上检索 |

空间很小（每小时音频约 4 MB）。没有音高不等于静音：节奏和停顿按能量判断，不看音高。

## 8. 节奏与卡拍

- 详情区的「节奏与卡拍」面板：音块（每个元音 / 拨音一块）、停顿与语段、卡拍方案（近快 / 近慢，每拍几格）、原句与卡拍的时间映射。
- **BPM** 在顶栏，全局一个；留空 = 保持原语速的卡拍。改了 BPM 会停止试听，方案按需重算。
- 试听：空格 = 原声，B = 卡拍；面板里还能选“原声＋咔哒”“纯咔哒”听节拍。
- 不满意时：「人工占格」改每块占几格；「在音素前拆开」处理同一元音重复发音；「语段切分」在音块前切开或合并自动切口；
  「按 mora（临时）」只在详情区临时试听，「写进人工占格」才保存。都可撤销。
- 卡拍是保音高伸缩（Rubber Band R3）：每块的起音核心逐样本保留，只伸缩中间的“桥”。

## 9. 三大搜索

采样库列表上方的检索按钮（随用途显示「节奏检索」「音高检索」「音色筛选」「瞬态筛选」，▾ 可以换）打开检索浮层：

- **节奏检索（语音）**：一串音块，每块可以写条件（辅音、元音、相对音高 / 响度），在网格上画出每块的时值（拍）。
  节奏策略选“不限节奏 / 必须满足节奏 / 按相似度排序”；首尾选“任意位置 / 从句首 / 到句末 / 句首与句末”。
  有 BPM 时按 BPM 比较，没有时比较归一化的节奏形状。需要先做语音分析。
- **音高检索**：画几个音高块（时长 + 音名或范围），在采样里或整条已测的原素材音轨上找；可以忽略八度。
- **单音 · 音色 / 瞬态**：按测出来的指标（有效声音时长、起音上升时间、谱质心、噪声倾向……）给范围，即时筛选列表。
  **目前是未经充分测试的 EA（抢先体验）状态**：指标的口径和默认范围可能还会调整，结果仅供参考。
- 浮层上写着覆盖情况（多少条已就绪）；缺索引时可以「准备…」（自动准备开着时一般不用管）。
- 「查找」后结果固定成一个标签页（不随资料变化自动重算，失效的命中会标出来）；每个命中可以定位、试听（原声 / 卡拍）、
  保存成新采样、拉平、导出 WAV / 卡拍 WAV / 视频片段、复制 REAPER 交接——都在命中的右键菜单里。卡拍用的是这条命中检索时选中的方案。

## 10. 拉平

把一段声音的音高拉成一个音（自动定音，或指定目标），用 PC-NSF-HiFiGAN 重新合成。

- 入口：采样右键 / 详情区「拉平…」、时间线选区「拉平」、命中右键、批量。打开拉平台：选处理范围（整段 / 仅元音 / 从首个元音起 / 内部拉平，首尾保留）、
  目标（段内自动 / 交界自动 / 手动指定音名）。
- 成品是一条新的音轨（素材库 `Tracks/…/Flatten/`），在原素材上照常截取、导出。
- 声码器是非商业许可（CC BY-NC-SA 4.0）。

## 11. 人声分离

需要另外安装 [PyMSS Studio](https://github.com/pymss-project/pymss-studio/releases)（免费软件，AGPL-3.0）：
Windows 按显卡选 CUDA（NVIDIA）/ ROCm（AMD）/ CPU 版；macOS 选 Apple Silicon 的 MLX 版。装好后在 Studio 里完成推理环境安装，再下载模型。

**推荐的模型**：
- **人声**：**HyperACE v2**（Studio 里叫 `bs_roformer_voc_hyperacev2`）——番剧对白分得干净，适合做默认人声轨、语音分析和检索。
- **三轨**：**BandIt v2 multi**——对白 / 音乐 / 音效分成三轨，找音效、去 BGM 用。

使用：
- 原素材 ⋯「整片分离…」或时间线选区「分离」：选模型、范围。整片分离一次，全集复用。
- 分离结果是新的音轨（`Tracks/…/Separation/`）。在「人声 / 音效与默认轨…」把人声设为默认人声轨、音效设为默认音效轨，之后批量建采样、语音分析都用它。
- 设置 → **PyMSS Studio** 可以把一个人声模型设为默认。模型没在 Studio 里下载时会报错；本应用不会替你下载分离模型，也不会换别的模型。
- 任务里的“分离设备设置”显示提交时冻结的 PyMSS 设置，与 ONNX 加速开关独立。“自动”表示交给 Studio 选择，不是已确认的实际计算设备；重试使用当前设备设置。命令行 `jobs.list` 的 `separationDevice` 返回同一份设置。

## 12. 交接：导出、REAPER、视频片段

详情区的「交接 ▾」、右键菜单、批量操作里都有：

- **导出原声 WAV / 卡拍 WAV**：文件放在 `Library/Exports/<日期>/`，同样的请求会复用已导出的文件。
- **拖出**：按住 Alt（macOS：⌥）拖动 = 拖出原声 WAV，Alt+Shift（⌥⇧）= 拖出卡拍 WAV，可以直接拖进 DAW 或文件夹。播放条上最近导出的文件名也可以直接拖。
- **复制 REAPER 交接（Ctrl+C / ⌘C）**：两种——“卡好拍＋起音标记”或“原声＋拉伸标记，可再调”（默认用哪种在 设置 → 导出）。
  到 REAPER 里粘贴即可；文件放在 `Library/REAPER/<日期>/`。
- **导出视频片段…**：原声版，或卡拍版（画面按同一映射变速 / 画面保持原速并另存卡拍 WAV）；可选不带声音。
  默认 H.264 MP4 + AAC，设置 → 导出 可改成 ProRes 422 HQ。画面超出视频流的部分补黑帧并在完成提示里写明。没有画面的采样会提示先「画面绑定…」。

## 13. 画面、回导、独立化

- **画面绑定…**（采样或原素材）：换成别的视频（同步，可加偏移）、循环动画（GIF 等）或静态图片；优先级 采样 > 原素材 > 原素材自带视频。
  详情区的画面在试听原声时跟着走，⤢ 放大到全宽。多选原素材后「画面绑定：匹配同名文件（n 个）…」可一次配上同名视频 / 图片。
- **回导**：在 DAW 里处理好的声音放回原位：选区操作栏「回导」→ 选文件，起点 = 当前选区起点，终点 = 起点 + 文件时长（越界不能保存）。
  文件复制进素材库（保持原格式），生成一条新音轨和一个新采样。
- **独立化…**：把采样用到的声音存成无损 WAV 切片、画面存成视频片段（`Library/Independent/`）。之后即使删除原素材，
  这些采样仍然可以播放、导出、读到原来的语音分析，只是不能再“返回原素材”看前后文。
- **删除原素材…**：确认框列出它的采样，可以勾选要先独立化的，点「独立化 n 个并删除原素材」。原素材记录变成“媒体已释放”，留在作品组里。
  磁盘上的原始文件和你导出过的文件永远不会被删。

## 14. 设置、存储与撤销

- 设置按组：通用、推理设备（ONNX 硬件加速：Windows 用 DirectML、macOS 用 CoreML；默认 CPU）、原素材、字幕、文本前端（用户辞典）、
  语音分析、拉平、导出、PyMSS Studio、任务（并发数）、存储与缓存、环境与模型。每次修改都可以撤销，只作用于之后的操作。
- **存储与缓存**：按类别列出占用和可清理量。「清理」只删可重建的缓存（波形、缩略图、试听渲染等）和成功的分离任务留下的中间文件，有任务在跑时不清理；
  空闲时也会自动整理（超过 1 天、或总量超过 512 MB 时）。分离成功后中间文件会自动删掉，失败的任务保留现场。原素材、素材库、测量结果、数据库、模型永远不当缓存删。
- **撤销**：Ctrl+Z / ⌘Z 或顶栏 ↶，撤销最近一次资料修改（悬停能看到是哪一次）。

## 16. 常见问题

**语音分析报“模型文件不在应放的位置”**：去 设置 → 环境与模型 下载或从文件导入。

**模型下载失败**：错误里写着下载地址和应放的位置。可以换个网络重试（任务抽屉里「重试」），或自己下载后「从文件导入…」。

**“文件在，还没校验”**：你自己放进 `Models/` 的文件还没核对过，点「检测环境与模型」。

**字幕导入报编码错误**：字幕要是 UTF-8，先转码（记事本“另存为”选 UTF-8，或交给 LLM agent）。

**台词的说话人不对 / 台词里混进了括号内容**：检查字幕写法（见[开始之前](#开始之前素材要先整理好)），或在 设置 → 字幕 改说话人规则（可以试算），再「按当前规则重新生成说话人」。

**从台词段批量建采样提示“要先指定默认轨”**：在「人声 / 音效与默认轨…」指定默认人声轨，或多选后「把原混音设为人声与默认人声轨（n 个）」。

**分离提示找不到 PyMSS Studio**：安装 Studio，或在 设置 → PyMSS Studio 里指定安装位置和数据目录。

**原素材移动了位置**：在原素材文件夹里移动的，重新扫描就会认出来；不在文件夹里的，右键「重新定位…」，多个一起搬家时勾选后「重新定位（n 个）…」选新文件夹。

**对齐不准**：先确认台词段的文字和边界对、默认轨是不是人声轨（分离后对得更准）；再用用户辞典修读音，或手动编辑音素时间。

**磁盘不够**：设置 → 存储与缓存 清理缓存；也会清理旧版遗留的、已成功分离任务的私有中间文件（保留日志，失败任务的证据不自动删除）。新分离任务成功登记成品后会自动回收输入/输出 WAV，MP3 成品不会被清理。不再需要整集的原素材，可以先独立化要留的采样再删除原素材。

**数据在哪**：工作区里——`Library/`（生成的音轨与导出，可以直接在文件管理器里用）、`Models/`（模型）、`Data/`（数据库与缓存，不要手动改）。

## 17. 让 agent 操作 OttoSmasher

能在你电脑上跑命令的 LLM agent（Claude Code、Codex 等）可以通过命令行 `otto` 操作**正在运行的** OttoSmasher：
它调用的就是界面用的那组功能，所以 agent 做的每件事你都能在应用里看到、撤销。
分工是：应用做确定的事（存资料、分离、分析、检索、卡拍、导出）；需要判断的事交给 agent——清理写法乱的字幕、挑出说某类内容的台词、
没有字幕时找 OP / ED、看分析结果哪里不对……它用自己的推理和工具做完，再把结论写回应用（标签、台词段、OP/ED、默认轨等）。

**怎么开始**
1. 打开 OttoSmasher（命令行只连接开着的应用；关着时 `otto status` 会说没在运行）。
2. 在终端里（开发版在仓库目录下用 `tools/otto`，Windows 用 `tools\otto.cmd`）让 agent 先读说明书：`otto guide`（中文，`--lang en` 英文，`--all` 全部）。
   也可以装成 skill（agent 需要时才读对应部分，更省上下文）：`otto guide --skill-dir <目录>` 写出 `<目录>/ottosmasher/` 文件夹。
   Claude Code 放在 `~/.claude/skills/`（或项目里的 `.claude/skills/`），Codex 放在 `~/.agents/skills/`（或 `.agents/skills/`）。
   说明书分两层：正式主题（应用的事实和必须遵守的规则）和 `notes`（实测攒下的经验，不是规定）。
3. 工作区不是默认位置时，设环境变量 `OTTO_WORKSPACE` 指向它。

**示例提示词**
```
用 otto 操作我开着的 OttoSmasher（先运行 otto guide 读说明书，设 OTTO_AGENT_SESSION=game-1）。
~/Movies/otomad素材/某番 里是新下的几集和字幕：先把字幕清理成说明书要求的写法（改之前把计划给我看），
登记文件夹，把准备清单做完（分离用 HyperACE v2），把说到游戏的台词都建成语音采样、分析、打上 topic:game，
然后在这些采样里找“前两拍各一个音、第二个音长”的节奏，把命中导出到 ~/Desktop/game-hits。做完告诉我建了哪些采样、哪些拿不准。
```

**两层命令**：除了操作资料库的命令，agent 还能用一组“原始能力”——日语对齐、读音分析、测音高、按应用规则读字幕文件。
它们只计算、不改你的资料，声音可以是库外的任意文件（说明书主题 `primitives`）。

**agent 听不到声音时**：很多 agent 只能看文字和图片，听不到声音。可以给它接一个音频分析工具 audio-mcp
（看频谱图、量响度、用 Whisper 转写并给出每个词的时间）。需要装好 `uv`；在终端里运行（Claude Code）：
```
claude mcp add audio -s user -e AUDIO_MCP_WHISPER_MODEL=turbo -- uvx --from "audio-mcp[speech]==0.4.0" audio-mcp
```
Codex 写进 `~/.codex/config.toml`：
```
[mcp_servers.audio]
command = "uvx"
args = ["--from", "audio-mcp[speech]==0.4.0", "audio-mcp"]
env = { AUDIO_MCP_WHISPER_MODEL = "turbo" }
```
第一次用会下载程序和 Whisper 模型（约 1.6 GB，放在 uv 与 Hugging Face 的默认缓存里）。它只用 CPU，长音频转写较慢。

**你会看到什么**
- 顶栏 ↶ 左边的「操作历史」按钮（agent 正连着时亮一个小圆点）：按时间列出所有资料修改，写明是你还是哪个 agent 会话做的、改了几处；
  能「撤销」其中某一条（它改过的东西之后没被再改过时才行），也能按会话筛选后「撤回这个会话…」。
- agent 改了资料时，底部照常提示“资料已更新”。
- agent 要做**撤销不了**的操作（删除原素材或采样、给作品文件夹改名、清理存储、独立化后删原素材）时，应用弹出确认框，写明是哪个会话、要做什么、影响多大；
  你点「允许」才执行。2 分钟没人回答就算没执行，这个请求会留在「操作历史」最上面的“错过的确认请求”里（按钮上亮红点），
  你回来能看到 agent 当时想做什么；让 agent 继续时它会再问一次。放行时如果资料和提问时不一样了（例如那个采样刚被你改过名），不会执行，而是带着新的影响再问你一次。
- 不想每次都确认：「设置 › 命令行与 agent › 撤销不了的操作也不用确认」打开后，这些操作直接执行。这一项只有你能在应用里改，agent 改不了，也撤销不了你对它的修改。

**撤回**：agent 的每个修改都记着会话名。「撤回这个会话…」从新到旧撤销；如果某条之后被你或别的会话又改过，就停在那里告诉你。
新建的采样、分离出的音轨、导出的文件不在修改记录里，撤回不了；要删 agent 建的采样，用删除（会让你确认）。
