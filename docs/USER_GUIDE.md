## 1. 基本概念

| 词 | 意思 |
|---|---|
| **工作区** | 你的全部数据所在的文件夹：数据库、素材库（生成的音轨与导出）、模型。程序目录只读，更新应用不动工作区 |
| **原片** | 你登记的动画集数或外部音频 / 视频文件。**原片不复制、不转码**，应用只记下它的位置 |
| **音轨（资产）** | 原片里的一条声音：原混音、分离出的人声 / 音效、拉平或回导的成品。每条音轨可以有角色（人声 / 音效） |
| **台词段** | 原片上“谁在什么时候说了什么”（一般来自字幕）。语音分析靠它知道该对齐哪段文字 |
| **音效提示、区段标签** | 原片上的时间标注：哪里有个音效、哪一段属于谁 / 什么场景。采样会继承它覆盖到的区段标签 |
| **采样** | 你截取并保存的一段：绑定在某条音轨的某个区间上，有名称、性质、标签、星标、备注 |
| **性质** | 采样的用途：**语音**（台词）、**调谐单音**（有明确音高的单音）、**非调谐单音**（打击、音效）、**未分类** |
| **任务** | 耗时的操作（语音分析、分离、拉平、下载模型、导出视频…）都在后台排队执行，任务抽屉（⌘J）里看进度、取消、重试 |

应用里的资料修改（改名、标签、性质、设置…）都可以 **⌘Z 撤销**。删除原片、全局改名这类操作执行前会先给你看影响范围。

## 2. 界面一览

- **左侧导航**：采样库（⌘1）、原片（⌘2）、工具（⌘3）；下面是任务（⌘J）和设置（⌘,）。
- **顶栏**：页面自己的切换（采样库的用途：全部 / 语音 / 调谐单音 / 非调谐单音 / 未分类）、全局 **BPM**（留空 = 原速卡拍）、
  **命令与跳转（⌘K）**、撤销、⋯（管理标签、主题、快捷键）。
- **底部播放条**：任何时刻只有一个声音在放；显示正在放什么、哪个版本；最近一次导出的文件也显示在这里，可以直接拖进 DAW。
- **命令面板（⌘K）**：在输入框里也能打开。最上面是对**当前对象**（勾选的采样，没有勾选就是正在看的采样；原片页是当前原片）能做的事，
  和右键菜单一样；输入几个字过滤，回车执行。直接输入 `180` 回车 = 把 BPM 设为 180。

## 3. 第一次准备

1. **下载模型**：设置 → **环境与模型** →「下载缺少的模型」（四个文件约 187 MB）。
   - 每个模型一个下载任务，可以在任务抽屉里取消；下完核对 SHA-256，一致才放进工作区 `Models/`。
   - 网络不通时：面板上每个缺的模型都写着下载地址和应放的位置。用浏览器或别的途径下载后，点「从文件导入…」
     选文件或整个文件夹，应用按内容认出是哪个模型并复制过去（文件名不对也行）。
   - 「检测环境与模型」重新核对文件；「实测（当前设备设置）」对每个模型做一次最小推理，确认真的能跑。
   - 拉平用的 PC-NSF-HiFiGAN 是**非商业许可**（CC BY-NC-SA 4.0），面板上有写。
2. **PyMSS Studio（只有分离需要）**：设置 → **PyMSS Studio**。没找到时点「打开 PyMSS Studio 发布页」下载安装，
   在 Studio 里装好推理环境、下载分离模型，回来点「重新检测」。找到后可以把一个人声模型设为默认。
3. 需要的话看一遍 设置 → **通用 / 原片 / 字幕**：作品与集数的推断规则、字幕说话人的解析规则都可以改，每项都写着默认值怎样生效。

## 4. 原片：登记、播放、台词

**登记**：原片页左上「＋」选文件，或把文件 / 文件夹拖进原片页。也可以在 设置 → 原片 里登记**原片文件夹**，以后重新扫描就能发现新文件。
登记后按文件名推断作品和集数（可在「作品与输入设置…」里改），列表按作品分组。

**播放**：时间线上点一下跳到那里。焦点在查看器时：空格 播放 / 暂停，⇧空格 只播选区（到终点精确停下），L 循环选区，F 适合窗口，Z 放大选区，←/→ 逐帧，Esc 清除选区。
拖动框出选区后，选区操作栏里有 截取、拉平、分离、回导、导出。
波形卡右上的「频谱 ▾」可以切到对数 / 线性 / Mel 频谱（视口 30 秒以内）。

**台词（文本层）**：原片 ⋯ →「导入字幕…」：选 SRT / ASS，预览每行是台词还是音效、解析出的说话人，勾选要导入的类别（台词段、音效提示、说话人、OP/ED）后导入到文本层；再导入时，你手改过的段受保护。
- 台词段可以直接编辑文字、边界、说话人；改文字或边界后，这段已有的语音分析停用，要重新分析。
- 「从字幕识别 OP/ED」「OP/ED…」：标出片头片尾，语音分析默认跳过它们。
- 「按当前规则重新生成说话人」：改了说话人规则后用；手改过的段不动。
- 时间线右键「新增区段标签…（当前选区）」：给一段时间打标签（例如 `character:京子`），落在里面的采样会继承。

**音轨与默认轨**：原片 ⋯ →「人声 / 音效与默认轨…」：给音轨标角色（人声 / 音效），指定默认人声轨。批量建采样、语音分析默认用默认轨。

## 5. 截取采样

- **手动**：时间线上框选 → 选区操作栏「截取」→ 名称（按命名规则给出建议，可改）、性质 →「保存为新采样」。
  保存后跳到采样库并打开它。
- **批量**：原片 ⋯ →「从台词段批量建采样…」或「从音效提示批量建采样…」：整页表格，勾选、指定音轨后一次创建。
- **整段**：原片 ⋯ →「建立全长采样…」（外部短音频常用）。
- **从采样库导入音频**：采样库的「导入」：选文件或文件夹，每个文件登记成一个原片，可以顺便建全长采样、按同名自动绑定画面。

采样只记“哪条音轨的哪个区间”，不复制声音；导出时才生成文件。

## 6. 采样库：浏览、筛选、整理

**列表与舞台**：左边是列表，右边是舞台（当前采样的画面、波形、语音、节奏、资料）。
- 空格 = 试听原声，**B** = 试听卡拍；**1 / 2 / 3 / 0** = 设为 语音 / 调谐单音 / 非调谐单音 / 未分类；**S** = 星标。
- 勾选框多选，⌘A 全选当前条件下的全部；勾选后顶部「批量操作 ▾」与右键菜单作用于勾选集。
- 列表第二行随性质显示：语音 = 节奏小图 + 音块数；调谐单音 = 音名 + 音高曲线；非调谐单音 = 起音时间 + 包络。

**查找栏**：
- **文字**：搜名称、备注，以及采样读到的台词段的原文和**读音**（搜「きょう」能找到「今日」）。
- **表达式**：标签表达式，`NOT` > `AND` > `OR`，可用括号、双引号，`命名空间:*` 匹配整个命名空间。写错时整框标红，下面写第几个字符出错。
- ★：只看星标。

**范围行**（查找栏下面）：「＋」按分面（作品、类型、人物、音高、其他）加条件，每个值后面写着采样数；同一分面内是“或”，不同分面是“且”。
单击人物块切换“只要单人”。⚑ 把当前范围**存为筛选器**，以后一点就用；改动后可以「更新」或「另存」。

**标签**：
- 批量「添加标签… / 移除标签…」「编辑资料…」都是先预览（逐字段前后对比）再应用，⌘Z 撤销。
- 舞台上的标签按分面分组，淡色写来源（本地 / 区段 / 原片 / 自动）；点一下继承来的标签可以「去来源」改原来的标注。
- 顶栏 ⋯ →「管理标签…」：按分面列出所有标签和计数，可以**全局改名或移除**（人物改名会连台词段的说话人一起改），应用前先给影响预览。

## 7. 语音分析

语音分析 = 文本前端（把台词转成音素和读音）+ pydomino 对齐（找出每个音素的时间）+ 派生（音块、停顿、语段），必要时顺便测音高。

- 入口：采样右键 / 舞台语音卡「语音分析…」、批量操作、原片 ⋯「语音分析…」（按原片的台词段批量）。
- 确认框写清：将分析几条、几条已是最新跳过、几条无法处理（原因，例如没读到台词段）。
- 分析结果属于“台词段 + 音轨”：同一段台词在同一音轨上只分析一次，所有读到它的采样共用。
- **对不准时**：舞台波形上切到“音素”层，「✎ 编辑音素时间」拖边界（保存为人工版本，不会被重新分析覆盖）；或者改台词段的文字、
  在 设置 → **文本前端 → 用户辞典** 里给专有名词指定读音（每行 `表记<Tab>読み`，可以先「预览」一句看结果），再重新分析。
- 读音预测用 tsqyomi；只用 pydomino 一个对齐模型，失败不会自动换模型重试。

## 8. 节奏与卡拍

- 舞台的「节奏与卡拍」面板：音块（每个元音 / 拨音一块）、停顿与语段、卡拍方案（近快 / 近慢，几格一拍）、原句与卡拍的时间映射。
- **BPM** 在顶栏，全局一个；留空 = 保持原语速的卡拍。改了 BPM 会停止试听，方案按需重算。
- 试听：空格 = 原声，B = 卡拍；面板里还能选“原声 + 咔哒”“纯咔哒”听节拍。
- 不满意时：「人工占格」改每块占几格；「在音素前拆开」处理同一元音重复发音；「语段切分」在音块前切开或合并自动切口；
  「按 mora（临时）」只在舞台上临时试听，「写进人工占格」才保存。都可撤销。
- 卡拍是保音高伸缩（Rubber Band R3）：每块的起音核心逐样本保留，只伸缩中间的“桥”。

## 9. 三大搜索

采样库列表上方的检索按钮（随用途显示「节奏检索」「音高检索」「音色筛选」「瞬态筛选」，▾ 可以换）打开检索浮层：

- **节奏检索（语音）**：一串音块，每块可以写条件（辅音、元音、相对音高 / 响度），在网格上画出每块的时值（拍）。
  节奏策略选“不限节奏 / 必须满足节奏 / 按相似度排序”；首尾选“任意位置 / 从句首 / 到句末 / 句首与句末”。
  有 BPM 时按 BPM 比较，没有时比较归一化的节奏形状。
- **音高检索**：画几个音高块（时长 + 音名或范围），在采样或整条原片音轨上找；可以忽略八度。
- **单音 · 音色 / 瞬态**：按测出来的指标（有效声音时长、起音上升时间、谱质心、噪声倾向…）给范围，即时筛选列表。
- 浮层上写着覆盖情况（多少条已就绪）；缺索引时可以「准备…」（语音分析后会自动在后台准备）。
- 「查找」后结果固定成一个标签页（不随资料变化自动重算，失效的命中会标出来）；每个命中可以定位、试听（原声 / 卡拍）、
  保存成新采样、拉平、导出 WAV / 卡拍 WAV / 视频片段、复制 REAPER 交接——都在命中的右键菜单里。

## 10. 拉平

把一段声音的音高拉成一个音（自动定音，或指定目标），用 PC-NSF-HiFiGAN 重新合成。

- 入口：采样右键 / 舞台「拉平…」、时间线选区「拉平」、命中右键、批量。打开拉平台：选处理范围（整段 / 仅元音 / 从首个元音起 / 内部拉平，首尾保留）、
  目标（段内自动 / 交界自动 / 手动指定音名）。
- 成品是一条新的音轨（放在素材库 `Tracks/…/Flatten/`），在原片上照常截取、导出。

## 11. 人声分离

- 需要另外安装的 PyMSS Studio（见第 3 节）。原片 ⋯「整片分离…」或时间线选区「分离」：选模型（人声模型或三轨模型）、范围。
- 分离结果是新的音轨（`Tracks/…/Separation/`），整片分离一次后全集复用。可以把人声轨设为默认轨，之后批量建采样、语音分析都用它。
- 模型没在 Studio 里下载时会报错，请到 Studio 里下载；本应用不会替你下载分离模型，也不会换别的模型。

## 12. 交接：导出、REAPER、视频片段

舞台的「交接 ▾」、右键菜单、批量操作里都有：

- **导出原声 WAV / 卡拍 WAV**：文件放在 `Library/Exports/<日期>/`，同样的请求会复用已导出的文件。
- **拖出**：按住 ⌥ 拖动 = 拖出原声 WAV，⌥⇧ = 拖出卡拍 WAV，可以直接拖进 DAW 或 Finder。播放条上最近导出的文件名也可以直接拖。
- **复制 REAPER 交接（⌘C）**：两种——“卡好拍＋起音标记”或“原声＋拉伸标记，可再调”（默认用哪种在 设置 → 导出）。
  到 REAPER 里粘贴即可；文件放在 `Library/REAPER/<日期>/`。
- **导出视频片段…**：原声版，或卡拍版（画面按同一映射变速 / 画面保持原速并另存卡拍 WAV）；可选不带声音。
  默认 H.264 MP4 + AAC，设置 → 导出 可改成 ProRes 422 HQ。画面超出视频流的部分补黑帧并在完成提示里写明。
  没有画面的采样会提示先「画面绑定…」。

## 13. 画面、回导、独立化

- **画面绑定…**（采样或原片）：换成别的视频（同步，可加偏移）、循环动画（GIF 等）或静态图片；优先级 采样 > 原片 > 原片自带视频。
  舞台画面在试听原声时跟着走，⤢ 放大到全宽。原片多选后「画面绑定：匹配同名文件（n 个）…」可一次给外部音频配上同名视频 / 图片。
- **回导**：在 DAW 里处理好的声音放回原位：选区操作栏「回导」→ 选文件，起点 = 当前选区起点，终点 = 起点 + 文件时长（越界不能保存）。
  文件复制进素材库（保持原格式），生成一条新音轨和一个新采样。
- **独立化…**：把采样用到的声音存成无损 WAV 切片、画面存成视频片段（`Library/Independent/`）。之后即使删除原片，
  这些采样仍然可以播放、导出、读到原来的语音分析，只是不能再“返回原片”看前后文。
- **删除原片…**：确认框列出它的采样，可以勾选要先独立化的，点「独立化 n 个并删除原片」。原片记录变成“媒体已释放”，留在作品组里。
  磁盘上的原片文件和你导出过的文件永远不会被删。

## 14. 设置、存储与撤销

- 设置（⌘,）按组：通用、推理设备（ONNX 硬件加速：macOS 用 CoreML、Windows 用 DirectML；默认 CPU）、原片、字幕、文本前端（用户辞典）、
  语音分析、拉平、导出、PyMSS Studio、任务（并发数）、存储与缓存、环境与模型。每次修改都可以撤销，只作用于之后的操作。
- **存储与缓存**：按类别列出占用和可清理量。「清理」只删可重建的缓存（波形、缩略图、试听渲染等），有任务在跑时不清理；
  空闲时也会自动整理（超过 1 天、或总量超过 512 MB 时）。原片、素材库、测量结果、数据库、模型永远不当缓存删。
- **撤销**：⌘Z 或顶栏 ↶，撤销最近一次资料修改（悬停能看到是哪一次）。

| ⌘, | 设置 |
| ⌘J | 任务与日志 |
| ⌘Z | 撤销最近资料修改 |

| Esc | 关闭面板（不会顺带清空勾选） |

| ⌘F / ⌘⇧F | 聚焦查找栏的文字 / 范围行的「＋」 |

## 16. 常见问题

**语音分析报“模型文件不在应放的位置”**：去 设置 → 环境与模型 下载或从文件导入。

**模型下载失败**：错误里写着下载地址和应放的位置。可以换个网络重试（任务抽屉里「重试」），或自己下载后「从文件导入…」。

**“文件在，还没校验”**：你自己放进 `Models/` 的文件还没核对过，点「检测环境与模型」。

**分离提示找不到 PyMSS Studio**：安装 Studio，或在 设置 → PyMSS Studio 里指定安装位置和数据目录。

**原片移动了位置**：原片右键「重新定位…」；多个原片一起搬家时勾选后「重新定位（n 个）…」选新文件夹，按相对路径或文件名一次找回。

**对齐不准**：先确认台词段的文字和边界对、默认轨是不是人声轨（分离后对得更准）；再用用户辞典修读音，或手动编辑音素。

**磁盘不够**：设置 → 存储与缓存 清理缓存；不再需要整集的原片，可以先独立化要留的采样再删除原片。

**数据在哪**：工作区里——`Library/`（生成的音轨与导出，可以直接在 Finder 里用）、`Models/`（模型）、`Data/`（数据库与缓存，不要手动改）。
