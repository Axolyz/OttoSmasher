# 12 功能规格：导出、拖出、REAPER 交接、画面与视频片段

> “DAW 交接是核心需求，不是附属功能。”【所有者原始需求】拖出 WAV 和 REAPER 交接都常用；任意采样的画面都要能导出成视频片段。
> 导出文件**不是采样**：不登记采样、不触发分析、不自动删除。

---

## 12.1 导出 WAV（含拖出）

- **内容**：当前资产的真实区间，PCM 24-bit WAV，采样率和声道跟随源；**不含**试听时的前后留白，也不受播放音量影响。
- **版本**：原声，或卡拍（烘焙后的严格卡拍，按当前 BPM 与方案）。卡拍版只能导出**完整采样或命中**（与方案对应的选区和绑定音源）。
  列表/命中的拖出**跟随该对象最近一次成功试听的版本**（左键试听过 → 原声；右键试听过 → 卡拍），没有试听过默认原声。
  这个“最近试听版本”只在本次运行期间记住。
- **从有损音轨导出**：源是 MP3 正式音轨时，按解码帧精确对齐（随机读取要预滚、丢弃编码延迟，导出首样本不能错位）。
- **位置**：默认放在素材库的导出目录（怎么分子目录由新开发者规划，§12.6）；设置了“默认导出目录”时直接放在那里。
- **文件名**（默认模板，旧版格式）：
  `<内容>__[<处理信息>__]<音轨>__<原片段>_<起止>__<导出键前 12 位>.wav`
  - **内容**：导出整个采样时用采样当前名称；导出选区或命中时用建议名（命名规则，04 §4.7）加“ · 片段”（提醒边界与字幕不一定一致）；没有原片时为“试听片段”。≤72 字节；
  - **处理信息**：拉平成品为 `拉平-<音名>`，卡拍为 `卡拍-<BPM>BPM`，两者都有时用 `_` 连接；为空时**整段省略**。≤45 字节；
  - **音轨**：按轨道角色写 原混音 / 人声 / 音效 / 拉平 / 卡拍 / 回导；其他声部写声部原名（大小写不敏感匹配角色名）。
    〔修正旧版缺陷〕旧版对不认识的角色一律写“音频”（如 `Vocals`、`instrument`）；
  - **原片段**：原片名（≤60 字节）+ `__` + 原片 ID 前 8 位，整段 ≤45 字节；
  - **起止**：原片时间 `HH-MM-SS.mmm-HH-MM-SS.mmm`；资产没有到原片的映射时写 `局部-` 加资产时间；
  - **导出键**：由“资产 + 文件身份 + 区间 + 版本参数 + 名称”算出的稳定键；
  - **可移植**：Unicode NFC；`\ / : * ? " < > |` 和控制字符换成 `_`；去首尾空格和点；Windows 保留名（CON、PRN、AUX、NUL、COM1–9、LPT1–9）前加 `_`；
    各段按 UTF-8 字节截断，整个文件名 ≤ 255 字节，保留处理信息段和导出键；保留中日文；还要考虑 Windows 完整路径长度。
    例：`日本語 / 中文` → `日本語 _ 中文__…`；`CON.txt` → `_CON.txt`。
  - **可配置**〔新：P13〕：设置里提供文件名模板（可选择/排列上面这些段），默认值就是上面的格式；模板预览给出一个真实例子。
  - 段里的固定词（音轨名、“拉平-”“卡拍-”“局部-”“ · 片段”“试听片段”）随界面语言（15 §15.7）；切换界面语言只影响之后的导出，已生成的文件不改名。
- **复用与安全**：按稳定键复用已生成的文件；同名文件被外部修改过 → 报错“已有导出文件被修改，不能覆盖”；
  生成期间源文件变化 → 报错；绑定的音轨缺失 → 报错“绑定音轨缺失，请重新定位；不能替换为原混音”。
- 导出后底部出现交接条（可再次普通拖动到 DAW、定位文件）。
- 每个导出旁可以写一个小清单（来源资产、区间、映射、版本、方案），供追溯；清单不是用户必须看的东西，放在数据目录而不是导出目录。

## 12.2 拖出手势（Option / Alt + 左键拖动）

- macOS 用 Option，Windows 用 Alt；只在桌面应用里。
- **可拖出的东西**：波形上的选区（按在选区内）或指针下的标注区间（音素、字幕、音块；只针对可见图层）；列表行（属于勾选集时拖出整个勾选集）；
  检索命中；分离结果的声部；参考音轨。不新增专门的拖拽把手；按钮、输入框、下拉、选区把手上按下不触发；普通拖动、右键行为不受影响。
- **时机**：按下时冻结导出请求；**移动超过约 4 px 才开始生成**（不在选区变化时预渲染）；生成期间提示“正在准备文件，保持按住鼠标 · Esc 取消”。
- **放弃**：生成期间按 Esc、松开鼠标、指针被取消、窗口失焦 → 放弃本次拖拽；即使后台随后生成完成，也不再发起系统拖拽
  （已生成的持久文件保留，可能被其他应用引用，不删除）。
- **进入系统拖拽后**，Esc 交给系统处理，不劫持右键。
- 生成失败要在界面上提示（旧版的错误事件没人监听，被静默吞掉）。
- 拖出手势本身是**半基线**（03 Part C）：保留“修饰键 + 拖动 = 拖出文件”的能力和上面的放弃语义，具体修饰键与提示样式可重新设计。

## 12.3 REAPER 交接

两种交接都常用，**含义不同**：

| | 拖出卡拍 WAV | 复制 REAPER 交接 |
|---|---|---|
| 内容 | 已烘焙的卡拍音频 | **未烘焙的原声** + 卡拍**拉伸标记**（可在 REAPER 里继续编辑） |
| 用途 | 直接用 | 在 DAW 里继续微调节奏 |

- **前提**：有有效的卡拍方案（需要时自动计算）。
- **原声文件**：复制到素材库的 REAPER 目录，文件名 `<名称>__<版本>__<内容哈希>.wav`；同名存在但内容不同 → 报错。
- **拉伸标记**：由时间映射的节点和受保护核心的锚点组成（目标时间与源时间都严格递增），每个起音都要有标记；
  吸附偏移：首个起音落在 REAPER 编辑光标（前导辅音留在光标之前），或以条目开头为准。
- **剪贴板格式**（REAPER 7.x 实测，macOS）：剪贴板类型 `REAPERMedia`，UTF-8，各行以 NUL 分隔，末尾两个 NUL；内容是一个 `<ITEM … >` 块：
  ```
  <ITEM
  POSITION 0 0
  SNAPOFFS <s> <s/拍长>
  LENGTH <d> <d/拍长>
  LOOP 0
  ALLTAKES 0
  FADEIN 1 0 0 1 0 0 0
  FADEOUT 1 0 0 1 0 0 0
  MUTE 0 0
  SEL 1
  IGUID {GUID}
  NAME "<标题>"
  VOLPAN 1 0 1 -1
  SOFFS 0
  PLAYRATE 1 1 0 -1 0 0.0025
  CHANMODE 0
  GUID {GUID}
  SM <目标> <源> 0 0 <目标/拍长> + <目标> <源> 0 0 <目标/拍长> + …
  <SOURCE WAVE
  FILE "<原声路径>"
  >
  >
  ```
  数值保留 12 位小数；文件路径加引号时从 `"`、`'`、`` ` `` 中选一个路径里没有的；路径含 NUL/CR/LF 或标记非单调 → 拒绝。
  写入剪贴板后回读校验，长度上限约 2 MB。提示：“已复制，在 REAPER 选择轨道和光标位置后粘贴”。
- **试验入口**：导出同内容的 `.RTrackTemplate`（换行分隔、只有 ITEM）——REAPER 文件解析与系统拖放分别验收。
- Windows 上的实际粘贴/拖放**未实测**，在实测前不得宣称可用。
- 每次交接写一份交接清单（方案、版本、吸附方式），放在 REAPER 目录。

## 12.4 画面绑定

- **模式**：
  - **同步视频**：画面时间 = 采样本地时间经映射换算的原片时间（分段映射照样适用；例：映射 [(0,10),(0.5,11),(1,14)]，本地 0.75 → 12.5 秒）；
  - **静态图片**；
  - **独立循环动画**：画面位置 = 采样本地时间 mod 动画时长（例：0.6 秒的循环，本地 1.45 秒 → 0.25 秒）；
- **优先级**：采样自己的绑定 > 原片的默认画面绑定 > 原片自带的第一条视频流（同步）。没有视频流的原片默认无画面。
- **时钟**：音频是唯一主时钟；画面一律静音；同步视频偏差超过约 0.08 秒才重定位；画面暂停时**不能靠逐帧反复 seek 维持同步**；
  播放速率超出可支持范围时暂停画面而不是乱跳。
- 编辑：「画面绑定…」（采样或原片），走可撤销编辑通道；绑定文件记录大小和修改时间，变了要报错。
- 缩略图同样遵守画面绑定（变化后失效）。

## 12.5 视频片段导出（新增，P1）

【所有者，2026-10-04】旧版的“导出选区视频”实际只导出 JSON 映射清单；新版要**导出真实的视频文件**，任意采样都可以，供 AE 等软件直接使用。

- **入口**：采样详情菜单「导出视频片段…」、列表/批量导出、命中右键、原片页选区操作栏的「导出 ▾ → 选区视频片段」。
- **画面来源**：按 §12.4 的画面绑定（同步视频取原片对应时间段；图片生成静止视频；循环动画按循环规则生成）。
- **版本**：
  - 原声版：画面按原速；
  - 卡拍版：**两种都提供**，导出时选择——画面按与卡拍音频**同一条时间映射**变速（音画同步，直接可用），或只导**原速**画面（变速在视频软件里自己做）。
- **取帧规则**〔推定 A24〕：输出的每一帧，按其时刻经（卡拍时为时间映射的逆）换算到原片时间，取**最近的源帧**，不插帧、不做光流；
  图片绑定按输出帧率重复同一帧；循环动画按“本地时间 mod 动画时长”取帧。输出帧率跟随原片（图片/循环且无原片视频时用动画自身帧率，图片默认 30 fps）。
- **画面超出视频流范围**〔推定 A24〕：（例如有的原片音频比视频长 4.5–28 秒，外部 MP4 的视频从 0.125 秒才开始）该部分补黑帧并在完成提示里说明，不移动音频。
- **声音**【所有者，2026-10-05 同意建议默认】：默认把对应版本的音频（同 WAV 导出）作为音轨带上，可选不带。
  卡拍版选“原速画面”时，画面与卡拍音频时长不同：默认带**原声**，并在旁边另存卡拍 WAV 和映射清单〔推定 A24〕。
- **格式**【所有者，2026-10-05 同意建议默认】：默认 **H.264 MP4 + AAC**；设置里可选高质量中间编码；分辨率跟随原片。
- **命名与位置**：同 WAV 导出的命名规则（扩展名不同），放在导出目录。
- **复用/安全**：同 §12.1。
- 可以同时写一份映射清单（采样 → 原片时间、画面模式、循环规则），作为辅助信息。

## 12.6 素材库目录（用户可见，基线）

**基线要求**（保留旧版要求）：

- 应用在工作区里有一个**用户可见的素材库目录**，放共享的正式生成音轨（分离声部、拉平成品、回导成品等）、
  按需导出的 WAV/视频片段（未设置导出目录时）、REAPER 交接用的原声和交接清单/条目文件。
- 原片留在用户登记的位置；数据库、索引、可清理缓存放在工作区的数据目录（不在素材库里）。
- 用户可以直接打开这些目录找文件；**重命名、移动、替换**素材库文件会破坏引用，要通过应用处理（重新定位 / 回导）。
- 素材库里的正式音轨和导出文件**不是缓存**，不会被自动清理。
- 不要在用户可见目录里留下 `.lock`、`.part` 之类的临时文件（旧版残留了大量零字节锁文件）；文件名不能出现程序内部数据（旧版拉平文件名里漏进了字典字面量）。

**新要求**【所有者，2026-10-05】：

- 素材库里的**目录名一律用英文**（旧版是 `素材库/音轨/`、`素材库/导出采样/` 这样的中文目录）。文件名里的内容部分（采样名、原片名）照常保留中日文。
- **具体怎么组织由新开发者自由规划**（按原片、按类型、按日期都可以），只要满足上面的基线要求，并在应用里能一键打开对应目录。
  仅作示意（不是要求）：`Library/Tracks/<source>/`、`Library/Exports/<source>/`、`Library/REAPER/`。
- 文档里的“素材库”“导出目录”“REAPER 目录”都指这里规划出的英文目录。
