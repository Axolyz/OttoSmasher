# 05 功能规格：原片、播放、音轨与分离

> 页面职责见 03 §3.5；概念见 04。本文件写**业务行为、默认值和失败语义**。

---

## 5.1 原片登记

- **输入**：一个或多个本地文件路径（系统文件选择，可多选）。能解码且**至少有一条音频流**的视频或音频都可以登记；
  没有音频流时报“原片没有音轨”。常见：MKV/MP4/MOV/WebM（HEVC Main10 + FLAC 很常见）、WAV/FLAC/MP3/M4A/OGG。
  音频文件里的封面图（attached picture）**不算视频**。
- **路径**：必须支持空格、方括号、日文、中文、全角符号、`♪`、`♯` 等（测试素材的文件名就是这样）。
- **登记做什么**：记录位置、内容指纹、时长、音视频流信息；推断作品和集数；关联同名字幕（只关联，不导入）；
  默认分析音轨 = 语言标记与“首选语言”（设置项，默认日语）相同的第一条，否则第一条。〔中英文预留〕将来中文、英文原片用同一规则。
- **登记不做什么**：不复制、不转码、不分析、不建采样、不要求字幕。同一路径重复登记返回已有原片并保留用户设置。
- **作品/集数推断**（只在首次登记时推断，之后用户改的为准）：
  - `[VCB-Studio] Yuru Yuri [01][Ma10p_1080p].mkv` → 作品 “Yuru Yuri”、集数 “01”；
  - `[DBD-Raws][Kemono Friends][02][1080P].mkv` → “Kemono Friends”、“02”；
  - `[Kemono Friends][01].mkv` → “Kemono Friends”、“01”；
  - `作品名 - 01.mkv` 形式同理；不能把发布组名或集数当作品名。
- **多音轨**（如 YY2 的两条日语 FLAC）：所有音频流都登记为可用的原始声音资产；默认分析音轨可在设置里随时改，
  只影响之后的默认播放与分离，已有采样不受影响。
- **登记后界面**：刷新列表，打开第一个新原片，并弹出「作品与输入设置」（只为第一个）。

## 5.2 原片设置

- 作品名、集数、来源类型：实时影响所有派生采样的 `work:`/`type:` 继承标签（集数不是标签）。各最多约 200 字。
- 字幕文件：关联 .srt/.ass，可清除；关联不等于导入标记。
- 分析音轨：见上。
- 修改走可撤销的编辑通道。

## 5.3 原生播放

### 5.3.1 必须达到的播放能力

- 在应用窗口内**嵌入**播放 1080p HEVC 10-bit + FLAC 的整集 MKV（约 24 分钟、600 MB–1 GB），打开后立即可播、可随意跳转，
  **不做整集转码或代理文件**。旧版的整集代理（首次准备 46 秒）和 HLS 分片（要等转换、累积重复缓存）都被淘汰过。
- 可以用**另一个音频文件**（分离出的声部）替换原片音轨与视频同步播放：外部音频按映射对齐到原片时间（例如音频延迟 = 原片范围起点 − 资产选区起点），
  加载外部音频期间原音轨必须静音。
- **范围播放精确截停**：播放选区时由播放引擎自己在终点停止（旧版验收：界面线程阻塞 700 ms 时仍在终点停止，误差 ≤ 2 个 48 kHz 采样）；
  支持 A-B 循环；任何普通跳转或“播放/暂停”先清除范围限制。**前端进度不能作为停止依据**。
- 逐帧移动（帧长按视频平均帧率；无视频按 1/25 秒）、Shift 按 1 ms 移动。
- 字幕：把当前时刻所有有效字幕的原文（换行拼接）**画在画面内部底部**（白字黑边，按画面高度缩放），按纯文本处理不执行样式指令；
  不显示媒体文件自带或自动发现的字幕轨（避免与所选字幕版本重复或冲突）。
- 被弹窗、下拉、抽屉等遮挡时，若原生画面层在网页之上，需要隐藏或裁剪，不能盖住弹窗；切页/不可见时自动暂停。
- 纯音频原片显示纯音频控制条，不留空白画面。
- 原生播放不可用时**明确报错**，不悄悄换成其他播放方式。
- 时钟：界面显示的本地时间 = 播放引擎时间 − 播放范围起点；换音源时用请求代次丢弃旧事件，旧状态不能覆盖新音源。

### 5.3.2 波形与可视化

- 波形峰值在后台生成，**不阻塞**视频打开和跳转；挂上波形时不把播放头拉回起点。长音频峰值点数有上限（旧版 ≤32000 点）。
- 频谱细看：取当前视口起最多 30 秒的**所选音频**（不是对波形峰值做 FFT），固定 −90–0 dB，刻度可选对数/线性/Mel，点击定位主播放器；越界报错、文件变化报错。
- 采样详情的波形叠加：金色 F0 线（只画可靠的实测帧，缺口处不插值）、半音横线与音名刻度（悬停显示“A4 +12 音分 · 1.23s”）、
  ◆ 音块标记、休止区间、命中区。原片页波形不画 F0。
- 分层：音素层（太窄时隐藏文字）、字幕层（“字幕 · 前 24 个字”）、区段标签层（含说话人单独一行、OP/ED）。图层可开关，吸附与拖出只作用于可见图层。
- 原片视口里的音素层：读取**在同一物理声音上测得的**对齐结果（可来自多次、多句分析，按视口 ±0.5 秒读取），**不推理**；
  换成没测过的音源就不显示，绝不借用其他音源的测量。

### 5.3.3 选区规则

- 一个视图只有一个选区，半开区间；拖动超过约 3 px 才建立选区，单击只定位。
- 选区只能拖两端调整，不能整体拖动。
- Shift+单击：选中光标下的整个区间（字幕优先于音素；音素用能量派生的有效范围）。
- Shift+拖动：按**原始手势范围**把与之重叠的字幕/音素区间并进来，只扩一次、不级联，正反向对称
  （例：区间 [1,2]、[1.9,4]、[3,5]，手势 (1.1,1.5) → (1,2)；手势 (2.5,1.5) → (1,4)；手势 (6,7) 不变）。
- 数字框可直接输入开始/结束（3 位小数）；I/O 设为播放位置。
- 切换音源、切页、后台任务完成都**不清空选区**。

## 5.4 音轨、角色与默认轨

- **参考音源列表**：原混音（容器音频流）+ 该原片的所有分离声部资产（标题“模型 · 声部”，显示覆盖范围；完整覆盖原片的排在前面）。
  只覆盖部分范围的分离结果也列出，但只能在其覆盖范围内播放（越界时报“此音轨仅覆盖原片 a–b 秒”）。
- **挂到原片时间轴的条件**：资产未变速、覆盖所请求的范围；否则明确报错，不回退原混音。
- **角色与默认轨**（见 04 §4.2.3；角色是每个声音资产的属性，取代旧版的“轨道组”〔新：19 F1〕）：「人声／音效与默认轨」弹窗只列容器音频流 + 完整覆盖原片且未变速的资产；
  角色可多选（人声、音效，一条轨可兼两个角色）；每个角色一个默认轨；改动立即保存（可撤销）。非整轨资产（如拉平成品）的角色在采样详情里改（03 §3.3）。
- **角色预填**：分离结果按“声部名 → 角色”别名表预填角色（不分大小写；设置里可改）——默认 `vocals` → 人声【旧版只有这一条】；`dialog`/`dialogue`/`speech` → 人声、`effect`/`effects`/`sfx` → 音效【推定 A9】；其他不预填。
  分离声部不继承输入资产的角色；拉平、回导成品则继承（见 04 §4.2.4）；
  **不自动设为默认轨**。
- 没有默认轨时，需要它的操作（字幕采样）在弹窗里提示“请先指定默认人声轨/音效轨”，并就地提供可选整轨的下拉，选定后继续；
  （语音分析不需要默认轨：它分析每个采样实际绑定的声音，见 08 §8.4。）
  **不隐式使用混音**。混音可以被手动赋予角色。

## 5.5 分离（调用外部 PyMSS Studio）

> Studio 的接入契约（探测、进程协议、模型列表、事件）见 14 §14.6。本节是业务规则。

### 5.5.1 两种方式、两种范围

| | 人声方式 | 三轨方式 | 其他模型（只用于选区分离：同一个分离弹窗在范围为“当前选区”时可选） |
|---|---|---|---|
| 可选模型 | Studio 中**已下载完整**、声部（不区分大小写）含 `vocals` 的模型；默认取设置里的“默认人声模型” | 已下载、声部经别名归一后同时含对白/音乐/音效的模型（对白：speech/dialogue/dialog；音乐：music；音效：effects/effect/sfx） | Studio 中**任意**已下载完整的模型（如去混响、乐器类模型），用于音效等素材的加工 |
| 输出 | 模型的全部实际声部（或用户选择的子集），如 `vocals` + `instrument`、`Vocals` + `Instrumental` | 对白、音乐、音效三个声部（保留模型给出的原名） | 用户选择的实际声部（空 = 全部） |
| 用途 | 对白分析与台词采样（人声）；伴奏/残差声部可作音效来源 | 鼓组/音效素材（音效声部），干净对白 | 灵活场景 |

- **范围**：整片连续音轨（原片 0 到时长）或当前选区。整片分离是“准备一次、全集复用”的前提。
- **输入**：提交时的“当前参考音源 + 音轨”的实际资产选区，**提交时冻结**；不要求字幕或任何分析。
- **设备**：取设置里的分离设备（自动/CPU/CUDA+编号/MPS），提交时冻结；“自动”交给 Studio 决定。设备不影响结果复用判断。

### 5.5.2 结果

- 每个声部登记为一个新声音资产：声部名**保留 Studio 给出的原样**（`Vocals` 与 `vocals` 都可能出现）；映射沿用输入；记录模型身份（名称 + 权重/配置文件指纹 + Studio 版本）和参数。
- 校验：每个输出必须存在、位于该任务的输出目录内；按输出采样率换算，与输入的样本数相差超过 1 就拒绝整次结果
  （与 04 不变量 6 一致；输出采样率可以与输入不同）；
  所选声部必须全部产出；任务期间模型或运行时变化则拒绝。任何不完整都**不登记残缺结果**。
- 结果**不登记为采样**。任务抽屉「打开结果」→「分离结果 · 声音资产」：每个声部可试听、保存为采样（名称“建议名 · 声部”，性质默认未分类）、Option/Alt 拖出。
- 结果出现在参考音源列表（三轨任务完成后也要刷新列表）。
- 复用：同一输入（同一原片内容 + 音轨 + 范围）+ 同一模型版本已经分离过的，可以直接复用已有资产，不重跑。
- 长音频：优先把整段交给 Studio（按模型配置内部分块）；若必须自行分块，要有重叠和交叉淡化、按原片采样时钟对齐、
  不允许缺口（任何一块失败整体失败，不用静音补）。

### 5.5.3 失败

- 找不到 Studio、没有活动推理环境、模型未下载、声部能力不符、设备不可用、输出缺失或时长不符——任务失败，给出具体原因和 Studio 日志位置；
  **不替 Studio 安装依赖、不下载模型、不换模型、不回退其他分离方式**。
- 失败任务保留输入/日志等排查证据；可以“重试”（新任务，使用当前设置）。

## 5.6 OP/ED

### 5.6.1 从字幕识别（显式操作，单个或批量）

1. 读取原片关联的字幕文件，对每行去掉样式标记和空白，把 `〜`（U+301C）统一成 `～`（U+FF5E）。
2. **只认**整行恰好为 `♪～` 的行为“开始”，恰好为 `～♪` 的行为“结束”（`♪ 歌詞` 这类歌词行不是标记）。
   开始/结束标记是**设置项**（P13 可配置项；默认就是这两个，可各填多个），换一种字幕写法时用户改设置，程序里不加特判。
3. 开始行的起点到结束行的终点为一个音乐区间。
4. 错误：重复开始、结束缺开始、开始缺结束、超出原片或时间倒置、超过两个区间（“需要人工指定用途”）。**有错误就不自动登记**，
   但结果弹窗仍列出已配对成功的区间（按前后半片给出 OP/ED 建议），用户可逐行改用途并「确认此区间」（来源记为人工确认）。
5. 恰好两个区间：前者 OP、后者 ED；一个区间：中点在前半片为 OP，否则 ED。
6. 与已有区间（包括人工标记）重叠的不覆盖；结果来源记为“字幕规则”，直接生效、可在表中删除。

真实数据中的已知情况（都可在测试素材复现，见 fixtures）：KF 用 `♪〜`/`〜♪`，YY 用 `♪～`/`～♪`；KF01、KF11 只有 ED 一对；
KF12 把 OP 曲当插入曲用并出现重复的开始/结束标记（报告错误）；YY2-06 有三对（报告）；YY2-08 有孤立结束标记（报告）；
YY2-11 没有 OP，但插入曲会被识别成 OP（用户撤销该标记，或撤销后按正确用途重新确认/手动标记——这是被接受的简单规则的代价）。

### 5.6.2 手动标记与排除语义

- 旧版的“参考帧扫描”（用一张 OP/ED 画面在视频里找候选区间）**已去掉**【所有者，2026-10-05】：OP/ED 只来自字幕规则（§5.6.1）和手动标记。

- 手动标记：原片、开始秒（可预览）、用途、长度；范围必须在原片时长内。
- **排除语义**：确认的 OP/ED 只影响：字幕采样预览（标“OP/ED 排除”，不可勾选）、批量语音分析的范围（按采样文本快照里的原字幕区间判断）、
  原片列表的句数/已分析计数。**不影响**：字幕标记导入（OP/ED 内的字幕照样登记为标记）、手动播放、手动截取、整轨分离、
  已有采样的显示（事后确认的 OP/ED 不会把已建的采样从采样库里藏起来）。
  部分重叠的字幕在标记预览中标出“跨 OP/ED 边界”。
- 撤销/删除标记不删除已有采样。
- OP/ED 绑定原片实体，重新定位文件后仍有效。

## 5.7 重新定位、删除

- **重新定位**：选一个新文件 → 确认（“只改文件位置引用，不校验内容和时长”）→ 原片指向新文件；已有资产、时间、分析、OP/ED、采样不变；
  之后播放和解析都走新路径；来回定位不改变任何身份。
- **删除原片**：见 04 §4.5。确认框列出将删除的采样数、生成音轨/成品文件数与大小；原片文件和导出文件不删；有相关任务运行或排队时拒绝。
- **采样独立化**（刚需）：见 04 §4.8。

## 5.8 原片列表的统计

- 句数 = 当前字幕版本中、不在 OP/ED 区间内的台词标记数；“已分析” = 其中至少有一个“由它创建的采样”或“以它为文字区段的资产+文字对象”
  具有有效对齐结果的标记数（测量属于采样或资产+文字，不属于标记本身）；“无字幕” = 没有导入过标记。
- 这些计数在相关任务完成后刷新（按任务影响的原片失效）。
