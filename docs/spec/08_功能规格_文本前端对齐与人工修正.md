## 8.1 一次“语音分析”包含什么

对一个采样（或“资产选区 + 文本区段”）做语音分析 =

1. **文本前端**：对齐文本 → 音素序列 + mora 映射 + 读音（§8.2）；
2. **对齐**：pydomino 在音频窗口上求每个音素的时间（§8.3）；
3. **派生**：元音/N 的有效范围（§8.5）、起音强度（§8.6）、停顿、停顿段、音块、语段（09）；
4. **音高与能量帧**（FCPE，见 10）——如果该声音还没有测过。

从任何入口发起的语音分析都必须产出**同一套**派生结果。〔修正旧版缺陷〕旧版的单条重跑少算了起音强度和覆盖估计，两边不一致。

## 8.2 文本前端（G2P）

### 8.2.1 对齐文本的选择

优先级：人工对齐文本 > 字幕行的自动对齐文本（去掉注释括号，见 06 §6.2）> 采样文本快照。结果记录文本版本和“是否等于原字幕”。

### 8.2.2 规范化（逐码位替换，保持字符位置不变，以便词/字符定位精确）

- 三种波浪号 `～`（U+FF5E）、`〜`（U+301C）、`~` → 长音符 `ー`；
- 空白（含全角空格、换行、Tab）与标点类字符 → `、`（视为停顿）；
- **符号类字符**（如 `♪`、`☆`）也按停顿处理，不得被读出来。〔修正旧版缺陷，18 A14〕旧版把 ♪ 读成「きごう」；
- 例：`〜~～！\t。` → `ーーー、、、`；`あ～, ええ` → `あー、、ええ`。

### 8.2.3 音素与 mora

- 用 pyopenjtalk-plus（启用 tsqyomi 读音预测，见 14）把规范化文本转成音素序列和“音素 ↔ 文字 ↔ 读音”的对应。
- 停顿类标签（pau、sil、sp、SP）统一记为 `pau`，连续的只留一个；**重复元音保留不合并**（「ええ」→ e e）；清音元音 I/U、拨音 N、促音 cl 原样保留。
  例：`あ～, ええ` → 音素 `a a pau e e`。
- mora：把读音（片假名）切成 mora，小写的ァィゥェォャュョヮ并入前一个字，「ー」单独成一拍。
  每个词只有在“核心音素数（a i u e o A I U E O N cl）= 该词 mora 数 = 切出的 mora 数”时才建立音素→mora 映射；辅音归属它后面的核心音素所在的 mora；
  对不上时映射为“未知”（不硬凑）。例：`a a pau e e` 的 mora 归属为 `0 1 未知 2 3`。
- 每个 mora 记录对应的原文词、字符范围、读音，用于命名（“原文 — かな”）和词定位。
  词定位只在长音等价时做归一：「まず大きく５つの気候帯に分離」配读音「マズオーキクイツツノキコータイニブンリ」可以定位到「大きく」「気候帯」；读音不匹配（如「猫」配「イヌ」）就不定位。
- 前端结果带版本（前端算法版本 + 辞典版本 + tsqyomi 模型版本），写进每条对齐结果。

### 8.2.4 用户辞典

- 全局一份。每行 `表记<Tab>片假名读音`：表记非空、不重复、≤200 字；读音只能是片假名（ァ–ヺ）与「ー」、≤200 字。错误要报行号（如“第 2 行”）。
- 保存时编译成形态分析器的用户辞典：先编译到临时文件、加载验证，成功后**原子替换**；失败时当前生效的辞典不变。
- 乐观并发：编辑期间辞典被改过则拒绝保存。辞典里的读音受保护（不被读音预测覆盖）。
- 预览：输入一句话（默认「京子が来た。」）看生成的音素和读音。
- 改辞典**不自动重跑**已有对齐；新的分析才使用新辞典。
- 实例（测试素材）：`歳納<Tab>トシノウ`。

### 8.2.5 前端失败

空文本、读音预测模型未准备或版本/指纹不符、辞典文件缺失 → 明确报“文本前端失败：原因”，该项分析失败（不跳过前端硬对齐）。

## 8.3 对齐（pydomino）

### 8.3.1 目标与窗口

- 每次对齐只送**本句**文本（该采样或所选文字区段自己的对齐文本），**不带邻句上下文**。
- **目标区间 = 采样选区**，所有入口一致〔新：所有者 2026-10-05，18 D41〕；字幕采样的选区就是“字幕区间 ± 扩展”（默认各 0.1 秒）。
  详情里的局部分析以当前选区为目标，文本为所选文字区段。
- **窗口** = 目标两侧各扩展**对齐容差**（默认 **0.65 秒**，可分别设 0–5 秒）；只在**同一物理声音**（同一文件、同一音频流、映射一致）的范围内扩展，
  记录请求的和实际的扩展量、是否被资产边界截短。
- 旧版两条路径的目标不同（批量用原字幕区间，单条重跑用采样选区），批量还会给手输文本的采样混入重叠的字幕行（同一段话送两遍）；新版统一，不再区分。
  `fixtures/reference/YY1-01_pydomino_fa_old_output.json` 正是“采样选区 ± 0.65 秒、只送本句”的结果，可以直接对比。
- 音频：按需从资产解码该窗口（不永久保存模型输入副本），用**带抗混叠的多相重采样**转成 16 kHz 单声道（各声道平均）。
  旧版参考输出就是这样重采样的；更换重采样方法前要先对比参考输出。

### 8.3.2 归属与输出

- 送入模型前按 14 §14.3 准备序列（清音 I/U 转为 i/u，`sil` 记为 `pau`，每句后加 `pau`，最前面加 `pau`，合并相邻 `pau`）。
- 模型输出去掉停顿类标签、统一小写后，必须与送入的音素序列（同样去掉停顿、小写）**完全一致**，否则判为“归属不确定”失败（不猜）。
- 只保留目标句的音素；目标句首末音素之间的静音（停顿）保留；零长度的边界静音不算失败。
- 时间分辨率 10 ms，结果连续覆盖窗口（含首尾停顿）。
- 清音元音：结果标签用小写 i/u，前端给出的原大写另存。
- 记录：模型身份/版本、前端版本、辞典版本、对齐文本版本、目标与窗口、容差、音频身份（文件指纹 + 音频流 + 映射）。

### 8.3.3 失败

- 文本前端失败、模型文件缺失、音素组合模型不支持（pydomino 只认它转移表里有的音素组合）、音频过短、归属不确定、
  输入音频在任务期间变化 → 该项失败并写明原因。
- **没有备用模型，不自动重试**。失败的采样照常可以播放、截取、整段拉平、音高检索；用户可以改对齐文本、辞典或选区后**显式重跑**。
  （2026-10-04 决定：不提供“从零手工放置音素”的功能。）

## 8.4 语音分析（一个操作，统一的复用规则）〔新：所有者 2026-10-05，18 D45〕

旧版有两个入口、两种语义：原片页「准备语音分析 / 补齐」复用已有结果，采样库「重新分析所选」强制重跑。新版合并成**一个“语音分析”操作**，
只是从不同入口发起时默认范围不同；复用规则全部相同。

| 入口 | 默认范围 |
|---|---|
| 原片页「语音分析…」（所选原片，可分批） | 所选原片中：性质为语音、有对齐文本、文本快照（原字幕区间）不与已确认 OP/ED 正长度交叠的采样 |
| 采样库「语音分析所选 N 项」；采样右键 / 命令面板「语音分析」 | 所选（或命令里写明的当前）采样中有对齐文本的；用户显式选的，不再按性质、OP/ED 过滤 |
| 采样详情「选区标注 / 对齐…」 | 当前选区 + 所选文字区段（不需要先保存采样） |

- **复用规则**：某个采样已有成功结果，且这次的输入（对齐文本版本、辞典版本、前端版本、模型版本、目标区间、容差、输入音频身份）与它**完全相同** → 跳过（重跑也得到同样的结果）；
  有任何不同 → 重跑。改了对齐文本、辞典、容差或音源之后再发起，相关采样自然会重跑。
- **确认框写清会发生什么**（P13）：“将分析 M 条；N 条已是最新，跳过；K 条无法处理（原因）”；另有一个默认不勾的「也重新分析已是最新的 N 条」（排查用）。
- **音频**：采样实际绑定的资产，**不触发分离、不换音源、不改绑**；绑在原混音上就分析原混音（详情里可以先显式切换音源，03 §3.3）。
- **处理不了的**：列出原因——缺对齐文本；截取范围与原台词不同且没有对应文本。
- **人工版本保护**不变：当前头是人工版本时，新结果只进历史（要回到模型结果用“切换版本”，§8.7）。

- 旧版原片页的「准备语音分析」会先按人声模型补做整轨分离并把采样改绑到整轨人声上再对齐；新版**不这样做**（18.2）：
  要用人声分析，先在原片页整轨分离、设好默认人声轨，再从字幕创建采样（创建时绑定默认轨）。确认弹窗里显示范围内绑在原混音或无角色资产上的采样数。
- **提交时冻结**：音频选区与身份（文件指纹 + 大小/修改时间）、对齐文本及版本、辞典快照、前端版本、请求的容差、当前头版本。
- **采纳规则**（按顺序检查）：任务已取消 → 不写；输入在任务期间变化（文本/辞典/音频）→ 只进历史；当前头是人工版本或已被更新 → 只进历史；
  否则成为新的当前头。失败结果只进历史，绝不让旧的成功结果“消失”，也不让旧结果冒充新结果。
- 成功后清理私有中间文件；失败时保留排查证据（输入、日志）。
- 并发：模型任务默认一个一个跑（见 13）；进度显示“台词 a/b”。完成后可打开「语音分析结果」表（03 §3.1.3）：逐条列出台词、状态（成功 / 跳过·已是最新 / 失败）、原因，
  可勾选失败项直接再发起语音分析。
- 性能参考：旧版 3,840 条 × 3 个模型共 414 分钟；单模型应约为三分之一或更好。

## 8.5 元音与 N 的有效范围（能量派生，带版本）

模型给的元音边界常包含前后的弱音或静音。为了显示、Shift 吸附、检索的“原声时值”、拉平取范围，派生一个“有效范围”：

- 适用：a i u e o、清音 I U、拨音 N（**不含**辅音 n）。
- 在该音素区间内按 10 ms 帧算能量（功率）：帧数 ≥ 4；峰值 = 区间能量的第 85 百分位；活跃帧 = 能量 > max(1e-10, 峰值 × 0.0064)（约 −22 dB）；活跃帧 ≥ 3。
- 有效起点 = 首个活跃帧中心 − 5 ms，有效终点 = 末个活跃帧中心 + 5 ms；只有边缘存在 ≥ 30 ms 的安静段才收缩，收缩后再向外保留 10 ms 护边；
  收缩后不足 30 ms 则保留原范围。
- **人工版本不收缩**；证据不足（能量全零等）保留原范围；**不以“无音高”或模型空白判断静音**。
- 原始边界永远保留；有效范围是派生值，带算法版本，算法变了可以重算。
- 例：能量只在 0.2–0.7 秒为 0.01 → 元音 a 的有效起点 0.19；N 的有效终点 0.71；辅音 n 没有有效范围。

## 8.6 起音强度【基线算法】

- 对句中每个元音或 N 音素，取**整个音素区间**的 RMS（窗口音频，多声道一起算），再除以全句所有元音/N 的最大值，得到 0–1 的强度。
- 音块的强度 = 其成员强度的最大值（09 §9.2）；供语音检索的“起音强度下限”使用。
- 自动结果和人工改过时间的版本都要计算（按当前时间重算）。〔修正旧版缺陷，18 A15〕旧版人工版本的强度变成未知，强度条件因此全部不命中。

## 8.7 人工修正（替代“换模型”的手段）

| 手段 | 规则 |
|---|---|
| **编辑音素时间** | 在波形上拖边界（主要方式），或在“精确时间文本”里改（每行：开始秒 Tab 结束秒 Tab 音素）。**只能改时间**：行数、标签、顺序都不能变；时间必须有限且满足 前一个结束 ≤ 本个开始 < 本个结束 ≤ 范围终点（不重叠，允许空隙）。保存为新的**人工版本**并成为当前头；之后的自动重跑不会覆盖它。乐观并发：版本变了要求重新载入 |
| **切换版本** | 在同一音源的历史版本（人工/模型）之间切换当前头 |
| **改对齐文本** | 原字幕不变；保存后需显式重跑 |
| **用户辞典** | 修正读音；之后的分析生效 |
| **对局部选区重跑** | 在详情里选一段 + 选文字区段 → 对齐当前选区（窗口与容差规则同上） |
| **拆点 / 合并、停顿参数、人工占格** | 见 09，只重建派生节奏，不跑模型 |
| **提供台词并分析** | 无文字的采样输入实际朗读的台词后分析 |

不允许：增删音素、改音素标签、按能量自动插音或裁辅音、把字/词级结果均分成伪音素。

## 8.8 测量的显示与读取

- 详情「音素与分析」页显示音素条、原句、读音；分析不可用时只在这里说明原因（缺文本 / 失败原因 / 尚未分析）。
- 原片页波形的音素层显示所有**在同一物理声音上**测得的对齐结果（多句可同时显示），不推理、不跨音源借用。
- 子采样（截取）使用覆盖它的测量的投影；处理过的声音不借用来源测量。
- “已分析”指存在覆盖该采样选区、属于同一物理声音的成功测量（测量属于采样或“资产 + 文本”，不属于字幕标记）。
- 读取测量不得有副作用。〔修正旧版缺陷〕旧版读取时会写快照。

## 8.9 中文与英文采样（后续支持，现在留好接口）〔新：所有者 2026-10-05〕

所有者明确：项目之后会支持**中文和英文**采样，**各个流程与日语完全相同**（字幕导入 → 采样 → 语音分析 → 音块/检索/卡拍 → 拉平/导出）。本轮不实现，但设计时要留后路：

- **语言是采样（及字幕、对齐文本）的属性**，默认日语；分析、检索、命名不能把“日语”写死在数据结构里。
- **可替换的部分**按语言插拔：文本规范化、G2P 与读音（日语 = pyopenjtalk-plus + tsqyomi）、mora/音节切分、对齐模型（日语 = pydomino）、
  “元音/音块核心”集合（日语 = a i u e o + N）、前导辅音的标签集、读音搜索的转换方式、用户辞典的格式。
- **与语言无关、直接复用的部分**：FCPE 测量、停顿检测、音块合组的时间规则（以“核心音素集合”为参数）、占格推断、卡拍与时间映射、音高检索、拉平、导出、REAPER 交接。
- 原片的音轨语言、字幕的语言用于默认值（例如默认分析音轨选与字幕同语言的那条），而不是硬编码“日语”。
- 新语言接入时的模型与前端选型由所有者另行确定；这不改变本轮“日语只用 pydomino”的定型（18 D3、D9）。
