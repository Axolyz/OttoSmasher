# 10 功能规格：音高测量、独立音高检索与单音声学筛选

> 服务场景 B（调音单音：找自然音高接近旋律的片段）、场景 D（鼓组/音效：按瞬态特征筛选）。
> FCPE 模型文件与接口细节见 14 §14.4。
>
> **测量与检索算法属于基线**【所有者，2026-10-05】：本轮只复现、不优化。标【基线参数】的是内部常数，标【界面默认】的是用户可见默认值。
> 查询的**输入界面**按所有者要求重做（§10.2.1），算法不变。

---

## 10.1 音高与能量测量（FCPE）

- **网格**：10 ms 一帧（16 kHz 下 160 个样本）；每帧记录 F0（Hz）、置信度、能量（该 10 ms 的均方值）。帧时间取帧中心（第 i 帧 = (i×160 + 80)/16000 秒）；
  检索把第 k 帧视为 [k×10 ms, (k+1)×10 ms)，命中时间按块起点报告。
- **可靠帧** = 有声 且 F0 > 0 且 置信度 ≥ **0.5**【基线参数】。音高检索、语音检索的音高类条件、拉平、单音指标都用这个门槛，用户不能调低。
  另有一个**有声帧**口径（置信度 > 0.05 且能量 > 1e-10）：只用于拉平重合成时决定哪些帧替换为目标音高（无声帧 F0 置 0，11 §11.3），以及显示和统计；
  语音检索的音高类条件全部用可靠帧（09 §9.6.3）。
- **输入重采样**〔新：所有者 2026-10-05 采纳 19 G2〕：所有 F0 测量路径——音高检索索引、语音分析特征、拉平——统一为
  解码 → 各声道平均成单声道 → **线性插值到 16 kHz**（与 HiFiShifter 前端一致）。长音频（如整轨建索引）分段推理，每段 60 秒、两侧各带 1 秒上下文，拼回连续网格。
  旧版音高检索索引是由 ffmpeg 解码时直接重采样的，同一段声音在两边的 F0 有极小差异；新版不再有这个差异。
  （pydomino 对齐的输入另用带抗混叠的多相重采样，08 §8.3.1，那是对齐模型的要求，不在此列。）
- 一次只加载一个模型实例；模型会话按设备设置（14 §14.7）。
- **存储**：逐帧无损保存（不降采样、不削精度）；按“声音内容”（文件内容指纹 + 音频流 + 模型版本 + 算法版本）共享，
  多个采样引用同一段声音时只测一次。测量**不是缓存**，不能被当作可清理文件。
- **处理后的声音**（拉平、回导、分离成品）有新的内容身份，必须单独测量。拉平成品输出后要重新测量 F0，供音高检索、单音指标、波形 F0 线使用；
  **`pitch:` 标签不依赖重测**，取拉平时记录的目标音（11 §11.4）。
- **音高波动范围** = 可靠帧 MIDI 的 P90 − P10（中间 80% 跨度）；检索里用音分（×100），声学指标里用半音。
- 〔中英文预留〕FCPE 与语言无关，中文、英文采样直接复用。

## 10.2 独立音高检索

**定位**：独立于对齐，不读音素/mora，不跑模型，不登记采样。用于找“自然音高已经接近某段旋律”的片段。
结果**明确标注为近似检索**（可能漏检）。它是“三大搜索”之一，性能目标见 §10.2.7。

### 10.2.1 查询编辑（图形界面）〔新：所有者 2026-10-05〕

旧版是一个纯文本框（每行 `秒数 音高`），所有者认为“太突兀，和其他检索不是一个画风”。新版要求：

- 查询由 **1–16 个音高块**按时间顺序首尾相接组成，在一条横向的**时间轴画布**上编辑（与语音检索的音符块画布同一套视觉和操作习惯，03 §3.4）：
  - 横向是时长：拖动块的右边缘改时长，或在块属性里输入；最短 0.1 秒，按 10 ms 取整（界面显示取整后的值）；总长 ≤ 10 秒；
  - 纵向或属性栏选音高：**单个音**（音名 + 八度），或**音高范围**（低音..高音，闭区间，低 ≤ 高）；
  - 可增加、删除、复制、调整顺序；违反限制时就地提示，不能提交（与旧版文本的报错规则相同：太短、超长、范围倒置、非法音名、空查询）。
- 音名：A–G + 可选升降号 + 八度（可为负），MIDI 0–127；A4 = 69 = 440 Hz；显示时 `#` 和 `♯` 等价、`b` 和 `♭` 等价。
- 检索参数（§10.2.2）放在画布旁；高级参数默认折叠。
- 可选〔建议，由新开发者决定〕：时长单位可切换为“拍”（按顶栏 BPM 换算成秒后检索，检索本身仍按秒）；用简单音色试听查询旋律；
  保留文本形式作为“复制/粘贴查询”的辅助（格式：每行 `秒数 音高` 或 `秒数 低..高`），但不作为主入口。
- 查询的内部表示 = 有序的 (时长帧数, 低 MIDI, 高 MIDI) 列表；帧数 = floor(秒数/0.01 + 0.5)。

### 10.2.2 参数【界面默认】

| 参数 | 默认 | 范围 | 含义 |
|---|---|---|---|
| 容差 | 50 音分 | 0–1200 | 可靠帧到音带外沿的允许距离（带内为 0） |
| 有效覆盖 | 0.8 | 0–1 | 每块：带内可靠帧数 / 该块全部帧数（不可靠帧也计入分母） |
| 最长缺口 | 0.12 秒 | 0–10 | 整个查询窗内最长的连续不可靠帧（不能在块边界把长缺口拆短） |
| 稳定度（高级，可选） | — | 0–12000 音分 | 每块可靠帧 MIDI 的 P90−P10 上限 |
| 能量上下限（高级，可选） | — | ≥0 | 每块全部帧能量的平均值 |

未知参数报错，不静默忽略；可靠门槛不能通过参数调低。

### 10.2.3 范围

- **已保存采样**（默认）：先用当前浏览范围（范围栏上的条件与主标签表达式）筛候选采样。
  每个采样的允许起点区间 = [ceil(采样起点/10 ms), floor(采样终点/10 ms) − 查询帧数]；只合并“允许起点”区间，**不合并声音区间**，
  所以相邻的两个采样不能拼出一个命中（例：1 秒 A4 分成两段采样，0.6 秒 A4 的查询无结果）。
- **已分析原片音轨**：按资产（音轨）检索；可按资产、轨道角色、原片、标题文字、作品、标签表达式（按查询窗与标注的正长度交叠求值）过滤；
  采样专用的条件（性质、星标、选中项、属性条件）在此模式下拒绝并说明。
- **句首/句尾条件**（原片模式，可选，容差 0–5 秒）：以台词标注为依据——查询起点与某条台词起点的距离 ≤ 句首容差、查询终点与某条台词终点的距离 ≤ 句尾容差；
  标注按资产自身时间或原片时间换算（需要该资产有到原片的映射）。没有台词标注或没有映射的音轨记为“边界未知”，不参与并在结果里计数。

### 10.2.4 近似流程【基线算法】

1. 每段声音有两层索引：原生帧（N × 3：F0、置信度、能量）和 50 ms 摘要（每 5 帧：可靠帧 MIDI 均值、可靠覆盖率、平均能量）。
2. **粗筛**（50 ms 起点网格，只在允许起点上）：对查询的每一块，覆盖该块的摘要格中，“摘要音高落在 [低 − 容差 − 100 音分, 高 + 容差 + 100 音分] 内”的格的
   可靠覆盖率之和 / 格数 = 粗覆盖；每块粗覆盖须 ≥ max(0, 有效覆盖 − 0.15)；粗分 = Σ(1 − 粗覆盖)。
3. **分组与预算**：同一段声音里间隔不超过一个粗格的合格起点为一组（一个“盆地”），组内按（粗分, 起点）排序；各组按（组内最好粗分, 声音, 起点）排序，最多 2000 组；
   然后**轮询**：每组先取第 1 个候选，再每组取第 2 个……直到 2000 个候选（一个长音不能独占预算）。
4. **精排**：每个候选在 ±50 ms 内按 10 ms 起点（只取允许起点）用原始阈值逐一严格判定：
   - 整个查询窗内最长连续不可靠帧 ≤ 最长缺口；
   - 每块：带内可靠帧 / 块帧数 ≥ 有效覆盖，且至少有 1 个可靠帧；稳定度、能量（若设置）满足；
   - 窗口分 = 各块“可靠帧到音带的距离（音分，带内为 0）的平均值”再对各块取平均。
   每组只保留分数最低（同分取起点早）的严格合格窗口；按（声音, 起点）去重。
5. 按（分数, 声音, 起点）排序，最多返回 100 个唯一窗口 / 100 个展示对象；被截断时标明。

已知的漏检来源（界面要说明“近似”）：50 ms 网格、摘要均值掩盖短变化、粗筛阈值、2000 候选上限、每组只留一个窗口、F0 本身的误差。
粗筛放宽**不能**成为正式命中（偏 80 音分的长音在 50 音分容差下不应出现在结果里）。
连续长音只算一个命中；被不合格段隔开的两个区域是两个命中。

### 10.2.5 索引

- 按声音内容建立；同内容、同模型版本、同算法版本共享；标签、名称、采样关系不进入声音身份。
- 写入新索引时不覆盖正在被读取的旧索引；查询时做轻量校验（大小/修改时间、算法版本、模型指纹、帧数），
  索引任务做完整内容校验；过期的不参与检索，计入覆盖报告；源文件缺失必须报告，**不能换成混音**。
- 覆盖预检：“a/b 已索引”；为 0 时禁用搜索并给出「准备当前范围索引」；准备任务完成后只刷新覆盖数，**不重新搜索**。
- 修改标签/范围即时生效，不需要重算 F0；修改对齐不影响 F0 索引；采样绑定变化或删除时清除它的覆盖记录（共享索引保留）。
- 音高索引由 F0 测量组成，**不可当作缓存清理**（与可随时重建的语音检索索引不同，13 §13.3）。

### 10.2.6 结果

- 采样模式：一个采样一行，多个独立命中在行内展开（命中时间为采样内相对时间），并附所有能完整包含命中的合格采样。
- 原片模式：一条音轨一行，附命中的原片时间范围；点击跳到原片页并带上命中范围和音源。
- 命中可循环试听、返回原片定位、保存为采样（先核对音频身份与完整包含关系，再转为资产选区，新建采样，性质由用户选）、
  拉平（打开拉平弹窗，外选区 = 命中范围）。音高命中**没有**“前后 0.3 秒”试听选项。

### 10.2.7 性能

- 旧版这一节的性能目标是所有者原始文档的错误，**已删除**【所有者，2026-10-05】。
- 现行目标与语音检索相同（09 §9.6.5、15 §15.2）：约 3 万条 × 3 秒的采样上，常见查询 30 秒内完成；非硬性，用于规划进程模型与索引/数据库结构。

## 10.3 单音 · 音色 / 单音 · 瞬态（采样整体声学指标）

- 对采样整体（不是逐音块）计算一组可解释的声学指标，供“单音 · 音色”“单音 · 瞬态”两种浏览模式筛选。
- **必须用采样自己的音高测量**（FCPE），不依赖对齐。〔修正旧版缺陷，18 A16〕旧版的音高类指标只取自语音分析记录，
  导致没对齐的调谐单音——包括拉平成品——音高类指标全是未知。
- 指标【基线参数】（算法版本记为同一个代号以便失效）：
  - 包络 5 ms RMS；有效范围 = 包络 ≥ 峰值 1%；
  - 起音上升时间（10% → 90%）、尾部衰减时间（峰后 90% → 10%）、峰均比、RMS（dB）；
  - 频谱（40 ms 窗、1/4 步长）：低频 20–200 Hz、中频 200–4000 Hz、高频 ≥4000 Hz 占比、谱质心、谱平坦度（噪声倾向）；分起音/主体/尾部三段；
  - 原始音高（MIDI）、音高波动（半音）、可靠发声时长、谐波能量占比、5 次以上高阶谐波占比、有效声音时长。
- 性质：比值和质心对增益不变（整体 ×0.1 不变），RMS 以 dB 表示（×0.1 降 20 dB）；没有可靠 F0 时音高类为未知；静音时全部未知。
- 默认展示的指标——音色：有效声音时长、原始音高、音高波动、可靠发声时长、高阶谐波占比、谐波能量占比、高频占比；
  瞬态：有效声音时长、起音上升时间、尾部衰减时间、峰均比、低频占比、高频占比、噪声倾向。每个指标悬停显示定义与单位。
- 筛选：勾选指标填最小/最大；缺少该指标的采样**不命中**并单独计数；筛选是即时浏览，不写库。
- 「后台准备当前范围指标」提交批量计算任务；指标随声音内容缓存，内容变了失效。
