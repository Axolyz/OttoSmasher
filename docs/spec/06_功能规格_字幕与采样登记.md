# 06 功能规格：字幕与采样登记

> 页面入口见 03 §3.5.5、§3.3.4；概念见 04。
> 核心原则：**字幕导入只登记标记，不建采样；采样都是用户显式创建的，每次显式创建都新建。**

---

## 6.1 字幕标记导入

- **入口**：原片页「导入字幕标记…」（单个或批量）。需要先在原片设置里关联字幕文件（或在弹窗里选择）。
- **读取**：SRT/ASS；UTF-8（有无 BOM 都要支持），LF/CRLF；ASS 转纯文本（`\N` → 换行，去掉 `{…}` 样式和 `<…>` 标签）。
  多行字幕保留换行；全角空格、全角数字、各种破折号/引号原样保留。
- **预览**：每行显示原文、区间、状态：
  - **可导入**；
  - **OP/ED 区间**（与已确认区间正长度交叠；仍可导入，取样和批量分析时跳过；部分跨边界的标出）；
  - **无效范围**（开始 < 0、结束 ≤ 开始、超出原片时长；例如零长条 `00:00:00,000 --> 00:00:00,000`）——不可勾选，导入时跳过并在结果里报告。
- **默认勾选全部有效行**；可用起止秒过滤显示；可只勾选一部分，分多批导入。
- **字幕版本**：按字幕文件**内容**区分（内容快照 + 指纹），不是按导入次数。同一内容的文件再次导入或分批导入都属于同一版本（只补登尚未登记的行，不重复），
  并把该版本设为当前版本——这也是**切回旧版本**的方法（重新导入旧文件）；内容不同的文件形成新版本并成为当前版本，旧版本的标记保留在旧版本里。
  预览之后字幕文件、音轨或 OP/ED 变化 → 要求重新预览。（所有者决定不另做“字幕版本列表”，18 D38。）
- **导入时做的事**：按**当时的字幕规则**（§6.2）给每行分类（台词/音效）、提取说话人标签，保存分类结果。
  **只插入不覆盖**：已经被用户编辑过的标记不会被再次导入改写。整批导入原子完成（失败则这批都不登记）。
- **不做的事**：不建任何采样；不触发分析；不因 OP/ED 未检查而阻塞（OP/ED 的排除是动态生效的，导入前后识别都可以）。

## 6.2 字幕规则（可编辑正则）

> 原则（P10）：字幕写法因字幕组/版本而异，**由用户可编辑的规则适配**；程序内不写针对任何字幕写法的特判。
> 规则覆盖不到的情况，用户可以改规则、在外部（包括用大模型）预先清洗字幕，或事后编辑标注。
> 多人同时说话这类情况处理不好可以接受。【所有者，2026-10-04】

### 6.2.1 规则项

| 规则 | 作用 | 默认语义 |
|---|---|---|
| **音效整行规则** | 清洗后的整行完整匹配 → 该行是**音效** | 整行只由一个或多个（可连续、可嵌套）完整括号组成（全角 `（）` 或半角 `()`，允许空白） |
| **注释括号规则**（命名组 `content`） | 找出行内的注释括号段 | 行内**所有最外层的完整括号段**（支持嵌套：`（京子(きょうこ)たち）` 是一个段），任意位置 |
| **说话人提取规则**（命名组 `name`） | 台词行里每个匹配 = 一个说话人 | 与注释括号规则相同：台词行里所有最外层括号的内容都是说话人，**不论在句首还是句中** |
| 说话人名拆分规则（可选） | 把一个匹配拆成多个名字 | 默认空（不拆）。界面给示例：`[･・＆&、/／]` |
| 说话人名清理规则（可选） | 从名字中删除匹配部分 | 默认空（不清理）。界面给示例：去掉嵌套读音 `[（(][^（）()]*[）)]` |

默认正则（方言需支持递归，以 Python `regex` 库写法为例；这三条已用 §6.2.1 的表格和 `fixtures/subtitles/规则样例.md` 验证过）：

```text
注释括号（search，全部匹配）：(?P<b>[（(](?P<content>(?:[^（）()]|(?&b))*)[）)])
说话人提取（search，全部匹配）：(?P<b>[（(](?P<name>(?:[^（）()]|(?&b))*)[）)])
音效整行（fullmatch）：      \s*(?:(?P<b>[（(](?:[^（）()]|(?&b))*[）)])\s*)+
```

由此得到（默认规则下）：

| 原文 | 种类 | 名称（标题） | 说话人 | 对齐文本 |
|---|---|---|---|---|
| `（ドア）（足音）` | 音效 | `ドア / 足音` | — | — |
| `（京子）こんにちは` | 台词 | `こんにちは` | 京子 | `こんにちは` |
| `台詞（結衣）続き` | 台词 | `台詞続き` | 結衣 | `台詞続き` |
| `aaa（xxx）yyy` | 台词 | `aaayyy` | xxx | `aaayyy` |
| `（yy（zzz））aaa（xxx）yyy` | 台词 | `aaayyy` | `yy（zzz）`、`xxx`（两人 → 参与者） | `aaayyy` |
| `（京子(きょうこ)たち）アッカリ～ン` | 台词 | `アッカリ～ン` | `京子(きょうこ)たち` | `アッカリ～ン` |
| `歳納(としのう)京子！` | 台词 | `歳納京子！` | `としのう`（默认规则的已知代价，可改规则或手改标签） | `歳納京子！` |
| `（ドアチャイム）⏎ウワーッ！` | 台词 | `ウワーッ！` | `ドアチャイム`（同上，已接受的代价） | `ウワーッ！` |
| `普通の台詞` | 台词 | 原文 | — | 原文 |

- 名称里的换行以空格连接（旧版有 146 条名称带换行）；对齐文本保留换行（文本前端按停顿处理）。
- 更多真实例子及“默认规则的已知代价”（音效描述与台词同条时被当成说话人等，所有者已接受）见 `fixtures/subtitles/规则样例.md`。
- 一人 → `character:名`；多人 → 每人 `participants:名`，并加 `speaker-status:多人未分段`【所有者，2026-10-05 同意】（便于一键排除这类低质量采样）；
  作用域为“人声”角色（04 §4.2.3）；**不推断各自时间**。
- 音效行的名称 = 各括号内容用 “ / ” 连接；音效行没有说话人。
- 歌词行（含 ♪）按同样的规则分类（多为台词）；它们若在 OP/ED 区间内会被排除。

### 6.2.2 规则的校验与试算

- 正则方言需支持**平衡/递归括号**（例如 Python 的 `regex` 库或 PCRE2 的递归语法）和**单次匹配超时**；界面写明方言。
- 保存时校验：能编译、包含要求的命名组、长度 ≤ 4096 字符、对试算样例单行匹配不超时（旧版 50 ms）。错误提示“字幕正则无效或执行超时：…”。
- 设置里提供**试算框**：输入一行字幕 → 显示种类、名称、说话人、对齐文本。
- **改规则只作用于之后导入的标记**，不自动重新分类已有标记。

## 6.3 对齐文本的来源（与字幕的关系）

- 每条台词标记的**自动对齐文本** = 原文去掉所有注释括号段（§6.2）后的文字（保留换行与正文标点，由文本前端统一处理，见 08）。
- 用户可以为某条标记或某个采样写**人工对齐文本**（优先于自动文本）；原字幕原文始终保留不变。
- 修正对齐文本**不会自动重跑对齐**，需要用户显式重新分析（结果页提示“重新分析后采用新读音”）。

## 6.4 字幕采样（音效 / 台词，两个独立操作）

- **入口**：原片页「从字幕导入音效采样…」「从字幕导入台词语音…」。
- **声音来源**：音效采样用该原片的**默认音效轨**，台词采样用**默认人声轨**；没有就在弹窗里提示并就地选择（只列可当默认轨的整轨），不回退混音。
- **候选**：当前字幕版本中对应种类的标记，状态：
  - **待创建**；
  - **OP/ED 排除**（与已确认区间正长度交叠）；
  - **轨道范围外**（完全在默认轨覆盖范围之外）；
  - **无有效名称**（清洗后名称为空）。
  只有“待创建”可勾选。可用起止秒过滤（改了要重新预览）。
- **区间**：标记时间前后各扩展（默认各 **0.1 秒**【所有者，2026-10-05】，设置里可分别设 0–5 秒，允许与相邻句重叠），再裁到默认轨覆盖范围，换算成默认轨上的资产选区。
  （旧需求文档写的是 0.3 秒，所有者实际一直用 0.1 秒，已定为出厂默认。）
- **默认一项都不勾**；表头复选框跨所有分页全选（有半选态）；「创建 N 项」。
- **每次显式创建都新建独立采样**：允许重复创建、删除后重建；不用导入历史或删除记录拦截。
- 新采样带：
  - 名称 = 分类得到的名称；性质 = 台词 → 语音、音效 → 非调谐单音；
  - **文本快照**（原文、自动对齐文本、原字幕时间）——之后字幕编辑/删除/切换版本不影响它；
    音效采样的快照只作“说明文字”，不作为对齐文本（要对齐需用户显式提供台词）；
  - **标签判定区间** = 未扩展的原字幕区间（裁到选区内），只用于标签继承（所以扩展部分碰到的相邻句说话人不会被继承）；
  - 来源记录（标记、字幕版本、预览行）。
- 说话人通过区段标签**继承**，不复制成本地标签。
- 创建原子完成（任何一条失败则这批回滚）；完成后提示创建数量；采样库出现“资料已更新”提示。

## 6.5 手动截取

- **入口**：原片页选区操作栏「截取」；采样详情选区行「截取」。（命中保存、分离结果保存见 §6.8，默认性质不同。）
- **输入**：当前选区 + 当前音源的实际资产（资产选区）。
- **名称**：按命名规则（04 §4.7）预填，随选区和音源实时重算，可改。
- **性质**：按资产的角色预填（只有人声 → 语音、只有音效 → 非调谐单音、都有或都没有 → 未分类；04 §4.2.7），弹窗里四个选项都可选（含未分类）。
- **结果**：一律新建采样；不跑模型。若存在覆盖该区间、来自同一物理声音的测量，子采样可以直接投影使用
  （完全或部分落在区间内的音素，部分截断的标 ◐；mora 按所含重新编号）；处理过的声音不借用来源测量。
- 保存后：原片页跳到采样库并打开新采样；详情里截取则打开新子采样；命中保存不改变当前结果列表。

## 6.6 外部独立导入

- **入口**：采样库「导入采样」或把文件拖进采样库页。
- 文件按原片对待：登记文件位置（不复制、不转码），同时为整段建一个采样；性质在导入弹窗里选（默认取侧栏当前性质或未分类）。
  这类原片在原片列表里以来源类型“独立音频”区分。
- 不靠文件名、音高推断性质；不关联原片之外的任何来源（不伪造片源）。

## 6.7 外部回导

- **入口**：采样详情「回导…」/ 原片页选区操作栏「回导…」。
- **规则**：
  - 只用当前选区**起点**；终点 = 起点 + 回导文件时长（手选终点被忽略）；
  - 终点不得超过当前资产的范围（超出报“回导文件从选区起点开始后超出当前资产边界”，不保存）；
  - 沿用该段的时间映射；不补静音、不裁切、不变速、不推断成品内部的剪辑；
  - 采样率可以与原音频不同（例：48 kHz 的成品回到 44.1 kHz 的人声轨），时长按文件自身计算。
- **存储**：回导文件**复制进素材库，保持原格式（无损）**【所有者，2026-10-04】，之后用户的原文件可以随意处置。
- **结果**：新的“外部回导”资产（不能借用来源测量；**继承输入资产的角色**，04 §4.2.4）+ 新采样（名称可改、性质默认未分类）；新采样出现在原选区的派生范围里；
  删除父采样后子采样照常解析。
- 弹窗预览：“文件时长 D 秒 · 回导终点 E 秒”。

## 6.8 其他保存途径

| 途径 | 规则 |
|---|---|
| 检索命中保存 | 先核对命中的音源身份和区间仍有效（失效 → “命中已失效，请重新查询”），转为资产选区，选性质（按命中所在资产的角色预填，04 §4.2.7〔新：19 F2〕；旧版固定默认语音），新建采样；当前结果不变 |
| 分离结果保存 | 对某个声部资产的相应区间新建采样；名称“建议名 · 声部名”；性质按声部资产的角色预填（例如人声声部 → 语音）〔新：19 F2〕；旧版固定未分类 |
| 拉平 | 拉平成功后自动登记**一个**调谐单音成品（这是拉平操作的定义，见 11）；失败不留任何登记 |
| 批量拉平 | 每个输入采样各产生一个调谐单音成品，直接登记（不进任何待审核状态） |
