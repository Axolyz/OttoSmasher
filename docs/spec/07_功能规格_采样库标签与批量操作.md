# 07 功能规格：采样库、标签、筛选与批量操作

> 页面入口见 03 §3.2–3.4；标签概念见 04 §4.2.9。

---

## 7.1 浏览列表

- 浏览 = 范围栏上的全部条件 ∩ 主标签表达式（∩ 单音模式下的属性条件）。条件之间取**交集**；同一分面内的多个值、性质多选取并集（§7.3）。
- **文字搜索**（任一字段命中即可）：
  - 名称、备注：子串匹配（拉丁字母不区分大小写）；
  - 原句文本：双方都做 NFKC、转小写、去掉标点/空白/控制字符后子串匹配；
  - 读音：原句与查询词都转成平假名读音（再按上一条规范化）后子串匹配。例：搜“きょう”能找到“今日はいい天気”。
    〔推定 A25〕旧版用 Sudachi + pykakasi 生成读音，它们不在新技术基线里；新版改用文本前端（pyopenjtalk-plus）的读音。
  - 〔中英文预留〕读音匹配按采样语言选择转换方式（中文可用拼音、英文不需要），本轮只做日语。
- **性质**筛选可多选时取并集（例：语音 + 调谐单音）；与星标等其他条件取交集。
- **没有隐性排除**（只排除应用内部的技术对象，如果有的话）：切换字幕版本、事后确认 OP/ED 都不隐藏已有采样；需要时用标签或表达式筛选。
- 排序：默认按创建时间倒序；可按名称、时长排序。固定结果内不能排序。
- 分页：一屏一页（默认，按面板高度）或固定 20/50/100；后端单页上限可以更大，但界面只取需要的。
- **性能**：10,000 条采样时取任意一页摘要应 < 3 秒（旧版实测约 60 ms）；摘要只含列表需要的字段，不带完整分析数据；
  “选全部匹配”返回全部 ID，与页偏移无关。
- 缩略图按需生成：取采样**本地中点经映射换算后的原片时间**的画面（不是两端点平均），无视频则无缩略图；限制并发、缓存；画面绑定变化后失效。

## 7.2 标签表达式

- 语法：`NOT`、`AND`、`OR`（不区分大小写）、括号、双引号。优先级 **NOT > AND > OR**，左结合。**没有隐式 AND**（`a b` 报错“需要 AND 或 OR”）。
- 标签名按**完整名称**匹配，区分大小写；带空格或与关键字同名的标签用双引号（引号内按 JSON 字符串规则转义）。
- 空表达式 = 匹配全部。
- 报错要指出位置（第 n 个字符）：如 `a b`、`(a OR)`、`a AND`、`"unclosed`、`()`、`a)`、`""`。
- 上限：表达式 ≤ 8192 字符、≤ 256 个词项。
- 匹配对象是采样的**有效标签集合**（本地 + 继承 + 自动）。`NOT` 的补集只在**当前已过滤的范围**内取。
- 例：`(character:京子 OR character:結衣) AND NOT "speaker-status:多人未分段"`：[京子] 匹配；[京子, 多人未分段] 不匹配；[character:京子2] 不匹配。
  `a or b and not c` 对 [a, c] 为真。
- **前缀通配**〔新：19 T2〕：以 `:*` 结尾的词项匹配该命名空间下的任何标签，如 `participants:*`、`"pitch:*"`；只支持“冒号后整体通配”，不支持任意位置的 `*`。
  例：`character:京子 AND NOT participants:*`：[character:京子] 匹配；[character:京子, participants:結衣] 不匹配。
- 只取部分标签的快速路径结果必须等于完整计算后再筛选的结果（旧版为性能做过快速路径，曾出错）；前缀通配同样适用。

## 7.3 范围栏、分面与保存筛选器〔新：所有者 2026-10-05 采纳 19 T1、T2、T4〕

**为什么要有“范围预筛”**【所有者，2026-10-05】：
制作时很多时候要先把范围限定在某部剧或某个角色的采样上，再在这个范围里反复变换检索条件。
如果这些范围条件也写进主标签表达式，表达式里就要常驻挂着两三个标签，每次改检索都得绕开它们。
所以范围**预先筛好**，主标签表达式保持短小、灵活，只写这次真正要找的东西。这个分工是基线；它的呈现方式按下面的新设计做。

- **范围栏**：列表上方一条，所有生效的范围条件都显示为可移除的**条件块**——文字、性质、星标、各分面条件（作品、类型、人物、音高、其他标签）、
  原片、属性条件（单音模式）、选用的保存筛选器。条件块之间取**交集**；同一分面里选多个值取**并集**（例：人物 = 京子 或 結衣）；性质多选取并集。
  “现在会作用于哪些采样”一眼可见（P13）。
- **分面条件**（取代旧版只能选一个标签的“单标签范围”）：每个分面一个可搜索的多选下拉，值来自现有标签并带计数；
  人物分面同时匹配 `character:` 与 `participants:`，可勾“只要单人”（04 §4.2.9）。分面名按界面语言显示，底层标签不变。
- **主标签表达式**单独一个输入框，不放进范围栏。
- **保存筛选器** = 一组范围条件的命名预设：名称（1–200 字）+ 条件（文字、标签表达式、分面条件、性质、原片、星标、属性条件）+ 用户排序。
  - 「把当前范围存为筛选器」：存下范围栏上当前的条件块（不含主表达式）；保存前校验（表达式能解析）。
  - 选用一个筛选器 = 在范围栏上加一个可展开的“筛选器：名称”条件块，与其他条件取交集；展开能看到它包含的全部条件；可关闭。
  - 增删改排序都可撤销；删除需确认；调整顺序是原子操作。
- 切换范围条件不重搜固定结果；固定结果保存当次的范围，不因筛选器后来被修改而重搜。
- 旧版对应物：侧栏的保存筛选器列表、“单标签范围”单选框（`character:` 显示为“角色：”、`participants:` 显示为“参与者（未分段）：”）、工具栏上的“筛选器：名称”。

## 7.4 标签操作

| 操作 | 规则 |
|---|---|
| 添加本地标签 | 详情顶部「+」内联添加；批量：「给所选 N 项添加标签…」 |
| 移除标签 | 只能移除**本地**标签（详情里点 ×；批量「从所选 N 项移除指定标签…」只列有本地数量的标签） |
| 批量预览 | 每个候选显示“本地 n / 继承 m”（按采样计数，不按继承路径重复计数）；两步：预览影响 → 应用；继承项给出跳到来源（区段标注或原片属性）的链接 |
| 全局改名 / 全局移除 | 在「管理标签」里右键标签；作用于：带该本地标签的采样、带该标签的时间标注、作品/来源类型匹配的原片。生成一份编辑：预览影响数量 → 原子应用 → 可撤销。**不允许全局添加** |
| 提升为区段标签 | 显式操作：把采样的本地标签变成一个区段标注（作用域默认取资产的角色——有两个角色时让用户选，没有角色则资产作用域；时间默认为采样选区换算到对应坐标，可改），同时移除这些本地标签；预览后应用，可撤销 |
| 改继承标签 | 去来源改：区段标注（编辑交叠标注）、原片属性（作品/来源类型）、资产角色 |

- 标签值约束：每个 1–500 字、非空；每个采样最多 512 个本地标签。
- **没有屏蔽层**：不能在采样上屏蔽某个继承标签（需求明确不要）。
- 标签按分面显示：详情和列表里按分面分组（人物：京子；音高：G♯5；其他：好用、尖叫），每个标签带统一的来源小标记（本地 / 区段 / 原片 / 自动），
  只有本地标签可以就地删除，其他点一下跳到来源。性质的用途视图见 §7.9。

## 7.5 选择模型与批量动作

见 03 §3.2.5。补充业务规则：

- 批量动作作用于**明确的选择集**（勾选），不作用于浏览焦点；需要“当前查看的采样”的命令要在名称里写明。
- 删除需确认：“删除 N 个采样？从采样库删除；保留原片和磁盘音频。”删除语义见 04 §4.5。
- 批量语音分析（「语音分析所选 N 项」）：确认框写明“将分析 M 条；N 条已是最新，跳过；K 条无法处理（原因）”，确认后排队（08 §8.4）；
  处理不了的项（缺对齐文本、截取范围与原台词不同且没有对应文本）列出原因让用户补。
- 批量拉平：选项与单个拉平相同，范围默认仅元音、目标默认段内自动（11 §11.6）；每项一个成品，直接登记为调谐单音；当前列表与选区不变。
- 批量导出：WAV 或视频片段，生成后可整体拖出或定位到文件夹。

## 7.6 资料编辑（统一、可撤销）

**所有对用户资料的修改**（名称、备注、评分、星标、性质、本地标签、时间标注、原片属性、对齐文本、画面绑定、资产角色与默认轨、保存筛选器）
都走同一套编辑通道：

1. **预览**：列出将改变的对象数和逐字段前后对比；未知字段报错；预览不写库。
2. **原子应用**：整批要么全成功要么全不写；对象版本不一致（期间被别处改过）就拒绝，不覆盖。
3. **撤销**：「撤销最近资料修改」从最近一次开始，找到第一个“所有对象的当前状态仍等于那次修改后状态”的修改并恢复；
   否则提示“没有仍可安全撤销的资料修改；后续编辑不会被覆盖”。没有重做。资料撤销与输入框内的文字撤销互相独立。

- 日常编辑用**表单和波形**（快捷编辑也要走这条通道，只是不弹预览）；批量的复杂修改用高级入口。
- 旧版的“业务编辑 JSON 文档”是临时方案，**新开发者不必照搬**；只要满足上面三条语义。
- 删除是显式操作（软删除或带确认的硬删除），删除的可撤销性由删除语义决定（04 §4.5）。

## 7.7 脚本批量操作入口（附加 P2）

- 位置：「工具与工作流」页。【所有者，2026-10-04】
- 目的：给用户一个从界面直接批量操作数据的口子——用户借助大模型写脚本，粘贴到框里运行。
- 约束：
  - 脚本只能调用**公开、有文档的业务接口**（查询采样/原片/标注/标签，提交与 §7.6 相同的编辑），不能直接读写数据库文件；
  - 所有写入先**预览**（对象数、字段前后对比），确认后**原子应用**，可撤销；
  - 运行有超时、可取消；失败不留半成品；运行日志可见；
  - 页面提供可复制的接口说明，方便交给大模型写脚本。
- 语言与沙箱方式由新开发者按架构选择，最好与后端语言一致【所有者，2026-10-05 同意，D33】。如果需要大改架构就先不做（所有者原话：“偏向添头，如果需要大改的话就还是先算了”）。

## 7.8 星标、评分、备注

- 星标：布尔，列表里直接切换；是状态不是范围。
- 评分：0–5 整数（详情「资料与来源」页）。
- 备注：≤100000 字，失焦保存（走统一编辑通道）。

## 7.9 性质的用途视图〔新：所有者 2026-10-05 采纳 19 N1〕

性质回答“这个采样拿来干什么”，对应 01 的制作场景（语音 ↔ 卡拍/人力；调谐单音 ↔ 调音；非调谐单音 ↔ 鼓组/音效）。
范围栏上的性质条件**只选了一种**时，采样库切到这种性质的**用途视图**——只改变默认显示和默认动作，**不限制任何功能**：

| 性质 | 列表多显示（一两列） | 默认检索方式 | 详情默认页 | 突出的动作 |
|---|---|---|---|---|
| 语音 | 原句 / 读音、音块数 | 语音检索（音块 / 节奏） | 音素与分析 | 卡拍试听、REAPER 交接 |
| 调谐单音 | 音名（`pitch:` 或测得的原始音高） | 音高检索、单音 · 音色 | 资料与来源 + 音高信息 | 拉平、拖出 |
| 非调谐单音 | 有效时长、起音时间 | 单音 · 瞬态 | 资料与来源 | 拖出、导出 |
| 未分类 | 来源、创建时间 | 浏览 | 资料与来源 | **一步归类** |

- 选“全部”或多选性质时用通用视图（列表三列：采样、时长、星标）。
- **“未分类”是待整理收件箱**：手动截取、导入、分离保存的东西先到这里，用户边听边一步归类（例如一个键直接设为语音/调谐单音/非调谐单音；具体键位属半基线）。
  归类后该行就地显示“已归类为…”、不立即消失（避免列表跳动），刷新或翻页后移出当前视图。
- 新建采样时，弹窗里的性质默认取当前用途视图（独立导入）或按 04 §4.2.7 的规则预填。
- 不做：不按音频自动判断性质（P2）；用途视图不隐藏任何动作，只调整默认值和排列。
