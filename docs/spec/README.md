# 原始规格（交接包）

这里是 OttoSmasher 重写时的**原始需求规格**：所有者在 2026-10-03/05 整理的交接包，正文原样收录（只把 `00` 里的链接改成了本目录的相对路径）。
新版就是照着它从零设计实现的；代码注释和文档里的“规格 06 §6.2”“R4.4”“S11.3”“P6”这类编号都指这里。

**它是出处，不是现行规矩。**之后所有者确认过的基线变更、实现时的取舍都记在 [`../DECISIONS.md`](../DECISIONS.md)，**两者冲突时以 DECISIONS 为准**。
没有被 DECISIONS 改过的部分仍然有效。

## 读之前要知道的

- **“旧版”**指交接之前的那一版 OttoSmasher（不公开）。规格里“相对旧版”“旧版教训”的内容是给重写的人看的背景。
- 规格里提到的 `fixtures/`（测试素材）是第三方版权内容，**不公开、不进仓库**；开发者只在本机通过环境变量 `OTTO_FIXTURES` 原地引用。
- 交接包里另有一份给第一个开发会话的提示词（含本机路径），没有收进来；`00` 里指向它和 `fixtures/` 的链接因此打不开。
- 文件按交接包原来的顺序编号：01 背景与方法论、02 产品基线与设计原则、03 页面职责与交互、04 领域模型、05–13 各功能规格、14 技术基线、15 非功能需求、16 验收清单、17 风险与旧版教训、18 决策记录、19 优化建议与所有者答复。
- 不要修改这里的正文；规矩变了写进 DECISIONS。
