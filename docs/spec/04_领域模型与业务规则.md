## 4.2 概念定义

### 4.2.1 原片（Source）

- **是什么**：用户登记的一个本地媒体文件（视频或纯音频），是声音资产、时间标注、采样的根。
- **必须有**：文件位置；内容指纹（用于判断文件是否被替换，算法自定）；时长；音频流列表（至少一条，否则拒绝登记）；视频流（可无；封面图不算视频）；
  默认分析音轨（优先语言标记与首选语言相同的第一条——当前默认日语，否则第一条，用户可改）。
- **用户属性**：作品名、集数、来源类型（如 动画/真人/游戏）——作品和来源类型以 `work:`、`type:` 标签的形式被该原片所有采样**实时继承**；集数不是标签。
- **还挂着**：OP/ED 区间、字幕版本（当前选中一个）、轨道角色与默认轨、原片默认画面。
- **不变量**：原片文件**永不移动、转码、删除**；登记不复制文件、不分析、不建采样、不要求字幕；
  重新定位只改文件位置引用（不校验内容和时长），已有资产、时间、分析、OP/ED 全部保留。
- **主时钟**：原片的时间轴就是媒体时间；音频是唯一主时钟，画面跟随音频。
  （注意：有的片源音频流比视频流长或起点不同，例如 KF01–06 音频比视频长 4.5–28 秒、外部 MP4 视频从 0.125 秒开始——以音频时钟为准，画面按自身时间戳对齐。）

### 4.2.2 字幕版本与时间标注（Annotation）

- **字幕版本**：按字幕**文件内容**区分（内容指纹）。同一内容的再次或分批导入归入同一版本，只补登尚未登记的行；
  导入内容不同的文件时形成新版本并成为**当前版本**；重新导入旧文件即切回该版本。每个原片同一时间只有一个当前版本。
  非当前版本的标注**在任何地方都不再参与**（显示、继承、命名、检索范围、字幕采样预览）；已经建好的采样不受影响（它们有自己的文本快照）。
- **时间标注**：时间轴上带文字和标签的区间。种类：
  - **台词**与**音效**：来自字幕行，**只按字幕规则分这两种**（见 06；含 ♪ 的歌词行按同一规则多分为台词，
    靠 OP/ED 排除或不勾选来避开——不为 ♪ 写特判）；
  - **歌词**（song）：只能由用户手动把某条标注的种类改为歌词；歌词不参与台词/音效采样导入；
  - **区段标签**（tag）：用户手动建立的纯标签区间（如“角色：京子”“effect:door”）。
- **字幕标注的文字与标签作用范围不同**【推定 A23】：字幕标注的**文字**在命名、字幕层显示、对齐文本查找时按**原片时间交叠**使用，
  不受角色限制（否则在没有角色的原混音上截取会取不到台词名——旧版就有这个问题）；它带的**说话人标签**只对带“人声”角色的资产生效（见下）。
- **作用域**（决定谁能继承它的标签，也决定它的时间坐标）：
  - **原片**：时间为原片秒，作用于该原片的所有资产；
  - **角色**：时间为原片秒，只作用于带该角色的资产（如“人声”）；
  - **资产**：时间为该资产的局部秒，只作用于这一个资产。
- **说话人**：来自字幕的说话人是台词标注上的标签：一人 → `character:名`；多人 → 每人一个 `participants:名`（并加 `speaker-status:多人未分段`，18 D35、D40），
  作用域是“人声”角色；**多人时不推断各自的时间**。
- **生命周期**：标注可编辑（时间、文字、标签、作用域）、可软删除，每次编辑留版本；**标注的任何变化都不移动、不改写已有采样**。

### 4.2.3 资产角色与默认轨〔新：所有者 2026-10-05 采纳 19 F1〕

- **角色**：每个声音资产带一组角色，取值只有**人声**、**音效**两种（可多选、可为空）。它取代了旧版的“轨道组”
  （旧版另有一套可自定义的组名，与角色并存；旧工作区里实际只用到了人声组）。
- **角色从哪来**：
  - 原片自带的音频流（原混音）默认没有角色，用户可以手动赋予——不分离、直接在原混音上建台词/音效采样时，就把原混音设为人声和/或音效；
  - 分离声部按“声部名 → 角色”别名表预填（默认 `vocals`/`dialog`/`dialogue`/`speech` → 人声，`effect`/`effects`/`sfx` → 音效；别名表可在设置里改，A9）；
  - 拉平、回导这类加工成品**继承输入资产的角色**；
  - 用户随时可以改任何资产的角色；用户显式移除的角色不会被系统再加回。
- **默认轨**：每个原片、每个角色最多一条，从带该角色、**完整覆盖原片且未变速**的资产中选（起点≈0、终点≈原片时长、每段映射未变速，容差 20 ms）；
  逐句片段永远不能当默认轨。
- **角色决定四件事**：字幕采样从哪条默认轨取声音；新采样的性质预填（§4.2.7）；角色作用域的区段标签（含说话人）能作用到哪些资产；导出文件名里的“音轨”段。
- **规则**：更换默认轨**只影响之后的采样**，已有采样和测量不换轨；区段标签按角色实时继承，改了资产的角色，继承结果随之改变（这是预期）；
  同内容的重复整轨只在显示层去重。

### 4.2.4 声音资产（SoundAsset）

- **是什么**：属于某个原片的一段可播放声音，有自己的**局部时钟**（0 到资产时长）和一条到原片时间的**映射**。
- **来源种类**：原片自带音频流；PyMSS Studio 分离出的声部（保留 Studio 给出的**实际声部名**，大小写原样）；拉平成品；外部回导成品；
  （导出/试听渲染不是资产）。
- **记录**：文件身份（位置 + 内容指纹 + 音频流）、局部时长、映射、生产方式（操作、参数、模型身份/版本）、输入（上游资产 + 区间）、角色。
- **不可变**：创建后不修改、不删除（唯一例外是用户确认的级联删除原片，或显式的存储迁移——迁移只能改文件位置/编码，不能改时间关系）。
  任何处理都产生**新**资产。
- **处理后的声音不能借用来源的测量**（例如拉平成品的音高必须重新测量）。
- **角色的传递**：
  - 拉平、回导这类“时长与输入一致的加工成品”在登记时**继承输入资产的角色**——所以人声轨上做的拉平成品仍是人声，
    继续继承说话人标签（所有者常用“人物筛选 + `pitch:`”找调谐单音），在成品上截取时性质预填也正确；
  - 分离出的声部**不继承**输入资产的角色，只按声部名别名表预填；
  - 用户可以在资产的角色设置里手改（03 §3.3、§3.5.6）。默认轨仍由用户指定。

### 4.2.5 资产选区（AssetSelection）

- `(资产, [start, end))`：资产局部时钟上的半开区间，满足 `0 ≤ start < end ≤ 资产时长`。
- **所有声音操作的统一输入**：截取、拉平、分离、回导、对齐、导出、检索命中，都以资产选区为输入。

### 4.2.6 采样（Sample）

- **是什么**：用户明确保存的一个资产选区，加上用户资料。
- **用户资料**：名称（非空）、性质、本地标签、星标、评分（0–5）、备注、画面覆盖。
- **选区**：创建后不变；要不同范围就截取新采样。截取**不复制音频**（新采样引用同一资产的另一段）。
- **文本快照**：从字幕创建的采样保存一份**独立的文本快照**（原文、对齐文本、原字幕时间）；之后字幕编辑、删除、切换版本都不改写它。
- **标签判定区间**：从字幕创建的采样额外记录**未扩展的原字幕区间**（裁到选区内），**只用于标签继承判定**；
  其他采样（以及从字幕采样再截取的子采样）都按自己的选区判定。【所有者，2026-10-04】
- **来源**：创建途径（手动截取/字幕采样/命中保存/处理产物/外部导入/回导）、父采样或父选区、创建时的性质规则。
  父采样被删除后，子采样保留来源记录（“已删除的父采样”），自己照常可用。
- **显式保存一律新建**：同一音源同一范围保存两次就是两个采样（所有入口一致），重复的由用户自己删。【所有者，2026-10-04】

### 4.2.7 性质（Nature）

- 取值：**语音**（speech）、**调谐单音**（pitched）、**非调谐单音**（unpitched）、**未分类**（unclassified）。
- 是筛选属性，不是文件夹；**创建时按明确规则预填，之后可改，永不从父采样继承**：

| 创建途径 | 初始性质〔新：19 F2，由 8 条简化为 4 条〕 |
|---|---|
| 字幕采样 | 台词 → 语音；音效 → 非调谐单音（由字幕行种类决定） |
| 其他从声音资产上保存的采样（截取、检索命中保存、分离结果保存） | 按该资产的角色：只有人声 → 语音；只有音效 → 非调谐单音；都有或都没有 → 未分类（弹窗里可改） |
| 拉平成品 | 调谐单音（固定，拒绝矛盾的请求） |
| 外部文件（独立导入、回导） | 弹窗里选择：独立导入默认取当前性质视图（07 §7.9），没有则未分类；回导默认未分类。不靠文件名、音高推断 |

（旧版：命中保存固定“语音”、分离结果保存固定“未分类”。按角色统一后，分离出的人声声部保存时预填“语音”，原混音上的命中保存预填“未分类”。）

### 4.2.8 测量（Measurement）

- **种类**：
  - **对齐**：音素序列及时间（含停顿）、音素到 mora 的映射、读音、使用的对齐文本版本、辞典版本、文本前端版本、模型身份/版本、目标区间、输入窗口与容差；
  - **音高与能量帧**：10 ms 网格的 F0、置信度、能量；
  - **声学指标**：音色与瞬态指标（见 10）。
- **对象**：测量总是针对**某个资产的某个区间**（对齐还针对某段文本）。
- **版本与当前头**：每次运行产生不可变的版本；每个归属对象（采样，或“资产 + 文本区段”）有一个当前采用的版本。
  - 自动结果**永远不覆盖人工版本**，也不覆盖比它更新的头；
  - 失败、取消、过期（输入在任务期间变了）的结果只进历史，不成为当前头；
  - 用户可以在历史版本间切换。
- **共享**：只有在“同一份文件内容 + 同一音频流 + 同一映射 + 完整覆盖所需区间”时，测量才能在不同采样/视图间共享。
- **不是缓存**：测量结果不能被当作廉价缓存清理；派生数据（音块、量化、卡拍方案、检索索引）可以随时重建。

### 4.2.9 标签

| 种类 | 来源 | 能否在采样上删除 |
|---|---|---|
| 本地标签 | 用户加在采样上 | 能（只有它能） |
| 原片标签 | 原片的作品 `work:`、来源类型 `type:` | 不能，去原片属性改 |
| 区段标签 | 时间标注上的标签（含字幕说话人 `character:`/`participants:`） | 不能，去标注改 |
| 自动标签 | 拉平目标音 `pitch:音名` 等，按绑定的音频实时计算 | 不能 |

- **有效标签实时求值，从不冻结到采样上**：本地 ∪ 原片标签 ∪ 区段标签（按作用域 + 正长度交叠）∪ 自动标签；同名去重时本地优先。
- **区段标签继承**：取采样的判定区间（默认选区；字幕采样用标签判定区间），映射到对应坐标后与标注做**正长度交叠**（端点相接不算）；
  角色作用域还要求资产带该角色。所以：分离出的人声共享“人声”角色上的说话人；音乐、音效轨不会继承说话人。
- **本地标签提升为区段标签**必须是显式操作（可预览、原子、可撤销），不会自动发生。
- **没有屏蔽层**：采样上不能屏蔽继承标签；继承错了要改来源（标注、原片属性、资产角色）。
- 常用命名空间：`work:` `type:` `character:` `participants:` `speaker-status:` `pitch:`；其余自由。
- **分面**〔新：19 T1、T3〕：标签按命名空间分成固定的几个分面来显示和筛选——作品（`work:`）、类型（`type:`）、人物（`character:`、`participants:`）、
  音高（`pitch:`）、其他（`speaker-status:` 与全部自由标签）。分面名按界面语言显示（如“人物 · 京子”），底层标签不变。
- **人物分面**〔新：19 T2〕：选“京子”同时匹配 `character:京子` 和 `participants:京子`；勾选“只要单人”时只匹配 `character:`。
  标签表达式另支持前缀通配 `命名空间:*`（07 §7.2）。

### 4.2.10 其他概念

| 概念 | 要点 |
|---|---|
| **OP/ED 区间** | 属于原片：类型（OP/ED）、区间、来源（字幕规则 / 人工标记；旧版的参考帧扫描已去掉）、证据。绑定原片实体（重新定位后依然有效）。只排除自动台词登记和批量分析 |
| **保存筛选器** | 名称 + 一组范围条件（文字、标签表达式、分面条件、性质、原片、星标、属性条件）+ 用户排序。在范围栏上作为一个可展开的条件块使用，与其他条件取交集；用途是预先圈定范围（07 §7.3） |
| **固定结果** | 一次检索的完整快照：查询、范围、条件、成员（顺序、命中、绑定快照）、界面状态（激活、页码、选中、滚动）。读取时只核对成员是否失效（已删除/绑定变化/索引变化），不重算不重排；关闭只删结果集合 |
| **业务编辑记录** | 每次资料修改（含快捷编辑）的 before/after；乐观并发（对象版本不一致就拒绝）；整批原子；撤销只在对象当前状态仍等于那次修改后的状态时进行，绝不覆盖之后的修改；没有重做 |
| **画面绑定** | 所有者：原片（默认画面）或采样（覆盖）。模式：同步视频（按映射取原片画面）、静态图片、独立循环动画（采样本地时间对动画时长取模）。优先级：采样绑定 > 原片绑定 > 原片自带的第一条视频流（同步）。画面静音，音频为主时钟 |
| **导出文件** | 拖出/导出生成的真实文件（WAV、视频片段、REAPER 原声）。**不是采样**，不触发分析；按稳定键复用；被外部修改过的不覆盖；**从不自动删除**（可能被 DAW 工程引用） |
| **任务** | 见 13 |
| **用户辞典** | 全局一份，带版本；编译成功才原子启用 |

## 4.3 时间与坐标

### 4.3.1 四种时钟

| 时钟 | 定义 | 用在 |
|---|---|---|
| **原片时间** | 媒体时间轴上的秒，[0, 原片时长] | 原片/角色作用域标注、OP/ED、字幕、映射的目标端、原片页波形 |
| **资产局部时间** | 资产起点为 0，[0, 资产时长) | 资产选区、资产作用域标注、测量 |
| **文件时间** | 物理文件里的秒（资产可能是文件的一段） | 解码、播放器、音高索引 |
| **采样显示坐标** | 采样选区起点为 0，[0, 选区长度) | 采样详情波形、音素层、派生轨 |

### 4.3.2 映射

- 资产到原片的映射是一串控制点 `[(局部秒, 原片秒), …]`：两个坐标都**严格递增**；第一点局部 = 0，最后一点局部 = 资产时长；
  中间按分段线性插值；**超出范围直接报错，不外推、不夹取**。
- 能表达：整体偏移（逐句切片）、微小整体缩放（编码导致的时长差）、分段变速（卡拍渲染的时间映射）。
  **不能**表达拼接、跳段、重复、倒放——如果将来需要，必须引入新概念，而不是硬塞进映射。
- 裁切：选区 [a, b) 的映射 = `[(0, f(a)), …中间点平移 −a…, (b−a, f(b))]`。
- 处理产物（分离、拉平、回导）沿用输入选区的映射（时长必须与输入一致，回导除外：回导终点按文件时长）。
- 卡拍：渲染出的“目标时间 → 原片时间”映射与父映射组合，用于导出清单和卡拍视频变速。
- 帧/样本舍入允许一帧（一个采样周期）的容差；其他不一致一律报错。

### 4.3.3 正长度交叠

- 判定：`a.start < b.end 且 a.end > b.start`。**端点相接不算交叠**。
- 用于：标签继承、命名时找交叠文字、派生范围投影、文字层显示、OP/ED 排除、音高检索的标签范围。所有地方用**同一个**判定（含同样的浮点容差）。

### 4.3.4 字幕边界 vs 测量边界

- 字幕时间约有 ±0.5 秒误差（实测：某字幕组整体晚 0.37–0.45 秒，用户逐集手动平移；未校正的第二季晚约 0.5 秒）。
  **字幕边界永远不能冒充测量边界**。
- 字幕采样区间 = 字幕时间 ± 扩展（默认各 **0.1 秒**【所有者，2026-10-05】，可分别设 0–5 秒），裁到默认轨覆盖范围；文本快照和标签判定区间保留原字幕时间。
- 对齐窗口 = 目标区间 ± 对齐容差（默认各 0.65 秒，可分别设 0–5 秒），只在同一物理声音范围内扩展，记录实际扩展量与是否被截断。

## 4.4 不变量（实现必须保证）

1. 原片文件永不被移动、转码、删除；重新定位只改位置引用并保留一切既有关联。
2. 声音资产只属于一个原片，创建后不可变；任何处理产生新资产。
3. 采样 = 一个资产选区引用，`0 ≤ start < end ≤ 资产时长`；截取不复制、不改动音频。
4. 映射严格单调、分段线性、只在覆盖范围内换算。
5. 播放、处理、分析、导出都使用采样实际绑定的资产；资产缺失或文件变化时报错，**绝不静默换成原混音或其他轨**。
6. 处理产物沿用输入映射；分离/拉平产物时长必须与输入一致（允许一帧舍入），否则拒绝登记；回导以选区起点为准且不得越出资产边界。
7. 时间标注与采样生命周期独立：标注的编辑、删除、版本切换不移动、不改写采样；字幕采样有独立文本快照。
8. 区段标签实时求值、正长度交叠才继承、端点相接不算；字幕采样用标签判定区间。
9. 采样上只能删除本地标签；继承标签去来源改；提升本地标签为区段标签必须显式、可预览、可撤销。
10. 性质创建时按规则预填、之后可改、永不从父采样继承。
11. 模型输出和处理资产都不是人工确认，也不是采样；只有用户明确保存才登记。
12. 自动测量结果永不覆盖人工版本或更新的头；失败/取消/过期结果只进历史。
13. 测量只在“同一文件内容 + 同一音频流 + 同一映射 + 完整覆盖”时共享；处理后的声音不借用来源测量。
14. 默认轨只能是完整覆盖原片且未变速的资产；更换默认轨不影响已有采样和测量。
15. OP/ED 只排除字幕采样导入和批量分析，不排除手动播放、截取、分离、已有采样的显示。
16. 缺失测量是未知，不是零；带条件的筛选和检索中未知不命中。
17. 规则和默认值的变化只作用于之后的操作，不追改已有记录。
18. 资料修改走统一的可预览、原子、可撤销通道；撤销绝不覆盖之后的修改。
19. 固定结果只标记失效、不重算、不重排；关闭结果不删除采样或媒体。
20. 导出文件不是采样、不触发分析、不自动删除、不覆盖被外部修改过的同名文件。

## 4.5 生命周期与删除语义

| 操作 | 会删除/改变 | 不会删除/改变 |
|---|---|---|
| **删除采样** | 采样本身、它的本地标签、画面覆盖、以采样为归属的测量采用关系、它在固定结果里的成员（保留位置并标“已删除”） | 声音资产、测量运行本身、时间标注、字幕版本、原片、子采样（子采样保留“已删除的父采样”来源记录）、导出文件 |
| **删除时间标注** | 软删除该标注（可撤销） | 任何采样（含它的文本快照） |
| **切换字幕版本** | 当前版本指针 | 旧版本数据、已有字幕采样 |
| **更换默认轨** | 之后的字幕采样用哪条轨 | 已有采样、测量 |
| **删除 OP/ED 区间** | 该区间 | 已有采样 |
| **删除原片**（确认框列明影响；有相关任务运行时拒绝） | 原片登记、它的采样、为它生成的库内音轨与成品文件、字幕版本、标注、测量、OP/ED、轨道角色、画面绑定【所有者，2026-10-04：绑定的分离轨和采样可以一并删除】 | 磁盘上的原片文件、已导出的文件（WAV/视频/REAPER 原声）；已“独立化”的采样（附加功能，见 §4.8） |
| **存储清理** | 可重建缓存（播放/可视化缓存、临时解码音频、派生节奏缓存）、未被引用的中间产物 | 原片、素材库里的正式音轨与导出、测量结果、数据库、模型 |

## 4.6 身份与去重

- **原片**：同一路径重复登记返回已有原片（并保留用户的设置）；不同路径的同一内容是不同原片（不做内容去重）。
- **资产**：同一输入、同一操作、同一参数、同一模型版本的处理结果可以复用已有资产（避免重复分离整集），但**采样永远新建**。
- **采样**：显式保存一律新建（D16）。
- **导出文件**：按“资产 + 区间 + 版本参数 + 名称”的稳定键复用；文件被外部改过就报错，不覆盖。
- **ID**：建议使用不透明 ID + 独立的内容指纹字段 + 独立的文件位置字段（旧版用路径/内容哈希派生 ID，导致重新定位后要反查最初路径，过度复杂）。

## 4.7 命名规则（所有新建采样、导出文件名共用）

按优先级取第一个可用的：

1. 有覆盖该选区、来自同一物理声音的**可靠对齐结果**：用对齐文本里与之对应的原文片段，加 mora 读音，形如“原文 — かな”。
2. 与选区（换算到原片时间）正长度交叠的**台词/音效标注文字**（当前字幕版本；不受角色限制【推定 A23】；
   用清洗后的文字，不含说话人括号和读音括号〔新·推定 A23〕），多条用“ / ”连接。
3. “原片名 起–止”（原片时间）；资产没有映射时用“原片名 · 资产局部 起–止”。

- 字幕采样直接用分类得到的名称（台词去掉括号；音效用括号内容 “ / ” 连接）。
- 分离结果保存时：建议名 + “ · 声部名”。
- 采样名称**不自动加音高后缀**（音高在 `pitch:` 标签里），不批量改旧名称；名称永远可以手改。
  （导出**文件名**另有“处理信息”段，如 `拉平-G♯5`、`卡拍-180BPM`，见 12 §12.1——那不是采样名称。）

## 4.8 采样独立化（**刚需**【所有者，2026-10-05 改定】）

**需求**【所有者，2026-10-04，原话大意】：“因为原片太大了，有些人电脑可能没那么多空间，所以可能会有采样‘独立化’的需求，
也就是和原片解绑，同时把所有和原片绑定的比如视频、标签和语音标记绑到自己身上，这样可以导入截取若干采样之后删除原片，
让这些采样仍然可用。”
（当时说“算添头”；2026-10-05 所有者改定为**刚需**：原片很大、用户磁盘有限，必须支持。数据模型、存储和删除流程从一开始就按它设计。）

**设计方向**（必须实现；形态已由所有者 2026-10-05 同意按 (b)，见 18 D32、D48）：

- 把采样用到的**声音区间**物化为库内独立资产（保留到原片时间的映射和来源记录）；
- 把采样对应的**画面区间**物化为视频片段，作为该采样的画面绑定；
- 标签与语音标记“带到采样身上”：**(b)** 把原片的元数据（作品、集数、来源类型、字幕标注、OP/ED、说话人等区段标签）以一个很小的
  “**媒体已释放的原片**”记录保留下来，标签继承和来源追溯照常工作；只是原片媒体文件不再可用。
  （没有采用的 (a)：把采样当时的有效标签和文字快照固化到采样上——会让同一事实出现两份、之后改作品名等不再传到这些采样。）
  界面上要明确区分“已独立化”的采样和“媒体已释放”的原片；
- 测量结果随声音资产一起保留（它们测的是同一段声音）；
- 删除原片时，已独立化的采样不在删除范围内；之后不能再从这些采样“返回原片”看前后文，界面要说明。

## 4.9 语言（为中文、英文采样预留）〔新：所有者 2026-10-05〕

- 项目之后会支持中文和英文采样，流程与日语相同（08 §8.9）。本轮只实现日语，但领域模型里要有“语言”这个属性，不把日语写死：
  - 原片的每条音频流、每个字幕版本、每个采样（及其对齐文本）都有语言，默认取来源的语言标记或首选语言（日语）；
  - 语音分析的结果记录所用语言及该语言的前端/对齐器版本；
  - 采样库要能按语言筛选（与性质、标签一样是交集条件；支持第二种语言后再加界面入口）；混合语言的采样库是正常情况。
- 与语言有关的规则（文本规范化、读音、mora/音节、核心音素集合、前导辅音标签、默认字幕规则）都作为“语言配置”的一部分，按语言选择。
