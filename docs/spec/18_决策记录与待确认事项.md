## 18.2 相对旧版的基线变化（由上面的决定引起）

- 对齐：三模型 → **只用 pydomino**；去掉“FA 模型顺序”设置、“切换音素模型”对话框、详情的模型切换、原片页音素层的模型选择、历史字符/音节对齐（Yohane/Qwen）。
- 版本：去掉 standard/experiment；不需要 PyTorch 运行环境。
- 说话人：从“所有括号/过滤规则”两套并存 → 一套**可编辑正则**（提取 + 可选拆分 + 可选清理）；多人加 `speaker-status:` 标签。
- 字幕采样：新增“标签判定区间”；默认扩展 0.3 → **0.1 秒**（旧需求文档写 0.3，所有者实际一直用 0.1）。
- 批量语音分析：旧版会按所选人声模型补做整轨分离、把采样改绑到整轨人声后再对齐；新版**只分析采样当前绑定的资产**，分离和默认轨须事先显式完成。
- 视频：新增真实视频片段导出（含卡拍两种画面）。
- 回导：从引用原文件 → 复制进素材库（原格式）。
- 保存：统一为显式保存总是新建（旧版部分入口去重）。
- 删除原片：从“有采样引用就拒绝” → 确认后级联删除；采样独立化（刚需）。
- 「工具与工作流」页：从空页 → 放附加的脚本批量入口。
- CLI：不再提供。
- OP/ED：去掉参考帧扫描；开始/结束标记可配置。
- 独立音高检索：纯文本 → 图形查询。
- 素材库目录：中文目录名 → 英文目录名。
- 量化：mora 参考校准、纯 mora、长音补格、段间休止调整从主界面 → 高级设置（功能保留）。
- 新增的可配置项（P13）：OP/ED 标记、各入口拉平默认值、声部名别名表、首选语言、导出文件名模板、视频格式。
- 界面：页面职责不变，区域布局与交互规则重做（半基线）。
- 筛选：侧栏筛选器列表 + “单标签范围”单选框 → 范围栏 + 标签分面（多值）；保存筛选器成为范围栏上的条件块；表达式支持 `命名空间:*`。
- 性质：从一个筛选按钮 → 用途视图（“未分类”作收件箱）。
- 轨道组 → 资产角色（人声/音效）；性质预填按角色（命中保存、分离结果保存不再固定为语音/未分类）。
- 语音分析：“准备/补齐（复用）”与“重新分析所选（强制）”→ 一个操作；对齐目标统一为采样选区；不带邻句。
- 拉平：单个弹窗新增“仅元音”，批量弹窗新增首元音起与交界/手动定音。
- 检索：前导辅音不计入 cl；走势与相对音高改用可靠帧；必须满足节奏接受任意 2^k 密度；命中卡拍试听用证据方案；严格命中显示真实平均误差。
- 测量：音高检索索引的重采样与其他 F0 路径统一。
- 界面国际化预留。
