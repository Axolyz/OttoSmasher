# 16 验收场景与规则清单

> 第一部分是基于 `fixtures/` 真实素材的**端到端场景**（人工或半自动验收）；第二部分是**规则级验收清单**
> （从旧版 330 多个测试中提炼、去掉实现细节、并按 2026-10-04/05 的决定更新）；第三部分是写合成测试数据的建议。
> 算法与参数按旧版复现（基线）：数值例子来自旧版测试，新实现应得到相同结果。
> 验收纪律：小批真实素材 + 合成测试；不全库重跑模型；“运行成功”不等于“质量好”；所有者说停止点击就停止。

## 第一部分：端到端场景（真实素材）

素材说明见 `fixtures/README.md`。下面的时间都是原片时间（秒）。

### S1 有字幕整批准备（YY1-01；也可用 KF08 复做）

1. 添加 `episodes/YY1-01/[VCB-Studio] Yuru Yuri [01][Ma10p_1080p][x265_flac].mkv`：不复制、不建采样；自动关联同名 `.srt`（只关联）；作品“Yuru Yuri”、集数“01”。
2. 整片人声分离（PyMSS Studio，人声模型）。没有 Studio 环境时，可以用测试钩子把 `stems/YY1-01/hyperacev2_vocals.mp3`
   登记为该原片的整轨人声资产（与原片 0–1436.435 秒一一对应），`hyperacev2_instrument.mp3` 同理。
3. 「人声／音效与默认轨」：把人声整轨设为默认人声轨（列表里只出现原混音和整轨，不出现逐句片段）。
4. 导入字幕标记：默认全选；导入后**采样数仍为 0**；字幕上下文列表跟随播放。
5. 从字幕识别 OP/ED：得到 OP ≈ 84.247–172.768、ED ≈ 1330.558–1419.114（来源“字幕规则”）。章节参考：OP 84.000–174.048、ED 1330.162–1420.127。
6. 从字幕导入台词语音：OP/ED 内的行标“OP/ED 排除”；默认不勾；全选（跨页）→ 创建 N 项；每个采样 = 字幕时间 ±0.1 秒（裁到轨道范围），性质“语音”，名称去掉括号。
   例：YY1-01 L3「（京子(きょうこ)たち）アッカリ～ン」→ 名称「アッカリ～ン」；说话人标签按**原字幕区间**继承（扩展部分碰到的邻句说话人不应继承）。
7. 原片页「语音分析…」：默认范围是带文本、语音性质、原字幕区间不在 OP/ED 内的采样；不触发分离、不换音源、不改绑；确认框写明“将分析 M 条；N 条已是最新，跳过”。
   每句只送本句文本，窗口 = 采样选区 ± 0.65 秒（所有入口一致）；「语音分析结果」表里能看到每句的成功 / 跳过 / 失败及原因。再发起一次时，未改动的全部跳过。
8. 这 9 句的分析结果（参考输出也是“采样选区 ± 0.65 秒、只送本句”）与 `reference/YY1-01_pydomino_fa_old_output.json` 对比音素时间：标签序列应一致（第一句除外——旧版把说话人「千歳」读进去了，新版对齐文本应为「あなたってば何なの？おジャマします」），边界应接近。
9. 关闭再打开应用：列表、筛选、当前采样、固定结果都恢复，不重新搜索、不自动播放。

### S2 无字幕、双音轨的手动截取（YY2-07）

1. 添加 `episodes/YY2-07/…[07]…[x265_2flac].mkv`：显示“无字幕”；两条日语 FLAC 音轨都可选（第二条可能是评论音轨或另一版混音，内容未确认）。
2. 连续播放、跳到任意位置立即出画面；波形后台生成；Space/I/O/方向键/Shift+方向键 正常（不重复触发）。
3. 拖选一段 → 截取：名称“原片名 起–止”，性质“未分类”（混音无角色）可改；跳到采样库并打开新采样。
4. Option/Alt 拖出该采样：生成 PCM24 WAV，内容与原片对应区间逐样本一致（同一音轨），文件名可移植；不新建采样。
5. 对该采样「提供台词并分析」后，节奏页可用。
6. 把 `episodes/YY2-07/后补字幕_未校正/` 里的字幕关联并导入标记（这份字幕整体晚约 0.5 秒）：已有采样不移动；个别标记可用「编辑字幕／区段边界」手动修。
   （整体偏移应在外部工具里校正后再导入——字幕时间校正不进主流程，02 §2.5；本步只验证已有采样不受影响。）

### S3 Rap 检索、卡拍与 REAPER 交接（接 S1）

1. 顶栏 BPM = 180。语音 · 音块检索：画三块 x-xx 节奏型（例：块在第 0、2、3 个半拍上），首尾“到句末”，策略“必须满足节奏”→ 查找。
2. 结果：只有严格命中；每个命中显示“严格 · 倍速×”；左键原声、右键卡拍，卡拍用该命中证据所选的方案（近快或近慢）〔修正 K3〕。
3. 改为“按节奏相似度排序”：出现近似命中，显示偏差、占格冲突、变速代价；原速偏好 0 与 1 的排序不同；开启倍速范围 0.8–1.25 后范围外的候选消失。
4. 后台跑一个分析任务：结果列表**不**重排、不刷新，只出现“资料已更新”提示。
5. 「复制 REAPER 交接」→ 在 REAPER 里选轨道和光标粘贴：得到未烘焙原声 + 每个起音一个拉伸标记，首个起音落在光标（人工验收；Windows 未实测前不宣称通过）。
6. 拖出卡拍 WAV：时长与方案一致，核心区逐样本等于原声。

### S4 调音单音：拉平（YY1-01）

1. 「歳納京子！」（L1526 附近，becruily 人声轨 1303.272–1303.899）先做语音分析，再用拉平「仅元音 + 段内自动」（与参考成品相同的设置；单个或批量都可以）：
   原始音高应在 MIDI 79.5 ± 0.15 附近，**G5 或 G♯5 都可接受**（旧版原始值 79.5045，正压在两者的四舍五入分界上），记录实际值；
   成品为调谐单音，标签 `pitch:<音名>`，名称不带音名；与 `reference/YY1-01_flatten/flatten_Gs5.mp3` 对比听感。
   注意：三个参考成品的对齐来自旧版的其他模型（G♯5 用 narabas，E5、D4 用 HubertFA），新版 pydomino 的元音区间会不同，参考成品只作听感参考，不要调参凑旧值。
2. 另两个参考：E5（1058.804–1059.303）、D4（212.425–212.845），同样只作听感参考。
3. 单个拉平弹窗：「从首个元音起」+ 交界左 / 右各试一次并记录；段内自动；手动 `A4`、`445Hz`（→ `A4+20c`，不吸附）；手动输入纯数字 `440` 应被拒绝并说明。
4. 交界一侧没有可靠音高时报错并建议换侧，绝不自动换侧。
5. 独立音高检索：在查询画布上放一个 0.40 秒、G♯5 的音高块（采样模式与原片音轨模式各一次）：结果标“近似”；原片模式按音轨分行；保存命中为采样（新建）。

### S5 人力 / 拼词（接 S1）

1. 语音检索（不限节奏）：两块，第一块前导辅音 `k`、元音 a；第二块元音 a → 只命中**相邻有序**的两块；中间夹其他块不命中；缺测量的不命中。
2. 定位命中 → Shift 吸附音素边界截取单个音节 → 拉平 → 拖出。
3. 改某个音素边界（拖动）→ 保存为人工版本 → 再对它发起语音分析（勾选“也重新分析已是最新的”）：人工版本不被覆盖，新结果只进历史。

### S7 PV：视频片段导出

1. 对 S1 的一个采样导出视频片段（原声版）：画面与原片对应区间一致、时长 = 采样时长、带声音。
2. 卡拍版两种：画面按同一映射变速（音画同步）/ 原速画面；分别检查时长与口型。
3. 画面绑定：给一个采样绑定静态图片、给另一个绑定循环动画（0.6 秒）——本地 1.45 秒处应显示动画的 0.25 秒处；导出视频片段遵守绑定。
4. 外部 MP4（`external_audio/千鹤弹吉他_消音.30775247570.mp4`，视频从 0.125 秒开始、音频从 0 开始）：以音频为主时钟，画面对齐。

### S8 外部回导

1. 正例：在 becruily 人声轨上选区起点 1303.272，回导 `external_audio/reimport/歳納京子！ · G♯5__8ca511050f35.wav`（0.627 秒，44.1 kHz）→ 终点 1303.899；
   文件被复制进素材库且保持 WAV；新采样出现在原选区的派生范围里；删掉原文件后新采样仍可播放。
2. 采样率不同：`千鹤吉他__cf6947c5be6a.wav`（0.956 秒，48 kHz）回导到千鹤 MP4 原片 13.187 秒处 → 终点按文件时长。
3. 反例：`仕事してP MEIKO KAITO - 番凩-2019-__92746b1de0d7.wav`（79.375 秒）回导到 YY1-01 的 1400 秒处 → 越界，拒绝，不新增采样。

### S9 失败保护

- 没装/找不到 Studio、模型未下载、选了不含 vocals 的模型做人声分离 → 任务失败，原因明确，不登记任何资产。
- 把采样绑定的分离轨文件改名 → 播放/导出报错，**不换成原混音**。
- 对齐文本里放一个 pydomino 不支持的音素组合或给一段极短音频 → 该项失败，旧结果保留；修改文本后显式重跑成功。
- 打开 ONNX 加速（macOS CoreML）跑一次分析 → 设置里显示“实测通过/失败”与加速节点数；请求的加速不可用时报错，不静默回退 CPU。
- 原片文件被替换成内容不同的同名文件 → 播放器报“音源已改变”。

### S12 删除与生命周期

1. 删除一个有采样的原片 → 确认框列出采样数、生成音轨数与大小；确认后这些登记与库内生成文件消失；原片文件和已导出的 WAV/视频仍在。
2. 删除一个父采样 → 子采样仍可播放，来源显示“已删除的父采样”。
3. 「撤销最近资料修改」能撤销最近的改名/标签/性质修改；之后再改过的对象不被覆盖。
4. 存储设置：清理可重建缓存后，测量结果、正式音轨、导出都还在；有任务运行时清理被拒绝。

## 第二部分：规则级验收清单

> 每条：规则 + 关键数值例子。“〔新〕”表示按所有者 2026-10-04/05 的决定与旧版不同；“〔新·推定 An〕”表示交接人推定（18.3），所有者可推翻；
> “〔修正〕”表示修正旧版的明显缺陷。没有标记的条目与旧版行为一致。

### R1 原片与身份

1. 登记不复制、不分析、不建采样、不要求字幕；同一路径重复登记返回已有原片并保留用户设置；音轨与字幕记录语言（默认日语，为中英文预留）。
2. 作品/集数推断：`[VCB-Studio] Yuru Yuri [01][1080p].mkv` → (Yuru Yuri, 01)；`[DBD-Raws][Kemono Friends][02][1080P].mkv` → (Kemono Friends, 02)；`[Kemono Friends][01].mkv` → (Kemono Friends, 01)。
3. 重新定位到内容不同的文件：只改位置；资产、映射、测量、OP/ED 不变；来回定位身份不变。
4. 删除原片〔新〕：级联删除其采样、生成音轨、标注、测量；原片文件与导出保留；有相关任务时拒绝。
5. 文件名含空格、方括号、日文、中文、`♪`、`♯` 均可登记、播放、导出。

### R2 声音资产、角色与默认轨

1. 默认轨只能选完整覆盖且未变速的资产（容差 20 ms）：逐句资产（0.1–0.4）不出现在列表；整轨（0–1）出现；把片段设为默认 → 报错。
2. 没有映射或映射变速的资产不是整轨（例：控制点 [[0,0],[0.5,0.2],[1,1]]）。
3. 同内容重复登记的整轨在列表里只显示一行，优先显示已设默认的那条。
4. 更换默认轨后，旧采样的绑定不变；同角色资产共享该角色的区段标签。
5. 分离出的 `vocals` 声部登记时按别名表得到“人声”角色；拉平、回导成品继承输入的角色；用户显式移除角色后，重复登记不会把角色加回〔新：角色取代轨道组，F1〕。
6. 性质预填（截取、命中保存、分离结果保存都按资产角色〔新 F2〕）：只有人声 → 语音；只有音效 → 非调谐单音；都有/都没有 → 未分类；字幕台词/音效固定为语音/非调谐单音。

### R3 时间映射与选区

1. 整轨映射 [[0,2],[0.4,3],[1,4]] 上选 0.2–0.7 → 裁切映射首点原片时间 2.5，第二点 [0.2, 3]；越界换算报错。
2. 多级裁切按原帧组合，不复制文件：子 0.1–0.7、孙取子的 0.125–0.225 → 绝对 0.225–0.325，PCM 与原信号对应样本相等。
3. 非线性映射后再裁切按控制点换算（不是按比例）：控制点 [[0,0.1],[0.3,0.2],[0.6,0.7]] 上裁 0.3–0.45 → 原片 0.2–0.45。
4. PCM 舍入允许一帧：终点 1 + 1/48000 接受并截为 1；终点 1.01 拒绝。
5. 同一原片坐标下的两个选区共享同一资产。
6. 共享整轨上的区间叠加文件偏移，不重复叠加：句窗 0.1–0.3 对应文件 0.5–0.7。
7. 回导：选区 0.2–0.7，导入 0.5 秒 → 映射 [[0,0.2],[0.5,0.7]]；导入 24002 帧@48k → 新资产时长 = 24002/48000，回导终点 = 0.2 + 24002/48000；导入 1 秒（超出 1 秒资产）→ 拒绝、不新增。
8. 回导沿用非线性映射：资产映射 [[0,0],[.4,.6],[1,1]]、选区 0.2–0.3，导入 0.5 秒 → 终点 0.7；导入 0.8 秒 → 恰到 1.0 允许。

### R4 字幕标记与字幕采样

1. 导入标记后采样数为 0；预览后字幕内容变化 → 旧预览失效，要求重新预览。
2. 字幕版本按文件内容区分：同一内容再次或分批导入归入同一版本（只补登）并设为当前版本；内容不同的新文件成为当前版本；旧版本的标记在各处都不再参与；已建采样不变；重新导入旧文件即切回旧版本。
3. 无效行（开始 < 0、结束 ≤ 开始、超出时长）不可勾选、被跳过并报告〔新·推定 A2：不再整批拒绝〕。
4. 默认分类：`(足音)(扉)` → 音效“足音 / 扉”、无说话人；`（京子）こんにちは` → 台词“こんにちは”、[京子]；`台詞（結衣）続き` → 台词“台詞続き”、[結衣]；
   `(京子)(結衣)こんにちは` → [京子, 結衣]；`普通の台詞` → 原文、无说话人；`（足音(走る)）（扉）` → 音效“足音(走る) / 扉”。
5. 嵌套括号整体算一个注释：`（京子(きょうこ)たち）台詞` 的对齐文本为“台詞”。
6. 自定义正则：缺命名组 → 报错；`(a+)+$` 作用于 10 万字符 → 超时报错。
7. 改规则不追改已导入的标记。
8. 字幕采样：区间 = 字幕 ± 扩展（默认 0.1〔新〕）并裁到默认轨范围（例：0.05–0.3 的音效扩展后起点截到 0）；音效 → 非调谐单音；台词 → 语音；
   说话人按**标签判定区间**继承〔新〕；每次创建都新建（重复创建、删后重建都允许）；每个采样有独立文本快照，标记编辑/删除不影响它。
9. 缺默认轨时拒绝创建（提示指定），不回退混音；预览后角色变化 → 拒绝并要求重新预览。
10. 字幕采样创建原子：中途失败则采样与来源记录都回滚。
11. 编辑标记的时间与文字不移动采样；原字幕原文保留。

### R5 说话人与区段标签

1. 默认规则〔新〕：台词行内**所有最外层括号**的内容都是说话人（任意位置）；`（yy（zzz））aaa（xxx）yyy` → 说话人 `yy（zzz）` 与 `xxx`（两人 → 参与者）。
   配置清理正则后 `（京子(きょうこ)）…` → 京子；配置拆分正则后 `（結衣･ちなつ）…` → 結衣、ちなつ。
2. 一人 → `character:名`；多人 → 每人 `participants:名` + `speaker-status:多人未分段`〔新〕；多人不推断时间；音效行没有说话人。
3. 区段标签按作用域与正长度交叠：角色作用域 0.4–0.6 的标签对不带该角色的资产无效；资产加上该角色后有效；只在端点相接的选区不继承。
4. 说话人不泄漏到音乐/音效轨：人声资产上的采样继承 `character:京子`，音乐资产上的同一时间采样不继承。
5. 说话人有独立显示层（显示“角色：あかり”，底层标签不变）；原片总览可以显示组作用域的标签，但不改变原混音的继承结果。
6. 本地标签提升为区段标签：预览前不变；应用后本地标签消失、有效标签仍在（来自区段）；撤销后恢复。

### R6 OP/ED

1. 确认区间排除字幕采样与批量分析，不排除手动截取（区内截取 0.1–0.2 照常入库）；部分交叠的标出边界。
2. 端点相接不算交叠：区间 0.2–0.8 下，0.1–0.3 被排除，0.8–0.9 不被排除；删除或重新确认区间不会自动增删采样。
3. 字幕规则：只认精确的 `♪～` 开始与 `～♪` 结束（忽略样式标签与空白，`〜` 等同 `～`）；`♪ 歌詞` 不是标记；片长 200 秒时 10–90 → OP、150–199 → ED；
   两对依次 OP/ED；重复开始、缺开始、缺结束、超过两对 → 不自动登记、只报告，但仍列出已配对区间供逐对确认（来源“人工确认”）。开始/结束标记可在设置里改〔新〕。
4. 规则结果带来源、幂等、不覆盖人工标记。
5. 没有参考帧扫描〔新：所有者 2026-10-05 去掉〕。
6. OP/ED 绑定原片实体，重新定位后仍有效〔新·推定 A10〕。

### R7 采样创建、命名、性质、删除

1. 显式保存一律新建〔新〕：同一命中保存两次 → 两个采样。
2. 新采样直接绑定资产选区，不跑模型。
3. 性质：裁切时显式指定的性质生效；拉平成品固定调谐单音；不从父采样继承；父性质变化不影响子。
4. 删除父采样后子采样保留“已删除的父采样”来源记录，仍可解析。
5. 选区与音效标注交叠时用标注文字命名（例：“（足音）”区间上保存 → 名称“足音”〔新·推定 A23：用清洗后的文字，不受轨道组限制〕）；
   命名优先级：可靠对齐原文/读音 → 交叠台词/音效文字 → 原片名 + 时间；不加音高后缀。
6. 派生范围跨资产按原片时间列出用户采样（不含内部技术对象）。

   → 只剩同时满足三者的采样；表达式改为 `NOT "pitch:A4"` → 京子的、Yuru Yuri 的、非 A4 的采样（补集只在范围栏筛出的范围里取）。
   人物 = 京子 同时匹配 `character:京子` 和 `participants:京子`；勾“只要单人”后只匹配前者；人物选“京子、結衣”取并集；
   保存筛选器在范围栏上显示为可展开的条件块；「把当前范围存为筛选器」不包含主表达式。

3. 性质多选取并集，星标独立取交集。
4. 属性条件（单音指标、音高等）缺失时为未知、不命中并单独计数；筛选不写库。
5. 保存筛选器取交集；全局改名可预览、可撤销（例：work:作品 → work:新作品）。
6. 标签计数按采样计数（同一采样多条继承路径只算一次）。
7. 原片作品/类型实时继承；采样本地标签默认不继承给子采样；没有屏蔽层〔新·推定 A11〕。
8. 任何为性能做的优化（例如只计算部分标签）结果都必须与完整计算一致。
9. 10,001 条按标题排序取第 101–200 条 < 3 秒，摘要不含完整分析；“选全部匹配”返回全部 ID。
10. 用途视图〔新 N1〕：范围栏上只选一种性质时切到该性质的用途视图（07 §7.9）；“未分类”视图里一步归类后，该行就地显示“已归类为…”、不立即消失，刷新后移出。

### R10 文本前端与辞典

1. `〜~～！\t。` → `ーーー、、、`；`あ～, ええ` → `あー、、ええ`，音素 `a a pau e e`，mora 归属 `0 1 未知 2 3`，第 0 个 mora 对应原文“あ～”。
2. 辞典行 `京子\tキョーコ` 合法；重复表记报“第 2 行”；平假名读音报错；编译失败不影响当前辞典。

### R11 对齐与人工修正

4. 有效范围：能量只在 0.2–0.7 → a 的有效起点 0.19、N 的有效终点 0.71；辅音 n 无有效范围；人工版本或全零能量保持原范围。
5. 自动结果不覆盖人工头或更新的头；失败、取消、过期结果只进历史。
6. 音素时间编辑：`.1 .5 a / .5 .8 a` → 新人工版本、mora [0,1]；之后自动结果被拒；用旧文档提交报“版本”；改标签报“标签”。

8. 重跑冻结当前音源、文本、辞典、容差（默认 0.65/0.65）；缺文本列入“需要补充”；可从“资产选区 + 文字区段”发起，不需要采样。

   人工改过时间的版本，起音强度按新时间重算〔修正 A15〕。

10. 原片视口可读同一资产上多次分析的结果，不跨声音身份读取（文件指纹不同 → 不显示）。
11. 读取测量没有副作用。

### R12 音块、停顿、语段、量化

1. 合组（例见 09 §9.2）；同元音合并时长、可手动拆开。
2. mora 计数不制造额外起音。
3. 停顿只看能量：标了 SP 但有声 → 不是停顿；1–2 秒置零 → 停顿起点约 1.02；音素内部 0.3–0.45 秒低电平 → 停顿 0.32–0.43；促音闭塞不是停顿。
4. 语段：0.70–1.35 秒（相对 10 秒处）的声学间隙把整句（10–12.4）切成两段，分界 11.025；模型空白或 0.15 秒的短间隙不切；手动合并/切分会改变语段身份；不能在第一块前切。
5. 语段 mora 从 0 重新计数，保留开头辅音和尾音；语段 mora 不可靠时为未知。
6. 原节奏路线与 mora 元数据无关；时值 (0.11,0.22,0.10,0.32,0.11) → 占格 [1,2,1,3,1]；1–3 块短句可用；11 ms 极短间隔不迫使极细网格。
7. 纯 mora 路线（高级设置）：关长音补格时占格 = 文本 mora 数；开补格只加格不加起音；缺 mora → 显式不可用（原节奏路线仍可用）。
8. mora 参考校准（高级设置）可以把占格缩/扩超过 1 格。主界面默认只出现“原节奏 · 无 mora”〔新：所有者 2026-10-05 把其余路线收进高级〕。
9. 合并的长元音与促音不产生新起音；声学停顿有独立的休止格、尾音保留。
10. 人工占格只锁改过的块；缺 mora 时可手动填占格。

### R13 卡拍与渲染

1. 近快 = 速度 ≥1 的最小密度；近慢 = 下一档；第三档 = 近快的 2 倍；极短音块时密度可以 > 8。
2. 不设 BPM 时实测原速 = 1（±1e-3），插入 1 秒停顿后仍为 1。
3. 映射图用真实秒数（目标时长 < 源时长时末点目标秒 < 源秒）。
4. 只改休止或画布不改变语音速度；整体速度是总时长之比。
5. 时间表平移不变；核心斜率为 1；核心逐样本不变，起音落在目标拍（±1 样本）；严重局部形变也成立。
6. 长静音只改弹性间隙，不移动核心；弹性间隙里的低电平声音保留（非零）。
7. 渲染裁掉空画布但保留所选音频与核心。

### R14 语音检索与固定结果

1. C-E-G 邻接、跨八度、缺失不命中（例见 09 §9.6.2）。
2. 八度：C4 匹配、C5 不匹配；辅音 ['k'] 精确，[] = 无前导辅音，促音 cl 不计入前导辅音〔新 G3〕；默认不跨停顿（同一停顿段），允许跨休止 + 最大间隔 0.1 又不匹配；
   首尾依据为停顿段或整个采样。
3. 最大间隔 = 下一元音锚点 − 上一块结束（结束 1.5、锚点 2.0 → 0.5；上限 0.4 不匹配，0.5 匹配）。
4. 音分容差 48 时偏差 49 不匹配；覆盖率 0.49 不满足 0.5；时值默认按有效持续算；持续未知时时值上限也不通过。
5. 覆盖率无帧时为未知不是 0；起音强度未知时 ≥0 也不匹配。
6. 能量取平均；无声帧缺口不算静音，只有显式停顿截断持续；相对音高/响度以**停顿段**为基线；音内走势和停顿段内相对音高都只用可靠帧（≥0.5）〔新 G4〕，走势按时间三等分比较。
7. 无 BPM 比较归一化形状；占格冲突使结果非严格；要求持续但持续未知 → 不命中。
8. 有 BPM 只比较近快/近慢：速度 1.8 与 0.9、原速偏好 0.1 → 选 0.9；倍速范围 1–1.8 → 选 1.8；上限 1.7 → 都不行；同分取近快。
9. 必需音块固定对应，不跳到同一模式的其他出现位置。
10. 检索不登记采样、不跑模型、不读波形；命中执行动作前核对版本与范围。
11. 音符块半开、块内不得有额外起音；BPM 只缩放秒数不改密度；完全拟合也计入形变与速度代价；匹配是纯函数。
12. 段间休止调整：只改段间整数休止（1–32），段内与段尾不变；组合搜索 ≤128 种，等价保留默认。
13. 固定结果：1207 条按 100 条分页读取，合起来顺序完整；恢复时保留滚动/选中/激活，不重新查询；成员改名显示新名；成员重新绑定 → “音源已变化”、命中禁用；关闭结果不删采样。
14. 检索索引只在相关原片/采样变化时失效（改采样标题不失效）。
15. 性能〔新〕：约 3 万条 × 3 秒的采样上，S3、S5 一类常见查询 30 秒内完成（非硬性；用合成数据测，不在用户工作区里做）。
16. 必须满足节奏 + 有 BPM 时，近快/近慢可以是任意 2^k 密度（例：极短音块近快密度为 16 的候选照样参与）〔修正 K1〕；严格命中显示的“平均偏差”是平均起音误差〔修正 A27〕。

8. 查询画布与语音检索的音符块画布同一套视觉和操作习惯〔新〕；性能目标同 R14.15。
9. 音高检索索引与语音分析特征对同一段声音测得的 F0 完全相同（同一种重采样，〔新 G2〕）。

7. 分块拼接（若自行分块）逐帧完整：13 秒立体声拆成 0–8 与 6–13 → 与原始一致；拆成 0–8 与 9–13 → 报“缺口”，不留输出。

### R19 任务与设备

1. 任务先持久化再执行；排队中的可以取消；重试生成新任务。
2. 取消只结束本任务的进程树。
3. 两条通道各自限流（模型 1、轻量 2；可设 1–4，0 拒绝）；裁切不等分离。
4. 任务摘要不嵌大结果，并声明受影响的采样/原片。
5. ONNX 默认 CPU；开启加速但会话没拿到请求的 EP → 报错不回退；DirectML 关闭 mem pattern、顺序执行。
6. 设备设置在提交时冻结（提交时开/设备 2，执行前改成关/0 → 执行仍用开/2）。
7. 运行库缺失时仍报告模型文件状态，实测状态单独显示。

### R20 存储与缓存

1. 逐帧特征无损存储、不降采样；共享元数据只存一份。
2. 解码只读需要的区间（读 0.5–1.5 秒得到对应样本）。
3. 并发生成同一 PCM：12 个读者都拿到完整文件，不留临时文件；清单类文件并发写入也是原子的（读者只看到完整内容）。
4. 清理只删未被引用的生成物；保留被引用的处理结果、特征、原片、模型；不跟随符号链接；保留近期文件；有任务时拒绝。
5. 自动清理只回收过期的可重建缓存；不删正在使用（有租约）的临时 PCM，不删任何测量结果（含音高检索索引）。
6. 对齐成功后清理私有中间文件，只留状态记录。

### R21 导出、拖出、REAPER、视频

1. 选区 0.123–0.456 导出 → 24-bit WAV，等于原信号对应样本（误差 2^-23）；位于素材库导出目录（目录名为英文〔新〕）；同请求复用同一文件；不新增采样、分析、任务。
2. 已导出文件被改动后不复用（报“修改”）；越界或原片缺失报错。
3. 文件名可移植：`CON.txt` → `_CON.txt`；`a<>:"/\|?*\n` → `a__________`；总长 ≤255 字节、保留处理参数段、以 12 位短 ID 结尾。
4. 卡拍导出的清单组合两层映射（资产映射 [[0,10],[0.4,10.8],[1,11.4]] → 清单 [[0,10],[0.5,10.8],[1,11.4]]），文件名含“120BPM”；卡拍只能导出完整选区。
5. 从 MP3 正式音轨导出时逐帧对齐（起点 0.123 与 2.123 都成立，首样本非零）。
6. 显式导出目录优先，不覆盖已有同名文件。
7. REAPER 剪贴板：以 `<ITEM\0` 开头、`\0\0` 结尾；含 `PLAYRATE 1 1 0 -1 0 0.0025`；标记行格式正确；路径引号安全；路径含换行或标记非单调 → 拒绝；原声不烘焙、每个起音都有标记。
8. 拖出：越过 4 px 才生成、请求在按下时冻结且只发一次；生成期间 Esc/松手/取消/失焦都放弃且不再发起系统拖拽；没按修饰键、右键或不属于本区域的元素不接管。
9. 视频片段导出〔新〕：原声版、卡拍两种画面方式，时长与音频一致；默认 H.264 MP4 + AAC 带声音；画面超出视频流的部分补黑帧并提示〔新·推定 A24〕。

### R22 播放器与界面

1. 外部分离轨按偏移挂到原片视频（原片 103–123 秒、分离轨局部 3–23 → 音频延迟 100）；不转码、不生成代理；波形懒加载；分离轨改变 → 报错；缺失 → 报错不改放原混音。
2. 内嵌音轨按“第几条音频流”选择，不按容器流序号（流 [视频0, 音频2, 音频4]，选流 4 → 第 2 条音频）。
3. 列表试听直接读绑定的区间，不导出 PCM；解析当前音源不读取完整采样资料。
4. 时钟为区间本地时间；加载前的跳转/播放挂起；结尾只触发一次结束；旧代次的状态被忽略。
5. 选区播放在终点停下；之后普通跳转恢复无界播放；区间终点以原片秒交给引擎，过期请求不能改终点。
6. 原生视图几何按缩放换算物理像素并支持裁剪（不支持裁剪时部分可见就隐藏）。
7. 渲染进程不能打开任意文件或远程 URL，不能操作其他窗口的播放器。
8. Shift 吸附正反向对称、不级联（[1,2],[1.9,4],[3,5]：(1.1,1.5)→(1,2)；(2.5,1.5)→(1,4)；(6,7) 不变）。
9. （若采用本地 HTTP 服务）接口错误提示：纯文本 500 显示“HTTP 500 + 路径”而不是 JSON 解析错误；400 的具体原因原样显示。
10. 频谱取所选音频窗口（2000 Hz 正弦 → 峰值 2000±30 Hz）；越界、文件改变报错；长音频波形峰值点数有上限，细节窗 ≤30 秒。
11. 缩略图取本地中点经分段映射后的原片时间（映射 [[0,0.1],[0.5,0.4],[1,0.9]] → 0.4 秒），有缓存；无视频无缩略图。
12. 画面绑定可撤销；图片继承到采样；循环 0.6 秒、本地 1.45 秒 → 0.25 秒；同步视频按分段映射（[[0,10],[.5,11],[1,14]]，本地 0.75 → 12.5）。
13. 界面国际化预留〔新〕：用一个测试用的伪语言（例如所有文案加上方括号）运行，界面上不应残留写死的中文（日志、用户数据除外）；后端错误以错误码 + 参数返回。

### R23 分发与安全

1. 程序目录、工作区、运行库三者分离，支持中文和空格路径。
2. （若采用本地服务）只接受本机 Host 与同源请求（外部 Host → 403；外站 Origin 的写请求 → 403）。
3. 发布包不含 PyTorch、不含模型权重；每个 ZIP < 2 GB；冒烟检查通过。

## 第三部分：写合成测试的建议（来自旧版测试的做法）

- **可检测偏移的音频**：1 秒、24 kHz 的线性斜坡（每个样本值都不同），任何错位都会被精确发现；立体声用 y 与 −y 检测声道交换。
- **判断用了哪条音轨**：混音 = 220 Hz + 880 Hz，“人声” = 只有 220 Hz；用 FFT 看 880 Hz 是否存在。
- **停顿/弹性间隙**：在已知时间段置零或衰减到 ×0.01/×0.001。
- **F0 帧**：10 ms 帧、前半 440 Hz 后半 660 Hz、置信度 0.9；能量只在某段非零；随机种子固定。
- **字幕**：内联 SRT 字符串（两条台词、音效+台词、音乐括号、倒置时间等）；不要把真实台词原文写进仓库测试（版权），用合成文本复刻同样的模式，必要时只记录行号和指纹。
- **节奏骨架**：用一组时长和 mora 数构造音块（例如每块一个元音“a”，从 0.2 秒开始），通过删 mora 字段模拟“对应缺失”，整体后移模拟停顿。
- **外部依赖替身**：伪 Studio worker（逐行输出 `task_done` 或 `error` 事件的脚本）、伪 ONNX Runtime（控制可用 provider 与会话实际 provider）、
  把重操作替换成“一调用就失败”来断言它们没有被调用（如检索时不得解码音频、不得推理）。
- **规模**：批量插入 1 万条采样测分页；约 3 万条 × 3 秒的合成采样（带合成对齐、F0）测三大搜索的 30 秒目标（不要在用户工作区里做）。
