# 11 功能规格：拉平

> 服务场景 B（调音单音）。**只把音高轨迹压成恒定目标音高，保留音色、辅音和时长；不是通用移调工具**（移调在 DAW 里做）。
> 模型与前端细节见 14 §14.4–14.5。参考听感：`fixtures/reference/YY1-01_flatten/`（旧版成品 G♯5、D4、E5，均为“仅元音 + 段内自动”）。
>
> **范围选取、定音和重合成算法属于基线**【所有者，2026-10-05】：本轮只复现、不优化。所有者现有的 72 个拉平成品绝大多数用“仅元音 + 段内自动”做成，
> 这个模式必须保留。单个拉平与批量拉平使用同一套选项〔新：所有者 2026-10-05 采纳 19 F3〕。

---

## 11.1 入口（同一个弹窗）

采样详情选区行「拉平…」与采样操作菜单；采样列表右键「拉平…」；原片页选区操作栏「拉平…」与波形右键；检索命中右键「拉平命中区…」；
批量操作「批量拉平所选 N 项…」（§11.6，独立的小弹窗）。

## 11.2 弹窗

- 打开时**冻结**当前音源（声音资产）和外选区 [a, b)，标题显示“音源：… · 外选区 [a, b) 秒（已固定）”。
  弹窗里有独立的小波形和播放器（关闭即释放，不影响主播放器）。
- **处理范围**（单个与批量相同；“内部”只在单个弹窗里有）：
  | 范围 | 语义 | 默认 |
  |---|---|---|
  | **整段拉平** | 整个外选区都重合成，两端不做淡化 | 从原片页、检索命中、采样列表单个发起时默认（这些地方通常没有对齐） |
  | **仅元音** | 每个元音/N 音素区间（按 08 §8.5 用本次测量的能量收紧，人工版本不收紧）分别重合成，区间之间的辅音和静音逐样本不变；**需要覆盖外选区的对齐结果**，没有就拒绝并说明 | 批量拉平默认（所有者最常用） |
  | **从首个元音起** | 从第一个元音或 N 的有效起点（08 §8.5；人工版本用原始起点）处理到外选区末尾；之前的声音原样保留；之后的有声辅音也用同一目标音高；无声部分不补音。**需要覆盖外选区的对齐结果**（同一物理声音），没有就拒绝并说明 | 从采样详情进入时默认 |
  | **内部拉平，首尾保留** | 在弹窗波形上拖金色“内部拉平”区域 [a', b']，两侧过渡默认各 0.05 秒；平台（a'…b' 去掉两侧过渡）至少 30 ms；过渡段里音高在 MIDI 域按 smoothstep 权重从原音高过渡到目标；外部原样 | 初始内区 = [min(0.1, d/4), max(d − 0.1, 0.75d)]（d 为外选区长度） |
  （旧版“仅元音”只出现在批量拉平里，单个弹窗没有；新版两处一致。）
- **目标音高**：
  | 方式 | 语义 | 默认 |
  |---|---|---|
  | **段内自动定音** | 处理区间内的帧中，有声（置信度 > 0.05 且能量 > 1e-10）且置信度 ≥ 0.5、F0 > 0 的帧（至少 3 帧）的 MIDI，以置信度为权重取加权中位数（累计权重首次达到一半处的值），**吸附最近半音**（floor(x + 0.5)） | 整段、仅元音时默认 |
  | **交界自动定音** | 以所选一侧边界向内 100 ms 的帧计算（左：[首个处理区间起点, +100 ms)；右：[末个处理区间终点 − 100 ms, 终点)），同样加权中位数吸附半音；**所选侧证据不足时报错并建议换侧、改段内自动或手动，绝不自动换侧** | 从首个元音起、内部时默认，左侧（起点）为默认侧 |
  | **手动指定** | 音名（`A4`、`C#5`、`B♭3`）→ 精确半音；带单位的频率（如 `445Hz`）→ **精确换算、不吸附**，名称带音分后缀（445 Hz → `A4+20c`）。不带单位的纯数字拒绝并说明（含义不明）。〔修正旧版缺陷〕旧版输入框提示“440（Hz）”，后端却把纯数字当 MIDI，440 直接报错 | — |
- **预估**：只读已缓存的测量（不跑模型）：“缓存预估：音名 · 参考 a–b 秒”，或“任务中分析确定”；后面注明“执行时以实际输入测量为准。”
- **成品名称**：自动命名（同命名规则，**不加音名后缀**），可改。
- 「开始拉平」：提交时核对冻结的资产未变，否则“声音资产已改变，请重新打开拉平弹窗”。

## 11.3 执行【基线算法】

1. 对冻结的输入（各声道平均成单声道）**重新测量** F0（FCPE，10 §10.1），用新测量计算处理区间和目标（预览只是估计）。
2. **处理区间**：整段 = [0, d]；内部 = [a', b']；仅元音 = 每个元音/N 音素区间（按 08 §8.5 用本次测量的能量收紧，人工版本不收紧）；
   从首个元音起 = [首个（收紧后）元音/N 起点, d]。
3. 声码器重合成（PC-NSF-HiFiGAN，按模型配置 44100 Hz / hop 512 / n_fft 与窗 2048 / 128 mel / 40–16000 Hz）：
   - 前端与 HiFiShifter 一致：每个声道分别线性插值到 44.1 kHz，补零到至少 4 个 hop，两端各反射填充 (2048 − 512)/2 = 768 点，
     2048 点 Hann 窗、512 步长取帧，幅度谱乘 Slaney mel 滤波器组后取 ln(max(·, 1e-9))；
   - 第 j 个 mel 帧的时间 = (j·512 + 256)/44100，取最近的 F0 帧（round((t − 0.005)/0.01)）：处理区间内且有声的帧用目标音高
     （内部拉平的过渡段：MIDI 域按权重混合原音高与目标），无声帧 F0 = 0，其余帧保持测得的 F0；
   - 模型输入 mel [1, 128, T] 与 f0 [1, T]，输出 [1, 1, N]，线性插值回原采样率。
4. **拼接**：在采样域按处理区间掩码拼接——区间外的样本**逐样本原样复制**；非整段模式在每个区间两端做 3 ms 线性淡化
   （淡化长度不超过区间长度的 1/4；波形淡化与 F0 过渡是两回事）。
5. 输出出现非有限值 → 失败；输出时长必须与输入相同（按输出采样率，样本数差 ≤ 1）→ 否则失败。
6. 成品存为库内正式音轨（有损 MP3 V0；只承诺编码前的 PCM 外部样本不变）。
7. 对成品**重新测量 F0** 并保存，供音高检索、单音指标、波形 F0 线使用（`pitch:` 标签不依赖它，§11.4）。

## 11.4 登记

- 新声音资产：沿用输入映射；记录目标音（音名、MIDI、Hz、原始 MIDI、偏移半音）、处理范围与实际处理区间、定音方式、参考侧与参考区间、
  内区与过渡、算法版本、模型身份、输入内容指纹。
- **角色传递**：成品继承输入资产的角色（04 §4.2.4），所以人声轨上做的拉平成品仍带说话人标签、命名仍能取到台词。
- **只登记一个**采样：性质固定为**调谐单音**；有效标签自动带 `pitch:音名`——取**登记时记录的目标音**，不是重测结果
  （按绑定音频实时求值：在拉平成品上再截取也带；同范围绑回原音频则不带）。
- 任务被取消 → 不登记；失败 → 不留任何登记（不留下“未拉平的中间采样”）。
- 相同输入 + 相同参数 + 相同模型版本的成品音频可以复用，但**采样永远新建**（显式操作一律新建）。
- 完成后只提示“资料已更新”，当前采样、当前列表和检索结果都不变；用户从任务抽屉「打开结果」跳到成品（03 §3.1.3）。不自动切换当前采样。

## 11.5 失败语义

| 情况 | 行为 |
|---|---|
| 自动定音没有 ≥3 个可用帧 | 报错（说明 F0 证据不足），建议手动或换范围 |
| 交界所选侧证据不足 | 报错并建议换侧/段内/手动，不换侧 |
| 仅元音 / 首元音起，但没有覆盖外选区的对齐结果或没有元音 | 拒绝，说明需要先分析或改用整段/内部 |
| 内部平台 < 30 ms 或区间越界 | 拒绝 |
| 手动目标为空、无法解析或是不带单位的纯数字 | 拒绝并说明 |
| 模型文件缺失或指纹不符、设备失败 | 任务失败，不回退其他设备 |

## 11.6 批量拉平

- 选项与单个弹窗相同〔新：19 F3〕：处理范围 = 整段 / **仅元音（默认）** / 从首个元音起；目标音高 = **段内自动（默认）** / 交界左/右 / 手动。
  每项按自己的范围与边界独立定音；手动目标对所有项相同。内部拉平需要逐个拖内区，不提供批量。各入口的默认值可在设置里改（03 §3.7）。
  （旧版批量弹窗只有“仅元音 / 整段”两种范围，目标固定段内自动。）
- 对所选 N 个采样各自执行一次，每项一个任务；需要对齐的范围（仅元音、首元音起）下没有可用对齐的采样单独失败并说明原因。
- 每个成功的结果**直接登记**为调谐单音采样。〔修正旧版缺陷〕旧版把结果放进一个界面上已不存在的“待审核批次”，用户看不到；
  失败项在任务结果里列出原因。
- 提交后当前列表和选区保持不变。

## 11.7 验收要点（数值例子来自旧测试）

- 前半 440 Hz、后半 660 Hz，外选区 0.2–0.8：交界左侧 → A4（69），参考 [0.2, 0.3]；右侧 → E5（76），参考 [0.7, 0.8]。
  把前 0.3 秒置信度置 0：左侧报错（提示换侧），右侧仍得 76。
- 首元音起：元音区间 [[0.2, 0.5], [0.7, 0.8]]、外选区到 1.0 → 处理区间 [[0.2, 1.0]]；按能量收紧时起点 > 0.2；没有元音区间 → 报错。
- 仅元音：处理区间就是各元音/N 区间（收紧后），区间之间的辅音逐样本不变；每个区间两端 3 ms 淡化。
- 内部拉平：内区 [0.2, 0.8)、过渡各 50 ms → 权重在 <0.2 与 ≥0.8 为 0，0.25–0.75 为 1，0.225 处为 0.5，0.201 处 < 0.002；内区 [0.2, 0.31] → 报“30 ms”。
- 加权中位数稳健：帧 [439, 440, 441, 880] → A4（440 Hz）；没有可靠帧 → 报错。
- 音名换算：A4 = 69；F#5 = G♭5 = 78；69 → 440 Hz；445 Hz → 69.196 → `A4+20c`；NaN、布尔值拒绝。
- 只登记成功成品：外选区 0.2–0.5 → 送入处理的音频恰好 0.3 秒对应的样本数；成功后新增 1 个采样，映射为 [(0, 0.2), (0.3, 0.5)]；失败不新增。
- 所有者实际使用：旧版 72 次拉平，对象多为喊叫和拖长音，目标 G3–A♯5，偏移都在 ±0.5 半音内。
