# Part B 交互意图（基线）

> 这些规则来自业务逻辑或所有者明确的取舍。新界面可以用不同的形式实现（键位、手势都可以重新设计），但**效果必须保留**。编号用 PA/PB/PD 前缀，避免与 18 的 A/D 编号混淆。

| # | 意图 | 理由 |
|---|---|---|
| PB1 | **原声与默认卡拍都能一步试听**：任何可试听的对象（列表行、命中、详情）都能一步听原声、一步听默认卡拍（旧版：左键原声、右键卡拍，所有者已用惯；改键位要在 PD3 的交互规则表里说明）；同一时刻只有一个试听在响，开始试听就暂停其他媒体 | 制作时最频繁的判断就是“原声好不好、卡拍后好不好”（01 场景 A） |
| PB2 | **拖出跟随最近一次成功试听的版本**（原声或卡拍）；修饰键 + 拖动 = 导出真实文件；越过阈值才生成；Esc/松手/失焦放弃；不加拖拽把手、不劫持普通拖动和右键 | 试听与拖出是一个动作链；不预渲染（12 §12.2） |
| PB3 | **浏览焦点不是选择**：批量动作只作用于用户明确勾选的集合；例外必须在命令名里写明（如“无勾选时作用于当前查看的采样”） | 防止误批量（07 §7.5） |
| PB4 | 选择集清楚可见（“N 项已选”）；能跨页全选“全部匹配结果”；改变条件时清空选择，不让旧选择悄悄作用于新范围 | 批量删除、批量加标签的安全 |
| PB5 | **同一加工，同一套操作**：截取、拉平、分离、回导、导出在原片页、采样详情（和检索命中）是同一套弹窗与规则，同级呈现；一个弹窗多个入口时，默认值随入口不同（如分离：工具栏默认整片，选区栏默认当前选区） | P4 |
| PB6 | **一个选区**：半开区间；可精确输入端点；有一步设起点/终点的方式；**切换音源时选区保留**；能一步选中整条字幕/整个音素、拖动时吸附到字幕/音素边界，只对可见图层、只扩一次不级联（旧版键位：I/O、Shift 点击、Shift 拖动，见 §3.8） | 手动截取的效率（场景 D、F） |
| PB7 | **检索只在用户点击时运行**；每次检索形成固定结果（成员、顺序、命中都固定），可与浏览并存、可关闭、重启后恢复且不重搜；后台变化只提示“资料已更新”，不刷新、不重排、不重选 | P8 |
| PB8 | **显式保存一律新建采样**；保存、拉平、导出后当前列表与结果不变；用户主动截取/回导后打开新子采样是唯一的“自动打开” | P1、P8 |
| PB9 | **准备是可选的**：没有字幕、分离、分析时，播放、截取、整段拉平、导出照常可用；缺什么就在用到它的地方说明并给出准备入口；分析缺失只在“音素与分析”处说明，不到处弹警告 | P11 |
| PB10 | 原片页同时看到**画面、字幕上下文、波形**，共用原片时钟；字幕上下文跟随播放（用户手动滚动后暂停跟随片刻）；点字幕 = 选区设为该字幕区间，不自动播放 | 场景 F：边看边截 |
| PB11 | 采样详情是加工台：波形、音高、音素、选区常驻；加工作用于“当前选区 + 当前音源”，二者始终可见 | P5、P13 |
| PB12 | 来源可追溯：原片页和详情都能看到派生的用户采样并点开；详情能回到父采样和原片 | P5 |
| PB13 | 后台任务统一在一处看进度、取消、重试、看日志、打开结果；批量分析/批量拉平有逐条结果表，可只重跑失败项 | 18 D10：失败只报原因、用户修改后显式重跑 |
| PB14 | 默认处理在发起处说清楚会怎么生效（例如导入弹窗写明扩展量与绑定的默认轨）；设置项旁说明默认值的效果 | P13 |
| PB15 | 危险操作确认时写清删什么、**不删什么**；所有资料修改可撤销 | P9 |
| PB16 | 检索查询用图形方式编辑：语音检索的音块条件与节奏卷帘、音高检索的音高块画布（同一种视觉和操作习惯） | 所有者 2026-10-05（第 7 条） |
| PB17 | 切页不卸载页面、保留各页状态；切页暂停所有声音 | 来回切换是常态 |
| PB18 | 说明放在不占版面的地方（如 ⓘ）；数字输入允许中间态；错误显示后端给出的具体原因；按钮切换状态时不位移 | 15 §15.7 |

# Part C 现有界面设计（半基线，参考）

> 以下 §3.1–3.10 是旧版界面（已修正已知 bug、按新决定更新）的完整记录：区域划分、入口位置、控件、快捷键、选择与右键规则、默认值。
> 它是**参考和“为什么这样做”的记录**，不必照搬；重做时遵守 Part A、Part B，目标见 Part D。
> 区域示意图只表达区域划分和信息密度，不是视觉稿。

## 3.1 全局外壳

### 3.1.1 窗口与导航

- 单窗口工作站。主导航只有三页：**采样库**（默认首页）、**原片**、**工具与工作流**。
- 三个页面**常驻**：切页只是隐藏，不卸载。切页时保留各页的筛选条件、选中项、当前音源、波形选区、缩放和滚动位置、
  当前标签页、固定结果标签、检索面板参数。
- 切页时**暂停所有正在播放的声音和视频**（隐藏页面里的播放器开始播放时也要立即暂停）。
- 窗口菜单（⋯）提供「另开窗口」（以当前页和当前采样打开一个新窗口）和「显示缩放 100% / 125% / 150%」。
  多窗口只在用户显式要求时出现。
- 默认窗口约 1440×920，最小约 850×600；顶栏和导航不随内容滚动；页面本身不整体滚动，只有承载集合的面板
  （列表、详情、原片表）各自滚动。

### 3.1.2 顶栏

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ OttoSmasher │ 采样库 · 原片 · 工具与工作流 │ BPM[  原速 ] │ 🔍⌘K │ 任务(2) │ ⚙ │ ⋯ │
└──────────────────────────────────────────────────────────────────────────────┘
```

| 控件 | 职责与规则 |
|---|---|
| **全局目标 BPM** | 数字框，范围 20–400，**可留空**（占位“原速”）。留空：卡拍试听保持原语速（原速卡拍），检索按归一化节奏形状比较；填值：默认卡拍方案用“不慢于原速的最近二进制密度”。修改后立即停止列表试听，并让当前卡拍方案失效重算。值在所有窗口间同步并持久保存。说明放在 ⓘ：“留空：保持原语速的卡拍；指定 BPM：默认使用不慢于原速的最近二进制方案。” |
| **命令面板** | ⌘/Ctrl+K 打开（在输入框里也生效），子串过滤。命令：音高检索、节奏检索、语音分析所选采样（无勾选时作用于当前查看的采样）、用户辞典 / G2P 预览、编辑所选资料、撤销最近资料修改、导入独立采样、添加 / 浏览原片、工具与工作流、全局设置、任务与日志 |
| **任务** | 按钮带角标：排队 + 运行中的任务数；打开右侧任务抽屉（§3.1.3） |
| **⚙ 设置** | 打开设置弹窗（§3.7），打开前重新读取当前设置 |
| **⋯ 窗口** | 另开窗口、显示缩放 |

### 3.1.3 任务抽屉「任务与日志」

- 列表列：任务（**本地化的操作名**，如“整轨人声分离”“语音分析”“拉平”）、状态（排队/运行中/成功/失败/已取消/已中断）、操作。
- 进度：分离显示段数与百分比（来自 PyMSS Studio 的进度事件），语音分析显示“台词 a/b”，其他显示阶段消息。
- 行操作：**查看日志**（日志尾部）、**取消**（排队/运行中）、**重试**（失败/已取消/已中断；以相同业务参数新建任务）、
  **打开结果**（按类型：分离 → 声部结果弹窗，可逐个试听、保存为采样、拖出；单个拉平/单条分析 → 选中结果采样并回到采样库；
  **批量语音分析 →「语音分析结果」表**：台词（点击打开该采样）/ 状态 / 失败原因，可勾选失败项后再次「语音分析」；
  批量拉平 → 结果表（成品链接 / 失败原因）；原片级任务 → 跳到原片页；其他 → 结果详情）。打开结果后关闭抽屉。行展开显示错误或结果摘要。
- 前端只在任务状态变化时更新；**有任务成功时只显示提示按钮「资料已更新 · 刷新浏览列表」**，用户点了才刷新（P8）。

### 3.1.4 其他全局元素

- **底部导出交接条**：任何导出成功后出现：“已导出 · 文件名 ↗ 拖到 DAW”（普通拖动即可拖进 DAW）、「定位文件」、「关闭」。
- **说明文字**统一放在可聚焦的 ⓘ 图标里，不占版面。
- **数字输入**允许空值和中间态；必填项清空后标红，提交类请求统一拦截并提示“请填写标红的数字输入框”
  （注意只拦截与该输入相关的提交，旧版误拦了无关请求）。
- **错误呈现**：错误用消息提示，保留后端给出的具体原因；面板崩溃只影响该面板，显示“此面板未能显示 · 重新打开面板”。
- **重启后恢复**：页面、范围栏条件（搜索词、性质、分面、保存筛选器）、标签表达式、检索模式、页码、排序、当前采样、侧栏收起状态、
  每页数量、检索参数、当前保存筛选器；固定结果标签及其激活状态、页码、选中项、滚动位置。勾选集合不恢复。

## 3.2 采样库页

采样库是制作时最常驻的页面：**找（筛选/检索）→ 听（左原声右卡拍）→ 修（详情加工）→ 交（拖出/交接）**。

> 〔新〕下面是旧版设计。已确认要改的：侧栏的筛选器列表与“标签范围”单选框改为**范围栏 + 分面**（07 §7.3）；性质改为**用途视图**（07 §7.9）；

### 3.2.1 左侧栏（可收起，收起状态持久化）

| 区域 | 职责与规则 |
|---|---|
| **导入采样** | 主按钮。打开系统文件选择（可多选）→「导入独立采样」弹窗：选性质（未分类/语音/调谐单音/非调谐单音，默认取侧栏当前性质），确认后逐个导入并选中最后一个。也可以把文件直接拖进采样库页导入（要排除从本窗口拖出的文件被当成导入）。不靠文件名、音高推断性质 |
| **性质** | 全部性质 / 语音 / 调谐单音 / 非调谐单音 / 未分类（旧版漏了“未分类”，应补上）。是筛选条件，不是文件夹 |
| **筛选器** | 「全部范围」+ 用户保存的筛选器列表。点击 = 在此范围内浏览/检索（与其他条件**取交集**）；右键：编辑 / 上移 / 下移 / 删除筛选器（删除要确认）。「保存当前条件为筛选器」把当前文字、标签表达式、性质、星标（以及属性条件，**只在单音模式下可见时**才带入）预填进编辑框；当前的单标签范围作为筛选器的“单标签”条件一并保存（编辑弹窗里可见、可改；旧版存了却在弹窗里看不到，不透明） |
| **筛选器编辑弹窗** | 名称（必填）、“名称／台词／备注包含”、标签表达式、单标签、性质（含未分类）、原片、作品（精确匹配）、仅星标、折叠的“属性条件”。说明：“点击后与搜索框条件取交集。”保存前校验表达式 |
| **标签范围** | 可搜索、可清空的单选框（占位“全部标签”）。独立的交集条件，切换它不覆盖保存筛选器，也不重搜固定结果。显示时把 `character:` 译作“角色：”、`participants:` 译作“参与者（未分段）：”，底层标签不改写 |
| **管理标签…** | 查找标签；右键单个标签：全局重命名… / 全局移除…（生成可预览、可撤销的编辑；显示影响数量）。说明“角色表示区间的单一角色；参与者表示多人或群体尚未分段。” |
| **仅星标** | 开关 |

### 3.2.2 工具栏与浏览条件

- **搜索框**（⌘/Ctrl+F 聚焦，占位“搜索采样、原句、备注”）：匹配名称、备注、原句文本、读音（假名）。
- **进一步筛选**：标签布尔表达式输入（语法见 07）。自动补全只替换最后一个词并给标签加引号；输入后约 200 ms 交后端校验，
  出错时输入框标红并在提示里给出位置。ⓘ：“完整标签名；NOT > AND > OR。带空格或保留字的标签用双引号。”
- **模式**：普通筛选 / 语音 · 音块检索 / 独立音高检索 / 单音 · 音色 / 单音 · 瞬态（§3.4）。
- 旧版：浏览列表 = 文字 ∩ 标签表达式 ∩ 单标签范围 ∩ 性质 ∩ 星标 ∩ 当前保存筛选器（∩ 单音模式下的属性条件）。新版见 07 §7.1、§7.3。
  条件变化后约 180 ms 自动刷新**浏览**列表（这是浏览，不是检索）；浏览条件一变，界面自动切回「浏览」标签，旧的固定结果标签仍可点回。
- 浏览列表**没有隐性排除**（只排除应用内部的技术对象，如果新架构有的话）。用户显式保存的采样（包括从字幕创建的）
  不会因为切换字幕版本、事后确认 OP/ED 或撤销标记而被隐藏；OP/ED 只在“从字幕导入采样”的预览和批量语音分析中排除。
  （旧版这条隐藏规则只针对早已废弃的“自动句子采样”，不要照搬。）

### 3.2.3 计数与选择栏

- 计数：“N 个采样”（浏览）或“N 个命中采样”（固定结果）。有新结果时出现「资料已更新 · 刷新浏览列表」。
- 「选全部匹配结果」（跨页全选）、「选本页」、“N 项已选”、「批量操作 ▾」、「清空 / 退出多选」。
- 每页数量：**一屏一页**（默认，按面板高度计算）/ 20 / 50 / 100。
- ⓘ：“单击查看详情，勾选框选择；⌘/Ctrl 点击切换选择，Shift 页内连选，翻页保留勾选，Esc 清空。”

### 3.2.4 列表

只有三列：**采样**、**时长**、**星标**（不显示性质、来源、日期、评分——需要时用筛选和详情）。

- **采样列**（可排序）：
  - 缩略图（约 72×44）：取原片或绑定画面在采样中点的帧；无画面时显示占位图标。缩略图按需生成、限制并发、缓存；画面绑定变化后要失效。
  - 缩略图左下角的**试听按钮**：**左键 = 原声，右键 = 默认卡拍**（按全局 BPM）；播放中显示暂停，再点暂停。全局只有一个列表试听器，开始试听时暂停其他所有媒体。成功试听过的版本会被记住，之后 Option/Alt 拖出该行时导出这个版本。
  - 名称；失效标记（“采样已删除”“音源已变化”）。
  - 最多约 5 个标签：本地人工标签、`pitch:`、角色/参与者、作品等用不同颜色区分；悬停说明来源（“字幕提供，未人工确认”“拉平目标音高”“来源继承”“本地标签”）。
  - 检索命中（固定结果时）：见 §3.4.4。
- **时长列**（可排序）、**星标列**（固定在右，可直接切换）。
- 排序默认按创建时间倒序；固定结果内禁止排序（顺序是结果的一部分）。
- 行文字不可选中（便于 Shift/⌘ 点击）；当前查看的行与勾选的行样式不同。

### 3.2.5 选择、右键与批量

- **复选框始终显示**；失效行不可勾选。
- 单击打开详情；⌘/Ctrl 单击切换勾选；Shift 单击页内连选（与页外已选合并）；勾选后进入多选状态，此时单击切换勾选，
  直到清空、Esc 或「退出多选」。
- **浏览焦点不是批量选择**：没有勾选时不显示“已选 N 项”，批量动作不得把正在查看的采样当成选择集
  （例外只有两处，且都明示：命令面板里写明“无勾选时作用于当前查看的采样”的命令；列表焦点下按 Delete 删除当前项，需确认）。
- 翻页保留勾选；Shift 只在页内；过滤、排序、切换结果标签时清空勾选。
- **右键规则**：右键未勾选的行 → 先把选择换成这一行；右键已勾选的行且勾选 >1 → 菜单作用于整个选择集。
  右键表头/空白处不弹采样菜单。
- **批量操作菜单**（= 多选时的右键菜单）：给所选 N 项添加标签… / 从所选 N 项移除指定标签… / 编辑所选 N 项资料… /
  语音分析所选 N 项 / 批量拉平所选 N 项… / 导出所选 N 项 ▸（WAV、视频片段）/ 删除所选 N 项…（确认框：“删除 N 个采样？从采样库删除；保留原片和磁盘音频。”）
- **单行右键菜单**：添加标签… / 移除标签… / 语音分析 / 编辑音素时间 / 编辑对齐文本 · 预览 G2P / 编辑资料… / 拉平… /
  多选 / 全选筛选结果（所有页）/ 删除 / 返回原片 / 重命名 / 导出 ▸（原声 WAV、卡拍 WAV、视频片段）/ 复制 REAPER 交接。
- 批量加/删标签弹窗：每个候选显示“{tag} · 本地 n / 继承 m”；移除时只能移除本地标签（没有本地数量的禁用）；
  两步：「预览影响」→「应用修改」；继承项给出跳转链接（“编辑区间标签来源 / 编辑原片属性来源”）。
- 批量拉平弹窗：选项与单个拉平相同（11 §11.6〔新：19 F3〕；旧版只有“仅元音 / 整段”且目标固定段内自动），范围默认仅元音、目标默认段内自动；
  结果**直接登记为调谐单音采样**（旧版放进看不见的“待审核批次”，是 bug）；提交后列表和选区保持不变。

### 3.3.2 三个标签页

默认标签页：有文字或性质为语音的采样默认「音素与分析」，否则默认「资料与来源」；换采样时重置。

**音素与分析**

- 音素条：每个音素一个按钮（部分被截断的标 ◐），与选区相交的高亮；点击 = 选中该音素的有效范围，Shift 点击从锚点连选。
- 原句文本；量化路线：主界面只显示默认的“原节奏 · 无 mora”，mora 参考校准 / 纯 mora 收在高级里（所有者 2026-10-05：不常用）。
- 按钮：分组与停顿… / 逐音属性… / 重建局部分析；无文字时「提供台词并分析」（输入实际朗读台词 → 排队分析）。
- 「单音声学属性…」（未准备时标明“尚未准备或已过期”）。
- 分析不可用时**只在本页**显示缺失原因（缺失是无字幕素材的正常状态，不在别处弹警告）。
- （新版没有“采用音素模型”切换；只有一个对齐模型。）

**节奏与卡拍**

- 顶部显示“原速卡拍”或“BPM n”；卡拍方案选择（近快 / 近慢 / 倍快，显示倍速与“n 格/拍”）。
- 映射图：原句与卡拍**共用同一秒数轴**并画对应连线，标注“原句 x s → 卡拍 y s · 同比例秒数轴”。
- 试听方式：严格卡拍 / 卡拍＋节拍 / 卡拍起点声 / 原始起点声 / 原声＋原始起点；「试听」。
- 「占格编辑…」（人工占格）。
- 无分析时：“此采样尚无节奏分析。可直接播放、截取、拉平或导出。”

**资料与来源**

- 性质（未分类/语音/调谐单音/非调谐单音，选了即保存）；备注；评分 0–5。
- 返回原片 / 技术详情（只读）。
- 来源：“↑ 父采样 · 操作名”+「试听父采样」；派生采样表（分页）。

### 3.3.4 详情面板里的弹窗

| 弹窗 | 内容与规则 |
|---|---|
| **截取** | 标题显示“a—b s · 音源”；名称按命名规则自动预填（可改）；性质按资产的角色预填（只有人声 → 语音，只有音效 → 非调谐单音，否则未分类），可改。保存后**打开新子采样**（用户主动截取的预期行为），列表不插入 |
| **拉平** | 见 11。冻结打开时的音源和外选区（显示“音源：… · 外选区 [a, b) 秒（已固定）”）；弹窗内有独立波形和播放器，关闭即释放；处理范围、目标音高、内部边界、预估、名称；「开始拉平」。提交时若资产已变：“声音资产已改变，请重新打开拉平弹窗” |
| **分离（PyMSS）** | 当前声音选区 [a, b)；模型：Studio 中**任意已下载**的模型（默认取设置里的人声模型；选区分离不限人声/三轨，例如用去混响、乐器类模型处理音效素材）；保留声部（按该模型的实际声部多选，空 = 全部）；用表单，不用 JSON。提交后：“分离已排队，任务结果中可试听并保存各声部” |
| **回导成品** | 说明：“起点 x 秒。终点由导入文件时长计算，忽略手选终点；超出当前资产边界时不保存。成品按原时间轴连续映射，不推断内部剪辑或变速。”选文件后预览“文件时长 … · 回导终点 …”；名称、性质（默认未分类）；「保存子采样」。菜单名不要再叫“等长成品” |
| **选区文字 / 区段标签 / 资产角色 / 对齐** | 显示资产局部区间；新增区段标注、编辑交叠标注（显示可读名称，不显示内部 ID）、编辑对齐文本、提升本地标签为区段；本资产的角色（人声/音效，可多选；〔新：19 F1〕取代旧版的“高级：任意轨道组”）。对齐：选择文字区段 →「对齐当前选区」（不需要先保存采样）；排队后回显实际输入区间和容差 |
| **画面绑定** | 模式：恢复默认/继承、同步视频、静态图片、独立循环动画；文件选择。“保存后在播放器预览；动画以声音为主时钟，循环画面保持静音。”可同时编辑“原片默认画面”和“采样画面” |
| **导出视频片段** | 版本：原声 / 卡拍；卡拍时画面：按同一时间映射变速（音画同步）/ 原速画面；是否带声音（默认带）。详见 12 |
| **人工占格** | 表格：音 / 目标拍 / 占格（≥1），改即保存，只重建派生节奏 |
| **分组与停顿** | 音素编号前拆点（逗号分隔）、停顿检测灵敏度（默认 1，0.5–2）、独立语段最短停顿（默认 0.28 秒）；高级：纯 mora 路线的“自动长音补格”开关。改即保存，只重建派生节奏，不跑模型 |
| **逐音属性** | 每个音块：首元音、相对音高、音内走向、相对响度；缺失显示“未知” |

## 3.4 检索模式（界面部分；算法见 09、10）

### 3.4.1 语音 · 音块检索

- **只在点「查找」时搜索**；没有音块时按钮禁用。查询是一次快照，后台索引变化绝不重跑。
- 三种策略：**不限节奏 / 必须满足节奏 / 按节奏相似度排序**；后两者旁边显示“BPM n”或“归一化节奏形状（无 BPM）”。
- 首尾条件：任意位置 / 从句首 / 到句末 / 句首与句末。
- 倍速条件（仅有 BPM 的节奏策略）：「限定播放倍速」默认关，范围初值 0.8–1.25×；「原速偏好」0–1，默认 0.1（“0 = 只按节奏排序；越大越偏好接近 1×”）。
- **输入**：
  - 不限节奏：一排编号音块（显示音名八度或“任意音高”、元音或“任意元音”、“≥Xs”），可拖拽排序，「＋ 音块」。
  - 节奏策略：钢琴卷帘（每拍约 90 px，吸附网格）：空白处拖动画块、拖块移动、拖右缘调长度，块不能重叠；
    双击/右键/回车编辑属性，Delete 删除。默认两块 [0, 0.5) 和 [1, 1.5) 拍，总长 4 拍，网格 0.5 拍。
- 【界面默认】策略“不限节奏”；首尾“任意位置”；首尾判断依据“停顿段”；不跨停顿；范围“整句和语段”；不调整段间休止。
- **音块属性弹窗**：起点/终点（拍）、前导辅音（任意/无/指定序列）、目标音高（音名 + 八度 + 音分容差，默认 50；“留空不限，八度留空匹配音级”）、
  音高波动范围上限（默认 100 音分）、有效 F0 覆盖率下限（默认 0.5）、原声时值（按有效持续或音块跨度，上下限秒）、首元音、
  角色、音内走势（上扬/下降，默认阈值 1 半音）、停顿段内相对音高（旧版文案“语段内音高”；偏高/偏低，默认 2 半音）、相对响度下限（dB）、时值范围（拍）、
  起音强度下限、“声音必须持续到块尾”。越界或重叠：“音块必须在查询范围内，长度为正且不能重叠”。
- **语音搜索设置**弹窗：首尾判断依据（停顿段 / 整个采样）、允许跨停顿（旧版文案“允许跨长休止”）、元音组末尾至下一元音锚点的最大间隔、
  查询长度（拍）、绘制网格（1/0.5/0.25/0.125 拍）、范围（整句和语段 / 整句 / 语段）、（高级）允许调整语段之间的休止、清空音块。
  （“停顿段”= 被任一检出停顿隔开的连续音块；“语段”= 按 ≥0.28 秒停顿切出的虚拟子句。旧版两个选项都叫“连续语段”，容易混淆，见 09 §9.3。）
- 状态行：“{n} 个采样 · {m} 处命中 · {t} ms · k 项缺少有效分析”。

### 3.4.2 独立音高检索

- 旧版：查询文本，默认 `0.40 A4` + 换行 + `0.30 C5..D5`（“每行：持续秒数 音符或范围”），下方实时画区间预览。
  **新版改为图形查询**【所有者，2026-10-05】：横向时间轴上的音高块画布，与语音检索的音符块画布同一种操作习惯（10 §10.2.1）；文本只作复制/粘贴辅助。
- 搜索对象：已保存采样 / 已分析原片音轨（原片音轨模式只保留文字、标签表达式、原片、保存筛选器这些范围条件）。
- 参数：容差（默认 50 音分）、有效覆盖（默认 0.8）、最长缺口（默认 0.12 秒）；折叠的高级参数（稳定度、能量上下限）。
- 索引覆盖：“a/b 已索引”；为 0 时禁用搜索并给「准备当前范围索引」；索引任务完成只刷新覆盖数，**不重新搜索**。
- 结果标明“近似检索”，候选被截断时提示。

### 3.4.3 单音 · 音色 / 单音 · 瞬态

- 说明：“条件作用于当前已登记采样整体。缺少所选特征时不命中；句内音块条件请使用语音检索。”
- 「后台准备当前范围指标」；勾选指标后填最小/最大；“更多指标”展开全部。
- 默认指标——音色：有效声音时长、原始音高、音高波动、可靠发声时长、高阶谐波占比、谐波能量占比、高频占比；
  瞬态：有效声音时长、起音上升时间、尾部衰减时间、峰均比、低频占比、高频占比、噪声倾向。每个指标悬停显示定义和单位。
- 这是**即时浏览过滤**（不是固定结果）。

### 3.4.4 结果呈现与固定结果

- 每次检索生成一个结果标签“节奏 · HH:MM:SS (条数)”/“音高 · …”，与「浏览」并排、可关闭（只删结果集合，不删采样）。
- 结果状态行：“固定结果 · N 项 · 固定成员与排序 · 后端 x 秒 · 显示 y 秒”、「用这些条件再搜」（生成新标签）、近似提示。
- 采样按行显示；**一个采样的多处命中在行内展开**：默认列前 3 个，可展开其余；每个命中：试听按钮（左键原声/右键卡拍，
  卡拍用该命中证据所选的方案〔修正：19 K3〕，旧版固定用近快；不强行重排成查询形状）、定位按钮（“起–止 s”）、证据标记（“严格/近似 · 倍速×”，悬停显示平均偏差、占格冲突、变速代价）；
  勾选“前后 0.3 s”扩大试听范围（只影响试听）。
- 命中右键（语音命中）：循环命中区 / 返回原片 / 保存命中区…（选性质，按命中所在资产的角色预填〔新：19 F2〕，旧版默认“语音”；**每次保存都新建采样**）/ 拉平命中区… / 导出原声 WAV / 导出卡拍 WAV /
  导出视频片段 / 复制 REAPER 交接 / 导出 REAPER 条目文件（试验）。保存或拉平后提示“…当前结果保持不变”，列表不插入不重排。
- 音高命中的右键只有：循环命中区 / 返回原片 / 保存命中区… / 拉平命中区…（音高命中没有卡拍，“前后 0.3 s”禁用）。
- 定位命中：打开该采样，波形画出“命中区”，选区设为命中范围并滚到命中前 0.3 秒，出现命中导航。
- 失效成员：保留原位置；显示“采样已删除”或“音源已变化”；其命中按钮和复选框禁用；点击已删除行提示“此采样已删除，保留搜索记录供参考”。
- 原片音轨结果（音高检索的原片模式）：一条音轨一行，没有缩略图和星标；点击跳到原片页并带上命中范围和音源。

| **编辑字幕／区段边界** | 让可见范围内的字幕和区段边界可拖；表单显示正在编辑的标注和开始/结束（原片秒或资产秒）；「保存边界」后可「撤销边界修改」。只改时间标注，不移动已有采样 |
| **分层控件与派生轨** | 同采样详情：派生范围开关/层级/角色；图层勾选音素、字幕、区段标签（默认全开）。派生轨显示该原片的所有用户采样（跨音轨和资产），点击打开该采样（跳到采样库）。音素层只显示**在同一物理声音上测得的**对齐结果（不推理）；区段标签层单独一行显示字幕带来的说话人（“人声 · 角色：X”/“人声 · 参与者：X”），并显示已确认的 OP/ED |
| **波形** | 原片时钟；高约 145 px；整集需要横向滚动；控制条同采样详情（播放/暂停、播放选区、循环、适合窗口、放大选区、总览、频谱）。原片页波形不画音高线 |
| **选区操作栏** | 播放位置（秒，步长一帧）、源开始秒、源结束秒（3 位小数）；**同级按钮：截取 / 拉平… / 分离… / 回导… / 导出 ▾**（选区 WAV、选区视频片段）。波形右键菜单与这些按钮同源，另含“设为开始 (I) / 设为结束 (O)” |

截取弹窗（原片页）：显示“a–b 秒”；名称预填（随选区和音源实时重算）；性质三选一 + 未分类（按音源轨道角色预填）。
保存后提示“已保存派生采样和来源”，**跳到采样库并打开新采样**。

### 3.5.5 字幕的三个独立操作

| 操作 | 规则 |
|---|---|
| **导入字幕标记** | 说明：“只保存标记，不创建采样。可分批勾选，也可限定时间范围。”起止秒过滤；表格：原文、区间、状态（可导入 / OP/ED 区间（采样时跳过）/ 无效范围（不可勾））。**默认勾选全部有效行**。「导入勾选标记」。可一次处理多部原片（某一部没有关联字幕只跳过该部并说明）。
字幕版本按**文件内容**区分：同一内容的再次或分批导入归入同一版本、只补登未登记的行；内容不同的文件形成新版本并成为当前版本；重新导入旧文件即切回该版本（见 06） |
| **从字幕导入音效采样** / **从字幕导入台词语音** | 起止秒 +「预览范围」（改起止要重新预览）。说明：“可勾选字幕分批创建；表头全选覆盖当前预览的所有分页。前后各扩展 0.1 秒（显示当前设置值），绑定默认人声轨/音效轨「名称」，可在设置中调整。每次勾选都会新建独立采样，允许重复导入或删除后重建；OP/ED 排除项跳过。”表格：名称、采样区间、状态（待创建 / OP/ED 排除 / 轨道范围外 / 无有效名称），只有“待创建”可勾。**默认一项都不勾**。表头复选框跨所有分页全选（有半选态）。「创建 N 项」（0 项禁用）；完成后提示创建了多少个 |

没有对应默认轨时报错：“请先指定默认音效轨 / 默认人声轨”（不回退混音）。

### 3.5.6 人声／音效与默认轨

- 说明：“这里只显示原混音和完整覆盖原片的音轨，不列出逐句片段。默认轨用于后续字幕采样，已有采样和分析不会换轨；同角色音轨共享区间标签。”
- 表格：原片音轨（标题 · 轨 n · 起–止 s，悬停显示路径）、角色（多选：人声、音效）、默认（每个已赋予的角色一个勾选）。改动立即保存，可撤销。
- 能列出的：容器里的每条音频流 + 完整覆盖原片且未变速的分离结果；同内容重复登记只在显示上去重（保留已设默认的那条）。

### 3.5.7 OP/ED

- 入口：右键「从字幕识别 OP / ED」（单个/批量）；右键「手动标记 OP/ED…」。（旧版的参考帧扫描已去掉【所有者，2026-10-05】。）
- 字幕识别结果弹窗「字幕音乐区间」：原片、识别结果（“OP · a–bs”）、状态（“规则识别 · 已应用 / 已存在”、错误原因、或“未发现成对标记”）；没有字幕时提示“未关联字幕；可手动标记”。
  **规则出错未自动登记时**，仍列出已配对成功的区间（按前后半片给出 OP/ED 建议），每行可改用途并「确认此区间」，来源记为“人工确认”。
- 已有标记的用途或范围要改：撤销后重新确认，或用「手动标记」重标。
- 「OP / ED 标记」弹窗：原片多选、「手动标记…」（原片、开始秒、用途、长度；可预览开头 [起点−3, 起点+7] 秒与结尾 [终点−4, 终点+3] 秒）；
  「已有标记」列表（原片/类型/时间/来源：字幕规则或人工确认；查看、撤销）。
- ⓘ：“标记只排除字幕采样导入和批量语音分析；手动截取、整轨分离和原片播放仍可用。撤销标记不会删除已有采样。”

### 3.5.8 语音分析（原片页入口）

- 旧版叫「准备语音分析…」，按钮「补齐缺失分析」；新版是统一的「语音分析…」（08 §8.4〔新：所有者 2026-10-05〕），只是从原片页发起时默认范围是“所选原片中性质为语音、带文本、原字幕区间不与已确认 OP/ED 交叠的采样”。
- 弹窗：说明“分析使用每个采样**实际绑定**的声音（不触发分离、不换音源、不改绑）”，并显示范围内绑在原混音或无角色资产上的采样数
  （提示：要用人声分析，应先整轨分离、设默认人声轨，再从字幕建采样）；“将分析 M 条；N 条已是最新，跳过；K 条无法处理（原因）”；
  默认不勾的「也重新分析已是最新的 N 条」；依赖状态（环境就位/缺失；“环境检查只确认文件存在，不代表模型推理已实测”）。
- 完成后在任务抽屉「打开结果」看逐条状态与失败原因（§3.1.3）。
- 旧版这一步会顺带按所选人声模型补做整轨分离并把采样改绑到人声轨上——新版**不这样做**（分离和默认轨须事先显式完成，见 18 §18.2）。

### 3.5.9 重新定位与删除

- **重新定位文件…**：选择一个文件（单选）→ 确认框说明“只改文件位置引用，不校验内容和时长”→ 执行 → 重新打开该原片。
- **删除原片…**：确认框列出将删除的内容：该原片的采样 N 个、为它生成的库内音轨/成品 M 个（大小）、字幕版本、标注、分析、OP/ED 标记；
  并写明“磁盘上的原片文件和已导出的文件不会删除”。有运行中/排队的相关任务时拒绝。删除当前浏览的原片会先暂停媒体。
- **采样独立化**（刚需）：在删除前可选择把部分采样“独立化”后保留（见 04 §4.8）。

## 3.6 工具与工作流页（附加功能 P2）

- 旧版这里是空页（“暂无工具”）。新版用来放**脚本批量操作入口**：用户（借助非 agent 的大模型）写好脚本，粘贴到框里运行，
  批量查询/修改库中数据。
- 必须遵守：脚本只能通过**公开的、有文档的业务操作接口**读写（不能直接写数据库）；所有写入先**预览影响**（对象数、字段前后对比），
  确认后**原子应用**，并能用「撤销最近资料修改」撤销；脚本运行有超时和取消；失败不留半成品。
- 页面上提供：接口文档（可复制给大模型）、脚本输入框、预览结果、应用、运行日志。
- 这是“添头”：如果新架构做它需要大改，就先不做，但不要把路堵死（业务操作接口本身对 UI 也有用）。

### 鼠标

- 波形：单击定位；拖动 >3 px 建立选区（只有一个选区）；只能拖两端调整，不能整体拖动；**Shift+单击**选中光标下的整个字幕或音素（字幕优先，音素用有效范围）；
  **Shift+拖动**按原始手势吸附与之重叠的字幕/音素边界（只扩一次，不级联）；吸附和拖出只针对**当前可见的图层**；滚轮缩放，横向滚动平移。
- 列表试听按钮：左键原声，右键默认卡拍。
- **Option（macOS）/ Alt（Windows）+ 左键拖动 = 导出拖出**：波形上按在选区内导出选区，否则导出指针下的标注区间（音素/字幕/音块）；
  列表行（属于勾选集时导出整个勾选集）、检索命中、分离结果声部、参考音轨都可以拖出。规则见 12（越过约 4 px 才生成；准备期间 Esc/松手/失焦即放弃；不劫持右键；按钮、输入框、选区把手上不触发）。
  可拖出的表面统一提示“Option/Alt＋拖动：导出音频；Esc 取消”。

### 文案与反馈

- 每个异步操作提交后给出“已排队/已保存”的反馈，完成或失败可在任务抽屉看到；后台失败必须让用户看见（旧版有几处错误事件无人监听，被静默吞掉）。
- 处理提交/完成后提示“当前结果保持不变”，不自动重排。
- 性质、操作名称在全应用统一（旧版“调谐单音/有音高”“星标/收藏”“原版/原声”混用）。

## 3.9 有意不存在的东西（界面级）

- 没有单独的“试听此音轨”按钮（选好音源后由统一播放器播放）。
- 没有“预览字幕 → 确认导入”两步关卡（标记导入一步完成；采样导入有预览但默认不勾）。
- 没有“加载整片连续播放”“手动刷新”“准备附近预览”按钮（原片打开即可整段连续播放；列表由任务变化提示刷新）。
- 没有重复的分离入口；没有“隐藏旧片段”的开关。
- 没有行末三点菜单列；详情「资料与来源」页里没有标签编辑（标签在详情顶部内联加/删；批量的「编辑资料」表单可以改本地标签）。
- 原片页没有卡拍试听和 REAPER 交接（卡拍需要采样的节奏分析，在采样库做）。
- 没有文件夹、集合、虚拟文件夹的界面。
- 没有 OP/ED 参考帧扫描（所有者 2026-10-05 去掉）。
- 没有模型选择、模型顺序、模型切换（只有一个对齐模型）；没有版本（edition）切换。
- 没有日常 JSON 编辑；JSON/脚本只作为高级入口；没有 SQL 控制台。
- 没有强制向导、没有新手引导。
- 没有自动重搜、自动刷新、自动重选（用户主动截取/回导后打开新子采样除外）。

## 3.10 旧版界面问题（不要照抄）

以下是旧版已知的界面问题，新版应避免（多数已在上文按正确行为描述）：

- 原片页截取、分离、拉平不在同一层级，原片波形没有右键菜单；切换参考音源会把选区重置为整个范围。
- 原片页画面焦点下方向键/空格被画面和外层各处理一次（跳 5 秒和逐帧互相覆盖）。
- “选区播放结束后再按播放”可能跳回范围开头（需确认的旧问题）。
- 导出选区时偷偷新建采样；“导出选区视频”实际导出的是 JSON 清单。
- 截取弹窗缺少“未分类”选项；性质、操作名称多套叫法混用。
- 批量拉平结果进入不可见的待审核批次。
- 详情面板的快捷编辑（改名、备注、评分、星标、性质、本地标签）绕过可撤销的编辑通道；存在采样级“标签屏蔽/覆盖层”。
- 卡拍相关导出要求先打开过节奏页；“试听父采样”会无故切换标签页。
- 多处默认对齐模型与设置不一致（新版只有一个模型，此问题自然消失）。
- 中断（interrupted）的任务界面不能重试，任务抽屉显示内部英文名。
- 空闲清理的说明文字与实际策略不一致；设置里两个重复的环境检测按钮。
- 分离进度条与 Studio 实际进度格式不匹配，从不显示；三轨分离完成后参考音源列表不自动刷新。
- 右键列表空白处沿用上一次右键的行；↑/↓ 会选到已删除的行；列表试听按钮在播放命中时状态错位。
- 数字输入的“标红拦截”误拦无关请求（例如滚动结果列表）。
- 缩略图在画面绑定变化后不更新；持久化的页码在启动时被清零。
- 一处字幕标记批量导入中，有一部原片没有字幕会导致整个弹窗失败。

# Part D 重做要求（半基线的改造目标）

## PD1 所有者对现有界面的评价【2026-10-05】

- 每个页面**承接哪些功能**已经优化得很好（Part A 是基线）；
- 但**布局只是勉强能用，而且很不统一；交互方式很混乱，并不好用**；
- 希望重构每个页面的布局和交互：每个区域承接哪些功能、入口放在哪里、如何交互、快捷键、选择与右键规则。

## PD2 交接人整理的具体不统一之处（从 Part C 与旧版问题归纳，供重做时参考）

| 方面 | 现状 | 期望 |
|---|---|---|
| 集合的选择规则 | 采样列表：常驻复选框 + 浏览焦点 + 多选状态（单击含义会切换）；原片表：另一套勾选；命中：行内展开、另有勾选与“前后 0.3 s”；分离声部、标签管理又各不相同 | 所有集合（采样、原片、命中、声部、标签）用**同一套**选择与右键规则，PB3/PB4 在各处一致 |
| 同一动作的名称与位置 | 回导 / 回导成品… / 回导…；拉平… / 拉平选区… / 拉平命中区…；截取 / 截取… / 保存命中区…；导出分散在菜单、选区栏、右键 | 一个动作一个名字；主入口位置固定（例如“选区操作栏”在原片页与详情同构），右键与命令面板同源 |
| 选区操作 | 原片页与详情的选区栏控件和顺序不同；旧版原片页还曾把截取/分离/拉平放在不同层级 | 两处的选区栏同构（PB5、PB6） |
| 检索模式 | 音块检索用卷帘与属性弹窗；音高检索是纯文本框（所有者：“太突兀，和其他检索不是一个画风”）；单音指标是一排数字框 | 三种模式的查询编辑和结果呈现风格统一（PB16）；音高查询见 10 §10.2.1 |
| 快捷键 | 方向键在“原片浏览区”和“视频画面”焦点下含义不同（逐帧 vs ±5 秒），旧版还会重复触发；Delete 在列表和原片表含义略不同 | 一张全应用的快捷键表，焦点规则明确、无冲突、无重复触发 |
| 弹窗 | 许多操作都是弹窗，弹窗里再开弹窗（拉平弹窗内有自己的波形播放器；筛选器编辑、标签批量、资料编辑各一套） | 常用操作就地完成，复杂操作用弹窗；不叠多层；弹窗风格一致 |
| 状态可见性 | 当前音源、当前选区、当前范围条件（保存筛选器、单标签、性质、表达式）、全局 BPM 分散在不同角落 | 关键状态一眼可见（P13），尤其是“现在的操作会作用于哪个音源、哪个选区、哪些采样” |
| 详情面板 | 常驻区很高，三个标签页（音素与分析 / 节奏与卡拍 / 资料与来源）的划分与操作菜单有重叠 | 划分可重议，但 PA3 的职责一项不少 |
| 结果与浏览 | 固定结果用标签页与「浏览」并排；浏览条件一变自动切回浏览 | 保留 PB7 的语义，呈现方式可重做 |

## PD3 动工前交给所有者确认的东西（一次）

1. 每个页面的区域草图（或可点原型），标出每个区域承接 Part A 的哪些职责；
2. **统一交互规则表**：单击、双击、勾选、修饰键点击、右键、键盘、拖出，在每类集合与波形上的行为；
3. **快捷键表**（含焦点规则）；
4. **入口表**：每个功能的主入口与同源入口（右键、命令面板），名称统一；
5. 与 Part C 不同的地方各用一句话说明理由（不需要走完整的 02 §2.7 模板）。

确认之后的细节调整不需要逐条确认；但不能删减 Part A 的职责、不能违反 Part B 的意图和 02 的原则。

## PD4 重做时不要做的

- 不要借重做之名改功能（增删功能、改默认处理、改算法）——那属于基线变更；
- 不要加向导、引导页、自动刷新/自动重选（02 P3、P8）；
- 不要把“浏览焦点”和“选择集”重新混在一起；
- 不要为了“简洁”把专业参数（音分容差、BPM、扩展量等）藏到找不到——高级参数折叠可以，但要能找到并说明效果（P13）。
