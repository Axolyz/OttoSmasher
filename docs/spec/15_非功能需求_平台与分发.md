# 15 非功能需求、平台与分发

---

## 15.1 平台

- **macOS 14+，Apple Silicon（arm64）**：所有者的主要开发与使用机器。
- **Windows 10/11 x64**：必须可用（2026-10-04 确认）。旧版 Windows 包曾通过 CI 冒烟测试，但 DirectML、原生视频嵌入、高 DPI、实际拖放和 REAPER 粘贴**都没有实机验收**。
- 不需要：macOS Intel、Linux 桌面包、浏览器版。
- 本地桌面应用；不需要账户、权限、联网（除了用户显式触发的模型下载）。

## 15.2 性能

| 场景 | 目标 / 参考 |
|---|---|
| 打开一集原片（1080p HEVC10 + FLAC，约 24 分钟） | 立即可播、可任意跳转；波形在后台生成，不阻塞播放 |
| 范围播放截停 | 由播放引擎保证，界面卡顿时仍准确（旧版：界面阻塞 700 ms 时误差 ≤ 2 个 48 kHz 采样） |
| 采样库翻页（10,000 条） | 单页摘要 < 3 秒（旧版约 60 ms） |
| **三大搜索**：音块检索、节奏检索、音高检索【所有者，2026-10-05】 | 约 **3 万条、每条约 3 秒**的语音采样上，常见场景（16 §S3、S5 及 R14、R15 的典型查询）**30 秒内**完成。非硬性目标，但用来规划进程模型（检索并行、可取消、不阻塞界面）、索引和数据库结构。旧版参考：约 4k 采样的音块检索 3.45–4.92 秒。旧文档里的音高检索性能目标有误，已删除 |
| 列表点击试听 | 快速开始（原生直接读原片/音轨的区间，不先导出 PCM） |
| 整集人声分离 | 由 Studio 决定（旧版 hyperacev2 整集约 15 分钟）；结果全集复用 |
| 批量语音分析 | 旧版 3,840 条 × 3 模型 414 分钟；单模型应约三分之一或更好 |
| 后台任务 | 不阻塞界面；界面不能因轮询任务而卡顿（旧版一次轮询 10 MB 的教训，摘要必须轻） |

## 15.3 存储

- 约 4k 采样时日常附带数据目标约 **4 GB**（不含原片、模型与环境、备份、开发副本）。
- 生成音频用 LAME VBR V0；原片不复制不转码；回导保持原格式；可清理缓存高/低水位 512/384 MiB、1 天过期（13 §13.3）。
- 原片可能很大且用户磁盘有限 → “采样独立化”是刚需（04 §4.8）。

## 15.4 可靠性与数据安全

- 原片和用户导出文件永不被应用删除或改写；生成文件原子发布；数据库事务；崩溃后不留半成品登记。
- 任何模型/外部工具失败都不破坏已有数据，不产生假成功的结果；失败原因可见、可重试。
- 删除和清理都要用户明确授权；危险操作（删除原片、全局改名）有影响预览。
- 资料修改可撤销（07 §7.6）。

## 15.5 可观察性

- 任务进度、日志、错误原因在界面可见；日志写在工作区，错误提示里给出位置。
- 外部工具（Studio、ffmpeg、Rubber Band）的版本、请求/命令、设备、输入输出路径都要记录。
- 模型状态区分“文件就位 / 运行库可加载 / 实测通过”。

## 15.6 安全

- 本地服务（如果新架构有）只监听本机，只接受本机 Host 与同源请求；渲染进程不能打开任意文件或远程 URL（播放器只接受应用自己提供的媒体）。
- 不上传原片或任何数据到在线服务；不自动下载模型。

## 15.7 界面基础要求

- 中文界面；当前只支持日语采样（中文、英文采样后续支持，流程相同，08 §8.9）。
- **界面国际化预留**〔新：所有者 2026-10-05〕：本轮界面只有简体中文，但必须按可翻译的方式实现，之后加语言不需要改业务代码：
  - 所有用户可见文案放在文案资源里按键查找，不写死在组件或后端里；用词以 01 §1.6 的术语表为准；
  - 后端返回**错误码 + 参数**，由界面按当前语言生成提示（规格里引号中的中文提示是 zh-CN 文案）；日志可以只用一种语言；
  - 数字、时间、文件大小按界面语言格式化；布局要能容纳较长的译文；
  - 性质、角色、分面、任务类型等的显示名都走文案资源；**数据里存稳定的内部值**，不存显示文字；
  - 导出文件名里的固定词（如“原混音”“拉平-”“卡拍-”“片段”）由文件名模板决定，默认取当前界面语言（12 §12.1）；
  - 界面语言与采样语言（04 §4.9）是两个独立的设置。
- 1920×1080、缩放 100%/125%/150% 下布局可用；最小窗口约 850×600。
- 页面不整体滚动，集合面板各自滚动；分页固定底部；按钮切换状态时不位移（如“播放/暂停”固定宽）。
- 说明放在 ⓘ 里；数字输入允许中间态。

## 15.8 分发

- 形态：macOS 的 `.app`（ZIP）与 Windows 的便携 ZIP；每个 ZIP **小于 2 GB**（旧版发布门槛：严格 < 2,000,000,000 字节）。
- 应用包含运行所需的一切（运行库、ONNX Runtime、媒体工具、播放组件、G2P 辞典与 tokenizer、模型配置等非权重支持文件）；
  **不包含**：模型权重、PyTorch、PyMSS Studio、用户素材。
- 首次启动可以把运行库释放到用户目录（旧版：按构建 ID 分目录、校验 SHA-256、支持中文路径、失败可重试、显示准备窗口）。
- 程序目录只读、工作区与程序分离；更新应用不覆盖工作区。
- 未签名/未公证时在文档里说明，并提供 SHA-256 校验和。
- 模型由用户按 README 自行下载放置（可以另行提供“模型合集”压缩包作为便捷选项，内含清单与校验值，只含定型的四类 ONNX 模型及支持文件）。
- 发布前的冒烟检查（旧版做法，建议沿用）：在含中文和空格的隔离路径、清空 Python/Conda 环境变量的条件下启动；空工作区；
  运行库探测通过；不含 torch 与权重；原生播放能精确截停一段短区间；媒体工具可用。
