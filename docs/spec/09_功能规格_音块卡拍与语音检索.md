## 9.0 术语（旧版两个都叫“连续语段”，新版必须区分）

| 术语 | 定义 | 用在哪里 |
|---|---|---|
| **停顿** | 按能量检出的安静区间（§9.3.1），是可伸缩的“弹性间隙”，其中的弱声保留 | 时值扣除、卡拍弹性 |
| **停顿段** | 被**任一**检出停顿隔开的连续音块；音块的停顿段序号 = 结束时刻不晚于该音块起音的停顿个数 | 检索邻接（默认不跨）、首尾判断依据、停顿段内相对音高/相对响度的基线、占格推断的累计重置 |
| **语段** | 按**较长**（默认 ≥0.28 秒）的停顿从整句切出的虚拟子句，父句保留 | 检索范围（整句/语段）、按语段量化、段间休止调整 |
| **音块** | 听感上的一个起音（§9.2） | 量化、检索、卡拍的基本单位 |
| **占格** | 一个音块从起音到下一个起音占的整数格数 | 量化骨架 |
| **方案** | 某个量化路线在某个密度（每拍 2^k 格）和 BPM 下的卡拍结果 | 试听、导出、交接 |

## 9.1 概念速览

```
音素（对齐结果）──合组──▶ 音块 ──按实测时值分配整数格──▶ 占格骨架（与 BPM 无关，存一次）
        │                                   │
   能量 ─┴─▶ 停顿 ─┬─▶ 停顿段（任一停顿切分）  │ 选 BPM 与 2^k 密度（近快/近慢）
                   └─▶ 语段（≥0.28 秒停顿切分）▼
                                     卡拍方案：起音目标拍 + 时间映射 → 渲染/试听/导出/REAPER
检索 = 在“相邻、有序的音块”上，先确定邻接，再按逐块条件和节奏证据筛选、打分
```

## 9.2 音块（节奏单元）

- 只有元音（a i u e o；清音 I/U 视为 i/u）和拨音 N 参与；**其他任何标签都打断**：辅音、促音 cl、停顿（pau/SP/AP）。
- 一个元音并入前一块的条件：前一个音素是元音（不是 N）、此处不是人工拆点、与前一块末尾的间隔在 **[−1 ms, 35 ms]** 内【基线参数】。
- N **只向后附着**到前一个元音所在的块；N 之后的元音另起一块。
- 每块记录：起音（第一个成员的开始）、结束（最后一个成员的结束）、首元音、成员、起音强度（成员强度的最大值，强度定义见 08 §8.6）。
- 例：`ch i i i` → 1 块；`k a i` → 1；`k u i` → 1；`e i` → 1；`o u` → 1；`k a N` → 1；`a N i` → 2；`a SP a` → 2；`k a k a` → 2。
  同一元音重复（如「ちいい」）默认合成一块，若实际是重新发音，用户在音素前**手动拆开**。
- 人工拆点按“第 k 个音素之前”记录，绑定分析版本（分析变了要重新确认）。
- 一句最多 128 个音块，起音必须严格递增。
- 〔中英文预留〕元音集合按语言给出（日语为 a i u e o + N）；见 08 §8.9。

## 9.3 停顿、停顿段与语段

### 9.3.1 停顿（只看能量，不看模型标签）【基线参数】

1. 在分析窗口内，对声道平均后的音频按**不重叠的 10 ms 块**计算 RMS（原采样率）。
2. 阈值 = max(全部块 RMS 的第 85 百分位 × 0.25 × 灵敏度, 1e-5)；RMS ≤ 阈值的连续块构成安静段，长度至少 0.12 秒 / 灵敏度。
3. 与促音（cl、q、Q、っ）重叠的安静段不是停顿（闭塞已经计入占格）。
4. 安静段裁到 [首个音素开始, 末个音素结束]，裁后仍须 ≥ 0.12 秒 / 灵敏度；最后两侧各内缩 20 ms，得到停顿区间（标记为保留音频的弹性间隙）。
- 【界面默认】停顿检测灵敏度 1（允许 0.5–2，每个采样可单独设置；旧版界面允许 0.2–3 而后端只收 0.5–2，要统一为 0.5–2）。
- 模型标了停顿但实际有声 → 不是停顿；没有停顿标签但实际安静 → 是停顿；音素内部的短安静核心也能检出（例：16 kHz 下 0.3–0.45 秒幅度 0.001 → 停顿 0.32–0.43，保留音频）。
- 停顿里的低电平声音（呼吸、弱辅音）在卡拍时**原样保留，不置零**。

### 9.3.2 停顿段

- 停顿段序号 = 结束时刻 ≤ 该音块起音的停顿个数。用途见 §9.0。

### 9.3.3 语段

- **自动切分**：停顿（内缩之后）长度 ≥ **0.28 秒**【界面默认，可设 0.16–2，每个采样可单独设置】，且左右各有完整的音块
  （左块结束 ≤ 停顿开始、右块起音 ≥ 停顿结束），切点 = 停顿中点，切点不落在任何有声音素内部，停顿不与促音重叠。
  模型空白、模型停顿标签、字幕空格都不是依据（例：0.65 秒的模型空白不切；0.15 秒的声学停顿不切）。
- **手动切分**：在第 k 块之前切（k > 0，不能在第一块前），切点左侧取前一块结束、右侧取下一块的前导辅音开始（辅音归右）；**手动合并**：抑制某个自动切口。
- 语段集合 = 整句 + 各语段；整句本身不被修改。
- 语段的 mora 从 0 重新编号，保留开头辅音和尾音；语段 mora 不可靠时记为未知，不吞并父句其余文字。
- 分析版本、切分参数变化后旧语段失效；用到旧语段的方案/命中要拒绝并提示重新生成。

## 9.4 时值、占格与量化

### 9.4.1 时值【基线参数】

- 第 i 块的区间 = 本块起音 → 下一块起音；最后一块的终点 = min(max(末块结束, 末块起音 + 1 ms), 分析窗口终点 − 1 ms)（分析窗口指采样或语段的范围）。
- 区间内与停顿重叠的时长记为**休止秒数**（最多扣到只剩 5 ms）；**时值** = 区间 − 休止秒数，至少 5 ms。语音总时长 = 各块时值之和。
- 时值 ≠ 音素时长。

### 9.4.2 量化路线

| 路线 | 说明 | 界面 |
|---|---|---|
| **原节奏 · 无 mora** | 只按实测时值推断整数格；**完全不依赖 mora 元数据**（改读音、改 mora 都不影响结果）。使用大数字惩罚 | **默认**；主界面只出现它 |
| mora 参考校准 | 把文本 mora 数作为软先验（权重 0.10），可让占格比 mora 多或少不止一格；复杂度权重固定 0.045（不随惩罚度变化） | **高级设置**（所有者 2026-10-05：不常用，收起） |
| 纯 mora | 直接用文本 mora 数作占格；任一块缺 mora 对应时整条路线**显式不可用**并说明原因（不拿时长去猜） | 高级设置 |

- **纯 mora 的逐块格数**：块的首 mora = 成员 mora 序号的最小值；块 i 的格数 = 下一块首 mora − 本块首 mora，末块 = mora 总数 − 末块首 mora；结果须在 1–64，否则该块缺 mora。
  （所以促音、长音的 mora 计入前一块。）
- **自动长音补格**（只对纯 mora 路线，默认关，高级设置）——**是什么**：台词里拖长的元音（比如喊“あ——”时实际拖了好几拍，但文字只算 1 个 mora），
  纯 mora 路线会只给它 1 格，卡拍时就被压得很短。打开补格后，系统按这句话的平均 mora 时长估一个“每格应有多长”，
  **如果某块的元音实际时长明显超过文字 mora 数应占的时长，就给这块多加几格**（只加格、不加起音，不改变其他块）。
  公式：τ = max(40 ms, 中位数{时值/格数 : 时值/格数 > 35 ms})；对不与停顿交叠的块，若元音（a i u e o，不含 N）总时长 > (格数 + 0.5)·τ，
  则格数 = min(64, max(原格数, round(元音时长/τ)))。
- **人工占格**：对任意块锁定格数（1–64），三条路线都生效；派生子采样不继承。缺 mora 时也可以手动填占格（不伪造文本 mora 数）。
- **大数字惩罚度**【界面默认 1×，范围 0–3】：1× 对应复杂度权重 0.045；只作用于原节奏路线；改动后只重建派生节奏和检索索引，**不重新推理**。

### 9.4.3 原节奏路线的占格推断【基线算法，逐项复现】

输入：各块时值 d（§9.4.1）、各块停顿段序号、上一块的休止秒数、人工占格、（mora 参考校准时）各块文本 mora 数 c。

1. 中位时值 m；权重 w = clip(d/m, 0.25, 1)；尺子范围 [lo, hi] = [max(0.015, m/5), max(2m, 0.03)] 秒。
2. **种子**：所有 d/n（n = 1..8）中落在 [lo, hi] 的值，再加 m；四舍五入到 6 位小数去重。
3. **基础代价**（用于筛种子）：n = clip(round(d/tick), 1, 64)（人工占格覆盖），代价 = 平均[w·ln(n·tick/d)² + cw·ln(n)² + 0.10·ln(n/c)²（有 c 时）]。
   按基础代价从低到高取种子，丢弃与已选种子对数差 < 0.035 的，最多取 12 个。
4. **束搜索**（对每个种子 tick）：逐块推进，状态 = (累计代价, 已选格数序列, 上一块的对数比, 当前累计格数, 当前累计秒数)。
   - 在第 0 块、停顿段变化处、或上一块休止秒数 > 0 时**重置**累计格数和累计秒数，步数从 1 重新计；
   - 每块候选 n：人工占格则只有该值，否则 {1} ∪ {clip(round(d/tick) + j, 1, 64) | j = −2..2}；
   - 加入的代价：时值拟合 w·r²（r = ln(n·tick/d)）；连续性 0.25·min(wᵢ, wᵢ₋₁)·(r − 上一块 r)²（重置时为 0）；
     累计漂移 0.055·((累计格数 + n − (累计秒数 + d)/tick)/√步数)²；大数字惩罚 cw·ln(n)²；（mora 参考校准）0.10·ln(n/c)²；
   - 以（累计格数 + n, n）为键去重保留代价最小者，每步保留代价最低的 48 个状态；
   - 结果代价 = 最优累计代价 / 块数。
5. **精修**：对代价最低的 3 个结果，用加权（w）几何平均重新估 tick = exp(Σw·ln(d/n)/Σw)，落在 [lo, hi] 内就再解一次。
6. 取代价最低者；同时按代价顺序保留最多 3 个占格互不相同的方案（含最优）作为备选。cw = 0.045 × 大数字惩罚度（允许 0–0.135）。

必须满足的性质（来自旧测试）：时值 (0.11, 0.22, 0.10, 0.32, 0.11) 秒 → 占格 [1, 2, 1, 3, 1]，tick ≈ 0.11 秒（±0.025）；
1–3 块的短句也能给出方案；一个 11 ms 的极短间隔不会迫使整句用极细网格；插入 1 秒停顿后占格不变、休止格单独记录、尾音保留；
合并的长元音、促音不产生新的起音；原节奏路线的结果与 mora 元数据完全无关。

### 9.4.4 由占格得到目标拍【基线算法】

在密度 d（每拍 d 格，d = 2^k）下：tick = 语音总时长 / 总格数；第 i 块的休止格 = max(0, round(休止秒数ᵢ / tick))；
目标拍：第 0 块为 0，之后逐块累加 (占格ᵢ + 休止格ᵢ) / d；句尾控制点 = 末块目标拍 + (末块占格 + 末块休止格)/d；
整体倍率（时长倍率）= 总格数 / d × 拍长 / 语音总时长（不含休止）。

## 9.5 卡拍

### 9.5.1 BPM 与候选密度【基线算法】

- BPM 来自顶栏全局 BPM（20–400）。**留空 = 原速卡拍**：先在 120 BPM 下求近快密度，再固定该密度在 20–400 BPM 间二分（最多 32 次），
  使语音播放速度 = 1（误差 < 1e-5 即停；最终误差 > 1e-3 则报“当前节奏在起音保护约束下无法保持原速”）。
- **语音播放速度** = 源语音时长（扣除弹性停顿、休止、首尾留白）/ 目标语音时长——总时长之比，不是各段速度的平均；必须用**真实时间映射**（§9.5.2）算，不能用公式估。
- **候选**：初始 k = ceil(log2(总格数 × 拍长 / 语音总时长))；若 2^k 下速度 ≥ 1−1e-5，再看 2^(k−1) 是否也 ≥ 1，是则 k 减 1 继续，否则停；
  若 < 1 则 k 加 1（最多 24 步，|k| ≤ 40）。得到：
  - **近快** = 速度 ≥ 1 的最小密度（“不慢于原速”的最近一档）；
  - **近慢** = 再低一档（速度 < 1）；
  - **倍快** = 再高一档（只用于方案选择/预览，不参与检索）。
  例：0.25 秒 × 4 块走纯 mora、120 BPM → 近快密度 2、速度 1；近慢密度 1；12–24 ms 的极短音块时密度可以 > 8。
- 默认卡拍方案（列表右键试听、详情默认方案）= 近快。

### 9.5.2 时间映射【基线算法】

- 控制点 = 各音块起音 + 语段段尾控制点 + 句尾控制点（按源时间排序）；每个控制点有源时间和目标拍。
- **保护核心**：每个控制点左右各 r 个样本原样复制，r = min(8 ms, 左侧间距/4, 右侧间距/4)，其中间距取“源侧间距”和“目标侧间距”中较小者；核心斜率为 1。
- 核心之间是“桥”；首个核心之前、末个核心之后的音频按**整体倍率**映射。
- 桥内的停顿是弹性片：先给停顿保留至少 min(停顿总长, 桥目标长度的 2%)，语音部分的伸缩比不超过整体倍率，剩余时间由停顿吸收；
  没有停顿的桥按比例整体伸缩。
- 映射以**源音频采样率**的帧计算（渲染、REAPER 标记都用它，保证核心逐样本复制）；检索时为了比较候选速度可以在 48 kHz 上计算。
- 平移不变（所有目标拍整体后移，映射整体后移）；空的查询画布在渲染时裁掉，但所选音频与核心保留；总长 > 10 分钟拒绝。

### 9.5.3 渲染与试听

- 每个桥用保音高的时间伸缩（Rubber Band R3 引擎，按精确目标帧数），两端 3 ms 交叉淡化；核心逐样本复制；输出 PCM 24-bit。
- 严格卡拍保证“当前对齐标记落位”，不保证标记本身准确——好不好听由人判断。
- 试听方式：严格卡拍 / 卡拍＋节拍 / 卡拍起点声 / 原始起点声 / 原声＋原始起点。命中试听可勾“前后 0.3 秒”（只影响试听，不进导出）。
- 方案身份 = (分析版本, 路线, 人工占格与拆点, 停顿参数, BPM, 密度, 惩罚度)；任一变化旧方案失效，**需要时自动重算**（不要求用户先打开节奏页）。
  导出清单记录方案与映射。

## 9.6 语音检索（统一音块检索）

### 9.6.1 查询

- 1–64 个**相邻、有序**的音块条件；策略：**不限节奏 / 必须满足节奏 / 按节奏相似度排序**。
- 节奏策略下每个音块有一个音符块 [起拍, 止拍)：有序、不重叠、长度为正、在查询长度内；相邻起拍间距必须 > 2 × 容差。
- 首尾：任意 / 从句首 / 到句末 / 句首与句末；判断依据：**停顿段**（默认）或整个采样。“首尾”指第一个/最后一个**节奏起音**，不是字幕边界。
- 允许跨停顿（旧版文案“跨长休止”）：默认不允许（窗口内不跨任一停顿）；允许时可设“元音组末尾到下一元音锚点的最大间隔”。
- 节奏范围：整句和语段（默认）/ 整句 / 语段。
- 检索范围：当前浏览范围（在检索时快照进固定结果）。
- 【界面默认】策略“不限节奏”、首尾“任意位置”、依据“停顿段”、不跨停顿、原速偏好 0.1、倍速范围关（初值 0.8–1.25×）、容差 min(0.1, 网格/3) 拍。

### 9.6.2 先邻接，后过滤【基线算法】

1. 在每个采样（及其语段）里枚举连续 n 个音块的窗口；不允许跨停顿时，窗口内所有音块必须属于同一停顿段。
2. 最大间隔：相邻两块之间 **下一块的元音锚点（起音）− 上一块的结束** 不得超过设定值（不是起音差，也不从辅音起点算）。
3. 首尾：窗口第一块是采样第一块，或（依据为停顿段时）前一块属于不同停顿段 → 视为“句首”；末块同理为“句末”。
4. 逐块检查属性条件；中间夹着一个不合格的块，这个窗口就不合格（**不能跳过**）。
   例：C-E-G 三块查询在音高 60,64,79 与 72,76,67 两处都命中（只给音级时跨八度匹配）；中间插入 61 → 只剩 1 处；末块音高未知 → 不命中。

### 9.6.3 逐块条件（缺失一律不命中）【基线算法】

帧口径：本节所有音高类条件都只用**可靠帧** = 有声 且 F0 > 0 且 置信度 ≥ 0.5（10 §10.1）。帧范围 [起音, 结束)。
〔新：19 G4〕旧版的“音内走势”和“停顿段内相对音高”用的是宽口径（置信度 > 0.05），新版统一为可靠帧。

| 条件 | 定义【界面默认】 |
|---|---|
| 目标音高 | 可靠帧 MIDI 的中位数（≥3 帧）。给了八度：与 音级 + 12×(八度+1)（C4 = 60）的绝对差；只给音级：圆周距离 ((x − 音级 + 6) mod 12 − 6)。容差【50 音分】，0–600。只填八度不填音名：界面禁止 |
| 音高波动范围 | 可靠帧 MIDI 的 P90 − P10，×100 为音分（≥3 帧）；上限【勾选后默认 100 音分】 |
| 有效 F0 覆盖率 | 可靠帧数 / 块内帧数；下限【0.5】；只在给了音高或波动条件时生效 |
| 首元音 | a/i/u/e/o（复合块取第一个元音；只有 N 的块为未知） |
| 前导辅音 | 从第一个成员向前取，遇到停顿、AP、spn、N、促音 cl 或元音即停（〔新：19 G3〕**cl 不计入**；旧版会把 cl 算进前导辅音）；规范化后与给定序列（模型音素标签，如 `k`、`sh`、`ky`）**完全相等**；“无前导辅音” = 空序列 |
| 原声时值 | 按“有效持续”（默认）= max(0, min(有效结束, 持续终点) − 有效开始)；或“音块跨度” = 有效结束 − 有效开始；上下限（秒）。有效开始/结束见 08 §8.5 |
| 持续终点 | 从块结束开始：块内若有停顿，截在第一个停顿开始；再截到块内最后一个“活跃帧” + 5 ms（活跃 = 能量 > max(1e-10, 整个采样能量第 85 百分位 × 0.0064)）；没有活跃帧为未知；人工版本取块结束 |
| 角色 | 块区间上的单一角色（`character:`）；多人或不唯一为未知 |
| 音内走势 | 用**可靠帧**（≥5 帧且首末跨度 ≥ 60 ms）：后 1/3 时间段的 MIDI 中位数 − 前 1/3 时间段的中位数；上扬/下降阈值【1 半音】 |
| 停顿段内相对音高（旧版界面叫“语段内音高”） | 块的可靠帧 MIDI 中位数（≥3 帧）− 所在**停顿段**内所有可靠帧 MIDI 的中位数（≥3 帧）；偏高/偏低阈值【2 半音】 |
| 相对响度 | 块能量 dB（块内各帧能量平均后取 10·log10）− 所在**停顿段**内各块能量 dB 的中位数 ≥ 下限 |
| 起音强度 | ≥ 下限（0–1）；强度未知时即使下限是 0 也不命中 |
| （节奏策略）时值（拍） | 按映射换算后的块长（拍）在上下限内 |
| （节奏策略）持续到块尾 | 持续终点映射到拍后要到达音符块终点 |

逐块分 = |音高偏差| / max(1, 容差)（给了音高时）+ 波动 / max(1, 上限)（给了波动时）。

### 9.6.4 节奏证据与评分【基线算法】

对每个窗口，在允许的范围（整句和/或语段）里分别计算证据，取最优（排序键 = (round(分数, 10), 速度 < 1)，即同分取近快）。
候选方案：有 BPM 时取近快、近慢两个（§9.5.1）；无 BPM 时只用密度 1 的方案。开启倍速范围时，播放速度不在范围内的候选作废。

**(1) 必须满足节奏 + 有 BPM**——平移拟合：

- 命中块与查询块一一固定对应；在所有平移量里找可行的：每个起音与对应起拍的偏差 ≤ 容差；每个音符块 [起拍, 止拍) 内不得有其他起音；
  时值（拍）条件按精确映射满足；要求“持续到块尾”的块，其持续终点映射后 ≥ 止拍。
- 可行平移中取（平均误差, 最大误差, |平移|）最小者。
- 代价 = 平均起音误差 + 0.03 × 形变 + 0.003 × 改动的休止格数（仅段间休止调整时）+ 原速偏好 × |log₂ 播放速度|；
  形变 = 各相邻控制点的局部时长比除以整体倍率后取 |ln|，再求平均。播放速度取这次匹配的实际速度。
- 候选方案的密度可以是任意 2^k（与 §9.5.1 一致）〔修正：19 K1〕。旧版这条路径只接受 1、2、4、8，近快/近慢落在其他密度（例如极短音块需要的 16）时该候选被静默丢弃。
- 结果里显示的“平均偏差”应是真实的平均起音误差〔修正 A27〕（旧版字段名不匹配，显示的是代价值；不影响排序）。

**(2) 按节奏相似度排序 + 有 BPM**——中位数平移：

- 用候选方案把窗口内各块的起音、块尾、持续终点换算成拍（在控制点之间线性插值）；整体平移 Δ = 中位数(查询起拍 − 实际起拍)。
- 偏差 = |实际 + Δ − 起拍|；持续不足 = max(0, 止拍 − 持续终点拍)（只对要求持续的块）；占格冲突 = 落在某个音符块 [起拍, 止拍) 内的其他音块起音个数。
- 代价 = 平均(max(偏差, 持续不足)) + 冲突数 + 原速偏好 × |log₂ 候选速度|；时值（拍）不满足的候选作废。
- **严格** = max(偏差, 持续不足) ≤ 容差 且 无冲突；否则为“近似”。

**(3) 无 BPM（两种策略都用）**——归一化形状：

- 实际位置按 [首个命中起音, 末个命中块尾] 归一到 0–1，查询按 [首块起拍, 末块止拍] 归一，容差也除以查询跨度；其余同 (2)，但没有速度项。
- “必须满足节奏”且无 BPM 时，只保留严格的。

**汇总**：「必须满足节奏」只保留严格命中；「按节奏相似度排序」保留严格和近似（近似标明，显示偏差、冲突、变速代价）；
算不出证据的窗口不进结果，计入“缺少有效分析”。
命中分 = Σ 逐块分 + 节奏代价；同一采样同一组音块只留最好的命中；采样内按（分数, 起点）排序，结果按（最佳分数, 采样）排序。

### 9.6.5 结果与性能

- 完整排序后**全部**存为固定结果（不截断），翻页读取（每次 ≤100 条），翻页不重搜；恢复时不搜索、不播放。
- 检索不跑模型、不登记采样、不读波形；只用派生索引（可以由已有测量现场补建投影，但不推理）。
- 状态：“n 个采样 · m 处命中 · t ms · k 项缺少有效分析”。
- **性能目标**【所有者，2026-10-05】：“三大搜索”——**音块检索**（不限节奏）、**节奏检索**（必须满足 / 按相似度排序）、**音高检索**（10 §10.2）——
  在约 **3 万条、每条约 3 秒**的语音采样上，常见场景（16 §S3、S5 一类：BPM 180 的 x-xx 到句末；C-E-G；几块带音高/元音条件的人力查询；一两行的音高查询）
  在 **30 秒内**完成。不是硬性指标，但要用它来规划进程模型（检索可并行、可取消、不阻塞界面）、索引结构和数据库设计。
- 索引在分析、设置（路线、惩罚度、停顿参数）、拆点/占格、采样绑定变化时失效；随时可重建，属于可清理的派生数据。

### 9.6.6 段间休止调整（高级，可选）

- 语音搜索设置里的“允许调整语段之间的休止”，默认关（所有者：不常用，收进高级）。
- 开启后，对有多个语段的采样，把各语段按顺序拼接：语段之间的休止格默认 = max(1, round(源间隙/tick))，可调范围 1 – max(32, 默认值)；
  语段内部节奏与段尾控制点固定；不能删除间隙或段尾。
- 候选组合有上限（最多评估 128 种）：只有一个连接时全部枚举；多个连接时取“保持原值、按查询跨度分摊、各连接附近的取值”等有界组合。
  排序 = (节奏误差, 改动格数总和, 代价, 组合)；零误差且零改动即停。代价额外加 0.003 × 改动格数。
- 时值条件用本段的段尾控制点，不用下一段起点。

## 9.7 命中上的操作

- 试听：原声与卡拍各一步（旧版左键原声、右键卡拍）。卡拍试听用**该命中证据所选的方案**（排序依据的是近快就用近快，是近慢就用近慢）〔修正：19 K3〕；
  旧版固定用近快。列表行（非命中）的默认卡拍仍用近快。
- 定位：打开采样，画出命中区，选区设为命中范围，滚到命中前 0.3 秒，出现命中导航。
- 保存命中区（新建采样，默认性质“语音”）、拉平命中区、导出原声/卡拍 WAV、导出视频片段、复制 REAPER 交接。
- 执行任何动作前核对命中仍有效（采样未删、绑定未变、分析版本未变），失效则提示“命中已失效，请重新查询”。
