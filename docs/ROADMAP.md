## 1. 当前版本

**0.1.10**（2026-11-12）已在 GitHub 发布，macOS arm64 和 Windows x64 均为云端构建。日用 Mac 已换成云端包，并打开原工作区。Windows 基础功能此前已通过实机验证，本轮新增改动通过云端验证，尚未在 Windows 实机复测。

发布前本地端到端测试 56 项通过、7 项跳过。两平台的发布包冒烟通过。Windows Core 的试听页测试修正文件名夹具后，在 `main` 上复测 707 项通过、19 项跳过，界面与打包检查也通过。发布方式见 [DEVELOPMENT.md](DEVELOPMENT.md)「发布」。
