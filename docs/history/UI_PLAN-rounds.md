## 11. v3 相对 v2 的修改（所有者 2026-10-05 第二轮意见）

| 意见 | 修改 |
|---|---|
| 未分类不是收件箱；很多采样分不进三类；不用字幕时性质要手动配，很多人会用默认值 | 去掉收件箱/分拣台；未分类按语音呈现（列表与舞台都同语音）；数字键设性质保留 |
| 不要任何海报墙 | 调谐/非调谐的卡片墙、原片片库都改成列表 |
| 列表必须有画面缩略图；采样的同步画面太小 | 每行 88×50 缩略图（播放按钮在缩略图上）；舞台画面 400×225，可放大到全宽 |
| 语音面板里的原句、读音重复 | 去掉；读音以“假名在上、音素在下”的 mora 分组显示 |
| 更想直接看到映射图和卡拍方案 | 节奏与卡拍面板常驻舞台：方案三选一 + 映射图 + 试听方式；不再需要“节奏台” |
| 单音也要语音面板 + 各自的声学面板；调谐单音不要拉平台按钮；单音不要节奏卡拍 | 照做（拉平仍可从动作条发起） |
| 标注想直接盖在波形上，但多层会乱、编辑不知道在改哪层 | §3.1：覆盖层只有一个且只有它能编辑；其他层可选车道/淡线/分带三种显示，请在原型里比较 |
| 原片也被当成采样了 | 原型里手动截取的采样按规格 04 §4.7 第 3 条命名为“原片名 起–止”，看起来像原片；现在名称写全起止区间，并在副信息标“手动截取 · 未分析” |

## 17. 阶段 4 实现时的取舍（2026-10-08，等所有者验收时确认）

- 设置「文本前端」：原型是一行「编辑用户辞典 / 预览 G2P」按钮，实现为直接在设置组里展开辞典编辑器（逐行报错、Tab 插入制表符）与预览（PROTOTYPE_GUIDE §2：照内容更丰富的一边）。
- 舞台波形卡：覆盖层可选「音素 / mora / 无」（字幕、区段·说话人、音块图层随后续阶段补），另一个作车道；「放大选区」「频谱」与舞台动作条留到阶段 5/8（ROADMAP L19）。
- 语音面板：「对齐文本 · G2P」「精确时间」做成锚定小面板；「分组与停顿」随阶段 6（L20）；多了「对齐选区…」（资产选区 + 文字区段，08 §8.4 第三个入口）。
- 原片时间线：覆盖层/车道多一个「音素」层，只显示当前音源资产上的测量（R11.10，L21），不可在原片页编辑。
- 语音分析确认框底部写明模型文件是否就位；缺文件时是红色警告（原型只有一行灰字）。

## 18. 阶段 5 实现时的取舍（2026-10-08，等所有者验收时确认）

- 拉平台照原型 flattenSheet：左侧“外选区”卡（台内独立试听、波形 + 金色 F0 线 + 对齐音素覆盖层、预估目标）与“成品”卡（名称），右侧处理范围与目标音高的选项卡片、交界选侧、手动输入；底栏写默认值随入口。比原型多：波形下一条“处理区间”车道（预估时 Core 算出的实际区间）、内部拉平的左右过渡可改（规格“默认各 0.05 秒”）、手动目标与选项的合法性由 Core 即时判断（纯数字、平台不足 30 ms、需要对齐时直接写原因并禁用「开始拉平」）、缺模型文件时的警告、打开就失败（如绑定音轨缺失）时的错误页。
- 批量拉平台：只有处理范围（整段 / 仅元音 / 首元音起）与目标音高（段内 / 交界 + 选侧），没有手动与内部（Q10）。
- 舞台动作条（L19）：▶ 原声 · 选区起止（可直接输入；没有选区时就是整个采样）· 截取（子采样）· 拉平 · 分离 · 导出 ▾（选区 WAV）；回导随阶段 9、卡拍随阶段 6。波形卡头加「放大选区」；频谱随阶段 8。「对齐选区…」从波形卡挪到语音面板的按钮行（它是语音分析的入口）。
- 入口：舞台动作条与舞台 ⋯ = 采样详情入口（默认首元音起 + 交界左）；采样右键、原片动作条与时间线右键「拉平选区…」= 其他单个入口（整段 + 段内自动）；批量 ▾「拉平 N 项…」。检索命中的「拉平命中区…」随阶段 7。
- 任务抽屉：单个拉平的「打开结果」直接跳到成品采样；批量是结果表（成品可点开 / 失败原因）+「只重跑失败项（n）」。
- 设置新增「拉平」组：三个入口各自的默认处理范围与目标音高。

- 全局播放条：当前声音的名称、版本标签（原声 / 卡拍 · BPM · 方案 / 原速卡拍 · 方案，非原声时加声音）、进度、停止。导出交接条（可再拖进 DAW）仍未做（阶段 8/9 与拖出一起）。

## 20. 阶段 7 实现时的取舍（2026-10-08，等所有者验收时确认）

- 结果头：「浏览 n」+ 每次检索一个可关闭的标签（“节奏 · HH:MM (n)”/“音高 · …”，组件库的 ClosableTabs）；检索按钮照原型是一个“⌖ 节奏检索 ▾”：左半边按用途打开默认方式（语音/未分类/全部 → 节奏检索，调谐 → 音高检索，非调谐 → 瞬态筛选），▾ 选其他方式。窄窗口时结果头换行。
- 检索浮层：从顶部展开、横跨采样库（原型同）；第一行最左边多了一个“检索方式”分段（语音 · 节奏/音块 / 音高检索 / 单音 · 音色 / 单音 · 瞬态），不用回到 ▾ 换方式。
- 所有者 2026-10-08 验收后：检索的准备改为自动在后台做（任务抽屉里标“后台”，设置「语音分析 → 自动准备检索」可关）；浮层里的覆盖数与「准备」按钮保留，用于还没准备好或关了自动的时候。
- 覆盖预检（原型只在音高里画了“已索引 a/b”）：语音也有“已就绪 n/m · k 项没有语音分析”和「准备当前范围索引（n）」——语音检索索引要解码音频算停顿，规格要求检索本身不读波形，所以要先准备（任务）；为 0 时「查找」禁用。音高的原片音轨模式显示“已测音轨 a/b”，准备 = 整轨测 F0。
- 节奏卷帘照原型（每拍 90 px、网格虚线、块里写编号与条件简写）；不限节奏时是一排编号音块（拖动排序、「＋ 音块」）。右侧就地编辑：前导辅音（任意/无/指定）、首元音、目标音高（音级 + 八度 + 容差），其余条件收在「更多条件」里。设置弹出：首尾依据、跨停顿与最大间隔、查询长度、网格、节奏范围、（高级）段间休止调整、清空。
- 音高画布：照原型（钢琴键列 + 0.5 秒竖线 + 琥珀色块），块可以是单个音 / 音高范围 / 滑音（滑音画成斜的平行四边形）；就地提示由 Core 校验（与检索同一套规则）；「更多」里是忽略八度、时长弹性（所有者 2026-10-08）与稳定度、能量、句首/句尾。文本只作「复制为文本」「从文本粘贴」。原型标的“近似检索”去掉（所有者：完整检索不漏检）。
- 单音 · 音色 / 瞬态：照原型的指标表（勾选、最小、最大、单位、缺失数），每个指标悬停 ⓘ 看定义；筛选作用在「浏览」上（即时，不是固定结果），状态行写“单音 · 瞬态筛选 · n 个条件 · 清除筛选”。
- 命中：行下命中时间线（绿 = 严格、琥珀 = 近似；悬停看偏差/冲突/变速代价；单击定位）；当前行展开命中小卡（▶ 左键原声、右键证据方案卡拍；默认列前 3 个、可展开其余；「前后 0.3 s」只在语音检索）。命中条是可视化的一部分（同波形画布），用原生按钮实现键盘与读屏。
- 定位：舞台选区 = 命中、波形画命中框（绿/琥珀）、滚到命中前 0.3 秒；舞台动作条右侧「‹ 命中 i/n ›」。
- 命中右键：定位、试听命中区、返回原片、保存命中区…（= 定位后打开舞台的「截取」，性质按资产角色预填，每次新建）、拉平命中区…；语音命中另有导出原声/卡拍 WAV、复制 REAPER 交接两种。视频片段随阶段 9。
- 失效成员：保留原位；写“采样已删除 / 音源已变化 / 命中已失效（分析或测量变了）”，命中禁用、不能勾选；单击已删除行提示“此采样已删除，保留搜索记录供参考”。原片音轨结果：一条音轨一行（没有缩略图和星标），单击命中跳到原片页并带上命中范围与音源。
- 状态行：“固定结果 · n 个采样 · m 处命中 · t ms · k 项缺少有效分析”，另写“n 项索引未就绪（没搜）”、BPM；「再搜一次」= 用这个结果当时的条件与范围再搜（新标签）。

## 21. 原片上的四类对象落到界面（所有者 2026-10-09【基线变更】，等所有者验收时确认）

所有者原文与答复见 docs/QUESTIONS.md「原片上的四类对象」。界面上的做法：

- **原片页**：图层栏 = 台词段（覆盖层默认）/ 音效提示（车道默认显示，可关）/ 区段标签（只放用户画的区段标签与 OP/ED）/ 音素 / 采样（2026-10-12 前叫“派生采样”，意思是“这个原素材上的采样”）；
  台本、画内字幕、字幕层显示同一份段文本。右键：
  - 段（台本行、画内字幕、波形上的段）：从这段建采样… · 语音分析这段… · 编辑这段… · 在这里拆分… · 与下一段合并 · 删除这段（被采样使用时写出数量）；
  - 音效提示：从这条提示建采样… · 编辑… · 删除；
  - 选区：添加台词…（与已有段重叠时选替换 / 切开 / 取消；切开只在每个重叠段都只从一侧伸进来时可用）· 新增音效提示… · 新增区段标签…；
  - 一处命中多个对象时各一个子菜单，只有一个时直接列出（菜单头写明是哪一段）。
- **建采样一个动作**：单条 = 锚定小面板（动作条「截取」、段 / 提示右键、命中「保存命中区…」、分离结果「保存为采样」），批量 = 整页表格（从台词段 / 音效提示 / 整段原片）；
  背后同一个 `samples.plan`，名称、性质、范围、判定区间、来源完全相同（e2e「看片逐句建采样」逐字段比较）。
  - 我定的：从段 / 提示右键建、命中保存、分离结果保存之后**留在原来的页面**，提示里给「打开」（场景 F 是边看边建，每次跳走会打断）；动作条「截取」照旧跳到采样库打开新采样。
- **导入字幕**：整页里四类开关、重叠时“替换 / 保留原有”、汇总（新增 / 无变化 / 替换（删除几个已有、其中几段有分析）/ 跳过）、按类分页的逐行表格（勾选 = 导入；跳过的行可「强制替换」，碰到受保护的段要二次确认并列出会丢掉的编辑与人工修正）、OP/ED 页（规则有错时逐对选用途）。批量导入（原片列表勾选）按默认选项各自导入。
- **舞台语音面板**：判定区间时间框 + 「设为选区」+ 波形上的“判定区间”带子；读到几段、选哪一段修；「编辑这段…」用原片页同一个段编辑框；「添加台词…」= 在文本层加一段（加完打开这段在这条轨上的分析确认框）；不可用时写明原因（第 X 段未分析 / 改过待重新分析 / 第 X 段与第 Y 段在 a–b 秒重叠）。
- **语音分析确认框**：原片入口与段右键可选「默认人声轨（没有就是原混音）」或「当前查看的轨」。
- **设置 · 语音分析**：「改段后自动在后台重跑」（默认关）。
- **列表状态**：新增“改过，待重新分析”“部分段未分析”；“已分析 ◐” = 只读到某段的一部分（采样范围没盖住整段）。被采样范围裁掉一部分的音素在舞台的音素上逐个标 ◐（QUESTIONS「原片上的四类对象」：原先“有音素伸出就 ◐”在原混音上几乎全是对齐假象，改了口径）。

## 22. 阶段 8 / 9 实现时的取舍（2026-10-09，等所有者验收时确认）

开发者定的细节都在 docs/QUESTIONS.md「阶段 8 / 9 开发者定的细节」1–17。界面上与原型的差异：

| 原型 | 实现 | 理由 |
|---|---|---|
| 范围行「＋」是一个常驻输入框，聚焦弹出分组建议 | 同；建议按分面分组、带采样数，人物写“n · 单人 m”；最后一组“高级 → 标签表达式…”打开一个小框（与主表达式各自校验） | 照原型 |
| 选用筛选器 = 用它替换范围行，改动后“已修改 · 更新 · 另存” | 同；⚑ 菜单里另有「管理筛选器…」（改名、上移下移、删除） | 原型那项只是提示 |
| 人物块没有“只要单人”的入口 | 单击人物块切换“只要单人”，块上写“（单人）” | 规格 07 §7.3 / 04 §4.2.9 要有 |
| 主表达式出错用提示条报位置 | 查找栏标红，下方一行写“标签表达式第 n 个字符：原因”，列表保持上一次有效的条件 | 提示条几秒就消失，不好对照 |
| 状态行“51 个采样 · 新建在前” | 同；点“新建在前 ▾”可换排序（按名称 / 时长）与每页行数（一屏一页 / 20 / 50 / 100） | 规格 07 §7.1 |
| 编辑资料、添加 / 移除标签是两步（预览 → 保存） | 同；预览是逐字段前后对比的表；移除标签只列有本地数量的，继承的给「去来源」 | 照原型 |
| 管理标签：⋯ 菜单 / 命令面板 | 顶栏 ⋯「管理标签…」与命令面板；表里每行「改名」「移除」，也可右键 | 照原型 |
| 舞台标签：继承的点一下去来源；“加入范围” | 单击任一标签出菜单：加入范围 / 去来源（继承的）/ 移除（本地的）；标签后面淡色写来源（本地 / 区段 / 原片 / 自动） | 一个动作入口装下三件事 |
| 舞台画面 400×225、⤢ 全宽 | 同；点画面 = 试听原声 / 停止；右下角写画面模式；没有画面时写“此采样没有画面”并给「画面绑定…」 | 照 UI_PLAN §3 |
| 导出视频片段框：版本 原声 / 卡拍、卡拍画面两种、带声音 | 同；单音没有卡拍版；没有画面时报错并给「画面绑定…」（Q8） | 照原型 |
| 命中右键「导出视频片段…」 | 与采样同一个框，标题写“某采样的命中 a–b 秒”；语音命中可选卡拍（按命中证据所选的方案，与命中卡拍试听 / WAV 同一段渲染和映射）与两种卡拍画面；音高命中只有原声 | 12 §12.5“卡拍版只能导出完整采样或命中”（L36，2026-10-10 补） |
| 术语：原片 / 集数 / 舞台（所有者 2026-10-10） | 界面改叫 **原素材 / 素材标识 / 详情区**（见 QUESTIONS「术语、快速开始、README 亮点」）。本文件里的“原片”“舞台”保留原样，分别等同于原素材、详情区 | 业务范围不只番剧：游戏语音、音效包、外部视频 |
| 批量「把原混音设为人声与默认人声轨（n 个）」 | 原素材多选菜单与作品组菜单；已有默认人声轨的不动；一次编辑可撤销 | 游戏语音、干声素材一次上千个，逐个开「人声 / 音效与默认轨…」做不完 |
| 命令面板（⌘K，原型 #palette） | 所有者 2026-10-10：简单版、按业务来，不必对照原型。⌘K 或顶栏「命令与跳转」打开（输入框里也生效）。最上面一组“作用于”当前对象——采样库：已勾选集，没有勾选就是**当前查看的采样**；原片页：已勾选的原片，没有勾选就是当前原片——就是右键菜单那一份（子菜单写成“父 › 子”），所以与右键同源；然后是本页动作（检索四种、用途视图、只看星标、筛选器逐个、清空范围、范围表达式、存为 / 管理筛选器、导入；原片页「添加原片…」），最后是全局（切页、撤销“某修改”、任务、刷新列表、管理标签、BPM 改回原速、设置及其各组直达、主题、快捷键）。子串过滤（空格分开的词都要出现，名称开头的排前，有输入时每条右边写分组），回车执行；输入 20–400 的数 = “BPM 设为 N”；最近用过的 5 条在空输入时排最上面（重启恢复） | 原型只有静态列表；按“对着当前对象做事”组织更顺手 |
| 删除原片框：先独立化要保留的采样（可选），表格 + 筛选 + “已选 n 个 · 约 x MB” | 同；另写几个要生成画面片段；确认按钮“独立化 n 个并删除原片”；批量删除多个原片时不出现这一块（已独立化的照样保留） | 照原型 |
| 回导框：选文件、预览“文件时长 · 回导终点”、名称、性质 | 同；越界时预览写明、保存按钮不可点 | 照原型 |
| （原型没有）存储面板 | 设置「存储与缓存」：按类别的占用表（可清理 / 不清理 / 近期受保护；可清理 = 缓存、语音检索索引、任务目录里成功分离的中间文件）、按原片的库内音轨、「清理缓存与闲置结果」 | 规格 13 §13.3.4 |
| （原型没有）播放条的导出交接 | 最近一次导出的文件名（可普通拖出）+「定位」+ × | UI_PLAN §1 |
| （原型没有）频谱 | 波形卡头「频谱 ▾」：波形 / 对数 / 线性 / Mel | 规格 05 §5.3.2 |
| （原型没有）媒体已释放的原片 | 查看器换成说明 + 留下的采样 + 台本；列表行写“媒体已释放 · n 个独立化采样” | 规格 04 §4.8 |
