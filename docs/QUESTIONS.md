### 原片上的四类对象：文本层的段 / 音效提示 / 区段标签 / 采样（2026-10-09，所有者定稿【巨大的基线变更】）

> **以下所有者原文是唯一准绳**：与交接包（docs/01–19）、本文件更早的条目（含 2026-10-08「分析挂在“句”上」）或任何其他文档冲突时，一律以这一版为准。影响阶段 1–7 的所有环节。

#### 所有者原文

**已经定下的设计**

**A. 原片上的四类内容**
1. 文本层（说了什么，供分析）：每个原片一层“台词段”，用原片时间。每段包含：区间、文本（即对齐文本）、说话人（属性）、来源（字幕行 / 手输），以及来源记录（字幕文件、行号、导入时间）。
   - 文本段作用于整个原片，不设作用范围。
   - 字幕来源和手输来源完全同级，编辑方式一样。
   - 字幕里本来就重叠的行（例如两人同时说话）允许存在。
2. 字幕音效提示层：字幕里的（某某音效）行放在这里。作用于整个原片，所有轨可见，可以开关；不进文本层、不做对齐、不带标签；可编辑、可删除，不做自动修正。
3. 区段标签：时间上的属性，保留原片 / 角色 / 资产三种作用域。
   - 说话人来自台词段的属性，由段参与标签继承，仍只对带人声角色的资产生效；
   - 用户自己画的区段标签是独立对象，互不影响。
4. OP/ED 区间：规则和语义不变。
5. 采样：表达“哪段有价值”。不在建采样时自动建同名标注；原片页通过派生轨显示采样。
   去掉“手动在某条轨上标注有价值音效”的单独入口；时间上的东西只来自字幕导入、音效提示，以及用户显式画的区段标签。

**B. 字幕导入 = 一次显式操作，四类一起进**
- 台词段 → 文本层；音效行 → 音效提示层；说话人 → 段属性；♪～/～♪ → OP/ED 区间。不建采样。
- 导入弹窗分四类预览，各自可以取消勾选（默认全选）。OP/ED 规则无错时随导入登记，有错时在弹窗内逐对确认。
- 整次导入原子提交、可撤销。顶部汇总：新增 / 无变化 / 替换（其中有分析结果、需重新分析的数量）/ 跳过。
- 取消字幕版本机制：文本层不分版本，重新导入就是一次批量编辑。
- 重叠判断：每一行新字幕与时间上正长度交叠的已有段比较：
  - 没有交叠 → 新增；
  - 文本和区间都相同 → 无变化；
  - 只与未受保护的导入段交叠 → 按全局选项“替换”或“保留原有”（选保留原有即跳过这一行）；
  - 与任何受保护段有交叠，哪怕只碰到一点 → 跳过这一行。
- 受保护段：段本身被用户改过（文本、边界、拆分合并产物、手输段一律算），或者在任一条轨上有人工修过的音素时间版本。两个标记在界面上可见。
- 跳过 = 这一行不进文本层，已有段不动，不裁剪也不切分。预览里逐行写明原因，用户可以逐行强制替换；替换受保护段要二次确认，写清会丢掉哪些编辑和人工修正。
- 被替换的段连同其分析一起删除（整次导入可撤销）；读它们的采样之后需要重新分析；采样的文本快照不变。音效提示和 OP/ED 按同样四种状态处理。
- 保留两个事后重做入口：「从字幕识别 OP/ED」、「按当前规则重新生成说话人」（只作用于未受保护的段）。
- 原片只关联了同名字幕、尚未导入时，播放区提供一键「导入到文本层」。画内字幕和字幕上下文都显示文本层的段。

**C. 分析**
- 分析结果归属于“段 + 具体那条声音资产”：版本、当前头、人工修音素时间都挂在这里；同一段在不同的轨上各有一份。
- 对齐窗口 = 段区间 ± 对齐容差（0.65 秒），只送这段的文本，不带邻句。D41 的“统一目标区间”改为以段为锚点；D45 的统一语音分析和“输入没变就跳过”的规则改为按“段 + 资产”判断。
- 原片页可以直接对段做分析（在默认人声轨或当前查看的轨上），不需要先建采样；分析过的段在原片波形上有音素层，截取时可以吸附音素。
- 采样独立化时，要把它读到的分析一起物化到新的音频资产上。

**D. 采样**
- 采样不拥有分析，只读取。每个采样都有一个可见、可编辑的“判定区间”（从段或音效提示建的 = 段或提示的区间；其余 = 选区），它同时决定标签继承和读哪些文本段。
- 读取规则只有一条：读与判定区间正长度交叠的所有文本段在该采样所在资产上的分析；只有一部分落入范围的音素标 ◐，与现有的子采样投影规则一致。
- 冲突：读到的多段音素在时间上重叠时，该采样的节奏分析显示“不可用 + 原因（第 X 段与第 Y 段在 a–b 秒重叠）”，不自动裁决。
- 节奏派生（音块、停顿、停顿段、语段、占格、拆点、人工占格、停顿参数）和三大搜索仍按采样计算，算法和参数一律不变；句子边界 = 采样范围。拆点、人工占格等节奏参数继续按采样存。
- 采样建立时记下的文本快照保留（用于命名和显示），之后改段不追改它；删除采样不删除段和分析。
- 所有建采样入口合并为一个动作：来源可以是选区、文本段、音效提示、检索命中、分离声部，也可以批量建。同一个弹窗、同一套默认规则、一律新建：
  - 从文本段建：选区 = 段区间 ± 字幕采样扩展量，默认建在默认人声轨上，也可以选「在当前轨上建」；名称 = 段文本；性质：台词 → 语音；
  - 从音效提示建：在当前查看的轨上（批量建时默认建在默认音效轨上），选区 = 提示区间 ± 扩展量；名称 = 括号内容（多个用“ / ”连接）；性质默认非调谐单音；
  - 其他来源的性质按资产角色预填（04 §4.2.7）；命名照旧按 A23 使用交叠的台词或提示文字。

**E. 编辑**
- 改对齐文本 = 改某一段的文本；可以拆分、合并段，改段的边界（即“改断句”）。
- 手输台词 = 在文本层加一段；和已有段重叠时，让用户选替换、切开或取消。为截取「提供台词」时也走这一条。
- 编辑界面写明“这段被 N 个采样使用，修改会影响它们”（P13）。

**F. 重要使用场景（新增）**
开着原片播放、挂上字幕，不是批量建采样，而是看到哪句好就直接从这句建采样（字幕上下文行、画内字幕、波形上的段右键都可以），看到某个轨上音效字幕对应的位置很好也能直接从这句字幕对应的范围建立采样。批量建台词采样和逐句建是同一个动作，产物完全相同。

最重要的哲学：对象各自只做一件事：

* 文本层的段 → 说了什么（给自动分析用）；
* 音效标签 → 质量参差不齐而且不知道在哪个轨上的音效（给人工拣选用）；
* 区段标签 → 时间上的属性（给继承和上下文用），之前那个；
* 采样 → 哪段有价值（给检索、组织、交接用）。

| 3 | 局部命名 | 先答“选1，但是直接写罗马字……只在一个台词块内……覆盖 1/2 及以下的音就这么命名”；**同日改回原推荐并补充**（“只选了辅音，没选元音，或者反之，就看不出来了”→ 选方案 A；“触发条件换回原推荐的没盖住整句就用”）：选区只碰到台词段、而且没有把读到的每一句都完整盖住 → 名称 =“选中部分（这几句，多句用 / 连接）”。选中部分里：完整盖住的句子写整句原文；完整选中的词写原文；词只选中一部分时，完整选中的拍写片假名，只选到半拍（只有辅音或只有元音）写罗马字。例：ボー → `ボー（…）`，只选 b → `b（…）`，ウ + 下一拍的 b → `ウb（…）`，跨两句 → `ですイk（A / B）`；完整盖住一句或多句仍是“A / B” |
| 4 | 详情区余量 | “余量里也能框选”：两边各留 max(1 秒, 采样长度的一半)（不超出音轨），余量灰显；更远用「返回原素材」 |
| 5 | 「返回原素材」换到哪条轨 | “每次都换到它来自的整轨”（拉平单音 → 它拉平前的人声轨；原混音上截的 → 原混音；回导成品 → 回导到的整轨），跳到采样的原素材时间、设好选区，在“采样”车道上突出它；永远不把局部成品当音源 |
| 6 | 旧数据 | “旧数据完全不必兼容，可以直接清空” |
| 7 | “派生”还有意义吗（截取 / 拉平 / 分离 / 回导的二次加工） | 加工一个不删：去掉的只是“采样 → 父采样”的指针；加工关系记在音轨上，任何音轨都能继续加工。原素材页“派生采样 n”改叫“采样 n”；详情区加“加工链” |
| 8 | “必须要有‘族’这个概念吗” | 不要。音素和台词段一样属于原素材时间线；只有回导例外。前提：“一个原片只有一个原始音轨……不用考虑多配音多语言多音轨的情况，如果那样的话我就拆成多个片导入了” |
| 9 | 分离出来的音效轨没有人声，怎么处理 | 用现有的音轨角色判断（见下） |

**做法**（ARCHITECTURE §4.5）：
- 音素键 = 段 + 原素材（回导来的：段 + 那个回导成品）；时间存原素材秒，各轨读时按自己的映射换算，越出这条轨的音素去掉、被裁掉一部分的标 ◐。
- 只在盖住整句、含人声的轨上测（对齐要整句）。原素材页 = 正在看的那条轨；采样详情 / 批量 = 默认人声轨，没有就是采样所在的轨（盖不住整句时沿加工链往上第一条盖得住的人声轨），再没有用原混音；
  明确选的轨不含人声或盖不住整句 → 写原因不分析，不偷偷换轨。
- **含人声** = 开着“人声”角色，或者一个角色都没开、又不是从分离声部来的（原混音以及从它截取 / 拉平 / 回导的）。只标音效的声部、没标角色的分离声部（如音乐）以及它们的加工成品不读音素、
  不能分析，列表语音状态显示“—”。按角色在读取时判断，改角色立即生效。
- 每条音轨在建立时由触发器抄下两件事：是不是从某个回导成品来的、是不是从分离声部来的（迁移 0015）。
- 去掉“按读的那条轨的文件指纹拦音素”（R11.10 对音素作废）；删除原素材、留下独立化采样时，音素和文本层一起留下，测它用的音轨只留一条记录（没有声音）。
- 采样存原素材起止（建采样时算好、不变）：排序、相关采样、“采样”车道、「返回原素材」都用它。
- 迁移 0015：加上面几列与触发器；删父采样两列；拉平采样的创建方式不再记“从哪个采样”；**旧的语音分析全部删掉**（键与时间的存法都变了），要重新语音分析一次。

**取舍（验收时请所有者确认）**：
1. 原素材换位置时换成了内容不同的文件（界面本来就提示“音轨签名不同”）：旧音素不再自动隐藏，重新语音分析即可。
2. 只盖住半句的回导成品没法单独分析（对齐要整句），确认框写原因。

**开发者决定（验收时请所有者看）**：选区同时盖到台词和音效提示时不用局部命名（照旧“A / B”）；读到的某句还没有音素时也照旧；只碰到某句前后空白（一个音都没选中）的句子只写进括号、不算没盖住；
拉平整个采样时成品沿用采样原名；导出文件名随采样名；相关采样包括所有音轨，端点相接不算，最多列 12 个 + “还有 n 个”；
半拍的罗马字：促音 cl 写成后一个辅音的首字母（后面没有辅音就省掉）、撥音 N 写 n；音素中点落在选区里的算选中；
从只盖住半句的音轨上改音素时间时只改它盖得住的那几个，被这条轨边界裁过、没改的端点保持原值；加工链里局部成品那一步点开 = 它往下第一条整轨；
没标角色的分离声部当作不含人声。

**被覆盖的旧条目**：02 P5“处理后的声音不借用来源的测量”收窄为只对回导；04 §4.2.6 来源（父采样）、§4.2.8 测量共享、§4.5 删除父采样、§4.7 规则 1（原文 — かな → 局部命名）；
