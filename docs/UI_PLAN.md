## 0. 设计理念：从“控制台”到“工作室”

旧版和 v1 的共同问题是**所有东西同时摆在桌面上**：三行筛选、侧栏、模式面板、标签页、按钮行……每个区域都在抢注意力。v2 的做法：

| # | 理念 | 具体做法 |
|---|---|---|
| D1 | **一屏一个主角** | 采样库的主角是右侧“舞台”（当前采样的大波形与加工）；原片页的主角是“画面 + 台本 + 时间线”。其余退到边上、变淡、变小 |
| D2 | **用途决定呈现**（只调整显示，不限制功能） | 统一用列表（不做卡片墙/海报墙）；每行都有画面缩略图；副信息随性质变化：语音 = 节奏字形，调谐单音 = 音名 + 音高曲线，非调谐单音 = 起音时间 + 包络。**未分类按语音呈现**（它不是收件箱：很多采样本来就分不进三类，懒得配性质的用户用默认值即可） |
| D3 | **按需出现，用完收起** | 检索编辑器是从顶部展开的浮层，查找后收起成一个结果标签；拉平、字幕导入、设置是从底部升起的**全屏工作台**；准备清单是一个弹出清单。音素编辑直接在舞台波形上进行（§3.1），节奏与卡拍直接显示在舞台上 |
| D4 | **一条全局播放条** | 窗口底部常驻：现在在响的是什么（原声/卡拍、方案、进度）；导出交接（可再次拖到 DAW）、“资料已更新”也在这里——“只有一个声音”一眼可见 |
| D5 | **原片页像视频编辑器** | 左侧可收起的原片列表 + 查看器（大画面 + 右侧台本 + 底部多车道时间线）；台本可以点句选区、Shift 点扩展，按文字截取台词 |
| D6 | **安静的视觉** | 深色工作室风格（可切浅色）；单一强调色（logo 蓝 #1b73e8，所有者 2026-10-06 由紫改蓝）；性质四色（语音青绿 #3ec7a6（2026-10-07 为避开主色由蓝改青绿）、调谐琥珀、非调谐珊瑚、未分类灰）只用在小圆点和大字上；标签收成一行淡色文字；数字等宽 |
| D7 | **交互规则统一**（沿用 v1 整理好的规则） | 单击只看不选、勾选只靠复选框类手势、右键不改选择且菜单头写明对象、⌥/Alt 拖出、同一动作一个名字（§6–§8） |

### 2.1 区域与职责

| 区域 | 职责（PA2） | 说明 |
|---|---|---|
| 顶栏的用途切换 | 性质的用途视图（未分类按语音呈现） | 就是范围的“性质”条件：单击只看一种；命令面板可多选（取并集，用通用视图） |
| 查找栏（主，列表正上方） | 文字 + 主标签表达式 + ★ 只看星标（临时条件） | 见 §2.3；最常用，所以放在列表正上方、最宽 |
| 范围行（副，一行小字） | 保存筛选器 + 标签条件（分面、可选标签表达式） | 见 §2.3；平时很少动，收成查找栏下面的一行 |
| 结果头 | 固定结果标签（浏览 + 每次检索一个，可关、可恢复）、分页、「＋ 导入」、**检索按钮** | 检索按钮随用途变：语音 → 节奏检索；调谐 → 音高检索；非调谐 → 瞬态筛选；其他用途下拉选择。状态行“固定结果 · n · m 处 · t ms · k 项缺少有效分析”，音高检索标“近似 · 可能漏检” |
| 检索编辑器（浮层） | 三种检索 + 单音指标 | 横跨整个采样库、从顶部展开，**查找后自动收起**变成结果标签；块画布 + 右侧就地属性；Esc 收起 |
| 列表 | 浏览、试听、勾选、批量、拖出 | 见 §2.2；勾选后底部浮出“n 项已勾选 · 全选全部匹配 · 批量操作 · ✕”，没有勾选时不出现 |
| 舞台（右侧） | 单个采样的加工台（§3） | 与列表同页；列表与舞台之间的分隔条可拖动（列表占 32–68%，重启恢复） |

### 2.2 用途与呈现（统一列表）

每行：复选框 · **画面缩略图**（左下角播放按钮：左键原声 / 右键卡拍）· 正文两行 · 星标。

- **第一行是名称，独占正文全宽，最多两行，超出才省略**（悬停显示全文；舞台标题完整显示、不截断）。采样名常常就是一整句长台词，所以不再和人物、时长挤在同一行。
- 第二行：副信息（随性质）· 人物 · 原片与时间 · 时长（右对齐）。
- 名称标 `lang="ja"`（中文采样标 `zh`），日文汉字用日文字形显示（ARCHITECTURE §1.3）。

| 用途 | 副信息 | 舞台面板 | 默认检索 |
|---|---|---|---|
| 全部 | 按各自性质 | 按各自性质 | — |
| 语音 | 节奏字形（音块起音与占格的小图）+ 音块数 | 语音 + 节奏与卡拍 | 节奏检索 |
| 未分类 | 同语音（无分析时显示“手动截取 · 未分析”） | 同语音 | 节奏检索 |
| 调谐单音 | 音名（`pitch:` 或测得音高）+ 音高曲线 | 语音 + 音高与声学（**没有**拉平入口按钮，也没有节奏卡拍） | 音高检索 |
| 非调谐单音 | 起音时间 + 包络 | 语音 + 瞬态（没有节奏卡拍） | 瞬态筛选 |

数字键 1/2/3/0 仍可一步设性质（对勾选集或焦点项，可撤销），改完该行留在原位、刷新后按新性质归位。

### 2.3 查找栏（主）与范围行（副）

依据规格 07 §7.3 / 18 D22 的分工：先把范围圈在某部剧、某个角色上，再在里面反复换检索条件。v3.1 按所有者第五轮意见：**常用的查找栏放在列表正上方**；**范围收成查找栏下面的一行小字**；**筛选器只放标签，文字不能进筛选器**。

```
┌ ⌕ 文字…  ⌘F                       │ 表达式 NOT "participants:*"        ┐ ★
└────────────────────────────── 白底，最宽：这次要找的，随时改 ─────────────┘
范围 ⚑ 二季·京子 ▾ · 作品 Yuru Yuri × · 人物 京子 × · ＋   已修改·更新·另存      ← 一行小字、淡色，很少动
```

| | 查找栏（主） | 范围行（副） |
|---|---|---|
| 位置 | 列表正上方、整列宽 | 查找栏下面一行（约 24 px 高） |
| 放什么 | 文字搜索（名称、读音、备注）+ 主标签表达式 + ★ 只看星标 | 保存筛选器（⚑）+ **标签条件**：分面（作品、类型、人物、音高、其他标签）+ 可选的“标签表达式”块（高级） |
| 改动频率 | 每次查找都可能改 | 很少：切用途、检索、翻页都不动它；重启恢复 |
| 保存筛选器 | 永不存入 | **保存的就是这一行**（只有标签）；选用一个筛选器 = 用它替换这一行；改动后显示“已修改 · 更新 · 另存” |
| 关系 | 在范围内再筛；`NOT` 的补集只在范围里取 | 各条件取交集，同一分面多值取并集 |
| 快捷键 | ⌘F 聚焦文字 | ⌘⇧F 聚焦“＋” |

- 性质不在这两栏里：它就是顶栏的用途切换。
- 文字、星标都是查找栏里的临时条件，不存进筛选器（所有者 2026-10-06）。规格 07 §7.3 里的“原片”条件：从原片页「派生采样」跳过来时，在查找栏出现一个临时的“原片：…”块，不存；单音的“属性条件”在单音检索浮层里（Q17，所有者已同意）。
- 固定结果保存当时两栏的快照；之后改了范围或筛选器都不重搜（规格 07 §7.3）。
- “标签表达式”块只给需要复杂范围的人（例如“排除所有多人台词”）；它和主栏表达式是两个独立的框，各自校验，出错各自标红。
- 范围条件多到一行放不下时折行。

### 2.4 命中的呈现

- 每个命中采样行下方一条**命中时间线**：整条代表采样时长，绿色块 = 严格命中，琥珀色 = 近似；悬停显示证据（偏差、倍速、方案、占格冲突）；单击 = 定位。
- **当前行**展开成命中小卡：`[▶ 0.35–0.89 s · 严格 · 1.24× · 近快]`，▶ 左键原声、右键卡拍（用该命中证据所选的方案，规格 09 §9.7）；外加“前后 0.3 s”开关。
- 定位后舞台出现命中导航（‹ i/n ›），选区 = 命中，波形上画绿色命中框。

### 3.1 波形图层：一个“覆盖层”+ 其他图层

问题：标注要直接盖在波形上才对得准，但一层以上同时盖在波形上会乱，而且编辑时分不清在改哪一层。做法：

- **覆盖层只有一个**：在图层栏选（舞台：音素 / mora / 无；原片页：台词段 / 音效提示 / 区段标签 / 音素 / 无）。它的区间以半透明色带盖住整个波形高度，标签贴在波形底部。**能编辑的只有覆盖层**。
- **编辑**：点「✎ 编辑音素」（或语音面板的「✎ 编辑音素时间」、波形右键），覆盖层加粗边框、边界出现把手，波形上方出现“正在编辑：音素时间（保存为人工版本）· [放弃] [保存]”；编辑期间不能切换覆盖层；Esc = 放弃。相邻区间共用的边界一起移动，不能越过邻居。音块是派生的，不能拖（拆分点在“分组与停顿”）。原片页同一组件，默认覆盖层是台词段（编辑段、音效提示、区段标签、OP/ED 的边界；段允许重叠）。
- **其他图层用车道显示**（所有者 2026-10-06 选定，Q19）：每层一条细车道放在波形正下方，同一时间轴；悬停某个区间时把它投影到波形上（虚线 + 淡色）。层再多也不乱。
  （比较过、没采用的：淡线——所有层都叠在波形上只画淡色边界，层多时线多；分带——波形顶部切窄带，占波形高度；多轨——每层一条小波形，太占纵向空间。）

- 双击某条车道 = 把它换成覆盖层。Shift 单击/拖动的吸附只对覆盖层生效，车道上单击 = 选中那个区间。

### 6.1 集合（采样列表、原片列表、命中、分离声部、字幕候选、标签、任务）

| 手势 | 规则 |
|---|---|
| 单击 | 设为**焦点**（查看）；**从不改变勾选**。采样 → 舞台；原片 → 查看器；命中 → 定位；声部 → 预览波形；任务 → 展开 |
| 双击 | 主动作：可听的 = 试听原声；原片 = 从当前位置播放；任务 = 打开结果；标签 = 重命名… |
| 复选框 / ⌘(Ctrl)+单击 / X | 切换勾选（复选框常驻；失效项不可勾） |
| Shift+单击 · Shift+↑↓ | 连续勾选 · 移动并勾选（页内，与页外已勾选合并） |
| ⌘/Ctrl+A | 勾选全部匹配（跨页） |
| Esc | 清空勾选（之前先关闭菜单/面板、取消拖出） |
| 右键 | 菜单对象：在已勾选项上且勾选 ≥2 → “已勾选 N 项”；否则 → 只这一项。**不改变勾选和焦点**，菜单第一行写明对象。空白处 → 集合级菜单 |
| 播放按钮 | **左键原声、右键默认卡拍**（命中用证据方案）；再点停止；全应用只有一个声音 |
| ⌥/Alt+拖动 | 拖出真实文件（越过 4 px 才生成；Esc/松手/失焦放弃）；版本跟随该对象最近一次成功试听；在勾选集里且 ≥2 → 拖出整个勾选集 |
| Delete/⌫ | 删除勾选项；无勾选时删除焦点项（都要确认，确认框写明对象） |
| 条件变化 | 改范围、表达式、用途、结果标签 → 清空勾选并提示“已清空 N 项勾选”；翻页保留 |
| 失效项 | 保留位置、标“已删除/音源已变化”；不可勾选、试听、拖出；↑↓ 跳过 |

## 10. 与规格 03 Part C（旧版）及 v1 的主要不同（每条一句理由）

| # | 改变 | 理由 |

## 20. 阶段 7 实现时的取舍（2026-10-08，等所有者验收时确认）

- 结果头：「浏览 n」+ 每次检索一个可关闭的标签（“节奏 · HH:MM (n)”/“音高 · …”，组件库的 ClosableTabs）；检索按钮照原型是一个“⌖ 节奏检索 ▾”：左半边按用途打开默认方式（语音/未分类/全部 → 节奏检索，调谐 → 音高检索，非调谐 → 瞬态筛选），▾ 选其他方式。窄窗口时结果头换行。
- 检索浮层：从顶部展开、横跨采样库（原型同）；第一行最左边多了一个“检索方式”分段（语音 · 节奏/音块 / 音高检索 / 单音 · 音色 / 单音 · 瞬态），不用回到 ▾ 换方式。
- 所有者 2026-10-08 验收后：检索的准备改为自动在后台做（任务抽屉里标“后台”，设置「语音分析 → 自动准备检索」可关）；浮层里的覆盖数与「准备」按钮保留，用于还没准备好或关了自动的时候。
- 覆盖预检（原型只在音高里画了“已索引 a/b”）：语音也有“已就绪 n/m · k 项没有语音分析”和「准备当前范围索引（n）」——语音检索索引要解码音频算停顿，规格要求检索本身不读波形，所以要先准备（任务）；为 0 时「查找」禁用。音高的原片音轨模式显示“已测音轨 a/b”，准备 = 整轨测 F0。
- 节奏卷帘照原型（每拍 90 px、网格虚线、块里写编号与条件简写）；不限节奏时是一排编号音块（拖动排序、「＋ 音块」）。右侧就地编辑：前导辅音（任意/无/指定）、首元音、目标音高（音级 + 八度 + 容差），其余条件收在「更多条件」里。设置弹出：首尾依据、跨停顿与最大间隔、查询长度、网格、节奏范围、（高级）段间休止调整、清空。
- 音高画布：照原型（钢琴键列 + 0.5 秒竖线 + 琥珀色块），块可以是单个音 / 音高范围 / 滑音（滑音画成斜的平行四边形）；就地提示由 Core 校验（与检索同一套规则）；「更多」里是忽略八度、时长弹性（所有者 2026-10-08）与稳定度、能量、句首/句尾。文本只作「复制为文本」「从文本粘贴」。原型标的“近似检索”去掉（所有者：完整检索不漏检）。
- 单音 · 音色 / 瞬态：照原型的指标表（勾选、最小、最大、单位、缺失数），每个指标悬停 ⓘ 看定义；筛选作用在「浏览」上（即时，不是固定结果），状态行写“单音 · 瞬态筛选 · n 个条件 · 清除筛选”。
- 命中：行下命中时间线（绿 = 严格、琥珀 = 近似；悬停看偏差/冲突/变速代价；单击定位）；当前行展开命中小卡（▶ 左键原声、右键证据方案卡拍；默认列前 3 个、可展开其余；「前后 0.3 s」只在语音检索）。命中条是可视化的一部分（同波形画布），用原生按钮实现键盘与读屏。
- 定位：舞台选区 = 命中、波形画命中框（绿/琥珀）、滚到命中前 0.3 秒；舞台动作条右侧「‹ 命中 i/n ›」。
- 命中右键：定位、试听命中区、返回原片、保存命中区…（= 定位后打开舞台的「截取」，性质按资产角色预填，每次新建）、拉平命中区…；语音命中另有导出原声/卡拍 WAV、复制 REAPER 交接两种。视频片段随阶段 9。
- 失效成员：保留原位；写“采样已删除 / 音源已变化 / 命中已失效（分析或测量变了）”，命中禁用、不能勾选；单击已删除行提示“此采样已删除，保留搜索记录供参考”。原片音轨结果：一条音轨一行（没有缩略图和星标），单击命中跳到原片页并带上命中范围与音源。
- 状态行：“固定结果 · n 个采样 · m 处命中 · t ms · k 项缺少有效分析”，另写“n 项索引未就绪（没搜）”、BPM；「再搜一次」= 用这个结果当时的条件与范围再搜（新标签）。

## 21. 原片上的四类对象落到界面（所有者 2026-10-09【基线变更】，等所有者验收时确认）

所有者原文与答复见 docs/QUESTIONS.md「原片上的四类对象」。界面上的做法：

- **原片页**：图层栏 = 台词段（覆盖层默认）/ 音效提示（车道默认显示，可关）/ 区段标签（只放用户画的区段标签与 OP/ED）/ 音素 / 派生采样；
  台本、画内字幕、字幕层显示同一份段文本。右键：
  - 段（台本行、画内字幕、波形上的段）：从这段建采样… · 语音分析这段… · 编辑这段… · 在这里拆分… · 与下一段合并 · 删除这段（被采样使用时写出数量）；
  - 音效提示：从这条提示建采样… · 编辑… · 删除；
  - 选区：添加台词…（与已有段重叠时选替换 / 切开 / 取消；切开只在每个重叠段都只从一侧伸进来时可用）· 新增音效提示… · 新增区段标签…；
  - 一处命中多个对象时各一个子菜单，只有一个时直接列出（菜单头写明是哪一段）。
- **建采样一个动作**：单条 = 锚定小面板（动作条「截取」、段 / 提示右键、命中「保存命中区…」、分离结果「保存为采样」），批量 = 整页表格（从台词段 / 音效提示 / 整段原片）；
  背后同一个 `samples.plan`，名称、性质、范围、判定区间、来源完全相同（e2e「看片逐句建采样」逐字段比较）。
  - 我定的：从段 / 提示右键建、命中保存、分离结果保存之后**留在原来的页面**，提示里给「打开」（场景 F 是边看边建，每次跳走会打断）；动作条「截取」照旧跳到采样库打开新采样。
- **导入字幕**：整页里四类开关、重叠时“替换 / 保留原有”、汇总（新增 / 无变化 / 替换（删除几个已有、其中几段有分析）/ 跳过）、按类分页的逐行表格（勾选 = 导入；跳过的行可「强制替换」，碰到受保护的段要二次确认并列出会丢掉的编辑与人工修正）、OP/ED 页（规则有错时逐对选用途）。批量导入（原片列表勾选）按默认选项各自导入。
- **舞台语音面板**：判定区间时间框 + 「设为选区」+ 波形上的“判定区间”带子；读到几段、选哪一段修；「编辑这段…」用原片页同一个段编辑框；「添加台词…」= 在文本层加一段（加完打开这段在这条轨上的分析确认框）；不可用时写明原因（第 X 段未分析 / 改过待重新分析 / 第 X 段与第 Y 段在 a–b 秒重叠）。
- **语音分析确认框**：原片入口与段右键可选「默认人声轨（没有就是原混音）」或「当前查看的轨」。
- **设置 · 语音分析**：「改段后自动在后台重跑」（默认关）。
- **列表状态**：新增“改过，待重新分析”“部分段未分析”；“已分析 ◐” = 只读到某段的一部分（采样范围没盖住整段）。被采样范围裁掉一部分的音素在舞台的音素上逐个标 ◐（QUESTIONS「原片上的四类对象」：原先“有音素伸出就 ◐”在原混音上几乎全是对齐假象，改了口径）。
