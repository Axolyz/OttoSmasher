## 0. 设计理念：从“控制台”到“工作室”

旧版和 v1 的共同问题是**所有东西同时摆在桌面上**：三行筛选、侧栏、模式面板、标签页、按钮行……每个区域都在抢注意力。v2 的做法：

| # | 理念 | 具体做法 |
|---|---|---|
| D1 | **一屏一个主角** | 采样库的主角是右侧“舞台”（当前采样的大波形与加工）；原片页的主角是“画面 + 台本 + 时间线”。其余退到边上、变淡、变小 |
| D2 | **用途决定呈现**（性质的用途视图做到底） | 语音 = 带“节奏字形”的台词列表；调谐单音 = **音高卡片墙**（大字音名 + 音高曲线）；非调谐单音 = **瞬态卡片墙**（起音时间 + 包络）；未分类 = **收件箱分拣台**（大按钮一键归类）。切换用途就像换一件趁手的乐器 |
| D3 | **按需出现，用完收起** | 检索编辑器是从顶部展开的浮层，查找后收起成一个结果标签；拉平、音素、节奏、字幕导入、设置是从底部升起的**全屏工作台**，做完就落下；准备清单是一个弹出清单。平时页面上只有“找”和“听” |
| D4 | **一条全局播放条** | 窗口底部常驻：现在在响的是什么（原声/卡拍、方案、进度）；导出交接（可再次拖到 DAW）、“资料已更新”也在这里——“只有一个声音”一眼可见 |
| D5 | **原片页像视频编辑器** | 片库（海报墙）↔ 查看器（大画面 + 右侧台本 + 底部多车道时间线）；台本可以点句选区、Shift 点扩展，按文字截取台词 |
| D6 | **安静的视觉** | 深色工作室风格（可切浅色）；单一强调色（紫）；性质四色（语音蓝、调谐琥珀、非调谐珊瑚、未分类灰）只用在小圆点和大字上；标签收成一行淡色文字；数字等宽 |
| D7 | **交互规则统一**（沿用 v1 整理好的规则） | 单击只看不选、勾选只靠复选框类手势、右键不改选择且菜单头写明对象、⌥/Alt 拖出、同一动作一个名字（§6–§8） |

### 2.1 区域与职责

| 区域 | 职责（PA2） | 说明 |
|---|---|---|
| 顶栏的用途切换 | 性质的用途视图；“未分类”= 收件箱（带计数） | 就是范围的“性质”条件：单击只看一种；命令面板可多选（取并集，用通用视图） |
| 范围行（一行） | 范围栏、分面、保存筛选器（规格 07 §7.3）；主标签表达式；导入独立采样 | **一个输入框**承载全部范围条件：输入时按分面（作品/人物/音高/其他/原片/性质）给出带计数的建议，回车 = 文字条件；每个条件是可删的小块；左端“⚑ 筛选器”= 保存的范围预设（选用、存为、管理）。主表达式是**右侧独立的等宽输入框**（与范围分开，保持规格的分工），出错时变红并指出第几个字符 |
| 结果头 | 固定结果标签（浏览 + 每次检索一个，可关、可恢复）、分页、**检索按钮** | 检索按钮随用途变：语音 → 节奏检索；调谐 → 音高检索；非调谐 → 瞬态筛选；其他用途下拉选择。状态行“固定结果 · n · m 处 · t ms · k 项缺少有效分析”，音高检索标“近似 · 可能漏检” |
| 检索编辑器（浮层） | 三种检索 + 单音指标 | 横跨整个采样库、从顶部展开，**查找后自动收起**变成结果标签；块画布 + 右侧就地属性；Esc 收起 |
| 列表 / 卡片墙 | 浏览、试听、勾选、批量、拖出 | 见 §2.2；勾选后底部浮出“n 项已勾选 · 全选全部匹配 · 批量操作 · ✕”，没有勾选时不出现 |
| 舞台（右侧） | 单个采样的加工台（§3） | 与列表同页 |

### 2.2 四种用途、四种呈现

| 用途 | 结果区呈现 | 舞台默认卡片 | 默认检索 |
|---|---|---|---|
| 全部 | 紧凑列表：复选框 · 播放 · 名称（性质色点）· 一行副信息 · 人物 · 时长 · 星标 | 按采样性质 | — |
| 语音 | 列表，副信息 = 读音 + **节奏字形**（音块起音与占格的小图，一眼看出 x-xx 形状） | 语音（音素、原句、读音、分析状态）+ 卡拍（倍速、方案、节奏字形） | 节奏检索 |
| 调谐单音 | **音高卡片墙**：大字音名（`pitch:` 或测得音高）+ 音高曲线 + 名称 + 时长 | 音高（大字音名、偏差、波动）+ 声学；「拉平台」是主按钮 | 音高检索 |
| 非调谐单音 | **瞬态卡片墙**：大字起音时间 + 包络形状 + 名称 | 瞬态四项大数字（起音、衰减、峰均比、低频占比） | 瞬态筛选 |
| 收件箱（未分类） | 列表，行尾三个归类按钮；归类后就地显示“已归类为…”（刷新后移出） | **分拣台**：四个大按钮「语音 1 / 调谐单音 2 / 非调谐单音 3 / 跳过 ↓」，归类后焦点到下一条未归类 | — |

### 2.3 命中的呈现

- 每个命中采样行下方一条**命中时间线**：整条代表采样时长，绿色块 = 严格命中，琥珀色 = 近似；悬停显示证据（偏差、倍速、方案、占格冲突）；单击 = 定位。
- **当前行**展开成命中小卡：`[▶ 0.35–0.89 s · 严格 · 1.24× · 近快]`，▶ 左键原声、右键卡拍（用该命中证据所选的方案，规格 09 §9.7）；外加“前后 0.3 s”开关。
- 定位后舞台出现命中导航（‹ i/n ›），选区 = 命中，波形上画绿色命中框。

## 6. 统一交互规则

### 6.1 集合（列表、卡片墙、片库、命中、分离声部、字幕候选、标签、任务）

| 手势 | 规则 |
|---|---|
| 单击 | 设为**焦点**（查看）；**从不改变勾选**。采样 → 舞台；原片卡 → 选中（双击进入查看器）；命中 → 定位；声部 → 预览波形；任务 → 展开 |
| 双击 | 主动作：可听的 = 试听原声；原片 = 进入查看器；任务 = 打开结果；标签 = 重命名… |
| 复选框 / ⌘(Ctrl)+单击 / X | 切换勾选（复选框常驻；失效项不可勾） |
| Shift+单击 · Shift+↑↓ | 连续勾选 · 移动并勾选（页内，与页外已勾选合并） |
| ⌘/Ctrl+A | 勾选全部匹配（跨页） |
| Esc | 清空勾选（之前先关闭菜单/面板、取消拖出） |
| 右键 | 菜单对象：在已勾选项上且勾选 ≥2 → “已勾选 N 项”；否则 → 只这一项。**不改变勾选和焦点**，菜单第一行写明对象。空白处 → 集合级菜单 |
| 播放按钮 | **左键原声、右键默认卡拍**（命中用证据方案）；再点停止；全应用只有一个声音 |
| ⌥/Alt+拖动 | 拖出真实文件（越过 4 px 才生成；Esc/松手/失焦放弃）；版本跟随该对象最近一次成功试听；在勾选集里且 ≥2 → 拖出整个勾选集 |
| Delete/⌫ | 删除勾选项；无勾选时删除焦点项（都要确认，确认框写明对象） |
| 条件变化 | 改范围、表达式、用途、结果标签 → 清空勾选并提示“已清空 N 项勾选”；翻页保留 |
| 失效项 | 保留位置、标“已删除/音源已变化”；不可勾选、试听、拖出；↑↓ 跳过 |

### 6.2 波形（舞台、原片时间线、工作台里的波形，同一个组件）

| 手势 | 规则 |

### 6.3 检索画布

拖空白画块、拖块移动、拖右缘改长度、单击选中后在右侧就地编辑条件；音高画布上下拖改音高、↑↓ 半音；越界/重叠/太短就地标红并禁用查找。

## 10. 与规格 03 Part C（旧版）及 v1 的主要不同（每条一句理由）

| # | 改变 | 理由 |
|---|---|---|
| 1 | 侧栏 + 三行筛选 → **一行范围输入**（条件块 + 分面建议）+ 独立表达式框 | 所有生效条件一眼可见又不占三行；保留“范围预筛 vs 主表达式”的分工 |
| 2 | 性质从筛选按钮 → **四种用途四种呈现**（台词列表、音高卡片墙、瞬态卡片墙、收件箱分拣台） | 让性质真正承担“拿来干什么”（规格 07 §7.9） |
| 3 | 收件箱：归类后**焦点自动到下一条** | 分拣是连续动作；只在用户归类时发生，不是后台自动选中。**需要你确认**（QUESTIONS Q13） |
| 4 | 模式面板常驻 → **检索浮层**，查找后收起 | 平时不占地方；查询仍完整保存在固定结果里 |
| 5 | 命中行内平铺 → **命中时间线 + 当前行展开小卡** | 一眼看到命中落在采样哪里；一步试听原声/卡拍仍在 |
| 6 | 列表缩略图 → 移到舞台头部的画面小窗（⋯ 里可打开“列表显示画面”） | 列表更安静、一屏能看更多条 |
| 7 | 详情三个标签页 → **一两张上下文卡片 + 全屏工作台**（拉平台、音素编辑台、节奏台） | 常看的在卡片上，精细编辑给足空间 |
| 8 | 拉平、字幕导入、设置从弹窗 → **全屏工作台** | 需要大波形或大表格；弹窗太挤 |
| 9 | 原片页左侧常驻原片列表 → **片库海报墙 ↔ 查看器** | 查看时画面、台本、时间线占满屏幕；管理时用海报墙 |
| 10 | 字幕上下文 → **台本**：Shift 单击扩展选区、双击播放该句 | 按文字截取台词更快；“点字幕 = 选区、不自动播放”不变 |
| 11 | 准备操作散在菜单 → **准备清单**（状态 + 入口，无顺序） | 一眼看出准备到哪一步；不是向导 |
| 12 | 底部导出交接条 → **全局播放条**（在响什么 + 交接 + 资料已更新） | “只有一个声音”与交接集中在一处 |
| 13 | 右键会先把选择换成这一行 → 右键不改选择、菜单头写对象 | 不会因为一次右键丢掉勾好的集合 |
| 14 | 单击在多选状态下变成切换勾选 → 单击永远只是查看 | 去掉模式切换 |
| 15 | 方向键在画面/外层含义不同 → 同一个波形焦点区，⌥←/→ = ±5 秒 | 消除重复触发 |
| 16 | 原片页“参考音源 + 音轨”两个下拉 → 一个音源下拉 | 与舞台同构；它们本来都是资产 |
| 17 | 列表试听只有鼠标 → 加 Space / B | 逐条审听手不离键盘；鼠标左/右键规则不变 |

规格 03 §3.9 “有意不存在的东西”全部保持不存在（单独的“试听此音轨”、两步字幕导入关卡、加载整片按钮、重复分离入口、行末三点菜单列、
原片页卡拍与 REAPER、文件夹/集合、OP/ED 参考帧、模型选择、日常 JSON 编辑、向导、自动刷新）。
