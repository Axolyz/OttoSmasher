## 0. 七条统一原则（整个界面都按它们做）

| # | 原则 | 解决规格 03 PD2 的哪类问题 |
|---|---|---|
| U1 | **同一个“工作台”**：原片页浏览区和采样详情用同一个波形工作台组件——音源行、图层开关、播放控制、波形、选区栏完全同构；选区栏按钮顺序固定为 `截取 · 拉平… · 分离… · 回导… · 导出 ▾` | 选区操作两处不同构、不同层级 |
| U2 | **同一套集合规则**：采样、命中、原片、分离声部、字幕候选、标签、任务、保存筛选器……所有列表用同一张规则表（§6.1）：**单击只看不选、勾选只靠复选框类手势、右键不改选择、菜单头写明作用对象** | 单击含义会切换、各集合规则不一 |
| U3 | **一个动作一个名字**，主入口位置固定，右键菜单与命令面板同源（§8 入口表） | 回导/回导成品/回导…、拉平选区/拉平命中区… 混用 |
| U4 | **关键状态常驻可见**：顶栏 BPM；工作台标题行常驻“音源 · 选区”；采样库常驻范围栏和“已勾选 N 项”；原片页常驻“准备状态条” | 状态分散在角落（P13） |
| U5 | **就地优先，弹窗不叠层**：块属性、标签、截取、归类在原处完成；拉平、分离、回导、字幕导入、语音分析确认、删除用弹窗；弹窗里需要的补充选择（如缺默认轨）就地放在同一弹窗内，绝不再开第二层 | 弹窗套弹窗 |
| U6 | **焦点区明确**：每页只有“集合区”和“媒体区”（工作台 + 画面）两类焦点区，带可见焦点框；同一按键在一个焦点区里只处理一次 | 方向键在画面/外层重复触发 |
| U7 | **发起处写明会发生什么**：每个带默认处理的弹窗顶部一句话说明（如“将创建 34 个采样，每个比字幕前后各多 0.1 秒，绑定默认人声轨「hyperacev2 · vocals」”）；说明性文字放 ⓘ | P13、PB14 |

| 区域 | 职责（PA2） | 说明 |
|---|---|---|
| ① 用途行 | 性质的用途视图；导入独立采样；标签管理 | 用途分段控件**就是范围栏的“性质”条件**：单击 = 只选这一种（切到用途视图），⌘/Ctrl+单击 = 多选（取并集，用通用视图）。“未分类”带待整理计数 |
| ② 范围栏 | 浏览筛选的“范围预筛”（规格 07 §7.3） | 所有生效条件都是可移除的条件块：文字、作品/类型/人物/音高/其他分面（多值取并集，人物有“只要单人”）、原片、星标、范围表达式、属性条件（单音模式）、选用的保存筛选器（可展开看内容、可关闭）。「+条件」加条件块；「筛选器▾」选用/编辑/排序/删除保存筛选器；「存为筛选器」把当前范围栏（不含主表达式）存成命名预设 |
| ③ 表达式 + 模式 | 主标签表达式（灵活、短小）；检索模式 | 表达式 200 ms 校验、错误标红并指出第几个字符；补全只替换最后一个词并按分面分组。模式切换不清空范围 |
| ④ 查询区 | 三种检索 + 单音指标的查询编辑（PB16） | 语音检索与音高检索用**同一种画布**（§5.2）；块属性在右侧面板**就地**编辑（旧版是弹窗）；参数在画布旁，高级参数折叠；「查找」或 ⌘↵ 才运行 |
| ⑤ 结果标签 | 固定结果的并存、切换、关闭、恢复（PB7） | 「浏览」永远在第一个；检索结果标签“节奏 · HH:MM · 条数”；关闭只删结果集合；浏览条件变化时自动回到「浏览」标签（旧标签仍在）；后台变化只显示「资料已更新 · 刷新浏览」 |
| ⑥ 列表 | 浏览、试听、勾选、批量、拖出 | 通用视图三列（采样、时长、星标）；用途视图按规格 07 §7.9 多一两列；命中在行内展开（默认前 3 个）；底部常驻“已勾选 N 项 · 全选全部匹配 · 批量▾ · 清空 · 分页” |
| ⑦ 详情 | 单个采样加工台（§3） | 与列表同页，中间分隔可拖动 |

**用途视图**（规格 07 §7.9；只改默认显示与默认动作，不限制功能）：

| 视图 | 列表多显示 | 默认模式 | 详情默认页 | 突出动作 |
|---|---|---|---|---|
| 语音 | 原句/读音、音块数 | 语音检索 | 音素与分析 | 行内“卡拍试听”、详情顶部「复制 REAPER 交接」 |
| 调谐单音 | 音名（`pitch:` 或测得音高） | 音高检索 | 资料与来源（顶部“音高与声学”） | 选区栏「拉平…」高亮、拖出 |
| 非调谐单音 | 有效时长、起音时间 | 单音 · 瞬态 | 资料与来源 | 拖出、导出 |
| 未分类（收件箱） | 来源、创建时间 | 浏览 | 资料与来源 | 行尾三个归类按钮 + 数字键 1/2/3 一步归类；归类后该行就地显示“已归类为 …”，刷新或翻页后才移出 |
| 全部 / 多选 | 三列 | 浏览 | 按采样性质 | — |

**检索状态行**：`n 个采样 · m 处命中 · t ms · k 项缺少有效分析`；音高检索加“近似检索 · 可能漏检”与截断提示；单音模式显示“缺少所选指标 k 项（不命中）”。

| 区域 | 职责（PA3） | 说明 |
|---|---|---|
| 标题行 | 名称（就地改名）、星标、试听（左原声/右卡拍）、**交接 ▾**（整采样的：导出原声 WAV、导出卡拍 WAV、导出视频片段…、复制 REAPER 交接、导出 REAPER 条目文件（试验））、⋯（采样操作：语音分析、编辑对齐文本、编辑音素时间、画面绑定…、标注与对齐…、返回原片、重命名、删除…） | 卡拍相关项在需要时自动计算方案 |
| 标签行 | 有效标签按分面分组；只有本地标签有 ×；继承标签点一下跳到来源（标注 / 原片属性 / 资产角色）；「+」内联加本地标签 | 规格 07 §7.4 |
| 命中导航 | 上一个/下一个命中；失效时“命中已失效，请重新查询” | |
| 工作台 | 音源切换（默认绑定资产；展开时才探测可用性，不可用的禁用并说明）；缺音高时音源行出现「测量音高」；图层；播放控制；频谱；编辑边界（这里编辑的是**音素时间**，保存为人工版本）；画面小窗（音频为主时钟，点击 = 播放/暂停） | 切换音源**保留选区** |
| 选区栏 | 截取、拉平…、分离…、回导…、导出▾（选区 WAV / 选区视频片段） | 作用于“当前选区 + 当前音源”，二者常驻在工作台标题行 |
| 音素与分析 | 音素条（与选区相交高亮，◐ 截断）、原句与读音、对齐文本（就地编辑 + G2P 预览）、版本切换（人工/模型）、「语音分析」、无文字时「提供台词并分析」、分组与停顿、逐音属性 | 分析缺失只在本页说明原因（PB9） |
| 节奏与卡拍 | 原速卡拍 / BPM n；方案（近快/近慢/倍快，倍速与 n 格/拍）；同比例秒数轴映射图；试听方式（严格卡拍/卡拍+节拍/卡拍起点声/原始起点声/原声+原始起点）+「试听」；人工占格表（就地）；高级：量化路线 | 无分析时一句话说明并给入口 |
| 资料与来源 | 性质（选即存）、评分、备注；音高与声学（原始音高、波动、指标；「准备指标」）；画面绑定；来源（↑父采样 · 操作名、试听父采样、派生采样表）；返回原片；技术详情（只读） | 调谐/非调谐视图里排在第一页 |
| 小试听条 | 卡拍、起点声、父采样等试听渲染 | 与列表试听共用一个“只有一个声音”规则 |

默认标签页：有文字或性质为语音 → 音素与分析；否则 → 资料与来源；换采样时重置（规格 03 §3.3.2）。

## 10. 与规格 03 Part C（旧版界面）不同的地方（每条一句理由）

| # | 旧版（Part C） | 新方案 | 理由 |
|---|---|---|---|
| 1 | 勾选后进入“多选状态”，单击含义变成切换勾选 | 单击永远只是查看；勾选只靠复选框、⌘/Ctrl+单击、X | 去掉模式切换，PB3 的“焦点不是选择”在任何时候都成立 |
| 2 | 右键未勾选的行会先把选择换成这一行 | 右键不改变勾选和焦点，菜单第一行写明作用对象 | 不让一次右键悄悄丢掉用户辛苦勾好的集合；作用对象透明（P13） |
| 3 | 原片页“参考音源”和“音轨”两个下拉 | 合并成一个“音源”下拉（每条容器音轨、每个声部都是资产） | 与详情同构；概念上它们本来就是同一种东西（资产） |
| 4 | 方向键在画面焦点和浏览区焦点下含义不同（跳 5 秒 / 逐帧） | 同一媒体焦点区：←/→ 逐帧，⌥/Alt+←/→ 跳 5 秒 | 消除重复触发和焦点歧义 |
| 5 | 音块属性、筛选器编辑、单音指标用弹窗 | 块属性在画布旁就地面板；筛选器在范围栏就地展开/更新 | 常用操作就地完成，不叠弹窗 |
| 6 | 独立音高检索是文本框 | 与语音检索同一种块画布（文本只作复制/粘贴辅助） | 所有者要求（PB16） |
| 7 | 侧栏：性质按钮、筛选器列表、单标签范围、仅星标、管理标签 | 用途行 + 范围栏 + 表达式行；侧栏取消 | 所有生效条件一眼可见；性质成为用途视图（规格 07 §7.3、§7.9） |
| 8 | 截取弹窗是模态 | 锚定在按钮旁的小面板（名称 + 性质 + 保存） | 最常用的动作一步完成，不打断视线 |
| 9 | 详情里采样操作散在 ⋯ 菜单、选区行和标签页 | 整采样的导出/交接集中到标题行「交接 ▾」；选区级操作只在选区栏；分析类操作在“音素与分析” | 一个动作一个位置（U3） |
| 10 | 原片页准备操作只在“字幕与音轨▾”和右键里 | 原片标题行「准备 ▾」+ 常驻“准备状态条” | 准备进度透明，且不是向导 |
| 11 | 列表试听只有鼠标 | 增加 Space = 原声、B = 卡拍 | 逐条审听时手不离键盘；鼠标左/右键规则不变（所有者已用惯） |
| 12 | 性质只能在详情里改 | 增加 1/2/3/0 一步归类（对勾选集或焦点行，可撤销） | 收件箱整理（规格 07 §7.9 要求“一步归类”） |
| 13 | 撤销最近资料修改只在命令面板 | 顶栏 ↶ + ⌘Z（不在输入框时）+ 提示条「撤销」 | 全局可用且可发现 |
| 14 | 双击无统一含义 | 双击 = 该集合的主动作（可听的 = 试听原声；波形 = 从此播放） | 统一 |
| 15 | 任务抽屉显示内部英文名、中断任务不能重试 | 本地化操作名；失败/取消/中断都可重试 | 修旧 bug（规格 03 §3.10） |

规格 03 §3.9 “有意不存在的东西”全部保持不存在（单独的“试听此音轨”按钮、两步字幕导入关卡、加载整片连续播放按钮、重复分离入口、行末三点菜单列、
资料页里的标签编辑、原片页的卡拍与 REAPER、文件夹/集合、OP/ED 参考帧扫描、模型选择、日常 JSON 编辑、向导、自动刷新）。
