## 0. 设计理念：从“控制台”到“工作室”

旧版和 v1 的共同问题是**所有东西同时摆在桌面上**：三行筛选、侧栏、模式面板、标签页、按钮行……每个区域都在抢注意力。v2 的做法：

| # | 理念 | 具体做法 |
|---|---|---|
| D1 | **一屏一个主角** | 采样库的主角是右侧“舞台”（当前采样的大波形与加工）；原片页的主角是“画面 + 台本 + 时间线”。其余退到边上、变淡、变小 |
| D2 | **用途决定呈现**（只调整显示，不限制功能） | 统一用列表（不做卡片墙/海报墙）；每行都有画面缩略图；副信息随性质变化：语音 = 节奏字形，调谐单音 = 音名 + 音高曲线，非调谐单音 = 起音时间 + 包络。**未分类按语音呈现**（它不是收件箱：很多采样本来就分不进三类，懒得配性质的用户用默认值即可） |
| D3 | **按需出现，用完收起** | 检索编辑器是从顶部展开的浮层，查找后收起成一个结果标签；拉平、字幕导入、设置是从底部升起的**全屏工作台**；准备清单是一个弹出清单。音素编辑直接在舞台波形上进行（§3.1），节奏与卡拍直接显示在舞台上 |
| D4 | **一条全局播放条** | 窗口底部常驻：现在在响的是什么（原声/卡拍、方案、进度）；导出交接（可再次拖到 DAW）、“资料已更新”也在这里——“只有一个声音”一眼可见 |
| D5 | **原片页像视频编辑器** | 左侧可收起的原片列表 + 查看器（大画面 + 右侧台本 + 底部多车道时间线）；台本可以点句选区、Shift 点扩展，按文字截取台词 |
| D6 | **安静的视觉** | 深色工作室风格（可切浅色）；单一强调色（紫）；性质四色（语音蓝、调谐琥珀、非调谐珊瑚、未分类灰）只用在小圆点和大字上；标签收成一行淡色文字；数字等宽 |
| D7 | **交互规则统一**（沿用 v1 整理好的规则） | 单击只看不选、勾选只靠复选框类手势、右键不改选择且菜单头写明对象、⌥/Alt 拖出、同一动作一个名字（§6–§8） |

### 2.1 区域与职责

| 区域 | 职责（PA2） | 说明 |
|---|---|---|
| 顶栏的用途切换 | 性质的用途视图（未分类按语音呈现） | 就是范围的“性质”条件：单击只看一种；命令面板可多选（取并集，用通用视图） |
| 范围行（一行，两栏） | 范围栏（副）、保存筛选器、分面（规格 07 §7.3）；查找栏（主）：文字 + 主标签表达式；导入独立采样 | 见 §2.4 |

### 2.2 用途与呈现（统一列表）

每行：复选框 · **画面缩略图**（左下角播放按钮：左键原声 / 右键卡拍）· 性质色点 + 名称 · 副信息 · 原片与时间 · 人物 · 时长 · 星标。

| 用途 | 副信息 | 舞台面板 | 默认检索 |
|---|---|---|---|
| 全部 | 按各自性质 | 按各自性质 | — |
| 语音 | 节奏字形（音块起音与占格的小图）+ 音块数 | 语音 + 节奏与卡拍 | 节奏检索 |
| 未分类 | 同语音（无分析时显示“手动截取 · 未分析”） | 同语音 | 节奏检索 |
| 调谐单音 | 音名（`pitch:` 或测得音高）+ 音高曲线 | 语音 + 音高与声学（**没有**拉平入口按钮，也没有节奏卡拍） | 音高检索 |
| 非调谐单音 | 起音时间 + 包络 | 语音 + 瞬态（没有节奏卡拍） | 瞬态筛选 |

数字键 1/2/3/0 仍可一步设性质（对勾选集或焦点项，可撤销），改完该行留在原位、刷新后按新性质归位。

### 2.3 范围（副栏）与查找（主栏）

依据规格 07 §7.3 / 18 D22 的分工：先把范围圈在某部剧、某个角色上，再在里面反复换检索条件。两者放在同一行、但做成两个**看起来就不同**的栏：

```
┌ 范围 ⚑ 二季·京子 ▾ 已修改·更新筛选器·另存 │ 作品 Yuru Yuri × │ 人物 京子 × │ 加条件… ┐  ┌ 查找 ⌕ 文字…          │ 表达式 NOT "participants:*" ┐
└──────────────────────── 淡紫底：很少改、跨检索保留 ──────────────────────────┘  └──────────── 白底：这次要找的，随时改 ────────────┘
```

| | 范围（副栏） | 查找（主栏） |
|---|---|---|
| 放什么 | 保存筛选器（⚑ 预设）+ 分面条件块（作品、类型、人物、音高、其他、原片、性质、星标）+ 可选的“范围文字”“范围表达式”块（高级） | 文字搜索 + 主标签表达式 |
| 改动频率 | 很少：切用途、检索、翻页都不动它；重启恢复 | 每次查找都可能改 |
| 保存筛选器 | **保存的就是副栏的全部内容**；选用一个筛选器 = 用它替换副栏；改动后显示“已修改 · 更新筛选器 · 另存” | 永不存入筛选器 |
| 关系 | 副栏各条件取交集，同一分面多值取并集 | 在副栏圈出的范围内再筛；`NOT` 的补集只在副栏范围里取 |
| 快捷键 | ⌘⇧F 聚焦副栏 | ⌘F 聚焦文字 |

- 固定结果保存当时的副栏与主栏快照；之后改了副栏或筛选器都不重搜（规格 07 §7.3）。
- “范围表达式”只给需要复杂范围的人（例如“排除所有多人台词”）；它和主栏表达式是两个独立的框，各自校验，出错各自标红。
- 副栏条件多到一行放不下时折行；选用预设后条件以预设分组显示。

### 2.4 命中的呈现

- 每个命中采样行下方一条**命中时间线**：整条代表采样时长，绿色块 = 严格命中，琥珀色 = 近似；悬停显示证据（偏差、倍速、方案、占格冲突）；单击 = 定位。
- **当前行**展开成命中小卡：`[▶ 0.35–0.89 s · 严格 · 1.24× · 近快]`，▶ 左键原声、右键卡拍（用该命中证据所选的方案，规格 09 §9.7）；外加“前后 0.3 s”开关。
- 定位后舞台出现命中导航（‹ i/n ›），选区 = 命中，波形上画绿色命中框。

### 3.1 波形图层：一个“覆盖层”+ 其他图层

问题：标注要直接盖在波形上才对得准，但一层以上同时盖在波形上会乱，而且编辑时分不清在改哪一层。做法：

- **覆盖层只有一个**：在图层栏选（音素 / 字幕 / 区段·说话人 / 音块 / 无）。它的区间以半透明色带盖住整个波形高度，标签贴在波形底部。**能编辑的只有覆盖层**。
- **编辑**：点「✎ 编辑音素」（或语音面板的「✎ 编辑音素时间」、波形右键），覆盖层加粗边框、边界出现把手，波形上方出现“正在编辑：音素时间（保存为人工版本）· [放弃] [保存]”；编辑期间不能切换覆盖层；Esc = 放弃。相邻区间共用的边界一起移动，不能越过邻居。音块是派生的，不能拖（拆分点在“分组与停顿”）。原片页同一组件，默认覆盖层是字幕（编辑字幕/区段边界）。
- **其他图层的三种显示方式**（图层栏“其他图层”切换，请你在原型里比较后定一种，或保留切换）：

| 方式 | 样子 | 优点 | 代价 |
|---|---|---|---|
| **车道**（默认） | 每层一条细车道放在波形正下方，同一时间轴；悬停某个区间时把它投影到波形上（虚线 + 淡色） | 最清楚，层再多也不乱 | 不与波形重叠，要靠悬停投影对位 |
| **淡线** | 所有层都叠在波形上，其他层只画淡色虚线边界和小字 | 所有层都和波形重合 | 层多时线多 |
| **分带** | 波形顶部切出几条窄带，每层占一条，与波形重叠 | 都在波形上又互不覆盖 | 占用波形顶部的高度 |
| （多轨，未做） | 每层配一条同步缩放的小波形 | 绝不混淆 | 很占纵向空间 |

- 双击某条车道 = 把它换成覆盖层。Shift 单击/拖动的吸附只对覆盖层生效，车道上单击 = 选中那个区间。

## 6. 统一交互规则

### 6.1 集合（采样列表、原片列表、命中、分离声部、字幕候选、标签、任务）

| 手势 | 规则 |
|---|---|
| 单击 | 设为**焦点**（查看）；**从不改变勾选**。采样 → 舞台；原片 → 查看器；命中 → 定位；声部 → 预览波形；任务 → 展开 |
| 双击 | 主动作：可听的 = 试听原声；原片 = 从当前位置播放；任务 = 打开结果；标签 = 重命名… |
| 复选框 / ⌘(Ctrl)+单击 / X | 切换勾选（复选框常驻；失效项不可勾） |
| Shift+单击 · Shift+↑↓ | 连续勾选 · 移动并勾选（页内，与页外已勾选合并） |
| ⌘/Ctrl+A | 勾选全部匹配（跨页） |
| Esc | 清空勾选（之前先关闭菜单/面板、取消拖出） |
| 右键 | 菜单对象：在已勾选项上且勾选 ≥2 → “已勾选 N 项”；否则 → 只这一项。**不改变勾选和焦点**，菜单第一行写明对象。空白处 → 集合级菜单 |
| 播放按钮 | **左键原声、右键默认卡拍**（命中用证据方案）；再点停止；全应用只有一个声音 |
| ⌥/Alt+拖动 | 拖出真实文件（越过 4 px 才生成；Esc/松手/失焦放弃）；版本跟随该对象最近一次成功试听；在勾选集里且 ≥2 → 拖出整个勾选集 |
| Delete/⌫ | 删除勾选项；无勾选时删除焦点项（都要确认，确认框写明对象） |
| 条件变化 | 改范围、表达式、用途、结果标签 → 清空勾选并提示“已清空 N 项勾选”；翻页保留 |
| 失效项 | 保留位置、标“已删除/音源已变化”；不可勾选、试听、拖出；↑↓ 跳过 |

### 6.2 波形（舞台、原片时间线、工作台里的波形，同一个组件）

| 手势 | 规则 |
|---|---|
| 单击 | 移动播放头 |
| 拖动（>3 px） | 新建选区（只有一个）；拖两端调整；不能整体拖动 |
| Shift+单击 · Shift+拖动 | 选中光标下整句字幕/整个音素（字幕优先，只看可见图层）· 按手势吸附扩展到重叠边界（只一次、不级联） |
| 双击 | 从此处播放 |
| ⌥/Alt+拖动 | 选区内 = 拖出选区；标注上 = 拖出该区间 |
| 右键 | 选区菜单（与动作条同源）+ 设为开始/结束 + 选中此句/此音素 + 播放选区 |
| 滚轮 · Shift+滚轮 | 以指针为中心缩放 · 平移 |

### 6.3 检索画布

拖空白画块、拖块移动、拖右缘改长度、单击选中后在右侧就地编辑条件；音高画布上下拖改音高、↑↓ 半音；越界/重叠/太短就地标红并禁用查找。

## 10. 与规格 03 Part C（旧版）及 v1 的主要不同（每条一句理由）

| # | 改变 | 理由 |
|---|---|---|
| 1 | 侧栏 + 三行筛选 → **一行范围输入**（条件块 + 分面建议）+ 独立表达式框 | 所有生效条件一眼可见又不占三行；保留“范围预筛 vs 主表达式”的分工 |
| 2 | 性质从筛选按钮 → 用途视图（统一列表，副信息与舞台面板随性质变化；未分类按语音呈现） | 让性质承担“拿来干什么”，又不强迫用户去分类（所有者 2026-10-05） |
| 4 | 模式面板常驻 → **检索浮层**，查找后收起 | 平时不占地方；查询仍完整保存在固定结果里 |
| 5 | 命中行内平铺 → **命中时间线 + 当前行展开小卡** | 一眼看到命中落在采样哪里；一步试听原声/卡拍仍在 |
| 6 | 舞台画面放大（400×225，可放大到全宽）；列表保留缩略图 | 所有者要求 |
| 7 | 详情三个标签页 → **按性质的面板常驻舞台**（语音、节奏与卡拍、音高与声学、瞬态）；音素在波形上直接编辑 | 不用切标签页；映射图与方案直接可见 |
| 8 | 拉平、字幕导入、设置从弹窗 → **全屏工作台** | 需要大波形或大表格；弹窗太挤 |
| 9 | 原片列表可收起 | 收起时画面、台本、时间线占满屏幕 |
| 10 | 字幕上下文 → **台本**：Shift 单击扩展选区、双击播放该句 | 按文字截取台词更快；“点字幕 = 选区、不自动播放”不变 |
| 11 | 准备操作散在菜单 → **准备清单**（状态 + 入口，无顺序） | 一眼看出准备到哪一步；不是向导 |
| 12 | 底部导出交接条 → **全局播放条**（在响什么 + 交接 + 资料已更新） | “只有一个声音”与交接集中在一处 |
| 13 | 右键会先把选择换成这一行 → 右键不改选择、菜单头写对象 | 不会因为一次右键丢掉勾好的集合 |
