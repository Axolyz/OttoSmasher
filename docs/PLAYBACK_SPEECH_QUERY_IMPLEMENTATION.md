# 播放、批量分析与统一语音检索

本轮实现基于现有 Electron/libmpv、WaveSurfer 7 和独立 Python 环境。保留原始媒体和已有分析，不全量重跑。

## 可用入口与行为

- 采样库“语音 · 音序 / 节奏”：共享逐音条件、两种布局。音序要求相邻音块，不先过滤再拼接。音高音级/八度、可靠覆盖率、音分容差、P90−P10 平稳度、元音/前导辅音、有效持续时间/音块跨度、语段或整采样首尾、跨休止及间隔均可组合。原始 IPA 标签仍保留，前导辅音使用统一日语名称。
- 结果按采样分组，先显示三个命中区，其余可展开。左键播放原声、右键生成并试听局部卡拍；可定位、前后命中切换、循环、带上下文试听。保存、拉平、导出和 REAPER 交接放在命中区右键菜单。普通查询不推理模型、不渲染声音、不登记采样。
- 采样右键/多选操作“切换音素模型”：先显示有效、缺失、失败、不适用数量。默认只切换已有；分析缺失项为独立明确操作。完成后查询会失效重取。绑定声音不改变；无法在相同声音上补齐时明确失败并保留原选择。
- 详情标题、标签和独立试听入口先出现；波形、当前分析、音高独立加载。逐音属性和频谱按需请求。旧请求不能覆盖新选择，过期测量投影通过后台任务重建。单条标签只计算祖先链与有关来源，不再计算全库。
- 波形读取实际绑定资产范围，复用 512/2048/8192/32000 档峰值缓存；放大时切换已有数据，不重新导出音频。F0 绘制只遍历可见范围。
- 普通点击定位并保留选区；拖动重新画选区；Shift 点击完整音素/字幕，Shift 拖动纳入与原始拖动范围相交的完整区间，不级联扩张。边缘仍可精调，内部拖动不移动旧选区。Zoom 使用官方插件操作。
- 节奏点为顶部菱形编号，金色保留给音高。范围播放把终点与循环交给 libmpv，显示进度不承担声音截止。新请求号与媒体代次屏蔽旧回报。
- “查看采样频谱”与选区无关。短采样完整显示，长素材随时间轴加载最多30秒分块。源范围以采样帧量化，只容忍不足一帧的舍入差。

## 执行与来源

生产分析按原片、源音轨、人声模型复用整轨人声，再生成所选台词输入。narabas、HubertFA、pydomino 每批一进程/一次初始化；FCPE 同批复用实例。MFA 一批语料调用一次 align。逐条原始输出与导入状态保存；局部输入失败不阻断其他项，重试复用已有成功结果。取消沿用独立任务进程组。

MFA 保留官方词典发音变体和概率列，缺词才使用官方 G2P；记录程序/分词器版本、模型与词典指纹及原始 TextGrid。保留 `--single_speaker`，没有把未确认多人语料用于单一说话人自适应。默认顺序仍为 MFA、narabas、HubertFA、pydomino。未新增 pydomino 尾音修正规则。

批量补模型遇到变形派生采样时先尝试从父测量投影；缺少父测量则明确要求先补齐原台词。绑定其他独立分离音源的采样不能偷偷改绑整轨人声。此类重新测量尚不是任意音源的通用转录流程。

## 协议

`POST /api/samples/speech-query`：`mode`, `scope`, `units`, `boundary`, `boundary_basis`, `cross_pauses`, `max_gap`, 可选 `rhythm`。旧节奏 API 保留。

返回 `speech-query-v1`，每个采样有 `hits`；每个命中包括局部起止、音块 ID/序号、逐条件实测依据、声音身份、分析签名/模型/版本及可选 `plan_id`。音源、分组或模型变化后，动作校验拒绝旧命中。

`POST /api/samples/speech-hit`：`hit` 与 `action`（play/quantized/save/flatten/export/export-quantized/reaper），可选 context/bpm/native/nature。命中卡拍只在明确操作时生成临时局部测量投影，无中间采样登记。BPM 空值使用原速卡拍。

`POST /api/samples/phone-models`：`ids`, `backend`, `action`（inspect/switch/analyze）。

## 已执行验证

- Python 相关回归64项、Node桥接/时钟/手势回归7项通过；TypeScript/Vite构建通过。
- 原生引擎测试 `desktop/tests/native-range-smoke.cjs`：非零来源偏移、46/163/257ms选区、阻塞JS线程700ms，原生终点仍在选区终点；引擎循环与普通seek退出循环通过。该测试使用静音PCM，不冒充主观试听验收。
- Electron 实测 `ミ… ミラクるん？`：完整2.269秒频谱正常，跨标注自由拖选、点击保留选区、命中定位/前后命中控件、统一音序入口均正常。范围引擎终点实测误差不足一个PCM帧。
- `data/validation/batch-lifetimes/`：两个真实问题句，各后端只记录一次初始化。narabas批次6.24s、HubertFA7.23s、pydomino0.79s（含进程启动）；FCPE初始化0.156s，两次推理1.480/0.215s。不同输入/硬件负载下不可直接外推整集耗时。
- `data/validation/batch-e2e/`：独立数据库中两句narabas生产管线、逐条导入、特征、投影、切换完成；原音源JSON保持一致。重复运行复用两条成功结果，不再启动对齐模型。查询/试听不增加采样，明确保存才增加一条。
- 同一实际采样的音序与节奏查询均返回5个不同命中；对应原声和局部卡拍可生成，材料数量不变。CEG单元测试覆盖八度、容差、低F0覆盖、辅音、持续时长、首尾/休止、多命中与不存在结果；另验证指定节奏对应关系不能偷偷换成其他位置。
- `data/validation/batch-partial-failure/`：真实 narabas 批次首条输入损坏，记录该项失败后继续完成下一条有效音频，模型仍只初始化一次；独立进程组取消回归确认其他任务仍存活。
- `data/validation/mfa-probabilities-v2/`：6句新旧词典路径、原始TextGrid、比较与环境清单。MFA程序3.4.2、声学/G2P模型3.3.0，SudachiPy0.6.11、词典20260723。3句边界完全相同，2个喊声案例有明显差异，1个多人案例音素序列不同；不宣称新路径质量全面改善。

## 验收边界

- 尚未建立这6句的人工精确边界真值，MFA质量比较仍需听音判定，未覆盖正式分析。
- 缓存后端详情/查询已测到毫秒级响应；没有把它等同于完整GUI首次绘制200ms的正式性能结论。
- 普通浏览器仍是HTML媒体兼容路径，截止由浏览器时钟控制，不能承诺与原生libmpv同等的忙线程范围精度。原生验收不以浏览器替代。
- 本轮没有全量旧语料推理，也没有重复完整REAPER验收。
