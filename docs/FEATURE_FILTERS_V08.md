# Demo 0.8：声学属性、慢放偏好与角色标注

## 当前行为

三条量化路线保留，无 mora 为默认。搜索只比较已保存的量化节奏型，不重排起点。
已移除旧的原录音仿射／LP 匹配器、锁定查询后重新分配起点，以及旧的分段 atempo 试听路径。
旧请求会明确失败；重新搜索获取当前 `plan_id`。历史导出的持久媒体不删除。

`time_mapping.schedule` 是不读取音频、不调用 Rubber Band 的纯计算模块，输入源范围、
全部起点／控制点／尾音点和休止，输出采样帧分段、保护核心和单调映射。
严格渲染消费该分段；搜索的持续时间和语音速度、TextGrid、点击声和 REAPER 使用同一映射。
REAPER 只需要计算映射并导出未变速原声，不再为了得到标记先运行 Rubber Band。

语音速度为所选范围内源语音时长除以其对应目标时长。计入前导清辅音，扣除已确认可伸缩间隙、
连接休止与前后填充；多段先累加时长，不逐段惩罚。慢放厌恶度默认 50，范围 0–100，
只向原排序代价追加 `0.5*(厌恶度/100)*max(0,ln(0.8/语音速度))²`。
原来的速度代价及可选时长倍率限制也使用语音时长。结果仍单独报告格点误差和原声形变量。

## 可选音块条件

右键音块打开筛选。所有属性默认关闭，缺失特征不通过已启用条件。

- 首元音只取复合单元的第一个 `a/i/u/e/o`。
- 音内升降比较单元首尾可靠发声区的音高，中位数抑制单帧异常；默认门槛 1 半音。
- 语段内偏高／偏低相对所属连续语段的可靠 F0 中位数，默认门槛 2 半音。
- 能量使用帧均方能量的单元平均值，与同语段各单元的能量中位数比较；建议门槛 3 dB。
  不用总能量奖励长音。
- 持续到块尾同时检查无额外起音和映射后的实际发声覆盖。音素覆盖、强静音边界及声音能量
  一同参与；CTC 空白和 F0 空缺本身不截断声音。
- 角色按命中声音的原片时间范围查询。人工标签覆盖字幕标签；跨越不同角色的单元为未知。
  聚类分组从不自动变成角色事实。

详情显示原始 F0 曲线（清音／低置信帧留空）、逐音相对音高、能量、标签来源及命中编号。
同一声音在整句、语段和休止组合中复用同一套语段参照属性。

## 数据与依赖

- `sound_features.FCPE`：项目内固定 FCPE ONNX，复用 HiFiShifter 的 16 kHz 线性重采样、
  1024 点对称 Hann、160 hop、Slaney log-magnitude mel、局部 argmax 解码。
  保留原始 F0、激活置信度、清浊判断与独立 10 ms 均方能量；没有跨空缺插值。
- `voice_embedding.CAMPlus`：官方 `campplus_cn_common` 权重导出 ONNX，16 kHz、80 维
  Kaldi fbank、均值归一化，输出归一化 192 维嵌入。原速分离人声，不拼接邻句凑长度。
- 权重、来源提交与校验值在 `dependencies/features-models.json`；推理环境锁在
  `dependencies/features.pip.lock.txt`。不依赖外部 HiFiShifter 克隆目录存在。
- 源帧版本 `fcpe-source-frames-v4`，单元投影版本 `unit-prosody-v1`，时间映射
  `shared-frame-map-v1`，索引方案 `indexed-reference-v2`。源帧按完整 pymss 资产的音频指纹复用，四模型不分别对裁后片段推理；
  单元投影持久缓存独立于量化排序参数；角色使用独立的源时间区间及可撤销操作日志。
- 模型推理、文件缓存、HTTP、macOS 剪贴板是外围适配；特征投影、属性判断和时间计算不依赖 GUI。

```sh

.runtime/envs/features/bin/python scripts/analyze_sound.py
.runtime/envs/core/bin/python scripts/build_rhythm_index.py
.runtime/envs/core/bin/python scripts/build_unit_features.py
.runtime/envs/features/bin/python scripts/analyze_speakers.py
```

## 角色视图

CAM++ 余弦距离、average-linkage 层次聚类，不预设角色数。短句、低能量、字幕标注多人、
句内嵌入明显不一致的样本单列待核验。松紧可调，字幕单角色提示提供建议阈值；校准按
同名／异名配对各占一半权重，防止不同角色配对数量占优。它是弱标签诊断，不是人工准确率。

支持试听代表句／离群句、跨组选择、批量命名、合并、移出、源时间范围拆分多人台词、撤销。
已经确认的源区间不因阈值、音素模型或虚拟语段变化而消失。浏览器只负责交互；未变速声音
及标签保存在本地。此轮不做重合成或拉平。
