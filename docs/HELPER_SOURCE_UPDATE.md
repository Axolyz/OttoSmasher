# 原片浏览、共享时间轴与 OP/ED 标记（2026-09-21）

## 使用入口

- **原片浏览**：顶部选择原片；也可以在采样详情点“返回原片”。视频叠加原字幕，右侧字幕可选区定位。切点、字幕、代理和参考声部均使用原片秒数；代理只改变播放文件的本地起点。
- **参考音轨**：原混音、人声、残差及已经生成的各模型声部。每条显示实际覆盖范围；选择局部声部时自动进入覆盖范围，不回退混音。当前范围分离可选 becruily Deux 或 HyperACE v2，默认 Deux。已有分析仍播放其原先绑定的音源。
- **保存选区**：可归档到语音、调谐单音（未拉平）、非调谐单音；“拉平并保存单音”只保存最终拉平结果。模型失败不留下未拉平的中间采样。原片浏览使用隐藏的技术来源父级，打开原片本身不创建日常库条目。
- **共享时间轴**：WaveSurfer.js 7 的波形、Regions 和 Timeline 插件，外加统一输入处理和 F0 叠层。滚轮左右移动；Shift＋滚轮以鼠标位置为中心缩放；拖动建立选区，边缘可调整。显示波形幅度包络，不将其标成 LUFS。
- **音高**：可靠 F0 与波形同轴叠放。每条横线相差一个半音，A4=440 Hz；标签按空间疏密显示。没有 F0 的区间断开，不补成零。音源切换后不把原分析音高冒充新音源的测量。
- **卡拍**：方案下面恢复紧凑映射图，上方为原始起点、下方为目标拍点，连线表示同一个节奏点。试听及导出仍使用原有 plan_id。
- **侧栏**：移除“素材来源”分组，保留全部、星标和文件夹。历史批次及测试文件夹折叠在独立按钮后；没有删除采样或人工标注。

底层复用依据：[WaveSurfer](https://wavesurfer.xyz/docs/)。自定义代码只负责共享交互、绝对时钟及音高叠层。

## OP/ED 插件流程

“工具与工作流 → OP／ED 范围标记”：

1. 可先添加尚未导入字幕的原片，仅登记来源，不登记采样；也可直接选择已有原片。
2. 上传从视频导出的参考帧、输入 OP/ED 长度，选择若干原片扫描。第一帧太黑时，可以选稍后的可辨识帧并填写它距开头的秒数。
3. 按源视频帧率做低分辨率外观匹配，保留最多三个相似候选并细化局部位置。扫描使用 FFmpeg 和数值计算，不调用大模型。
4. 查看原片开头／结尾，微调范围后确认。无可靠候选时不自动标记；支持手工填写范围。相似度不是识别概率，剪辑差异、片头字幕或低辨识度画面可能导致漏检。
5. 确认后可以撤销。停用插件只关闭入口，已确认的原片范围仍有效。

| 操作 | 默认处理已确认 OP/ED |
|---|---|
| 字幕台词自动登记 | 与标记相交的整句不登记；原始字幕仍保存，用于原片观看 |
| 日常文字／节奏筛选 | 排除自动原句条目；明确保存的手动派生仍可使用 |
| 批量音素准备、对齐与节奏索引 | 跳过标记内原句；历史测量不删除 |
| 角色嵌入与聚类 | 跳过对应台词，旧嵌入也不参与新的聚类视图 |
| 自动剧情打击音发现 | 相交事件不进入类别分析、候选清单 |
| 整轨分离／视频预览／字幕校时 | 保留完整媒体；避免打断连续分离和丢失观看上下文 |
| 手动截取、明确请求的采样分析 | 可使用，保留来源；不会因 OP/ED 身份强制删除 |

原片身份与字幕内容身份分开。给预登记的同一原片首次添加字幕现在被允许；替换已有字幕的旧规则仍要求保留来源版本。已有自动原句行不会被破坏性删除，而是在检索时排除；撤销后可重新登记／显示。

## 模型与验证

### Deux

官方 `becruily/mel-band-roformer-deux`，固定 revision 和文件 SHA256 见 `dependencies/vocal-models.json`。使用官方配置；不要让模型目录的别名下载覆盖该配置。

```sh
.runtime/envs/core/bin/python scripts/setup_deux.py
# 两条路线均可通过现有 separate 命令的 --model 选择
```

修正了 `Vocals` 大小写识别，以及长驻人声分离进程接受不同模型请求的问题。生产人声缓存按模型指纹隔离。实际 12 秒素材的人声适配器运行完成，保留 44.1 kHz 双声道和原时长；没有重跑旧语料。

### SFC-Locoformer

已与官方 `separate_sample.py` 核对：官方单文件推理使用 `task.model`，上一版采用 EMA shadow。本版改用普通模型，并更新适配器身份以避免混用旧缓存。

同一 100–112 秒片段 CPU 普通权重推理约 77.9 秒，峰值 RSS 约 6.20 GB。与旧 EMA 相比，各轨 RMS 几乎不变（对白约 0.00014 → 0.00017，音乐约 0.04719 → 0.04718，音效约 0.00395 → 0.00388）。这不代表质量改善，对白异常弱的问题仍未解决。依照本轮要求停止深入排查，保留旧／新音轨供试听，默认电影路线为 BandIt v2。

参考轨已挂在第 2 集 100–112 秒范围，标题分别注明 Deux 和 SFC 官方普通权重。它们不是新采样，不自动进入候选批次。

## SubPlz 独立 CLI

本地源码 `work/SubPlz`；隔离环境 `.runtime/envs/subplz`；提交 `6be8b6fab185372b458bdde13c61f4da204dc6fc`。未加入 Helper 工作流。包装器只配置进程内 PATH 和项目缓存，不修改全局环境。

```sh
./scripts/subplz --help
./scripts/subplz sync --audio /绝对路径/原片.mkv --text /绝对路径/清洗后字幕.srt \
  --output-dir /绝对路径/输出目录 --language ja --model turbo --device cpu \
  --threads 4 --quantize --respect-grouping --cache-dir /绝对路径/缓存
```

本机已安装的 turbo 权重可以离线使用。12 秒片段完成实际转写，并通过 `gen` 生成非空 SRT。该短片的文本 `sync` 因上游章节匹配未命中而跳过输出；即使打印成功也要检查输出文件。已有整集 `sync` 结果仍保留在 `outputs/subtitle-preprocessing`，本轮未重跑整集。
