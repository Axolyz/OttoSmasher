# Ant Design 工作站界面（2026-09-22）

## 操作组织

Electron、React、Python 服务和领域算法保留，通用界面采用 Ant Design 6。主导航只保留「采样库」「原片」「工具与工作流」，任务在右侧抽屉，全局默认在设置弹窗。窗口标题栏和导航不随内容滚动。

- 采样库：服务端筛选、分页及排序，虚拟表格显示名称、作品/角色/本地标签和时长。列表和右侧详情各自滚动，可拖动中间分隔线。星标是状态，文件夹是范围；Ctrl/Cmd 单击可选多个文件夹。普通筛选不创建批次。
- 原片：合并准备和浏览入口。左侧紧凑来源表格，最新登记在前；右侧连续播放、字幕上下文和 WaveSurfer 选区。作品名/集数、字幕和分析音轨在来源菜单的设置弹窗修改；无字幕不阻塞添加、播放、保存选区、整段拉平、导出或音频插件。
- 详情：波形、音高、音素和选区是常驻制作区域；节奏与卡拍、音素与分析、资料与来源分标签页。参数解释通过可聚焦的 ⓘ 查看。节奏映射图保留紧凑布局，十二平均律参考线仍在 F0 叠层中。
- 工作流：卡片选择工具，专用页面单独展示。OP/ED、角色审核、区间命中、声音候选和历史任务使用表格。插件管理、环境配置和高级参数在弹窗中。独立插件自带网页仍保留，不强迫插件作者使用 Ant Design；历史 demo 继续作为兼容入口。
- 切页保留各页条件、选中记录、源选区和滚动位置；不打开新窗口。显式「另开窗口」保留。切页暂停普通媒体和 WaveSurfer 自建播放器。

## 精简与保留

删除主界面的独立「试听此音轨」及「预览字幕→确认导入」操作。选择原片音轨后由统一播放器播放。字幕导入单次执行，但后端仍检查范围有效性、重复版本和 OP/ED 排除；原来的预览 API 保留兼容调用。原片保存的名称和归档位置在同一个弹窗填写，不再多弹一次标题确认。

重建分析、人工占格、暂停阈值、模型切换、标签覆盖、技术来源和手动重试仍可用，分别放在分析页、菜单或弹窗，未删除其业务能力。缺失音素是无字幕素材的正常状态，不在普通浏览时弹警告；仅进入音素页后显示缺失原因。

通用控件、表格、分隔面板、菜单、弹窗和提示统一为 Ant Design。WaveSurfer 继续承担声学交互；节奏卷帘、F0 和映射图是专用可视化，不用普通表单替代。

## 快捷操作与默认值

- Ctrl/Cmd+F：聚焦素材搜索；Ctrl/Cmd+K：操作搜索。
- 素材列表方向键：切换选中记录；Space：播放；I/O：设置选区边界。输入文本、弹窗内编辑不会触发这些制作快捷键。
- 波形滚轮：官方 Zoom 插件默认缩放；横向滚动平移，支持全局线性/指数曲线及累计阈值。
- 节奏卷帘：空白拖绘音块、拖动移动、拖右边调整长度、右键/双击编辑属性、Delete 删除。音块不允许重叠。命中行显示查询点对应读音，选择哪个方案就试听该 `plan_id`。
- 全局设置：新语音默认模型、新采样量化路线、人声模型、波形缩放和持久导出目录。不会追改已有采样选择或模型测量。

## 标签与来源

新增轻量展示元数据和继承规则，不改变不可变媒体和时间映射：

- 作品和来源类型从原片实时解析；修改原片属性，派生采样和筛选自动反映。
- 角色优先从人工确认的原片时间区间解析；可选导入字幕中的说话人声明，并注明未经人工确认。多人或群体只记参与者，不猜测时段。裁切子采样继承对应来源；聚类建议不升级为事实。
- 本地作品/类型/角色覆盖优先，可清空屏蔽、恢复继承。
- 自定义标签默认不继承；用户可以按标签开启。文件夹、批次、星标、采样用途不自动继承。
- 保留历史手工标签；新派生不再把父标签复制成冻结快照。

新增 `/api/ui/catalog` 返回分页摘要；分析详情仍按需加载。`/api/ui/settings`、`source-labels`、`tag-rule`、`tag-override` 服务 GUI。节奏搜索沿用已有索引，未增加模型推理。

## OP/ED 快速路径

「原片 → 所选项 → 从字幕识别 OP/ED」读取关联文件的原始字幕事件，去除样式、空白并统一波浪符号后，仅匹配独立的 `♪～` 和 `～♪`。开始字幕的开始至结束字幕的结束形成区间。

两对标记依序作为 OP/ED；一对按原片前后半区归类。孤立、重复开始或超过两对均只报告待检查。规则输出保存字幕指纹和 `subtitle-rule` 来源，明确 `verified:false`，不冒充人工核验。与已有标记重叠时保留已有标记。可在 OP/ED 表格删除规则区间；不删除人工采样。

参考帧扫描缓存 24×14 RGB 和实际解码 PTS，按媒体指纹和扫描范围复用。硬件解码失败记录原因后使用 CPU。查询向量化打分，再局部细查原生帧；候选仍需要审核。只有完整缓存原子落盘后才供复用，中断文件不当成完成结果。静态画面可能给出多个相近命中，不宣称唯一准确起点。

- 独立工作区在 GUI 中完成无字幕视频添加、1–2 秒取样、再派生和 WAV 导出；测试数据未进入正式库。
- 真实番剧加载 24 分 26 秒连续播放器、原声波形、音素/F0、三自适应方案及严格试听文件。未重新跑全量模型，未做新的音质排名，未重复验收 REAPER。
- 12 秒真实视频参考帧基准：冷索引总约 1.02 秒，复用缓存约 0.253 秒（其中查询约 0.002 秒，局部细查约 0.249 秒）。这是短范围测量，不是整集耗时承诺。
- TypeScript 检查与生产构建通过。Ant 通用 UI 块约 843 KB（gzip 271 KB），Vite 保留大块提示；这是本地 Electron 页面，未用调高阈值掩盖提示。

### 2026-09-22：性质与目录、明确删除

- `materials.nature` 独立保存 speech / pitched / unpitched / unclassified。侧栏性质筛选和虚拟文件夹取交集；文件夹移动不改变性质，拉平结果为 pitched。无性质判断的外部文件保留未分类，可在资料页指定。
- 采样全选覆盖当前筛选所有页；右键删除、批量删除及列表内 Delete/Backspace 均使用明确确认。删除文件夹仅解除归档，不删除采样。
- 清空不隐藏记录。删除过的原句有同步排除记录，只有明确重新导入对应字幕才恢复；原片、上游分析、共享音轨及磁盘导出文件保留。
- 默认性质不再自动建立同名文件夹；空库没有虚拟文件夹，可自由新建。

### 性质的创建与继承规则

| 操作 | 初始性质 | 用户控制 |
| --- | --- | --- |
| 独立文件导入 | 当前性质筛选作为预选，否则未分类 | 导入弹窗明确选择；不凭文件名、F0 或目录推断 |
| 字幕台词登记／带文本的新语音 | 语音 | 保存后可更改 |
| 采样裁切（时间或音素） | 父级当前性质作为预选 | 保存弹窗可选择三种性质或未分类 |
| 原片手动截取 | 界面预选语音 | 保存前选择性质；没有字幕也可操作 |
| 拉平 | 调谐单音 | 创建时固定；拒绝矛盾的处理请求 |
| 分离、音源切换后保存、卡拍 | 父级性质的快照 | 不因人声声部就强制改为语音 |
| 通用插件区间保存 | 各自父级性质 | 保存区间时可统一指定性质 |
| 剧情打击音审核保存 | 非调谐单音 | 由这个特定工作流明确指定，不从文件夹推断 |
| 批次接收／移动文件夹 | 保持候选自身性质 | 接收位置不改变分类 |

父级以后改变性质不追改子级。相同处理结果复用已有采样时保留已有性质，包括用户手动更正。性质属于结构化属性，不作为可继承标签传播。派生记录保存 nature_at_creation，区分用户指定、父级快照和拉平规则。旧 API 的保留目录 ID 只兼容为未归档，不再设置性质；调用方应显式传 nature。

原片列表支持全选、右键／批量删除及 Delete/Backspace。删除原片登记同时清除关联字幕与分析登记，但不删除磁盘原文件；仍有正式采样引用时明确要求先移除采样，原片浏览产生的临时记录可一起清理。
