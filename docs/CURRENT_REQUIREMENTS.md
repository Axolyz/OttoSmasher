# 当前要求：精简工作站与统一检索

2026-10-01 修订。本文取代探索期 demo、插件平台和 MFA 方案；历史文档只作技术背景。

## 产品与数据

- 无字幕也能导入原片、连续播放、分离、选区、裁切、拉平和导出。字幕只用于可选台词登记与文字对齐。
- Ant Design 工作站同窗导航、保留选区和音源。保留“工具与工作流”空页面；没有插件安装、分享、配置、网页桥接或组合执行接口。
- OP/ED 属于原片属性，在原片页维护；确认区间排除自动台词登记与批量分析，不禁止播放、全轨分离或手动取样。
- 核心保留媒体身份、派生关系、精确时间映射、任务进度/取消/日志、人工标签、明确保存和导出。模型输出不自动成为采样或人工确认。
- 语音、调谐单音、非调谐单音是性质筛选，不是文件夹。普通裁切按明确角色预填性质，用户可修改，不继承父性质；拉平只登记最终成品及音高。
- 播放、处理与导出使用同一真实绑定资产，不静默替换混音。Electron 使用 libmpv 原生播放；浏览器兼容播放不代表原生验收。

## 模型与环境

- standard / experiment 共用代码和素材库，一次运行一个版本；存在排队或运行任务时禁止切换。
- core 负责服务/调度，onnx 环境服务两版且无 torch；experiment 独有 inference/PyTorch。ONNX 默认 CPU，可启用 Windows DirectML 或 macOS CoreML NeuralNetwork；Linux 保持 CPU。standard 分发包含完整运行环境及模型支持文件，只排除 ONNX 权重和外部权重数据。本轮不生成安装包、不处理下载、不发布。
- 分离统一使用外部 PyMSS Studio 已下载模型；人声模型与三轨模型按实际声部能力选择。缺模型须在 Studio 下载，不自动替换。保留 FCPE 与现用 HiFiShifter 的 ONNX 拉平。
- 内置 PyMSS 与 Qwen/Yohane 进入 archive，默认两版都不包含；显式开发恢复仍受 edition 依赖限制。
- SubPlz/sub-align 等尚未接入功能的试验迁往 ~/Documents/AudioLab，各项目独立源码和环境。
- narabas、HubertFA、pydomino 的有序设置首位决定新任务默认模型，迁移保留原默认值；不表示自动依次回退，不修改旧采样选择，不增加尾音修正规则。整轨人声准备与使用当前声音重新 FA 是独立操作。
- Yohane 保留音节，Qwen3-ForcedAligner-0.6B 保留字符/词，独立显示、定位和试听；不伪造音素，不更换音素检索计数单位。
- 退休 MFA/SOFA/CDX23/BandIt Plus/SFC/AV-CASS/PANNs/CLAP/角色聚类与专属环境、MLX路径。清除 MFA 测量/缓存；原片、字幕、正式采样及人工标签保留。
- SAM 三套权重保存在独立 SAM-Audio-Deploy；本项目不再提供 SAM/ComfyUI。独立 SubPlz 和字幕预处理保留。

## 统一语音检索

- 同一组相邻、有序节奏音块，三种策略：不限节奏、必须满足节奏、按节奏相似度排序。
- 先建立邻接再筛选属性；保留音高/音级/八度/音分容差/稳定度/F0覆盖/元音/辅音/原声时长/能量/说话人/首尾/休止/拍点/占格/持续条件。缺失值是未知，不能当作零或自动放宽。
- 有 BPM 检索只比较近快/近慢两个候选，取综合分最优、同分优先近快；预览仍可提供第三种倍速。无 BPM 比较归一化节奏形状。相似结果显示偏差和占格冲突，不冒充严格结果。
- 倍速范围按实际播放速度筛选，默认关闭，初值 0.8–1.25×。原速偏好范围 0–1、界面默认 0.1，代价为权重乘以 abs(log2(播放速度))；旧查询缺省权重为 0。完整候选排序后存入固定集合，每次读取 100 条，翻页不重搜。
- 两种命中共用音源、版本、音块对应、范围和高亮。试听近似结果时使用自身卡拍版，不强行重排成查询形状；查询不推理模型、不生成采样。
- 删除 FFT/自相关辅助、慢放厌恶度；保留有效语音时长、休止扣除、时值拟合、连续性、累计漂移和人工占格。
- 大数字惩罚度 0–3×，默认 1×=0.045，作用于无 mora 整数占格推断；变化只重建派生节奏与索引。

## 统一素材与文本编辑（已确认需求，实施状态见 STATUS）

- 原片保存来源/主时钟/全局标签/默认画面；声音资产保存文件身份/来源选区/精确映射；时间标注保存字幕、音效和区段标签；采样固定保存资产选区、名称、本地标签。字幕修改不移动采样。
- 统一操作输入 AssetSelection，裁切复用声音资产，拉平/分离/外部回导创建新资产。删除采样不删除共享资产、字幕、分析和原片，保留已删字幕采样抑制登记。
- 迁移需空闲队列、一致性备份、规范化 JSON 核对和事务切换；旧数据只读保留。普通资产迁移不移动文件、不自动推理或补分离，缺失不换混音；用户明确批准的存储压缩例外见下文。
- 标签按原片、明确轨道组或资产动态求值；正长度交叠才继承。对白分离版本可以共享 dialogue 组；音乐和效果音不自动继承说话人。轨道组可手改，本地标签提升为区段须明确操作。
- 共用文本编辑器及 JSON CLI。标签语法限定 NOT/AND/OR/括号/引号，NOT > AND > OR，完整名称匹配；NOT 的补集限当前范围。保存原子、版本冲突不覆盖、删除显式、资料撤销独立于输入框撤销。
- 三 FA 共用一次 pyopenjtalk-plus/tsqyomi 前端结果。重复元音不合并；波浪号三种形式统一成长音符，其余标点和空白为合并后的停顿。保留原字幕，对齐文本独立；辞典每行表记 Tab 片假名、编译成功后原子启用，人工读音受保护。
- FA 可从原片声音资产与文字区段发起，不依赖正式采样；重新 FA 冻结实际音源/文本/辞典/模型/容差，绕过结果缓存，失败/过期/取消不覆盖旧结果，人工时间版本不被自动抢占。前后容差独立，默认各 0.65 秒，邻句策略独立显示。
- 只编辑已有音素时间，保留标签、顺序与 mora；不提供任意音素标签编辑，不靠能量补音。Hubert 自有适配保留模型已解出的短停顿；pau/SP 打断合组，最大间隔为下一元音 anchor 减上一元音组末尾。
- 名称统一由选区与文字标注查询：可靠 FA 读音/原文、交叠台词/音效说明、来源名/时间逐级回退；原片与采样相同。不自动添加目标音高后缀，不批量改旧名称。子采样范围与字幕/音素分层显示，名称悬停或选中展示。
- PyMSS 处理实际资产选区，保留实际声部名，结果作为资产、明确保存才登记。外部回导以选区起点为准，终点按导入音频时长计算，只允许位于实际资产边界内；沿用对应时间映射，不做补静音/裁切/变速，也不推断成品内部剪辑。
- 拉平弹窗冻结外选区与实际资产，独立波形编辑内部边界，关闭释放播放器；统一采样、原片及选区右键入口，不提供原始 JSON 参数。新增 from_first_vowel 从首个有效元音/N 起处理到选区末尾，之前音频保留，之后有声辅音也共用目标；缺匹配 FA 则拒绝。新任务采用段内自动/交界自动/手动，交界默认左侧，向内 100 ms 至少 3 帧有声、置信度 ≥0.5、有限正 F0 的加权中位数吸附半音；所选侧不足不换侧。预览只读缓存，最终执行重测；版本、处理区间、参考侧与目标进入产物身份及来源。
- 兼容旧拉平 all/vowels/interior；vowels 包含规范化 N，不包含辅音 n。多元音共用可靠 F0 置信加权 MIDI 中位数的最近半音，或显式目标。interior 默认两侧 50 ms 平滑 MIDI 过渡、平台至少 30 ms；渲染 PCM 的外部波形逐样本不变，最终有损 MP3 不承诺逐样本不变。F0 过渡与波形淡化分开；新渲染输出重新测量 F0。
- sync/image/local_loop 正式用于播放器、缩略图和 PV 导出。音频唯一主时钟，视觉静音；循环定位为采样本地时间取动画时长模。默认从原片继承，采样可覆盖。
- 音高查询独立于 FA，1–16 段定长音高范围、10 ms 网格、最多 10 秒，明确近似漏检。十万采样/50 小时唯一音频为首版基准；性能与算法见 [PITCH_SEARCH](PITCH_SEARCH.md)。原片音轨模式与句首尾条件不依赖音素。

## 独立版响应、时间线与固定结果（2026-10-01）

- Electron 为主要验收入口。播放、波形、分析与后台任务各自加载；旧选择响应不得覆盖新选择。相关模型切换不重建播放器；处理提交/完成不自动重选、不插入/重排当前结果。
- 任务轮询使用摘要且只广播变化。面板按对象与操作类型失效；新采样提示由用户刷新纳入。当前音源解析不得依赖完整分析读取。
- 派生范围放在波形内单条紧凑轨道，与同一视口同步；字幕、音素、区段标签分层开关。原片视口可读多个有效句子 FA，严格核验声音身份与记录映射，处理后测量不借用来源。
- 常用选区标签、字幕/音素边界、拉平、PyMSS、回导、画面绑定以波形及表单操作。JSON 仅作高级批量入口；对齐文本、辞典、布尔标签和音符查询保留文本。
- 节奏与音高只在显式搜索时运行。每次形成固定结果标签，持久保存范围、条件、成员、命中、顺序及选中/滚动；恢复不搜索、不播放。普通浏览条件变化进入浏览，旧结果仍可切回。
- 音高使用主列表，一采样一行、多个独立命中展开；原片按声音资产分行。相邻粗筛起点分组，先分配不同区域精排机会，每组保留严格合格最佳窗口。零索引覆盖给准备入口，更新索引不重搜。
- 失效/删除的结果成员保留位置并禁用旧命中；关闭结果集合不删除媒体或采样。索引与查询算法、近似漏检见 PITCH_SEARCH。

## 存储预算与生命周期（2026-10-01）

- 当前约 4k 采样的日常附带数据目标约 4 GB；原片、权重/环境、备份、开发验证副本另计，设置页列明分类、格式、模型和每集持久音轨。
- 正式生成声音使用 LAME VBR V0、最高算法质量，共享整轨与资产选区；不再永久保存每句 WAV、三套模型各自的目标裁切及 16k/44.1k 输入副本。原片与显式导出不强制转码。
- 保留三套既有音素分析、F0/声学测量及人工时间版本，接受压缩后沿用旧测量，不进行全库模型重跑。迁移校验父子音轨来源、长度、引用完整性及数据库约束，更新文件身份/偏移后再删除可重建生成 WAV。
- 支持数组的模型直接读取选区；必须接收文件的模型按需生成带使用锁的 PCM。空闲清理默认 512 MiB 高水位、384 MiB 低水位及一天过期；正在使用和近期无使用锁的文件暂缓回收。测量侧车、原片和正式音轨不作为便宜缓存删除。

## 字幕与素材库交互（2026-10-02）

- 字幕标记导入、音效采样导入、台词采样导入为三个独立手动操作，允许按时间或勾选分批。无默认角色轨时先指定；不隐式退回混音。混音可手动赋予角色。
- 仅括号（全/半角、连续）视作音效；括号外有文本视作台词。音效名称合并括号文字，性质非调谐；台词名称去掉括号，性质语音，说话人是人声角色范围的区间标签，多人不推断时间。
- 设置提供音效整行/括号内容两个正则及试算、语法与超时检查；改规则不自动改旧记录。采样前后各 0.3 秒可独立设置，允许重叠，裁到实际资产范围，字幕/说话人时间不变。重复导入和删除后同步不补建采样。
- 虚拟文件夹从活动结构/API/界面退役；保留独立批次身份。迁移不创建替代标签、不改变性质/归属，先一致性备份，再事务迁移。
- 左侧保存筛选器可命名、编辑、排序、删除，包含性质、标签表达式、来源、作品、星标、属性条件；与搜索取交集。固定搜索结果保存当次范围，不因筛选器更新重搜。
- 标签批量增加/指定移除；预览本地/继承数量。所选采样只能移除本地标签，继承项跳转源资料。全局改名/删除使用事务文档和撤销，不增加屏蔽层。
- 始终显示复选框、选本页/全部匹配、清空/已选数；翻页保留，Shift 页内，过滤/排序清空。右键已选项用整个选择集，未选项先换选择。顶部与右键共用批量动作。
- 数字编辑允许空值/中间态，提交校验必填项；可选空值不限。音高波动范围指可靠帧 P90−P10，中间 80% 跨度，100 音分=半音。
- 截取/分离/拉平同级按钮；固定播放宽度；原片列表留边；紧凑音高固定音名刻度与悬停提示；侧栏可收起，分页固定底部，列表/详情各自滚动。

- 左侧单标签范围为可搜索、可清空的独立条件，与保存筛选器、性质、文字及顶部“进一步筛选”标签表达式取交集；切换不覆盖保存筛选器，也不重搜固定结果。角色/参与者仅翻译展示，底层标签不改写；全局管理入口保留影响预览及事务撤销。
