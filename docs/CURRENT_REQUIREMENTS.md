# 当前要求：精简工作站与统一检索

2026-09-23 修订。本文取代探索期 demo、插件平台和 MFA 方案；历史文档只作技术背景。

## 产品与数据

- 无字幕也能导入原片、连续播放、分离、选区、裁切、拉平和导出。字幕只用于可选台词登记与文字对齐。
- Ant Design 工作站同窗导航、保留选区和音源。保留“工具与工作流”空页面；没有插件安装、分享、配置、网页桥接或组合执行接口。
- OP/ED 属于原片属性，在原片页维护；确认区间排除自动台词登记与批量分析，不禁止播放、全轨分离或手动取样。
- 核心保留媒体身份、派生关系、精确时间映射、任务进度/取消/日志、人工标签、明确保存和导出。模型输出不自动成为采样或人工确认。
- 语音、调谐单音、非调谐单音是性质筛选，不是文件夹。普通裁切由用户选性质；拉平只登记最终成品及音高。
- 播放、处理与导出使用同一真实绑定资产，不静默替换混音。Electron 使用 libmpv 原生播放；浏览器兼容播放不代表原生验收。

## 模型与环境

- core 负责服务/调度；inference 共用 PyTorch/ONNX。Mac MPS/CPU、Windows CUDA/CPU；显式 GPU 不静默降级，设备设置只作用于后续任务。
- becruily Deux 默认人声、HyperACE 备选；BandIt v2 多语言三轨；FCPE 与现用 HiFiShifter 拉平。
- narabas 默认音素，HubertFA、pydomino 备选；不增加 pydomino 尾音修正规则。先按原片/音轨/模型复用整轨人声，再按台词裁取输入；同批模型只初始化一次。
- Yohane 保留音节，Qwen3-ForcedAligner-0.6B 保留字符/词，独立显示、定位和试听；不伪造音素，不更换音素检索计数单位。
- 退休 MFA/SOFA/CDX23/BandIt Plus/SFC/AV-CASS/PANNs/CLAP/角色聚类与专属环境、MLX路径。清除 MFA 测量/缓存；原片、字幕、正式采样及人工标签保留。
- SAM 三套权重保存在独立 SAM-Audio-Deploy；本项目不再提供 SAM/ComfyUI。独立 SubPlz 和字幕预处理保留。

## 统一语音检索

- 同一组相邻、有序节奏音块，三种策略：不限节奏、必须满足节奏、按节奏相似度排序。
- 先建立邻接再筛选属性；保留音高/音级/八度/音分容差/稳定度/F0覆盖/元音/辅音/原声时长/能量/说话人/首尾/休止/拍点/占格/持续条件。缺失值是未知，不能当作零或自动放宽。
- 有 BPM 对照现有三个候选；无 BPM 比较归一化节奏形状。相似结果显示偏差和占格冲突，不冒充严格结果。
- 两种命中共用音源、版本、音块对应、范围和高亮。试听近似结果时使用自身卡拍版，不强行重排成查询形状；查询不推理模型、不生成采样。
- 删除 FFT/自相关辅助、慢放厌恶度；保留有效语音时长、休止扣除、时值拟合、连续性、累计漂移和人工占格。
- 大数字惩罚度 0–3×，默认 1×=0.045，作用于无 mora 整数占格推断；变化只重建派生节奏与索引。

## 验收边界

在现有素材小批验证，不全量重跑、不重复 REAPER、不修改字幕预处理。测试输出与成功执行不是主观质量结论。Windows/CUDA 未有实机证据前必须标为未验收。当前证据与限制见 [精简实施记录](SIMPLIFICATION_2026_09.md)。
