# 洗字幕

目标：每个视频一个同名的 UTF-8 `.srt`，每条只写一个人说出口的话。改字幕前都留一份备份。

## 推荐顺序

洗文字、拆行和标说话人放在同一轮做完，最后只产出一份字幕。后面的步骤依赖前面的结果：

1. 分离人声。
2. 核对这个版本的时间轴，修掉整体偏移。对齐要求窗口离语音足够近。
3. 把文字洗到只剩说出口的话，它就是对齐用的文字。
4. 给标注做体检。
5. 拆开两人条目。声纹要求每段只有一个人。
6. 对拆好的句子算声纹，标上说话人。
7. 写成一份最终字幕，检查后只导入一次。

## 开工前

尽量用分离后的人声，因为拆字幕要听得清。用音频工具实际处理一小段真实音频：工具列得出来不等于能用。

## 给标注做体检

不同来源标说话人的习惯不一样，所以每个来源都要先统计。唯一确定的规律是：换人必换行。

按来源分别统计：

- 一条里两行都标了（换人）
- 只标第一行（多半同一个人）
- 只标第二行
- 名字单独占一行
- 相邻两条标同一个名字

然后按“来源 × 写法”抽样实听。只数名字和两行字幕不够。试过的字幕里，相邻两条都带标注时是同一个人的比例从 3% 到 47%，只标第二行的字幕从 0 条到上千条。

字幕组的字幕一般没有标注。CC 字幕只在看不出是谁时才标，所以有标注的行往往更难判断。

## 统一说话人写法

- 一条字幕只放一个人连续说的话。
- 每个台词行都以 `（名字）` 这样的标注开头，不知道是谁就不写。
- 几个人同时说写 `（A、B）`。
- 同一个角色全季只用一个名字。
- 音效单独成一条，时间和原来那条相同。
- 台词里不留别的括号：读音直接删掉，说出口的词只去掉括号。

拆开一条里的两个人：

1. 用强制对齐器依次对齐这两行，窗口是字幕时间前后各 0.2 秒。
2. 在两行之间空隙的中点切开，两条可以延伸到对齐找到的说话起止。
3. 如果某一行对齐出来不到 0.1 秒，多半是在人声里没找到。这条就不拆、不标。

没有标注的条目想靠声音补，用 skill `labeling-speakers`。

## 常见问题

| 问题 | 改法 |
|---|---|
| 中日双语 ASS | 按样式名或文字本身只留日语。同一条用 `\N` 叠两种语言时留日语那行。删掉特效标签和只有特效的行。 |
| 歌词 | 删掉 OP/ED 和插入曲的歌词行，或者和台词分开放。 |
| 台词里有读音，如 `歳納(としのう)京子` | 删掉括号。 |
| 第一行音效、第二行台词 | 拆成两条，时间相同。 |
| 哼歌写成 `♪（ハミング）` | 改成音效行 `（ハミング）`，或者写出歌词。 |
| 字幕文件名和视频不同 | 写一份同名的。正式字幕和机器转写都有时用正式字幕，因为它带说话人。 |
| 内挂字幕 | 用 `ffmpeg -i ep01.mkv -map 0:s:0 ep01.ass` 提取。图形字幕要先做文字识别。 |
| 字幕来自别的版本 | 用 skill `retiming-subtitles`。 |
| 没有字幕 | 用 skill `transcribing-without-subtitles`。 |

## 音乐标记

`♪～` / `～♪` 可以标 OP/ED，也会标插入曲和卡拉 OK 场景。如果工具把它们配成 OP/ED，正确的字幕也可能报错，例如配出三对，或者有一个落单的结尾标记。真正的 OP、ED 标记留着，其他音乐改写成音效行，例如 `（音楽）`。

## 检查结果

看说话人里有没有台词片段、读音或奇怪的名字，这说明括号没清干净；看有没有只标了部分行的条目；再看文字是不是实际说出口的话。
