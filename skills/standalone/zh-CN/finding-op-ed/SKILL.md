# 找 OP 和 ED

同一部作品每集的 OP、ED 通常是同一首歌。

1. 抽出几集开头和结尾几分钟的音频，比如用 ffmpeg。
2. 用手边的音频比对方法互相比较，比如互相关或音频指纹。最长的一段近乎相同的就是 OP 或 ED。
3. 按用户想要的形式写出结果，每集都有时间。
4. 对不上的集（换了版本、没有 OP）如实报告，不要硬标。

如果文件带章节，先看章节，可能已经有答案。

在一部番剧上试过：起点误差不到 0.1 秒，终点晚了约 6 秒，所以终点要再核对。
