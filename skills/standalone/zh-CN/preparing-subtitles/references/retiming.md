# 对轴

分离后的人声比原混音稳定。

## 强制对齐的特点

对齐器会把整句塞进给它的窗口。它不会自己找这句话在哪，也不会报告“没找到”。窗口必须贴着实际的语音，前后各留 0.1–0.2 秒。

用 pydomino 对 60 句日语测过：窗口前后各放宽到 0.5 秒，约一半句子的起止会移动超过 0.3 秒；时间偏移 0.5 秒以上，几乎对不好。

对齐成功不能证明窗口是对的，窗口要另外核对。

## 修一句的边界

1. 用带词时间的转写或音量起止，把边界粗对到 0.1–0.2 秒以内。如果有字幕组的粗轴，就从它开始：在粗轴上微调，比目前试过的自动工具都好。
2. 用对齐器给出的首尾音素时间精修。
3. 把新时间写回去。

如果窗口两端和首尾音素之间几乎没有空隙，或者某个音长得离谱（例如 0.8 秒的「ン」），多半是窗口没盖准，或者和别的台词重叠。

如果是在截取的片段上测的时间，写回前要换算成原视频的时间。

## 字幕来自别的版本

TV 版或流媒体的字幕配 BD 视频时，可能整体差几秒，可能从原来 CM 的位置开始错开，也可能少了整段对白。

1. 开头、中间、结尾各抽几句，对照语音。
2. 整体偏就全部平移；从某处开始偏，就从那一条起平移。
3. 把剪辑点定位到具体某一句。版本之间多出对白时，只定位到最近的字幕不够准。
4. 把只存在于一个版本的对白明确记下来，不要把对齐硬塞到不同的词上。

边界筛查同时看首尾，没有静音 gap 也要核验。结合实际曲线、整句内容与邻句。转写词时间、能量 run 和对齐只能作线索，不当真值，不固定扩边或自动取中点。
