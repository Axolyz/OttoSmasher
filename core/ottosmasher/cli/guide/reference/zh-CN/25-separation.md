# 选择分离范围

先查 `tracks.separatedVocals` 和 `assets.tracks`，直接用已有声部；缺默认轨时用 `tracks.defaultFromSeparation`。每次新分离都会重算，已有轨道就不要重复提交。

| 任务 | 可以从哪里开始 |
|---|---|
| 字幕、整季采样库 | 整轨人声，后续步骤都可复用 |
| 少数台词、先试质量 | 带前后文的局部范围 |
| 很多短段 | 一次 separation.submit 传 ranges，减少重复启动 |
| 难处理的对白或歌曲 | 先比较少量代表范围，再决定模型和批量范围 |

默认人声／音效轨必须覆盖整片；局部声部用显式 assetId。局部分离每个声部自动建采样，整轨不建。保留用户要求的声部，原始声部名不改，用不区分大小写的角色别名设置识别人声和伴奏。命令、队列和特定机器／模型的实测耗时见 prepare，不能当任务时限。

`studio.status {"refresh": true}` 刷新已装模型列表，不下载权重。缓存身份包含子目录文件，在子目录添加模型也会失效。模型由 Studio 安装，Otto 不改其环境。诊断过期列表时不要随意删除缓存或模型文件。
