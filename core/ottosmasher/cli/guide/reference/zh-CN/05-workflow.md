# 范围与精度

## 选定范围和精度

先明确素材或集数、想要的产物，以及可以复用的工作。沿用用户要求和适用的 playbook 偏好；精度还没定时，问一次快速／标准／精细，并说明当前任务里的实际区别。

| 精度 | 字幕任务 | 台词／音色／分离任务 |
|---|---|---|
| 快速 | 清文字、核版本偏移和标注习惯，处理明显问题 | 小候选集，先完成可用的初选 |
| 标准 | 全范围筛查，核高风险项，再抽查其他场景和角色 | 扩大搜索，比较代表候选 |
| 精细 | 核完全部可疑起止、换人和重叠项，抽查正常场景 | 多轮搜索，核完约定的全部候选 |

用户也可以要求逐句检查，或只精修某几集。说明各档在时间和 token 投入上的区别；约定的范围需要缩减时，先与用户商量。各档都保留未知身份和未决项，方便后续处理。

## 按素材选择方法

先读相关技能和引用，再按来源调整路线。有些步骤有先后依赖，例如声纹参考需要先分成单人区间；满足这些依赖后，工具和顺序可以灵活选择。

分页、时间换算和计数适合交给脚本。统计字幕写法前，先看原文，再选例子对照声音；遇到新惯例时调整统计办法。应用解析器用来检查最后的导入格式，原字幕的含义由你结合上下文理解。

## 留下能继续工作的记录

长任务在临时任务目录记下输入版本、已处理范围、已核条目、决定和未决项，形式按实际需要选择。sources.prep 给出应用的准备状态，内容核验的进度写在任务记录里。

## 收尾

将请求范围与落盘文件、应用状态和逐项结果对一遍。精细档每个可疑项都有保留、修正或仍待定的结论。汇报实际核验范围，以及还需留意的地方。

修订后复查重叠和覆盖，刷新受影响的分析。编排变化时一起更新相关时间行，或注明哪些行仍对应旧版本。遇到必要工具或外部条件暂时不可用，保存进度，说明继续工作需要什么。
