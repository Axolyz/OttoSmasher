# 找 OP 和 ED

同一部作品每集的 OP、ED 通常是同一首歌。

1. 抽出几集开头和结尾几分钟的音频。
2. 互相比对，把近乎相同的段当候选；重复对白、回顾和片尾背景声也需排除。
3. 按约定精度（`otto guide workflow`）核对完整音乐起止，再用 `oped.add` 写回去；歌词字幕的起止不代表整首音乐边界。
4. 对不上的集（换了版本、没有 OP）如实告诉用户，不要硬标。

2026-10-24 在摇曳百合上试过：起点误差不到 0.1 秒，终点晚了约 6 秒，所以终点要再核对。
