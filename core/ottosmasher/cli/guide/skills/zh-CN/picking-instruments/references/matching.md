# 按用途选声音

## 先把声部的需要写出来

把工程里的需要写成几项能比较的特征。例如“高音区、约 40 ms 的密集单音，需要容易分辨的起音”和“同时四音、持续半秒，需要叠起来不刺耳”，会指向不同的素材。参考音频还可以帮助判断明暗、厚薄、气声、粗糙程度和角色辨识度。

下面是找候选的起点，结合原曲和用户方向调整。

| 用途 | 可从哪里找 | 重点比较 |
|---|---|---|
| Lead | 清楚的元音、喊声、谐波丰富的效果音 | 目标音域里的存在感、发音一致性、弯音后是否仍可辨认 |
| Bass | 低元音、鼻音、低沉效果音 | 基频与上部谐波的平衡；下移后是否只剩低频，是否需要包络塑成拨弦感 |
| 和弦、pad | 较长、音高稳定的元音或效果音 | 复音时的厚度、刺耳和拍频，延音或循环的可用长度 |
| Arp、chip | 起收音容易控制、频谱有特点的短音 | 最密节奏下的清楚程度，最高音移调后是否足够长 |
| 底鼓 | 低沉撞击、爆破音、拍击 | 起音与低频尾音是否配合，是否需要调尾音的音高 |
| 军鼓、拍手 | 宽频撞击、爆破、短噪声 | 瞬态、噪声体感与尾音；叠在底鼓上能否分开 |
| 镲、hi-hat、shaker | 高频摩擦、气声、金属声 | 高频颗粒、开闭长短和连续触发时的听感 |

鼻音可能很适合低频主体，却缺少参考贝斯的上部细节；清楚的喊声可能适合铜管式和弦，却在四音叠加后过于突出。也可以分层使用，说明各层的作用。角色表情和原句情绪仅在用户把它们列入要求时作为筛选条件。

## 综合看测量

先比较几个真实片段，再选择有区分力的指标。复用已有分析，按需要补测；批量准备前用 `metrics.status` 看范围内的计数。`samples.metrics` 读取缓存时可显式传采样 ID。

- 有音高的声音看基频、音高波动和有效有声时长。高置信度只说明模型偏向某个音高；用谐波间距或另一种测量核对可疑的八度错误、叠唱和背景音乐。
- 明暗看频谱重心、滚降、频带能量；看频谱中谐波与噪声如何分布。不同采样率、窗长和算法的数值分开解释。
- 鼓组看起音上升、峰均比、衰减、频带能量和噪声成分。短暂的基频或扫频可以保留为音色特点，无稳定音高的鼓声不必硬标根音。
- 音高平稳还不够：元音变化、气声、混入另一人的声音或残留伴奏，都可能让循环和复音时的听感改变。回到上下文与频谱核查。

测量帮助解释差异，不能用一个分数排定所有用途。可以为当前音域和素材写筛查脚本，保留少量有代表性的结果做进一步比较。

## 移调与音长一起看

变速移调时，升高 `s` 半音的播放倍率是 `2 ** (s / 12)`，可用时长约为原时长除以这个倍率。例如 160 ms 的单音升高一个八度只剩约 80 ms。按实际音符检查，而不是只比较原切片长度与最长音。

根音用稳定部分的实测音高估计，并写明音名约定，例如 C4 = MIDI 60。若实测 71.8，设根音 72 后约需 +20 音分校正；试听渲染器也可以直接用实测值计算倍率。

最高与最低音、最长音、最密音群、和弦叠音都是有用的试点。循环可延长持续音；保持时长移调、拉平也可以改变适用范围，分别比较处理后的表现。低频不足、共振峰变化或噪声被一起拉长时，换一个原音也常有帮助。

## 精修切点

音色单音通常取稳定的主体，按需要保留一小段辅音作为起音。鼓声以波形里的瞬态为起点，保留想要的衰减。看清切点附近的变化，试短淡入淡出或相位合适的循环，检查点击声与突兀的尾部。

强制对齐适合定位已知台词里的音素，长喊声、鼻音和唱歌仍可能对不准。对齐成功只表示给出了结果；结合波形、频谱和原句检查。手动缩窗或换原音后，更新根音、时长和其他指标。
