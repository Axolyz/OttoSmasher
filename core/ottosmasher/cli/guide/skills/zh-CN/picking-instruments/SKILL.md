# 挑乐器采样

先读 `otto guide workflow`，沿用已有范围、精度和偏好。把目标声部需要的声音特点，与素材里可用的声音联系起来：找到原音，切出可复用的部分，再放进实际音域和节奏里比较。人声、音效和歌曲里的声音都可以成为乐器；选择取决于任务。

## 用户选项与精度

先从工程、参考和已有约定里找答案，只问仍影响选择的未定项。下面是常用选项，不必整张表逐项询问。

| 选项 | 怎么确定 |
|---|---|
| 素材范围 | 哪些作品、集数和角色；人声、音效、歌曲是否都可用。沿用用户已选的来源 |
| 匹配目标 | 有 MIDI 就按声部、音域和时值选；有参考音频就比较音色和作用；只给用途也可以先找代表音 |
| 音色取向 | 更像原曲乐器、更容易认出素材角色，或两者兼顾；没有特别要求时兼顾，保留有区别的备选 |
| 处理方式 | 沿用工程；未定时先试变速、简短起收音，延音不足时再试循环。保持时长移调、拉平、失真等按需要选用 |
| 候选与交付 | 标准档可先按每用途约三个不同音色候选，附原切片、理由和同段试听；数量可调整。入库、导出、试听页沿用用户所要的产物 |

用户未选精度、也没有适用偏好时，问一次，并说明区别：

| 档位 | 实际做什么 |
|---|---|
| 快速 | 从小批代表素材为所选用途找可用初选，核候选的基本切点与音域；说明实际搜索范围 |
| 标准 | 在约定来源中扩大筛查，比较不同场景与音色，核选中候选的单音边界和目标音域，给同段试听与推荐理由 |
| 精细 | 多轮复筛，逐个核完约定候选的上下文、切点、移调、延音与叠音表现；根据比较结果再调整选择 |

## 理解目标声部

有 MIDI 时先读实际音符和控制事件，列出所选轨道的音域、常用与极端音长、密度、复音和弯音；轨名与程序音色可作线索。鼓轨按鼓件区分用途，同一鼓轨里可能需要底鼓、军鼓、镲等不同声音。没有 MIDI 时，从参考片段或用户描述提炼这些需要。

结合用途选声音、解释测量时，读 `references/matching.md`。先找少量音色差别明显的样例试适配，再扩大到其他声部；同一个单音可以服务几条轨，比较它们同时发声时是否仍分得清。

## 找到并修好候选

复用已有采样、分离轨和分析。人声长元音、鼻音、喊声，或音效里的撞击、爆破、摩擦，都可以作为入口；字幕帮助找角色和出处，声音本身决定切点。候选集中于少数场景时，再查约定范围内的其他场景。

在原句或音效上下文里看候选的波形、频谱和音高。音高稳定的窗口可能跨了几个音素；必要时用对齐辅助缩到单元音或鼻音，再复测。鼓声保留真正的起音与需要的尾音。候选的边界变化后，跟着更新指标和试听。

`samples.metrics` 可读已有单音指标，`measure.f0` 读音高帧，`spectrum.get` 看频谱；具体参数查 `otto describe`。还没切成采样的声音，可以在资产区间或导出切片上分析，选中后再按约定建库。用指标缩小候选，用目标声部里的表现决定取舍，阈值按当前素材校准。

## 检查检索覆盖

按音高找之前，对同一范围调用 `search.coverage`，缺基频时按 `otto guide search` 补测。用音色或瞬态指标筛选时，先对加指标阈值之前的范围调用 `metrics.status`，检查实际要用的每个指标。按需用 `metrics.prepare` 补测，再查一次缺口。基频和声学指标可以独立准备。只有要按音素确定人声切点时，才需要为这些候选补音素对齐。

快速初选可以先比较已测的部分。任务要求找全、判断有没有匹配，或要推荐整个范围里最合适的声音时，先补测范围内能补的部分。汇报实际检查了多少条、范围里有多少条，以及仍缺哪些数据。

## 比较与交付

先比较原切片，再用同一组音符、和弦或鼓型比较各候选。响度差异影响判断时做等响试听；说明为了试听做过哪些处理。记录听到的特点，或说明结论来自频谱等分析。

需要做 MIDI 试听、命名或网页对照时，读 `references/auditions.md`；其中有可选的 `scripts/build_audition.py`，把已生成的音频整理成试听页，也可自行设计。

保留原音、出处与选择理由，让候选能重新定位和复用。按用户所要的产物保存选中项，核对所选声部都有候选或明确缺口，再汇报推荐、差别与仍需处理的地方。
