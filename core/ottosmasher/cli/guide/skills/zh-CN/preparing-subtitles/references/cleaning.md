## 给标注做体检

不同来源标说话人的习惯不一样，所以每个来源都要先统计。唯一确定的规律是：换人必换行。

按来源分别统计：

- 一条里两行都标了（换人）
- 只标第一行（多半同一个人）
- 只标第二行
- 名字单独占一行
- 相邻两条标同一个名字

然后按“来源 × 写法”抽样实听。只数名字和两行字幕不够。试过的字幕里，相邻两条都带标注时是同一个人的比例从 3% 到 47%，只标第二行的字幕从 0 条到上千条。

字幕组的字幕一般没有标注。CC 字幕只在看不出是谁时才标，所以有标注的行往往更难判断。

## 说话人只有一种写法

- 一条字幕只放一个人连续说的话。
- 每个台词行都以 `（名字）` 开头，不知道是谁就不写。
- 几个人同时说写 `（A、B）`。
- 同一个角色全季只用一个名字。
- 音效单独成一条，整行一个括号，时间和原来那条相同。
- 台词里不留别的括号：读音直接删掉，说出口的词只去掉括号。

拆开一条里的两个人：

1. 用 `speech.align` 的 `lines` 对齐这两行，窗口是字幕时间前后各 0.2 秒。
2. 在两行之间空隙的中点切开，两条可以延伸到对齐找到的说话起止。
3. 如果某一行对齐出来不到 0.1 秒，多半是在人声里没找到。这条就不拆、不标。

没有标注的条目想靠声音补，见 `references/speakers.md`。

## 常见问题

| 问题 | 改法 |
|---|---|
| 中日双语 ASS | 按样式名或文字本身只留日语。同一条用 `\N` 叠两种语言时留日语那行。删掉特效标签和只有特效的行。 |
| OP/ED、插入曲歌词 | 删掉歌词行，再看下面的“音乐标记”。 |
| 台词里有读音，如 `歳納(としのう)京子` | 删掉括号。 |
| 第一行音效、第二行台词 | 拆成两条，时间相同。 |
| 哼歌写成 `♪（ハミング）` | 改成音效行 `（ハミング）`，或者写出歌词。 |
| 字幕文件名和视频不同 | 写一份同名的。正式字幕和机器转写都有时用正式字幕，因为它带说话人。 |
| 内挂字幕 | 用 `ffmpeg -i ep01.mkv -map 0:s:0 ep01.ass` 提取。图形字幕要先做文字识别。 |
| 没有字幕 | 见 `references/no-subtitles.md`。 |

## 核对这个版本的时间轴

来自别的版本的字幕（TV 版或流媒体配 BD 视频）可能整体差几秒，可能从原来 CM 的位置开始错开，也可能少了整段对白。

1. 开头、中间、结尾各抽几句，对照词时间和音量起止。
2. 整体偏就全部平移；从某处开始偏，就从那一条起平移。
3. 把剪辑点定位到具体某一句。版本之间多出对白时，只定位到最近的字幕不够准。
4. 把只存在于一个版本的对白明确记下来，不要把对齐硬塞到不同的词上。

对齐成功不能证明窗口是对的，窗口要另外核对。

## 转写只用来核对

转写可能漏词，也可能编出没人说过的话（见 `otto guide combine`）。它和字幕不一致时，看波形、对照原字幕来判断。

## 音乐标记

`♪～` / `～♪` 也会标插入曲和卡拉 OK 场景，所以正确的字幕也可能报 OP/ED 错误，例如配出三对，或者有一个落单的结尾标记。
真正的 OP、ED 留着。其他音乐改写成音效行，例如 `（音楽）`。音效提示最长 120 秒，更长的拆成首尾相接的几条。

## 放回应用

1. 用 `subtitles.parse {"path", "duration"}` 检查文件。看 `speakers`（出现台词片段、读音或奇怪的名字，说明括号没清干净）、`withheld` 为真的条目（有标注但没记）、`problems`、`oped`。
2. 已登记的原素材运行 `sources.rescan --wait`，再到 `sources.list` 确认 `subtitle_path`。手动选过字幕的原素材不会自动换，要换就用 `edits.apply`（实体 `source`，字段 `subtitle_path`）。
3. 按 `otto guide prepare` 导入。时间和文字都没变的段不会更新说话人，要从头来就先运行 `subtitles.clear`。
