# 对轴

对齐器会把整句塞进给它的窗口，不会自己找这句话在哪。相关数字见 `otto guide primitives`。如果有字幕组的粗轴，就从它开始：在粗轴上微调，比目前试过的自动工具都好。

## 修一句的边界

1. 用带词时间的转写（例如 audio-mcp 的 `audio_transcribe`）或音量起止，粗定位语音，再结合整句与相邻对白核对边界。从导出文件得到的时间，按它的 `mapping` 换回原片（`otto guide export`）。
2. 用 `speech.align` 给出的首尾音素时间辅助精修，它不会写入资料库。窗口前后可先各留 0.1–0.2 秒，并用分离后的人声，它比原混音稳定；最终边界再对照实际语音。
3. 用 `edits.apply` 把段写回去（见 `otto describe edits.apply`）。很多段放进同一批，这样一次就能撤销。

## 窗口不对的迹象

对齐结果里 `edges` 接近 0，或者某个音长得离谱（例如 0.8 秒的「ン」），多半是窗口没盖准，或者和别的台词重叠。

## 检查首尾

首尾都要看，包括没有静音间隙的相邻发言。按实际声音区分顺序发言和同时重叠。精细档核完全部可疑项，其他场景抽查，见 `references/verification.md`。
