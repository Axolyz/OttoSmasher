# 对轴

先核对字幕和片源的版本差异，再修每句边界。用实际对白找整体偏移和剪辑点；OP/ED 歌词标记可以帮助定位，完整音乐的起止再听看确认。

## 修一句边界

1. 取整句和相邻对白，查看波形／能量曲线，用字幕及必要的转写核对内容。ASR 词时间可用于粗定位。
2. 判断边缘声音属于当前句还是邻句，包括没有静音间隙的连续发言。窗口贴近这句话后，可用 speech.align、lines 精修，或用声纹辅助判断换人。
3. 确认修改后记下理由。已有台词段用 edits.apply 小批写回，最后统一查覆盖、顺序与重叠。

## 怎样找疑点

边界两侧仍有声音、尾音像被截断、相邻内容接不上、edges 接近零、音素异常长，都值得回看。精细档核完这些可疑项，其他条目按场景抽查，见 verification.md。

## 对结果的判断

加减上下文做 A/B 转写可以帮助核对完整词语。ASR 有时漏词或多认，结合原文和实际曲线判断。对齐器擅长精修给定窗口，因此要先找准这句话。边界按实际发言调整：有真实空隙时可从空隙切开，同时发言则保留重叠。
